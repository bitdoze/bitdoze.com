## Was OpenCode eigentlich ist

OpenCode ist ein terminalbasierter Open-Source-Coding-Agent, der deinen Code liest, Änderungen plant, Dateien editiert, Befehle ausführt und Fehler iterativ behebt. Über den Katalog von [models.dev](https://models.dev) unterstützt OpenCode über 300 Provider (Anthropic, OpenAI, Google, Alibaba, MiniMax, DeepSeek, Xiaomi, Moonshot) sowie lokales Ollama.

Du bestimmst das Modell pro Aufgabe: DeepSeek V4.1 Flash ($0,15/M Input) für den Alltag, GLM-5.3 für komplexe Refactors. v2 bringt außerdem eine Desktop-App (Beta) und eine punktuelle Web-UI über `opencode pair`.

## OpenCode v2 auf einem VPS installieren

### Voraussetzungen

<ListCheck>
<ul>
<li>Ein Linux-VPS mit 1 GB+ RAM (kein Node.js nötig für den offiziellen v2-Installer)</li>
<li><code>curl</code> sowie ein Provider-API-Key oder ein OpenCode-Go-Abo</li>
<li>Ein modernes Terminal wie Ghostty oder WezTerm für Drag-and-drop-Screenshots (optional über SSH)</li>
</ul>

### Mit dem v2-Skript installieren

<Notice type="warning" title="Der alte Befehl installiert jetzt OpenCode v1">
`https://opencode.ai/install` leitet auf die alte v1-Linie um. Beide Linien installieren den Befehl `opencode` und **können nicht nebeneinander laufen**. Entferne alte v1-Pakete (`npm rm -g opencode-ai`) vor dem Wechsel.

| Linie | Installationsbefehl | npm-Paket |
|---|---|---|
| **v2 (aktuell)** | `curl -fsSL https://opencode.ai/v2/install \| bash` | `@opencode/cli` |
| v1 (veraltet) | `curl -fsSL https://opencode.ai/install \| bash` | `opencode-ai` |
</Notice>

```bash
curl -fsSL https://opencode.ai/v2/install | bash
opencode --version
```

Erwartete Ausgabe: `2.x` (`2.3.2` im November 2026).

## Modell-Provider und lokales Ollama einrichten

In v2 verbindest du Provider über `/connect` in der TUI oder per `{env:VAR}` in `opencode.jsonc` (verlass dich nicht auf das undokumentierte v1-`.env`-Verhalten).

- **OpenCode Console (ehemals Zen):** Key unter [opencode.ai/console](https://opencode.ai/console/login) holen, `/connect` ausführen und `opencode` wählen. Gratismodelle lassen sich mit `OPENCODE_DISABLE_FREE_MODELS=1` ausblenden.
- **OpenRouter:** 300+ Modelle über einen Key per `/connect` oder `opencode.jsonc`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/deepseek/deepseek-v4.1-flash",
  "providers": {
    "openrouter": {
      "settings": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

- **Direkte Keys & ChatGPT:** `MINIMAX_API_KEY` ([MiniMax](https://go.bitdoze.com/minimax)), `ZAI_API_KEY` ([Z.AI / GLM](https://go.bitdoze.com/glm)), `MIMO_API_KEY` ([Xiaomi MiMo](https://go.bitdoze.com/mimo)), `DEEPSEEK_API_KEY`, `MOONSHOT_API_KEY` oder **Sign in with ChatGPT** für Plus-/Pro-Nutzer.
- **Lokales Ollama (Autodiscovery):** v2 erkennt laufendes Ollama auf `http://127.0.0.1:11434` automatisch und listet Modelle direkt unter `/models`.

## Alltag, MCP und VPS-Betrieb

- **`AGENTS.md`:** lege Projektregeln in `AGENTS.md` im Repo ab (v2-sicherer Weg, falls `/init` nicht vorhanden ist).
- **Plan vs Build:** mit `Shift+Tab` (oder `Tab` / `/agents`) umschalten, erst Plan prüfen, dann Änderungen bauen lassen.
- **Shortcuts:** `@pfad/datei.ts#20-45`, `/undo` & `/redo`, `!befehl` für Shell-Modus, `/btw` für Zwischenfragen, `F2` für Modellwechsel, `@general` für Hintergrund-Subagents.
- **MCP-Memory:** Langzeitgedächtnis ergänzt du per [Hindsight in Docker](/de/hindsight-docker-deployment/) im `"mcp"`-Block von `opencode.jsonc`.
- **VPS-Betrieb:** läuft entspannt auf einem $6-[Hetzner Cloud VPS](https://go.bitdoze.com/hetzner) in tmux oder einem der [besten Terminal-Multiplexer](/de/beste-terminal-multiplexer/). Bei Problemen mit dem geteilten v2-Hintergrunddienst helfen `opencode service restart` oder `opencode --standalone`; für CI/Cron nutzt du `opencode run`, für kurzen Browser-Zugriff `opencode pair`.

## OpenCode vs Claude Code vs Codex CLI (November 2026)

| Feature | OpenCode v2 | Claude Code | Codex CLI |
|---|---|---|---|
| **Preis** | Gratis (API) oder Go ab $10/Mo | $20/Monat + API | Im ChatGPT-Abo enthalten |
| **Modellauswahl** | 300+ Provider (models.dev) | Nur Anthropic | Nativ OpenAI |
| **Open Source** | Ja | Nein | Ja |

| **Undo/Redo** | `/undo`, `/redo` | Git-basiert | Eingeschränkt |
| **Desktop / Web** | Desktop Beta + `opencode pair` | Nein | Desktop-App |

## Troubleshooting & FAQ

| Problem | Ursache | Lösung |
|---|---|---|
| `opencode: command not found` | PATH nicht neu geladen | `source ~/.bashrc` oder neue SSH-Session |
| `opencode --version` zeigt `1.x` | Alter v1-Installer | `npm rm -g opencode-ai`, dann `/v2/install` |
| API-Key fehlt | v1-`.env`-Gewohnheit | `/connect` oder `{env:VAR}` in `opencode.jsonc` |
| Hintergrunddienst hängt | Service-Konflikt | `opencode service restart` oder `opencode --standalone` |

</Accordion>

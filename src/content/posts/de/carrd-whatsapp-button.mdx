## Warum ein WhatsApp-Button für deine Carrd-Seite

Ein paar Gründe, warum das funktioniert:

1. **Sofortiger Kontakt** – Besucher können dir direkt schreiben, statt auf E-Mail-Antworten zu warten.

2. **Höhere Conversion** – Menschen melden sich eher, wenn es so einfach ist.

3. **Mobilfreundlich** – WhatsApp ist schon auf ihrem Handy. Ein Tap und sie chatten.

4. **Vorausgefüllte Nachrichten** – Du kannst eine Standardnachricht setzen, damit Besucher nicht überlegen müssen, was sie schreiben.

5. **Globale Reichweite** – WhatsApp hat über 3 Milliarden monatliche Nutzer (Stand 2025). In vielen Ländern ist es der Hauptweg, wie Menschen einem Business schreiben.

Ein simpler Floating-Button deckt die meisten Fälle ab. Wenn du ein „WhatsApp-Chat-Widget für Carrd“ mit Nachrichtenvorschau willst, bevor der Chat öffnet, ist Option 3 unten dafür gebaut. Service-Businesses, lokale Läden und Freelancer holen meist am meisten daraus.

## So fügst du einen WhatsApp-Button in Carrd ein

Drei Schritte: Baue deinen `wa.me`-Link, füge ein Embed-Element hinzu, füge einen der vier Code-Styles unten ein. Alles ist Inline-HTML, -CSS und -SVG. Kein Widget-Skript, kein externer Font und (in der Regel) keine Cookie-Consent-Last durch den Code selbst.

### Schritt 1: Deinen WhatsApp-Chat-Link holen (wa.me)

WhatsApps Click-to-Chat-Linkformat ist:

```text
https://wa.me/YOURNUMBER
```

Ersetze `YOURNUMBER` durch deine Telefonnummer im internationalen Format, ohne `+`, Leerzeichen oder Bindestriche. Zum Beispiel:
- US-Nummer: `12125551234`
- UK-Nummer: `447911123456`

Für eine vorausgefüllte Nachricht:

```text
https://wa.me/YOURNUMBER?text=Hi,%20I%20found%20you%20on%20your%20website
```

Leerzeichen müssen in URLs `%20` sein. Nutze `%0A` für Zeilenumbrüche.

<Notice type="info" title="Das Nummernformat ist der häufigste Fehler">
Kein <code>+</code>, keine Leerzeichen, Striche, Klammern oder führenden Nullen. <code>12125551234</code>, nicht <code>+1 (212) 555-1234</code>. Alles andere lehnt WhatsApp mit „phone number shared via url is invalid“ ab.
</Notice>

Zwei weitere offizielle Varianten, beide in WhatsApps [Click-to-Chat-Hilfeseite](https://faq.whatsapp.com/5913398998672934) dokumentiert:

- **Nummernloser Pick-a-Chat-Link** – `https://wa.me/?text=Hi!%20Quick%20question` öffnet WhatsApp und lässt den Besucher wählen, wem er es schickt.
- **WhatsApp-Business-Kurzlink** – `https://wa.me/message/YOURSHORTLINKCODE` versteckt deine Telefonnummer im Seitenquelltext. Ich behandle das ausführlich im Datenschutz-Abschnitt unten.

`wa.me` ist das einzige Format in den aktuellen offiziellen Docs. Nutze nicht die alten `api.whatsapp.com/send?phone=`-Links, sie sind nicht mehr dokumentiert. Es lohnt sich, die offizielle Click-to-Chat-Seite ab und zu erneut zu prüfen, falls WhatsApp das Format ändert.

### Schritt 2: Ein Embed-Element in Carrd hinzufügen

Das erfordert Pro Standard oder höher. Klicke auf das `+`-Zeichen und füge ein Embed-Element hinzu:

- Type: Code
- Style: Hidden

<Picture formats={["webp"]} fallbackFormat="webp" src={imag1} alt="Carrd-Embed-Element-Einstellungen mit Type auf Code und Style auf Hidden" />

Hidden hat drei Positionen im aktuellen Carrd: **Head**, **Body Top** und **Body End**. Faustregel:

- **Body End** – alle vier Optionen. Jede enthält sichtbares Markup (ein `<a>` oder `<div>`), das in den Seiten-Body gehört, und Option 3s Skript fragt das DOM ab, du willst das Widget-Markup also zuerst geparst haben
- **Head** – nur für reine `<style>`-Snippets, etwa das Anpassungs-CSS weiter unten, wenn du es in einem separaten Embed hältst
- **Body Top** – verfügbar, hier nicht gebraucht

Wird das Elements-Panel unübersichtlich: Carrd hat im August 2026 ein Elements-Panel ausgeliefert (More Actions → Elements), das eingebetteten Code im Builder leichter auffindbar macht.

## Deinen WhatsApp-Button anpassen

Kleine CSS- und URL-Tweaks, nachdem der Button live ist.

### Position ändern

Verschiebe den Button in eine andere Ecke:

```css
/* Bottom left */
.whatsapp-float {
  bottom: 25px;
  left: 25px;
  right: auto;
}

/* Top right */
.whatsapp-float {
  top: 25px;
  right: 25px;
  bottom: auto;
}
```

Nutze eine der beiden Regeln und tausche `.whatsapp-float` gegen `.wa-button`, `.wa-widget` oder `.chat-buttons`, falls du Option 2, 3 oder 4 gewählt hast. Für Option 3 links drehst du außerdem das Popup um: `.wa-widget-popup { left: 0; right: auto; transform-origin: bottom left; }`.

Egal welche Ecke du wählst: Stelle sicher, dass der Button nicht über Carrds eigenen Floating-Elementen liegt (siehe den Overlap-Fix in der Fehlerbehebung).

### Größe ändern

Passe die Button-Maße an:

```css
.whatsapp-float {
  width: 50px;  /* Smaller */
  height: 50px;
}

/* Or larger */
.whatsapp-float {
  width: 70px;
  height: 70px;
}
```

Halte auf Mobile mindestens ein 48px-Touch-Target. Darunter verfehlen Taps den Button.

### Puls-Animation deaktivieren

Entferne das `::before`-Pseudo-Element oder setze `animation: none`:

```css
.whatsapp-float::before {
  display: none;
}
```

### Eigene vorausgefüllte Nachricht

Passe an, was erscheint, wenn Besucher den Chat öffnen:

```text
https://wa.me/12125551234?text=Hi!%20I'm%20interested%20in%20your%20web%20design%20services.%20My%20name%20is%20___
```

Nutze `%20` für Leerzeichen und `%0A` für Zeilenumbrüche.

Zwei Ops-Tricks, die sich lohnen: Schreib deine Antwortzeiten in die Nachricht („Ich antworte meist innerhalb von 2 Stunden“), damit die Erwartungen vor der ersten Nachricht gesetzt sind, und markiere die Quelle („gefunden auf deiner Website“), damit du weißt, welcher Kanal konvertiert.

### Klicks tracken (optional)

Messe es, sonst weißt du nicht, ob der Button seinen Platz verdient. Carrd Pro Standard enthält schon Analytics (Google Analytics, Plausible, Matomo und andere), Tracking kostet dich also nichts extra auf dem Plan, den du ohnehin brauchst. Füge ein `onclick`-Attribut zum `<a>`-Tag hinzu:

## Fehlerbehebung: WhatsApp-Button funktioniert nicht in Carrd

Prüfe diese Punkte der Reihe nach. Die ersten zwei lösen die meisten Fälle.

### Button erscheint überhaupt nicht

Ursache: Der Embed-Style steht nicht auf Hidden, dein Plan enthält keine Embeds (Free oder Pro Lite) oder du hast gespeichert, ohne erneut zu veröffentlichen.

Fix: Setze das Embed auf Type: Code, Style: Hidden, bestätige, dass du Pro Standard oder höher hast, veröffentliche erneut und lade die Live-Seite hart neu. Kollidiert es weiterhin mit einem anderen fixierten Element, gelten dieselben Stacking-Regeln wie bei einem [Floating-Menü in Carrd](/de/carrd-floating-menue/) oder einem [Sticky-Header in Carrd](/de/carrd-sticky-header-hinzufuegen/).

### „Phone number shared via url is invalid“

Ursache: Die Nummer im `wa.me`-href ist nicht im vollen internationalen Format.

Fix: Entferne `+`, Leerzeichen, Striche, Klammern und führende Nullen. `12125551234`, nicht `+1 (212) 555-1234`. Prüfe jeden `wa.me`-href, wenn du die Multi-Chat-Option eingefügt hast.

### Popup-Widget öffnet sich nicht (Option 3)

Ursache: Das Skript lief, bevor das DOM fertig war, oder die Element-IDs stimmen nicht.

Fix: Nutze das DOMContentLoaded-geschützte Skript aus Option 3 und verschiebe das Embed von Head nach Body End. Behalte die IDs `waButton` und `waPopup` wie im Snippet. Erneut veröffentlichen.

### Button überlappt andere Floating-Elemente

Ursache: Zwei fixierte Elemente kämpfen um dieselbe Ecke und denselben `z-index`.

Fix: Senke den WhatsApp-`z-index` (z. B. `9999` → `999`) oder verschiebe ihn in eine andere Ecke (siehe Position ändern). Dieselbe Kollision tritt bei Floating-Menüs und Sticky-Headern in Carrd auf.

## Datenschutz-Tipp: Nummer mit einem WhatsApp-Business-Kurzlink verstecken

<Notice type="warning" title="Deine Nummer ist ab Veröffentlichung öffentlich">
Ein simpler <code>wa.me/YOURNUMBER</code>-Link legt deine Telefonnummer im Seitenquelltext offen. Scraper greifen sie ab, und du solltest mit Spam-Anrufen und WhatsApp-Nachrichten rechnen. Das ist kein Carrd-Problem, sondern so funktioniert das Linkformat.
</Notice>

Zwei Abschwächungen:

1. **Nutze eine dedizierte Business-Nummer** statt deiner privaten. Günstige SIM, separater WhatsApp-Account, saubere Trennung.
2. **Nutze den WhatsApp-Business-Kurzlink** – `https://wa.me/message/YOURSHORTLINKCODE`, generiert in den Business-Tools der kostenlosen WhatsApp-Business-App (Labels variieren je nach Version). Er verrät die Nummer nicht.

Drop-in-href-Tausch für jede der vier Optionen:

```html
<a href="https://wa.me/message/YOURSHORTLINKCODE" class="whatsapp-float" target="_blank" rel="noopener" aria-label="Chat on WhatsApp">
```

Mit Kurzlinks verlierst du die `?text=` vorausgefüllte Nachricht, also wähle: versteckte Nummer oder vorausgefüllte Nachricht. Für die meisten Solo-Betreiber gewinnt die vorausgefüllte Nachricht, und die Nummer steht ohnehin schon auf der Kontaktseite.

Zum Cookie-Consent: Weil dieser Code ein simples `<a>` mit Inline-CSS und -SVG ohne Drittanbieter-JavaScript ist, fügt er für sich genommen in der Regel keine Cookie- oder Consent-Last hinzu. Das ist eine allgemeine Einschätzung, keine Rechtsberatung. Lässt du Analytics-Skripte laufen (inklusive der Klick-Tracking-Snippets oben), ist das eine separate Frage, und du brauchst eventuell [einen Cookie-Hinweis auf deiner Carrd-Seite](/de/carrd-cookie-hinweis-hinzufuegen/).

## WhatsApp-Button auf Mobile vs. Desktop

Der Button funktioniert auf beiden, aber das Erlebnis unterscheidet sich:
- **Mobile**: Öffnet direkt die WhatsApp-App
- **Desktop**: Öffnet WhatsApp Web in einem neuen Tab

Willst du den Button nur auf Mobile zeigen:

```css
@media (min-width: 769px) {
  .whatsapp-float {
    display: none;
  }
}
```

Option 2 kollabiert unter 600px ohnehin zum Icon. Egal welchen Style du nutzt, halte das Touch-Target bei mindestens 48–60px, damit Daumen es zuverlässig treffen.

</Accordion>

<Accordion label="Kann ich das auf anderen Site-Buildern nutzen?" group="faq">

</Accordion>

Lass deine KI-Coding-Agents auf einem 4-5-EUR-VPS laufen und steuere sie vom Smartphone entweder mit der **kostenlosen offiziellen Herdr Mobile App** (iOS/Android per SSH/Tailscale auf `herdr-core`) oder mit **Moshi + `moshi-hook v0.4.62`** (Mosh-UDP-Roaming, Lockscreen-Approve/Deny-Push und Support für Herdr TUI sowie `herdr-core`).

Coding-Agents blockieren oft mitten in einem 20-Minuten-Lauf wegen einer 5-Sekunden-Bestätigung. Auf einem dauerhaft laufenden Server bleiben alle Sessions aktiv, und dein Handy, Tablet oder Laptop dient nur noch als Fenster darauf.

Die größte Neuerung Ende 2026: **Herdr liefert jetzt seine eigene kostenlose Mobile-App** für iPhone, iPad und Android aus. Unten findest du den direkten Vergleich und das Setup für beide Wege.

<Notice type="info" title="Claude Code läuft nicht direkt auf dem Smartphone">
Agent-CLIs, Git-Repos und Zugangsdaten bleiben vollständig auf deinem VPS oder Heimserver. Das Smartphone ist nur Terminal-Fenster und Benachrichtigungs-Klingel.
</Notice>

## Offizielle Herdr Mobile App vs Moshi: Was passt besser?

Wähle **Herdr Mobile**, wenn du `herdr-core` / Herdr Desktop nutzt und eine kostenlose, kontofreie Direkt-SSH-App willst; wähle **Moshi + `moshi-hook v0.4.62`**, wenn du Herdr TUI (oder beides) nutzt, im Mobilfunknetz Mosh-UDP brauchst oder Lockscreen-Approvals samt nativem Chat View möchtest.

| Merkmal | Offizielle Herdr Mobile App | Moshi + `moshi-hook v0.4.62` |
|---|---|---|
| Preis | **Kostenlos** (App Store + Google Play) | Gratis-SSH-Stufe; Pro `$7,99/Mo` oder `$69,99/Jahr` (3 Geräte) |
| Unterstütztes Herdr-Backend | **Nur `herdr-core` (`hc`)** (kein Herdr TUI) | **Beide**: Herdr TUI (`v0.9.5`) und `herdr-core` (`hc`) |
| Transport | Direktes SSH / Tailscale SSH | SSH, Mosh (UDP), Eternal Terminal, Tailscale |
| Lockscreen-Approve/Deny-Push | In-App-Banner im Vordergrund | Ja (Push + Live Activities über `moshi-hook`) |
| Nativer Chat View & Diffs | Echtes Terminal + Compose + Foto/Sprache | Echtes Terminal + Tier-A Chat View (Claude/Codex/Hermes/Antigravity/OMP) + Diffs |
| Git-Worktree vom Handy | Spiegelt Desktop-Spaces | Neue Worktrees direkt aus Herdr-Space (`v0.4.60+`) |
| Account / Relay | Keines (direktes SSH) | Push-Relay (256-Zeichen-Limit; kein Code-Upload) |

## Weg 1: Kostenlose Herdr Mobile App + `herdr-core` auf dem VPS

```bash
# Auf deinem Ubuntu/Debian-VPS
curl -fsSL https://releases.herdr.dev/core/install.sh | sh
sudo loginctl enable-linger $USER

# Agent im Hintergrund starten
hc run --bg --name api claude
hc ls
```

Installiere **Herdr** aus dem [App Store](https://apps.apple.com/app/id6828898364) oder bei [Google Play](https://play.google.com/store/apps/details?id=dev.herdr.app) und verbinde deinen VPS per SSH oder Tailscale SSH. Die Inbox sortiert blockierte Agents nach oben; **Compose** unterstützt Screenshots, Fotos und lokales Sprachdiktat, ohne Fenstergrößen in [Herdr Desktop](/de/herdr-app-layouts-und-mods/) zu verändern.

## Weg 2: Moshi + Herdr TUI (oder Core) mit Lockscreen-Approvals

![Architektur: Herdr-Server auf dem VPS, Moshi-App über Mosh und moshi-hook für Push-Freigaben](@assets/images/26/09/herdr-moshi-architecture.webp)

![Moshi auf dem iPhone mit Claude Code über Mosh](@assets/images/26/09/moshi-dash.webp)

### Schritt 1: VPS vorbereiten (Herdr TUI + Mosh + UTF-8)

Ein kleiner 2-vCPU-/4-GB-VPS bei [Hetzner Cloud](https://go.bitdoze.com/hetzner) oder [Hostinger VPS](https://go.bitdoze.com/hostinger-vps) reicht problemlos (siehe [günstige Hetzner-Cloud-Tarife](/de/hetzner-cloud-guenstige-tarife/)).

```bash
curl -fsSL https://herdr.dev/install.sh | sh
sudo ln -sf ~/.local/bin/herdr /usr/local/bin/herdr
herdr --version

sudo apt update && sudo apt install -y mosh tmux
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8

# Bei reinem Tailscale-Zugriff keine öffentlichen Ports öffnen
sudo ufw allow OpenSSH
sudo ufw allow 60000:61000/udp
```

Prüfe vom Laptop aus `ssh du@vps 'command -v herdr'`: Die Ausgabe muss `/usr/local/bin/herdr` liefern, sonst erkennt Moshi den Herdr-Tab nicht.

### Schritt 2: `moshi-hook` koppeln und Linger aktivieren

Kopiere den Token in **Moshi > Settings > Hooks** auf dem Handy:

```bash
curl -fsSL https://getmoshi.app/install.sh | sh
moshi-hook pair --token <DEIN_TOKEN>
moshi-hook install
sudo loginctl enable-linger $USER
moshi-hook serve
```

Seit `v0.4.34` aktualisiert sich `moshi-hook` alle 6 Stunden selbst (`moshi-hook set auto-update ask` zum Bestätigen). `v0.4.62` (November 2026) unterstützt sowohl Herdr TUI als auch `herdr-core`, deckt Claude Code, Codex, OpenCode, Hermes, Antigravity und OMP ab und begrenzt Push-Texte auf 256 Zeichen.

![Approval-Fluss von der Agent-Abfrage über moshi-hook und Push-Meldung zurück zum Agenten](@assets/images/26/09/moshi-hook-approval-flow.webp)

### Schritt 3: Agents starten und Integrationen aktivieren

```bash
herdr
herdr integration install claude
herdr integration install codex
herdr session list --json
```

Kombiniere Claude Code mit [OpenCode](/de/opencode-setup-guide/) ([OpenCode Go](https://go.bitdoze.com/opencode-go)) oder Pi in eigenen Tabs statt winziger Split-Panes.

## Typische Stolperfallen schnell gelöst

<ListCheck>
<ul>
<li><strong>Moshi zeigt keinen Herdr-Tab:</strong> <code>sudo ln -sf ~/.local/bin/herdr /usr/local/bin/herdr</code> anlegen und sicherstellen, dass ein Herdr-Server läuft.</li>
<li><strong><code>moshi-hook</code> stoppt nach SSH-Logout:</strong> <code>sudo loginctl enable-linger $USER</code> ausführen und mit <code>moshi-hook status</code> prüfen.</li>
<li><strong>Herdr Mobile bleibt leer:</strong> Prüfen, ob Agents in <code>herdr-core</code> (<code>hc</code>) statt in <code>herdr</code> TUI laufen und kein verschachteltes tmux dazwischenhängt.</li>
<li><strong>Detach statt Stop:</strong> <code>Ctrl+B q</code> trennt sicher; <code>herdr server stop</code> beendet alle laufenden Pane-Prozesse.</li>
</ul>
</ListCheck>

## Sicherheit und Häufige Fragen (FAQ)

Nutze Key-Only-SSH, biometrischen Schlüsselschutz am Handy und [Tailscale](/de/tailscale-einrichten-anleitung/) (oder [selbst gehostetes Headscale](/de/headscale-tailscale-self-hosted-einrichten/)), damit keine öffentlichen Ports nötig sind.

<Accordion label="Funktioniert die offizielle Herdr Mobile App mit Herdr TUI?" group="faq" expanded="true">
Nein. Herdr Mobile verbindet sich ausschließlich mit `herdr-core` (`hc`). Für Herdr TUI (`v0.9.5`) nutze Moshi, ColliePWA, Heeler oder SSH/Mosh.
</Accordion>

<Accordion label="Lohnt sich Moshi Pro, obwohl Herdr Mobile kostenlos ist?" group="faq">
Für `herdr-core` über Tailscale ohne Mosh-UDP und Lockscreen-Buttons reicht die kostenlose **Herdr Mobile App**. **Moshi Pro** ($7,99/Mo oder $69,99/Jahr) lohnt sich bei häufigem Mobilfunk-Wechsel, nativem Chat View mit Lockscreen-Approvals oder gemischtem Betrieb mit Herdr TUI und tmux.
</Accordion>

<Accordion label="Was passiert bei einem VPS-Neustart?" group="faq">
Laufende Prozesse enden. In Herdr TUI kehrt das Layout zurück und `herdr integration install` erlaubt die Fortsetzung per Session-ID. In `herdr-core v0.1.21` bewahrt `restore_screen = true` in `config.toml` den letzten Bildschirminhalt über einer frischen Shell.
</Accordion>

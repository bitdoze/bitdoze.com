## 5. UPI QR Code Payment Gateway (Free)

<Picture formats={["webp"]} fallbackFormat="webp" src={imgUpi} alt="UPI QR Code Payment Gateway plugin" />

[UPI QR Code Payment Gateway](https://wordpress.org/plugins/upi-qr-code-payment-for-woocommerce/) adds UPI as a checkout payment option for Indian stores. Customers see a QR code with the payment details; on mobile they get a button that opens their installed UPI app directly (BHIM, Google Pay, Paytm, PhonePe, WhatsApp Pay). No gateway fees, no commissions.

This is India-specific: only useful if your customers pay via UPI.

The plugin is now maintained by **KnitPay**. v1.7.0 (2026-10-21) is a security release: the plugin now validates screenshot uploads server-side (real JPEG/PNG only, size limit), deletes screenshots with the order, and includes UPI/transaction IDs in WordPress personal-data export/erasure tools. The customer-screenshot upload flow is an attack surface, so don't run old versions of this plugin.

v1.7.0 · 10,000 active installs · 96% rating (256 ratings) · tested up to WP 7.2

### Upgrade path: automatic verification with Knit Pay

The free UPI plugin is manual: the customer uploads a payment screenshot and you verify it by hand. The same team's **Knit Pay UPI** (`knit-pay-upi`) and **Knit Pay** (`knit-pay`) integrate business apps (Paytm Business, PhonePe Business, BharatPe, HDFC) for automatic payment verification. Both have small install counts (roughly 200 and 2,000 respectively), so test on staging before committing.

## Before you install: 3 checks (HPOS, plugin health, backups)

<ListCheck>
  <ul>
    <li>Plugin declares HPOS compatibility (or you've verified it works with HPOS on)</li>
    <li>Plugin is healthy on wp.org: not closed, recently updated</li>
    <li>Backup and staging in place before you install anything</li>
  </ul>
</ListCheck>

### Check HPOS compatibility

Modern WooCommerce runs High-Performance Order Storage. Plugins that write barcode data into order meta must declare HPOS compatibility. Quick check on any store:

```bash
# HPOS enabled?
wp option get woocommerce_custom_orders_table_enabled   # true/false
# syncing state (if migrating)
wp option get woocommerce_hpos_data_syncing
```

Also check each plugin's readme or admin notice for an "HPOS compatible" declaration. Don't assume it. Run these checks on staging first. If you don't have a staging environment, [spin up a WordPress test site with Docker Compose](https://www.bitdoze.com/install-wordpress-docker/).

### Check plugin health before installing

The Payment QR WooCommerce closure is a useful lesson: before installing anything, check wp.org for "last updated" and whether the plugin has been closed. One-liner:

```bash
curl -s "https://api.wordpress.org/plugins/info/1.2/?action=plugin_information&request[slug]=wc-qr-payment" \
  | jq '{name, version, last_updated, active_installs}'
```

An empty or error response means the plugin is likely closed. A closed-for-security plugin leaves existing installs orphaned: no updates, no patches, and you may not even know.

### Back up (and stage) before installing

Back up your site before adding or updating plugins. See the [best free WordPress backup plugins](https://www.bitdoze.com/best-free-wordpress-backup-plugins/) for options that won't cost you anything. Test on staging before touching production. If your current host has no staging environment, a [managed WordPress host with staging](https://go.bitdoze.com/cloudways) is the low-effort option.

While you're hardening things: [secure your WordPress admin with two-factor authentication](https://www.bitdoze.com/secure-wordpress-2fa/). Every installed plugin is an attack surface.

## Which WooCommerce barcode plugin should you use?

**For inventory and order management** (scanning, stock updates, PDF label printing), YITH is the most capable paid option, but try the free Barcode Scanner plugin first. It covers the core scan-to-act workflow at zero cost. Pay for YITH when you need auto-generation, scan-triggered stock/order actions, and PDF label sheets at volume.

**For printing physical labels**, the free Barcode Generator plugin covers product labels and order labels on A4 and thermal printers. No need to pay.

**For e-tickets, event check-ins, and reservations**, WooCommerce Order Barcodes is purpose-built. Just read those reviews first.

**For QR-based payments**, use UPI QR Code Payment Gateway if you're in India (with the Knit Pay upgrade path for automatic verification), or QR Payment for WooCommerce for IBAN-based bank transfer QR elsewhere.

**For marketplace compliance** (EAN/UPC/GTIN codes), the EAN Barcode Generator plugin is the cheapest solid path. Its free tier is enough for most catalogs.

**For general QR codes on any page** (product links, contact info, URLs), Kaya QR Code Generator is free and does the job.

## FAQ

<Accordion label="What happened to Payment QR WooCommerce?" group="faq" expanded="true">
  It was closed by WordPress.org on April 29, 2025, for a security issue. The plugin is gone from the directory and no longer available for download. If you had it installed, remove it. Use QR Payment for WooCommerce instead, and run the plugin-health check (see "Before you install") before adding any new plugin.
</Accordion>

<Accordion label="Can I use my phone as a WooCommerce barcode scanner?" group="faq">
  Yes, for testing and light work. Any QR/barcode app on your phone will scan the codes these plugins generate. For actual desk or packing-station volume, use a USB or Bluetooth barcode scanner. They're faster and more reliable than holding a phone. The Barcode Scanner (+Mobile App) plugin has a companion mobile app for on-the-go scanning and order creation.
</Accordion>

<Accordion label="Do these plugins work with WooCommerce HPOS?" group="faq">
  Check each plugin's readme or admin notice for an "HPOS compatible" declaration before installing. Then verify on staging with `wp option get woocommerce_custom_orders_table_enabled`. Plugins that write barcode data into order meta are the ones most likely to break if HPOS compatibility isn't declared. Don't assume compatibility: verify on staging first.
</Accordion>

<Accordion label="Do I need a paid plugin to print barcode labels?" group="faq">
  No. The free Barcode Generator plugin covers A4 paper and thermal printers (DYMO, Zebra, Brother) for both product labels and order labels. Paid plugins add auto-generation, scan-triggered actions, and bulk PDF sheets with stock counts. Those help at volume, but they are not required to get labels printed.
</Accordion>

## ¿Qué es Keila?

Keila es una plataforma de newsletter open source construida con Elixir y Phoenix. Tiene licencia AGPL-3.0 y está diseñada para el autoalojamiento. La ejecutas en tu propio servidor y eres dueño de tus datos. Ningún tercero tiene acceso a tu lista de suscriptores ni al contenido de tus campañas.

La arquitectura es sencilla. Keila se ejecuta como un contenedor Docker, se conecta a PostgreSQL para el almacenamiento de datos y usa tu proveedor de email configurado (SMTP, AWS SES, Sendgrid, Mailgun o Postmark) para entregar los mensajes. Los suscriptores interactúan con formularios de registro, páginas de confirmación y enlaces de baja que Keila sirve directamente desde tu servidor.

<Notice type="info" title="Nota sobre la licencia AGPL-3.0">
Si modificas el código fuente de Keila y lo ejecutas como un servicio de red, debes poner el código modificado a disposición de todos los usuarios que interactúan con él, incluidos los suscriptores que usan formularios de registro, páginas de baja o endpoints de seguimiento. Para la mayoría de los autoalojados que ejecutan Keila sin modificar, esto no es un problema.
</Notice>

Keila prioriza la privacidad por defecto. El seguimiento de campañas (aperturas, clics) es opt-in por campaña, así que puedes enviar newsletters sin píxeles de seguimiento ni redirecciones de enlaces si lo prefieres. La plataforma soporta 8 idiomas: inglés, alemán, francés, español, búlgaro, húngaro, portugués brasileño e italiano.

## Características principales de Keila

Keila ha evolucionado de una herramienta básica de newsletter a una plataforma completa de email marketing open source. Esto es lo que ofrece a fecha de la v0.30.2:

### Gestión de contactos

Importa contactos vía CSV, añade campos personalizados y usa etiquetas para organizar tu lista. Los segmentos inteligentes te permiten filtrar contactos según criterios que defines, incluida la segmentación basada en interacciones (introducida en la v0.18) que apunta a suscriptores por aperturas, clics o participación en campañas. La búsqueda y ordenación de contactos están integradas para consultas rápidas.

### Editor de emails y plantillas

Keila incluye un editor visual de bloques para crear campañas sin código. También puedes escribir en Markdown, usar MJML para plantillas responsive (añadido en la v0.15) o recurrir al texto plano. Las vistas previas para móvil y escritorio te permiten comprobar cómo se renderizan las campañas antes de enviarlas. El bloque de iconos de redes sociales (v0.18) añade enlaces para compartir a tus emails. A partir de la v0.30, las plantillas reutilizables con ranuras de contenido te permiten mantener una imagen de marca coherente entre campañas.

### Doble opt-in y cumplimiento

El doble opt-in se añadió en la v0.13 y ahora es una función madura. Dispones de asuntos y cuerpos de email de confirmación configurables, mensajes de error personalizados y URLs de redirección, además de enlaces de opt-in protegidos (v0.19) que evitan la activación accidental por parte de escáneres de correo. La protección captcha soporta tanto hCaptcha como Friendly Captcha para bloquear registros de bots. Keila es respetuoso con el GDPR por diseño. Sin seguimiento de usuarios a menos que lo actives explícitamente por campaña.

### Envío y entregabilidad

Keila soporta de forma nativa SMTP, AWS SES, Sendgrid, Mailgun y Postmark como tipos de remitente. Los emails de bienvenida (v0.19) saludan automáticamente a los nuevos suscriptores. Puedes enviar emails de vista previa/prueba antes de lanzar a toda tu lista. El nuevo planificador de emails introducido en la v0.20 es mucho más rápido para campañas grandes.

### Emails transaccionales y API

A partir de la v0.30, Keila ofrece una API de emails transaccionales para enviar mensajes puntuales como confirmaciones de pedidos, restablecimientos de contraseña y notificaciones. La API REST también cubre contactos, campañas y formularios, así que puedes integrar Keila en tus aplicaciones existentes.

<Notice type="success" title="Keila ha crecido mucho">
A fecha de la v0.30.2 (junio de 2026), Keila soporta emails transaccionales, plantillas reutilizables, MJML, emails de bienvenida y segmentación basada en interacciones, funciones que faltaban cuando este artículo se publicó por primera vez en noviembre de 2023.
</Notice>

Los certificados HTTPS se configuran automáticamente con EasyPanel.

## Proveedores SMTP para enviar newsletters

Keila soporta cinco tipos de remitente de forma nativa: SMTP, AWS SES, Sendgrid, Mailgun y Postmark. Cada uno tiene precios y límites de nivel gratuito diferentes. Aquí va una comparación rápida:

| Proveedor | Nivel gratuito | Precio de pago | Notas |
|----------|-----------|-------------|-------|
| AWS SES | 62.000 emails/mes (desde EC2) | 0,10 $/1.000 emails | El más barato a escala, requiere configuración de AWS |
| Sendgrid | 100 emails/día (~3.000/mes) | Desde 19,95 $/mes | Fácil de configurar, buena entregabilidad |
| Mailgun | 5.000 emails/mes (primeros 3 meses) | Desde 35 $/mes | API amigable para desarrolladores |
| Postmark | 100 emails/mes | 10 $/10.000 emails | Excelente para transaccionales |
| SMTP2GO | 1.000 emails/mes | Desde 15 $/mes | Relay SMTP sencillo |
| Mail.Baby | Ninguno | 1 $/mes + 0,20 $/1.000 | Económico para bajo volumen |

Para una configuración económica, [Mail.Baby](/es/resena-mail-baby/) a 1 $/mes más 0,20 $ por cada 1.000 emails es difícil de superar para listas pequeñas. Si estás en una instancia EC2, AWS SES te da 62.000 emails gratis al mes.

<Notice type="info" title="Consejo de entregabilidad">
Independientemente del proveedor, configura los registros SPF, DKIM y DMARC para tu dominio de envío. Estos registros DNS demuestran a los servidores de correo receptores que estás autorizado a enviar email desde tu dominio. Sin ellos, tus newsletters acabarán en las carpetas de spam. Consulta [cómo configurar un relay SMTP en un VPS](/es/configurar-relay-smtp-zeptomail/) para una guía detallada.
</Notice>

## Keila vs ListMonk: ¿qué plataforma de newsletter elegir?

ListMonk es la otra opción popular de newsletter autoalojada. Así se comparan:

| Característica | Keila | ListMonk |
|---------|-------|----------|
| Lenguaje | Elixir (Phoenix) | Go |
| Licencia | AGPL-3.0 | GPL-3.0 |
| Estrellas en GitHub | ~2.200 | ~21.000 |
| Editor visual | Editor de bloques + MJML | Texto plano / HTML |
| Doble opt-in | Sí (v0.13+) | Sí |
| Emails transaccionales | Sí (v0.30+) | Sí |
| Emails de bienvenida | Sí (v0.19+) | No (manual) |
| Archivos públicos de campañas | Sí (v0.18+) | No |
| Opción cloud | Keila Cloud (alojado en la UE) | Ninguna |
| Multiidioma | 8 idiomas | Limitado |
| Base de datos | PostgreSQL | PostgreSQL |

**Elige Keila si** quieres un editor visual de bloques con soporte de plantillas MJML, una opción cloud gestionada, o funciones como emails de bienvenida y archivos públicos de campañas.

**Elige ListMonk si** prefieres un binario ligero en Go, quieres una comunidad más grande o no necesitas un editor visual.

Si estás explorando otras opciones, [Notifuse es otra newsletter autoalojada](/es/notifuse-newsletter-autoalojado/) que vale la pena revisar.

Monitorizar la CPU es muy importante en un servidor Linux, ya que puede haber casos en los que tus aplicaciones necesiten más CPU y acaben consumiéndola por completo. Querrás recibir una notificación por correo electrónico si el uso de la CPU se dispara y tienes que hacer algunas comprobaciones.

> Si te interesa monitorizar los recursos del servidor, como la CPU, la memoria o el espacio en disco, puedes consultar: [Cómo monitorizar recursos del servidor y Docker](/es/monitorizar-servidor/)

Para que tu servidor pueda enviar correos necesitarás tener configurado un relay SMTP o un servidor de correo alojado en el VPS que se encargue de enviar la alarma.

Si usas un proveedor de VPS online como Hetzner o DigitalOcean, un script de este tipo puede ser muy útil, ya que puede detectar problemas que provengan de tu proveedor de hosting o de tu aplicación. Para más detalles sobre Hetzner, puedes consultar esta reseña.

En este artículo configuraremos un script que se ejecutará en crontab cada 5 minutos y comprobará si el uso de la CPU supera el 80 %; si eso ocurre, recibirás un correo electrónico con:

- El uso actual
- Los 20 procesos que más CPU consumen
- Los 10 procesos que más CPU consumen según el comando ps
- El uso de memoria del servidor

## El script de shell que vamos a usar

A continuación está el script que vamos a utilizar para monitorizar el uso de la CPU; te servirá tanto para versiones de Ubuntu como 20.04 o 22.04 como para distribuciones de RedHat.

```
    #!/bin/bash
    cpu_idle=`top -b -n 1 | grep Cpu | awk '{print $8}'|cut -f 1 -d "."`
    cpuuse=`expr 100 - $cpu_idle`
    date=$(date '+%Y-%m-%d %H:%M:%S')
    if [ "$cpuuse" -ge 80 ]; then
    SUBJECT="ATTENTION: CPU load is high on $(hostname) at $(date)"
    MESSAGE="/tmp/Mail.out"
    TO="youremail@domain.com"
      echo "CPU current usage is: $cpuuse%" >> $MESSAGE
      echo "" >> $MESSAGE
      echo "+------------------------------------------------------------------+" >> $MESSAGE
      echo "Top 20 processes that consume high CPU" >> $MESSAGE
      echo "+------------------------------------------------------------------+" >> $MESSAGE
      echo "$(top -bn1 | head -20)" >> $MESSAGE
      echo "" >> $MESSAGE
      echo "+------------------------------------------------------------------+" >> $MESSAGE
      echo "Top 10 Processes which consuming high CPU using the ps command" >> $MESSAGE
      echo "+------------------------------------------------------------------+" >> $MESSAGE
      echo "$(ps -eo pcpu,pid,user,args | sort -k 1 -r | head -10)" >> $MESSAGE
      echo "Memory Utilization on the server" >> $MESSAGE
      echo "+------------------------------------------------------------------+" >> $MESSAGE
      echo "$(ps_mem)" >> $MESSAGE
      mail -s "$SUBJECT" "$TO" < $MESSAGE
      rm /tmp/Mail.out
    else
    echo "$date: Server CPU usage is in under threshold.CPU current usage is: $cpuuse%"
      fi
```

En este script tienes que cambiar el TO por tu correo electrónico y, si quieres modificar el umbral, poner el valor que prefieras en el -ge 80 (ahora es 80).

## Activar el script de monitorización de CPU

### Instalar ps_mem

Es una herramienta que te muestra de forma más clara el uso de memoria por proceso; para instalarla haz lo siguiente:

Obtén ps_mem:

```
      sudo wget -qO /usr/local/bin/ps_mem https://raw.githubusercontent.com/pixelb/ps_mem/master/ps_mem.py
```

Haz ps_mem ejecutable:

```
sudo chmod a+x /usr/local/bin/ps_mem
```

Comprueba la versión:

```
      ps_mem --version
```

Si recibes el mensaje de error /usr/bin/env: 'python': No such file or directory, tienes que crear un enlace simbólico para /usr/bin/python. En Ubuntu 20.04 o Ubuntu 22.04 solo viene instalado Python 3 por defecto.

```
      sudo ln -s /usr/bin/python3 /usr/bin/python
```

### Añadir el script a crontab

Crea un archivo con el script en /opt/scripts o en cualquier ubicación que prefieras:

```
vi /opt/scripts/cpu-alert.sh
```

Haz el archivo ejecutable:

```
sudo chmod a+x /opt/scripts/cpu-alert.sh
```

Ejecuta el script:

```
      /opt/scripts/cpu-alert.sh
```

Activar el script en crontab y crear un log de la ejecución:

```
    # abrir crontab en modo edición
    contab -e
    # añadir la siguiente línea
    */5 * * * * /bin/bash /opt/scripts/cpu-alert.sh >> /opt/scripts/cpu_check_cron.log 2>&1
```

Lo anterior creará un log en /opt/scripts/cpu_check_cron.log con la salida generada cuando no se está enviando un correo.

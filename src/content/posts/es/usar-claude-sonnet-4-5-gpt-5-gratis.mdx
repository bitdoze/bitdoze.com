## ¿Por qué usar Claude Sonnet 5.5, GPT-6 y Gemini 3.1?

Los modelos que la gente quiere en 2026 no son los que este artículo nombraba antes. Los buques insignia actuales:

<ListCheck>

- **Claude Sonnet 5.5**: el caballo de batalla de Anthropic para programación, fuerte en tareas tipo SWE-bench y trabajo agéntico de larga duración. 2 $ de entrada / 10 $ de salida por millón de tokens.
- **Claude Opus 5.5**: el nivel de razonamiento pesado. 4 $ / 20 $ por millón de tokens. Por encima está Fable 5.1 a 10 $ / 50 $, por si de verdad lo necesitas.
- **Familia GPT-6.x**: GPT-6.1 Sol, GPT-6 Astra y la línea GPT-5.6 Sol / Terra / Luna. GPT-5.5 y GPT-5.3-Codex siguen disponibles. La página de precios de OpenAI esconde las cifras por token tras una interfaz dinámica, así que revisa la página de precios de la API antes de presupuestar.

## Método 1: Droid CLI de Factory - créditos gratis + respaldo de Droid Core

**[Droid CLI de Factory](https://go.bitdoze.com/droid-cli)** es la opción centrada en la terminal, y a la que recurro cuando quiero un agente corriendo sobre un repositorio sin abrir un editor. Las cuentas nuevas reciben créditos de prueba gratuitos. Factory no publica la cantidad exacta de registro en su documentación (guías antiguas dicen 20 millones de tokens, algunos vídeos dicen 40 millones), así que fíjate en lo que te muestre el registro y toma esa cifra como la buena.

### ¿Qué es Droid CLI?

Droid CLI es un agente de codificación de línea de comandos con un catálogo multimodelo: Claude Sonnet 5.5 y Opus 5.5, GPT-6.1 Sol y GPT-6 Astra, Gemini 3.1 Pro, Grok 4.7 y más. La parte que importa para el uso gratuito es **Droid Core**, un pool gratuito de modelos de pesos abiertos (Inkling, GLM-5.3, Kimi K3, Qwen3.8 Max, DeepSeek V4.1 Flash, MiniMax M3, Mistral Large 4) al que las sesiones pueden recurrir cuando los créditos de pago alcanzan un límite de velocidad. La documentación vive ahora en `docs.factory.com`; los enlaces antiguos de `docs.factory.ai` redirigen.

### Características clave

<ListCheck>

- Un selector multimodelo para cambiar entre Claude, GPT, Gemini y modelos de pesos abiertos en cada sesión
- Niveles de esfuerzo de razonamiento: `off`, `low`, `medium`, `high`, `xhigh`, `max` en los modelos compatibles
- Factory Standard Credits: un único pool medido con límites móviles de 5 horas, 7 días y 30 días
- El comando `/limits` para ver un desglose interactivo de lo que te queda, dentro de la sesión
- Respaldo de Droid Core para que las sesiones sigan funcionando con modelos abiertos gratuitos cuando los créditos se limitan
- Integración con IDE: el mismo agente en tu editor si la terminal no es lo tuyo

</ListCheck>

### Cómo empezar

Requisitos previos: macOS, Linux o Windows con acceso a una shell. En Linux, `xdg-utils` es necesario para el inicio de sesión desde el navegador:

```bash
sudo apt-get install xdg-utils
```

Después instala por la vía que encaje con tu máquina:

<Tabs>
<Tab name="macOS / Linux">

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

</Tab>
<Tab name="Homebrew">

```bash
brew install --cask droid
```

</Tab>
<Tab name="npm">

```bash
npm install -g droid
```

</Tab>
<Tab name="Windows">

```powershell
irm https://app.factory.ai/cli/windows | iex
```

</Tab>
</Tabs>

Lánzalo e inicia sesión:

```bash
droid
```

Elige tu modelo en el selector (Sonnet 5.5 como modelo de codificación por defecto, Haiku 5.5 o Droid Core cuando quieras gastar poco), ajusta el esfuerzo de razonamiento si la tarea lo merece y a trabajar.

Un prompt real se ve así:

```text
Create a Python web scraper that extracts product prices from
e-commerce sites, handles pagination, and exports data to CSV
with error handling
```

### Verifica tus créditos gratuitos

No adivines lo que te queda. Ejecuta `droid`, escribe `/limits` y obtendrás un panel interactivo con los saldos de créditos de 5 horas, 7 días y 30 días. Contrástalo con Settings -> Usage en el panel de Factory. Confirma también qué modelo de respaldo está configurado, para que una sesión limitada caiga en Droid Core en vez de morir.

Si `/limits` no muestra nada o da errores, tienes un binario antiguo. Vuelve a ejecutar el comando de instalación y consulta `docs.factory.com/droid-cli/quickstart` para el flujo actual.

### Cuando llegas a los límites (modos de fallo)

- **Límite de velocidad agotado**: ventanas móviles de 5 h/7 d/30 d, no un muro mensual fijo. Con el respaldo configurado, las sesiones continúan en Droid Core (modelos gratuitos, más débiles). Sin él, toca esperar.
- **Rotación por retirada de modelos**: Factory retira modelos con poco aviso. DeepSeek V4 Flash 0731, Kimi K2.5, GLM-5.1 y MiniMax M2.7 ya no están en el catálogo. Los usuarios gratuitos se migran automáticamente, así que no fijes nada crítico a un nombre de modelo concreto.
- **Los créditos son compartidos**: el mismo pool paga el chat, las ejecuciones de agentes y el trabajo en segundo plano. Un bucle de agente descontrolado es la vía más rápida a cero.

### Escalera de pago (para que conozcas la salida)

Pro cuesta 20 $/mes, Plus 100 $ (unas 5 veces Pro), Max 200 $ (unas 10 veces). Extra Usage es prepago desde 10 $ y no caduca. Los multiplicadores del catálogo son el verdadero modelo de coste: Sonnet 5.5 a 0,8x, Opus 5.5 a 1,6x, Fable 5.1 a 4x, Haiku 5.5 a 0,04x, GLM-5.3 a 0,06x. Si subes a razonamiento de clase Fable en cada prompt, quemarás un mes de créditos gratuitos en una tarde.

### Mejores casos de uso de Droid CLI

- APIs de backend, capas de base de datos y configuración de servidores
- Scripts de automatización, procesamiento de datos y código de pegamento
- Revisión y limpieza de código en bases de código existentes
- Pruebas de concepto rápidas antes de comprometerte con una arquitectura
- Agentes en un VPS: ejecuta el CLI en una máquina y déjalo trabajar (mira la [configuración de VPS para agentes de codificación IA](/es/vps-configuracion-codificacion-ia/))

Las herramientas centradas en la terminal también son fáciles de scriptar. Si quieres una alternativa open source en la misma línea, [OpenCode, una alternativa open source a Claude Code, en tu VPS](/es/guia-configuracion-opencode/) merece un vistazo.

Cognition (la gente detrás de Devin) se hizo con el editor Windsurf. Los productos actuales son Devin Desktop (el IDE), Devin CLI, Devin Web y Fusion. Quien aterrice en enlaces antiguos de precios de Windsurf está viendo los planes de Devin. La buena noticia: sigue habiendo un nivel de 0 $, y posiblemente mejor que lo que ofrecía Windsurf, porque los autocompletados con Tab y las ediciones inline son ilimitados.

| Plan | Precio | Qué obtienes |
| --- | --- | --- |

| **Pro** | 20 $/mes | Cuotas ampliadas, modelos frontera (OpenAI, Claude, Gemini, SpaceXAI más open source), uso gratuito de SWE-2, agentes Devin Cloud, uso extra a precio de API |

Antes de prometerte un modelo concreto, abre el selector de modelos y compáralo con lo que Free ofrece. Los modelos frontera de la lista (los niveles más nuevos de Claude y GPT) están bloqueados tras Pro.

## Método 3: AgentRouter - créditos de API gratis (úsalo con cautela)

**[AgentRouter](https://go.bitdoze.com/agentrouter)** es un router de API unificado que ha anunciado unos 200 $ en créditos gratuitos para acceder a modelos premium a través de un endpoint compatible con OpenAI. Ten presente la palabra «anunciado».

### ¿Qué es AgentRouter?

Una URL base, una clave, muchos modelos. Apuntas un cliente compatible con OpenAI a `https://agentrouter.org/v1` y detrás tienes Claude Code, OpenAI Codex y modelos de clase Gemini CLI. Se conecta a Roo Code, Kilo Code, Cline y herramientas similares.

El 2026-10-20 el sitio servía un CAPTCHA deslizante a clientes que no eran navegadores y no pude reverificar la oferta de 200 $, la lista de modelos ni siquiera la URL base. Eso no lo convierte en una estafa. Sí significa que no puedo avalarlo, y tú tampoco deberías hasta ver las condiciones por ti mismo al registrarte.

### Configuración (Roo Code / Kilo Code)

Si sigues adelante, crea primero la clave API con una cuota dura por clave. Es el paso que casi todo el mundo se salta y el que limita el radio de daño cuando una clave se filtra.

<ListCheck>

- Pon una cuota por clave (por ejemplo 10 $), nunca un cheque en blanco
- Restringe la clave a los modelos que vayas a llamar
- Usa una clave por herramienta o entorno, para que revocar una no lo rompa todo
- Nunca reutilices una clave en una configuración del lado del cliente o de un repositorio público

</ListCheck>

Luego, en Roo Code, crea un perfil:

```json
{
  "profile_name": "AgentRouter Free",
  "provider": "OpenAI Compatible",
  "base_url": "https://agentrouter.org/v1",
  "api_key": "your_api_key_here",
  "model": "gpt-5",
  "enable_streaming": true
}
```

En Kilo Code: settings -> «Use my own key» -> proveedor «OpenAI Compatible» -> URL base `https://agentrouter.org/v1` -> pega la clave -> elige un modelo. Reverifica ese endpoint al registrarte antes de fiarte del fragmento de arriba.

### Consideraciones importantes

<Notice type="warning" title="Aviso de fiabilidad">

AgentRouter es un servicio difícil de auditar. El sitio está detrás de un CAPTCHA, sus ofertas no son verificables de forma independiente, y las condiciones del servicio determinan qué pasa con tus prompts.

- **No envíes código propietario o de clientes** por routers no verificados. Punto.
- Pon cuotas por clave y restricciones de modelos siempre.
- Vale para probar, aprender y trabajar en open source. Nunca para producción.
- Las ofertas gratuitas como esta desaparecen sin aviso. Confirma la promesa de 200 $ al registrarte hoy, no en un artículo del año pasado.

</Notice>

Si prefieres pagar unos dólares por modelos baratos auditados antes que apostar por routers gratuitos, hay un camino mejor: [DeepSeek V4 Flash, GPT 5.6 Luna y Kimi K3 baratos vía OpenCode Go o ClinePass](/es/opencode-go-vs-clinepass-modelos-baratos/).

### Mejores casos de uso de AgentRouter

- Experimentos de API: comparar modelos con el mismo conjunto de prompts
- Pruebas de humo por lotes con datos no sensibles, ejecuciones desechables
- Comparación de costes: medir qué modelo maneja tu carga antes de pagar a nadie
- Prototipos no críticos: cosas que no te importaría perder

## Método 4: Google Antigravity - Gemini 3.8 Flash + Claude Sonnet 4.6 gratis

**[Google Antigravity](https://antigravity.google/)** ya está en disponibilidad general, no es una vista previa pública. El plan Individuals cuesta **0 $/mes**, y es la mejor oferta gratuita de esta lista para trabajo agéntico que necesita verificarse en un navegador.

### ¿Qué es Google Antigravity?

Una plataforma de desarrollo centrada en agentes. La familia de productos abarca Antigravity App, IDE, CLI, SDK y Extensions, con un concepto de Remote Control para delegar trabajo. El flujo de trabajo principal no ha cambiado:

- **Vista Editor** para trabajo síncrono: autocompletados con Tab, comandos inline, un agente en el panel lateral
- **Vista Manager** para ejecución asíncrona en paralelo: lanza varios agentes en distintos workspaces y síguelos en una bandeja de entrada

Lo interesante es el modelo de artefactos. En vez de ahogarte en llamadas a herramientas o soltarte un diff final, los agentes producen listas de tareas, planes de implementación, recorridos, capturas de pantalla y grabaciones de navegador que puedes revisar. Para trabajo de UI, ese bucle de verificación es la clave.

### Qué incluye el plan gratuito

El plan Individuals te da una variedad de modelos de agente, autocompletados con Tab ilimitados, solicitudes de Command ilimitadas y un límite de velocidad básico **semanal** que se renueva en ciclo semanal. Los límites se correlacionan con el trabajo realizado, no con el número bruto de prompts.

## Método 5: el nivel gratuito de GitHub Copilot - GitHub AI Credits explicados

**[GitHub Copilot](https://github.com/features/copilot/plans)** sigue teniendo un nivel Free de 0 $ permanente. La unidad de facturación, eso sí, no es la que describen las guías antiguas. Las «premium requests» son cosa del pasado. Ahora todo funciona con **GitHub AI Credits**: el chat, el modo agente, la revisión de código, los agentes en la nube, Copilot CLI y Copilot Apps consumen del mismo pool de créditos.

### Free vs Pro vs Pro+ - AI Credits

| Plan | Precio | AI Credits base (+ flex) | Notas |
| --- | --- | --- | --- |
| **Free** | 0 $ | Una asignación (uso limitado de chat/agente) | Solo selección automática de modelo; tope de 2.000 autocompletados/mes |
| Student | 0 $ | Asignación | Excluye agentes de terceros |
| Pro | 10 $/mes | 1.000 (+5 $ flex, unos 15 $ de valor) | Selección de modelos |
| **Pro+** | 39 $/mes | 3.900 (+31 $ flex, unos 70 $ de valor) | Modelos premium |
| **Max** | 100 $/mes | 10.000 (+100 $ flex, unos 200 $ de valor) | Acceso prioritario a modelos premium |
| Business | 19 $/asiento | 1.900/usuario | Funciones de equipo |
| Enterprise | 39 $/asiento | 3.900/usuario | Exceso a 0,01 $/crédito |

Dos advertencias que conviene conocer antes de planificar con estas cifras. Primero, la propia nota al pie de GitHub dice que las asignaciones flex «pueden cambiar con el tiempo», así que no presupuestes un flujo de trabajo sobre ellas. Segundo, el plan Free no te deja elegir modelos. Si quieres Claude Sonnet 5.5 u Opus 5.5 en concreto, Free no te dará un selector; te toca la elección automática. El viejo esquema de 50 solicitudes más multiplicadores que este artículo publicaba está muerto, junto con su tabla de modelos.

Si de 39 a 100 $ al mes es más de lo que necesitas, hay [alternativas más baratas a GitHub Copilot](/es/alternativas-github-copilot-2026/) que vale la pena leer antes de subir de plan.

### Primeros pasos

Requisitos previos: una cuenta de GitHub. Nada más.

1. Activa Copilot Free desde la [página de planes](https://github.com/features/copilot/plans). Guías antiguas, incluidas versiones anteriores de este artículo, anuncian una prueba Pro de 30 días sin tarjeta. No pude confirmar esa oferta en la documentación actual de GitHub el 2026-10-20. La página de planes lista Pro a 10 $/mes y lo marca como «gratis para algunos usuarios» (estudiantes, profesores, mantenedores populares de OSS). Revisa la página para ver qué prueba existe hoy en lugar de fiarte de un artículo del año pasado.
2. Instálalo en tu editor: VS Code, JetBrains, Zed, Vim o la app de escritorio de Copilot.
3. Para el CLI: Copilot CLI ahora es una herramienta independiente. El viejo flujo `gh extension install github/gh-copilot` está obsoleto, así que no copies ese fragmento de artículos desfasados. Obtén el comando de instalación actual en la documentación oficial de Copilot CLI en docs.github.com/copilot.
4. Las funciones en vista previa y los controles de modelo viven en tu configuración de Copilot en github.com. En el plan Free casi todo eso aparece en gris, lo cual es esperable.

### Verificación y modos de fallo

**Verificación**: GitHub -> Settings -> Copilot -> monitoriza el uso de AI credits. Ese panel muestra el gasto frente a tu asignación. Si no lo encuentras, la página de documentación «Monitor AI usage for Copilot» tiene la ruta actual.

**Modos de fallo**:

- **Créditos agotados.** El chat y las funciones de agente se limitan hasta la renovación. En planes de pago los autocompletados siguen fluyendo; en Free también tienes el tope de 2.000 autocompletados/mes en qué pensar.
- **Las asignaciones flex cambian.** Lo dijo GitHub. Espera movimiento.
- **Free no puede elegir modelos.** La queja más común con diferencia, y un bloqueo firme.

### Mis recomendaciones

**Elige Droid CLI si:**

- Vives en la terminal o quieres agentes en un VPS
- Te gusta tener un respaldo gratuito de pesos abiertos (Droid Core) cuando los créditos se limitan
- Quieres un solo selector para Claude, GPT, Gemini y Grok

**Elige Devin Desktop si:**

- Quieres un editor completo nativo de IA por 0 $
- Te importan más el Tab y las ediciones inline ilimitados que la cuota de agente
- Vienes de Windsurf y quieres el sucesor más cercano

**Elige AgentRouter si:**

- Necesitas acceso directo a la API para experimentos y puedes aceptar el compromiso de confianza
- Quieres probar muchos modelos rápidamente a través de un endpoint compatible con OpenAI
- Mantienes las claves con cuota limitada y nunca envías código que no puedas permitirte filtrar

**Elige Google Antigravity si:**

- Quieres agentes que verifiquen su trabajo en un navegador real
- Necesitas ejecución de agentes en paralelo con artefactos revisables
- Te conformas con Gemini 3.8 Flash y Claude 4.6 en Free

**Elige GitHub Copilot si:**

- Quieres el nivel gratuito más apto para producción con un proveedor que no va a desaparecer
- Trabajas todo el día en issues y PRs de GitHub
- Necesitas autocompletados más que elegir modelos frontera

- **Droid CLI** para trabajo de terminal y automatización, con Droid Core como suelo gratuito

- **Antigravity** para tareas agénticas que necesitan verificación en navegador
- **GitHub Copilot** para flujos nativos de GitHub y autocompletados
- **AgentRouter** para experimentos de API en un sandbox, nada más

Son cinco superficies cubiertas sin una sola suscripción.

## Cómo funciona «gratis» ahora: cuotas, créditos y multiplicadores

La era de «aquí tienes N tokens gratis» ha terminado en su mayor parte. Cada proveedor mide ahora el acceso gratuito como una **cuota o pool de créditos**, y pone precio a los modelos dentro de ese pool con un multiplicador. Entender esta única idea es la diferencia entre un nivel gratuito que dura un mes y uno que dura una tarde.

![Diagrama de cómo los multiplicadores de crédito de los modelos vacían un pool gratuito compartido: los de clase Haiku a 0,04x apenas se notan mientras los de clase Fable a 4x lo vacían rápido](@assets/images/25/10/quota-burn-rate.svg)

Toma el catálogo de Factory como ejemplo concreto. El mismo prompt cuesta 0,04 créditos en Claude Haiku 5.5, 0,8 en Sonnet 5.5, 1,6 en Opus 5.5 y 4 en Fable 5.1. GLM-5.3 en el pool gratuito de Droid Core va a 0,06. Un «prompt gratis» en un modelo de clase Opus quema tu pool compartido de 5 a 50 veces más rápido que un prompt de clase Flash o Haiku, según por dónde empezaste.

<Notice type="info" title="Ojo con los finales de promoción y la trampa del tokenizador">

Tres fechas que vale la pena marcar en el calendario:

- **2026-11-22**: GPT-5.6 Sol pasa de 1,6x a 2x en el catálogo de Factory
- **2026-12-01**: el precio de la API de Gemini 3.1 Pro se duplica de 2 $/10 $ a 4 $/20 $ por millón de tokens
- **2027-01-01**: las tarifas promocionales de Gemini 3.8/3.7 Flash pasan a sus tarifas normales

Y una trampa que no es una fecha: Claude 4.7 y los modelos más nuevos usan un tokenizador que emite aproximadamente un 30 % más de tokens para el mismo texto. El mismo prompt que ejecutaste el año pasado cuesta más de lo que recuerdas, incluso con tarifas por token sin cambios.

</Notice>

<ListCheck>

- Redacta y edita con los modelos baratos (Haiku, Flash, Droid Core). Escala solo para la decisión difícil.
- Mantén el contexto largo fuera de los modelos frontera cuando uno pequeño puede responder desde un resumen.
- Revisa `/limits` o el panel del proveedor semanalmente, no cuando algo se rompe.
- Fija tus suposiciones a una fecha. Las tarifas promo caducan.
- Cuando las cuotas gratuitas se agoten, mira los [modelos de IA más baratos por debajo de 1 $ por millón de tokens](/es/mejores-modelos-baratos-hermes-agent/) antes de sacar una clave API de modelo grande.

</ListCheck>

Los agentes de codificación open source como [OpenCode Go](https://go.bitdoze.com/opencode-go) también pueden enrutar modelos baratos de pesos abiertos cuando quieres una vía de API económica en vez de vigilar niveles gratuitos.

## Seguridad y privacidad: qué no enviar por los niveles gratuitos

<Notice type="warning" title="La única regla innegociable">

Nunca enrutes código propietario, de clientes o sin publicar por un servicio que no puedas auditar. Los routers de API no verificados (la categoría AgentRouter) son exactamente eso. Si el código le importa a alguien además de ti, no pasa.

</Notice>

El resto, en orden aproximado de gravedad:

1. **Las condiciones de retención varían.** Factory señala que los modelos Anthropic de clase Mythos conllevan un requisito de retención de datos de 30 días. Productos distintos, reglas distintas. Lee la política de datos del nivel en el que estás, no la página de marketing.
2. **Condiciones de consumidor vs empresa.** Antigravity Free funciona bajo las condiciones de consumidor de Google. Si necesitas compromisos de nivel cliente, Gemini Enterprise empieza en 30 $/asiento/mes con condiciones de Google Cloud y controles de gasto. Elige el adecuado para el trabajo que tienes delante.
3. **Asume que las entradas del nivel gratuito se registran.** Limpia secretos, contenidos de `.env`, claves API y datos personales antes de pegar nada en un prompt. Esto también es higiene básica en niveles de pago.
4. **Las ofertas gratuitas se pudren sin aviso.** Amp Code Free se pausó. Windsurf se convirtió en Devin. La unidad de facturación de Copilot cambió. No construyas nada irreemplazable sobre el nivel gratuito de otro.

<Accordion label="¿Los niveles gratuitos de IA entrenan con mi código?" group="faq" expanded="true">

Depende del producto y del plan. La mayoría de los niveles de codificación de consumo tienen controles de datos que te permiten excluirte del entrenamiento, y los planes business/enterprise suelen no entrenar con tus datos por defecto. Revisa los controles de datos de cada proveedor explícitamente. «Gratis» y «no entrenaremos con tu código» son ajustes separados.

</Accordion>

<Accordion label="¿Es legítimo usar estos niveles gratuitos?" group="faq">

Sí. Todo lo de aquí es un plan gratuito o una prueba oficial del proveedor. Los riesgos son la rotación de ofertas y el manejo de datos, no la legalidad. Cuando marco afirmaciones sin verificar (los 200 $ de AgentRouter, el crédito exacto de registro de Droid), es una advertencia de verificación, no una acusación de fraude.

</Accordion>

<Accordion label="¿Qué no debo pegar nunca en un nivel gratuito?" group="faq">

Secretos de cualquier tipo, código de clientes o empleadores, datos personales, planes de producto no publicados y cualquier cosa cubierta por un NDA. Si no lo subirías a un repositorio público, no lo pegues en un prompt de un nivel no verificado.

</Accordion>

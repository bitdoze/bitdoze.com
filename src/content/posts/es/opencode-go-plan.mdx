## Que es OpenCode Go

OpenCode Go es una suscripcion plana del equipo de OpenCode: una API key, 31 modelos, $10/mes — o $40/mes con Go Plus, que sube los limites por modelo. Sin cuentas por token. Sin cuentas separadas en cada proveedor.

Los modelos se sirven desde EE.UU., UE y Singapur. La mayoria de los proveedores afirman cero retencion, asi que tu codigo no deberia entrenar el siguiente modelo de nadie. Las excepciones importan: Grok 4.7/4.6, GPT 6 Luna, GPT 5.6 Luna, Claude Haiku 5.5 y Cat Jam Free guardan logs durante 30 dias, y los dos modelos Contributor (Gemini 4 Argon, Muse Spark 1.2/1.3) son mas baratos precisamente **porque entrenan con tus prompts**. Importa si trabajas con codigo propietario.

No necesitas OpenCode el IDE para usar Go. Apunta cualquier cliente compatible al endpoint: [Hermes Agent](/es/guia-configuracion-hermes-agent/), [OpenClaw](/openclaw-alternatives/), [Pi Agent](/es/guia-configuracion-pi-agent/), Mastra, Agno, Codex, lo que ya uses.

## Limites de uso

Go no es ilimitado, pero los limites funcionan distinto ahora. Cada modelo tiene su propia cuota mensual en dolares — $15 para el tier premium, $60 para la mayoria del catalogo, $80 para DeepSeek V4.1 Flash, e ilimitado para las promos gratuitas. Los topes de 5 horas y semanal son porciones de esa cifra mensual:

| Limite | Parte de la cuota mensual |
|--------|--------------------------|
| Por 5 horas | 20% |
| Por semana | 50% |
| Por mes | 100% |

Asi que un modelo del tier de $60 te da $12 cada 5 horas y $30 por semana — la misma matematica que los topes planos de antes — mientras que un modelo de $15 como GLM-5.3 o Kimi K3 te da $3 cada 5 horas. Go Plus ($40/mes) sube la cuota mensual de cada modelo, mas o menos 2-4x segun el modelo.

Si tienes creditos en tu saldo de la Console, puedes activar la opcion "Use balance". Cuando se agotan los limites de Go, cae al saldo pay-as-you-go en vez de bloquear las solicitudes. Y si llegas al tope de un modelo de pago, los previews gratuitos (LongCat 2.5, Cat Jam) siguen funcionando.

## Configuracion

La configuracion toma unos dos minutos.

1. Ve a [opencode.ai/auth](https://go.bitdoze.com/opencode-go) y crea una cuenta
2. Suscribete a Go (o Go Plus) en la Console y copia tu API key
3. En OpenCode, ejecuta `/connect`
4. Selecciona `OpenCode Go` y pega tu clave
5. Ejecuta `/models` para ver los modelos disponibles

Algo que cambio desde el lanzamiento: ya no hay una sola URL base. El endpoint depende del protocolo del modelo:

| Endpoint | Modelos |
|----------|---------|
| `https://opencode.ai/inference/go/openai/v1/chat/completions` | GLM, Kimi, DeepSeek, MiMo, LongCat, Hy, Space Bunny, previews gratuitos |
| `https://opencode.ai/inference/go/openai/v1/responses` | Grok, modelos GPT Luna, Muse Spark |
| `https://opencode.ai/inference/go/anthropic/v1/messages` | Claude Haiku 5.5, MiniMax, Qwen3.8/3.7 |

Trae la lista viva de modelos y sus IDs con:

```bash
curl https://opencode.ai/inference/go/v1/models
```

### Usar Go con otros agentes

OpenCode ahora publica una lista de clientes validados con Go — Hermes, Claude Code, Codex, ZCode, Pi, jcode y Kilo Code CLI envian bien las cabeceras de sesion. Algunos (DeepSeek Harness, GitHub Copilot Chat, Kimi Code, MiMo Code) tienen soporte incompleto que puede degradar el enrutado. Uses el cliente que uses, pon un user agent real y un `x-opencode-session` estable por conversacion — Go lo usa para el cacheo de prompts y el enrutado.

<Tabs>
<Tab name="Hermes Agent">
```bash
echo "OPENAI_BASE_URL=https://opencode.ai/inference/go/openai/v1/chat/completions" >> ~/.hermes/.env
echo "OPENAI_API_KEY=tu-clave-go" >> ~/.hermes/.env
hermes config set model opencode-go/glm-5.3-flash
```
Consulta la [guia de Hermes](/es/guia-configuracion-hermes-agent/) para instrucciones completas. Hermes envia la cabecera de sesion en builds con el PR #101864 (mergeado despues de v0.21.0).
</Tab>
<Tab name="OpenClaw">
Configura la URL base como `https://opencode.ai/inference/go/openai/v1/chat/completions` y usa tu API key de Go en la configuracion de OpenClaw. Consulta el articulo de [alternativas a OpenClaw](/openclaw-alternatives/) para mas detalles.
</Tab>
<Tab name="Pi Agent">
```bash
export OPENAI_BASE_URL=https://opencode.ai/inference/go/openai/v1/chat/completions
export OPENAI_API_KEY=tu-clave-go
# /model, selecciona el proveedor opencode-go
```
Consulta la [guia de Pi](/es/guia-configuracion-pi-agent/) para instrucciones completas.
</Tab>
<Tab name="Mastra">
En la configuracion de tu agente Mastra, usa OpenCode Go como proveedor de modelos:
```typescript
import { createOpenAI } from '@ai-sdk/openai';

const opencodeGo = createOpenAI({
  baseURL: 'https://opencode.ai/inference/go/openai/v1',
  apiKey: process.env.OPENCODE_API_KEY,
});

// Usar en la definicion del agente
const agent = new Agent({
  name: 'assistant',
  model: opencodeGo('glm-5.3-flash'),
  // ... otra configuracion
});
```
Consulta la [guia de Mastra](/build-ai-agent-mastra/) para instrucciones completas.
</Tab>

## Para quien es esto

Go tiene sentido si:

- No quieres gestionar multiples API keys y paneles de facturacion
- Estas fuera de EE.UU. y quieres acceso de baja latencia a los modelos (los endpoints de Singapur y UE ayudan)
- Quieres un costo mensual predecible en vez de facturacion por token
- Usas multiples agentes (OpenCode + Pi + Hermes + Mastra + ZCode) y quieres una sola clave para todos

Go no tiene sentido si:

- Solo usas uno o dos modelos y ya tienes acceso barato a la API
- Necesitas modelos que no estan en la lista (como Claude Sonnet/Opus o los tiers Pro de GPT — Haiku 5.5 es el unico Claude)
- Haces trabajo de produccion intensivo que necesita limites muy altos o ilimitados — aunque Go Plus a $40/mes suaviza eso
- Tu cliente esta en la lista de problematicos (DeepSeek Harness, Copilot Chat, Kimi Code, MiMo Code tienen lagunas en las cabeceras de sesion)

## Como se compara con gestionar tus propias clave

Hice los numeros para mi propio uso. Normalmente uso MiniMax M2.7 y DeepSeek V4 Pro a traves de sus APIs directas. Mi costo mensual con claves API directas era de $15-20 dependiendo de cuanto usaba los agentes ese mes.

Con Go a $10/mes, tengo acceso a esos mismos modelos mas otros que no me habria molestado en configurar. Meses despues, los limites siguen sin morderme en el uso diario normal — las unicas veces que toque un tope fueron sesiones deliberadas con Grok y Kimi K3.

La contrapartida es el control. Con claves API directas, puedo cambiar de proveedor si uno falla. Con Go, dependo del equipo de OpenCode para manejar la conmutacion por error. En la practica, no he tenido problemas de tiempo de inactividad, pero vale la pena mencionarlo.

<Accordion label="¿Como se compara Go con OpenRouter?" group="faq">
OpenRouter es un agregador de pago por token. Cargas creditos y pagas por lo que usas. Go es una suscripcion mensual fija con limites de uso. Si usas muchos tokens, Go es mas barato. Si usas muy pocos tokens, OpenRouter podria ser mas barato. Go tambien incluye modelos de proveedores que no estan en OpenRouter.
</Accordion>

<Accordion label="¿Puedo usar Go con herramientas que no sean OpenCode?" group="faq">
Si. Los endpoints de Go hablan protocolos OpenAI-compatible, Responses y Anthropic segun el modelo. Cualquier herramienta que soporte endpoints personalizados en uno de esos protocolos puede usarlo — Hermes, OpenClaw, Pi Agent, Mastra, Claude Code, Codex y ZCode estan validados. Configura la URL base con el endpoint `https://opencode.ai/inference/go/...` correspondiente y usa tu API key de Go.
</Accordion>

<Accordion label="¿Que pasa si alcanzo los limites de uso?" group="faq">
Las solicitudes se bloquean hasta que el limite se reinicia. El limite de 5 horas se reinicia de forma continua y el semanal cada 7 dias. Si tienes creditos en tu saldo de la Console, puedes activar "Use balance" para continuar. Los previews gratuitos (LongCat 2.5, Cat Jam) siguen disponibles de todos modos.
</Accordion>

<Accordion label="¿Mi codigo se usa para entrenamiento?" group="faq">
Mayormente no, con excepciones reales. La mayoria de modelos mantienen cero retencion y no entrenan. Grok 4.7/4.6, GPT 6 Luna, GPT 5.6 Luna, Claude Haiku 5.5 y Cat Jam Free guardan logs 30 dias por monitorizacion de abuso. Los modelos Contributor — Gemini 4 Argon y Muse Spark 1.2/1.3 — tienen descuento porque tus prompts y completions pueden usarse para entrenamiento. El acuerdo de cero retencion de DeepSeek se renueva mensualmente. Es su politica publicada; yo no la he auditado por mi cuenta.
</Accordion>

## Mi opinion tras meses de uso

Si ya tienes claves baratas y solo usas un modelo, Go es opcional. Comodo, no cambia la vida. Para mi el gancho es la simplicidad: una factura, una clave, y funciona en todos los agentes que ya uso. El catalogo casi se duplico desde que me di de alta, y existe Go Plus si el tier de $10 se queda corto.

Si todavia andas copiando cinco API keys, el mes a $10 se justifica solo. Dejo Grok, GLM-5.3 y Kimi K3 para lo dificil, MiniMax M3 o GLM-5.3-Flash para sesiones normales, y DeepSeek V4.1 Flash o MiMo cuando solo quiero volumen.

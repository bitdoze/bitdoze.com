Los mejores prompts para Fish Shell en 2026 son Tide, Starship, Pure e Hydro, además de los temas que Fish incluye de serie. Fish viene con un prompt por defecto funcional, pero la mayoría de la gente lo reemplaza por algo con más información: rama de git, duración de comandos, versiones de lenguaje. Esta guía cubre la instalación y configuración de cada uno, notas de compatibilidad con Fish 4.x y cómo elegir el prompt adecuado para tu flujo de trabajo.

Probado con Fish 4.9.3, Tide 6.2.1, Starship 1.27.0 y Pure 4.19.2 (noviembre de 2026).

**Qué necesitas antes de empezar:**

<ListCheck>
<ul>
<li>Fish shell instalado (3.x o 4.x; consulta las notas de Fish 4 más abajo). ¿Nuevo en Fish? Revisa antes nuestra <a href="/es/fish-shell-vs-bash-vs-zsh-comparacion/">comparativa de Fish vs Bash vs Zsh</a>.</li>
<li><a href="/es/mejores-plugins-fish-shell/">Gestor de plugins Fisher</a> (necesario para Tide, Pure e Hydro)</li>
<li>Una Nerd Font configurada en tu emulador de terminal (recomendada para los iconos de Tide y Starship; opcional para Pure e Hydro)</li>
</ul>
</ListCheck>

Más allá del prompt, el [autocompletado y las sugerencias de Fish Shell](/es/fish-shell-autocompletado-sugerencias/) son la mitad de la experiencia de usuario y vale la pena ajustarlos después de que tu prompt quede bien.

## Temas integrados de Fish Shell

Antes de instalar nada, Fish tiene su propio sistema de temas. Ejecuta:

```fish
fish_config theme show
```

Esto imprime los temas de color disponibles directamente en tu terminal. Para aplicar uno:

```fish
fish_config theme choose dracula
fish_config theme save
```

Puedes forzar una variante oscura o clara con `fish_config theme choose THEME --color-theme=(dark|light)`.

Para prompts específicamente:

```fish
fish_config prompt show
fish_config prompt choose informative
fish_config prompt save
```

Ejecuta `fish_config prompt list` para ver todo lo que hay disponible. El conjunto exacto varía según la versión de Fish. Estos prompts integrados son ligeros en funcionalidades (sin renderizado asíncrono, sin detección de lenguaje), pero cargan al instante y no necesitan dependencias externas.

También puedes ejecutar `fish_config` sin argumentos para abrir una herramienta de configuración en el navegador donde puedes previsualizar todo de forma visual. Si quieres personalizar los colores más allá del prompt, consulta nuestra [guía de resaltado de sintaxis en Fish Shell](/es/fish-shell-resaltado-sintaxis/).

## Tide: el prompt potente nativo de Fish

[Tide](https://github.com/IlanCosman/tide) es el prompt nativo de Fish con más funcionalidades. Es para Fish lo que Powerlevel10k es para Zsh: renderizado asíncrono, un asistente de configuración, integración profunda con git y un prompt transitorio que colapsa los prompts antiguos para ahorrar scrollback. Tiene mantenimiento activo (v6.2.1, noviembre de 2026, 4.3k estrellas).

### Instalar Tide

Necesitas [Fisher](/es/mejores-plugins-fish-shell/) primero. Después:

```fish
fisher install IlanCosman/tide@v6
tide configure
```

Verifica que se instaló:

```fish
fisher list | grep tide
```

El prompt cambia inmediatamente después de la instalación.

<Notice type="info" title="Requisito de Fish 4.x">
En Fish 4.3 o posterior, asegúrate de tener Tide ≥ 6.2.1. Las versiones anteriores de v6 tienen errores con el modo vi y al redimensionar la ventana en Fish 4.x; la v6.2.1 (noviembre de 2026) corrigió ambos problemas.
</Notice>

### Configurar Tide

El asistente `tide configure` te guía a través de:

- Estilo Powerline vs. texto plano
- Prompt de una o dos líneas
- Estilo de iconos (requiere Nerd Font para iconos)
- Colores y espaciado

Toma unos 30 segundos y te da un prompt pulido sin edición manual.

<Tabs>
<Tab name="Asistente interactivo">
Ejecuta `tide configure` y responde a las preguntas. Es la vía habitual. Verás una vista previa en vivo a medida que haces cada elección.
</Tab>
<Tab name="Automatizado (dotfiles)">
Ejecuta `tide configure --auto` para configuraciones no interactivas. Aplica un preset por defecto sin preguntar, que es lo que necesitas en scripts bootstrap de dotfiles o entornos CI donde no hay una TTY para responder preguntas.
</Tab>
</Tabs>

Más allá del asistente, puedes extender Tide [creando funciones personalizadas de Fish Shell](/es/fish-shell-funciones-comandos-personalizados/) que inyecten elementos en el prompt.

### Qué muestra Tide

Por defecto, Tide muestra:

- Directorio actual (truncado inteligente al prefijo único más corto)
- Rama y estado de git (sin seguimiento, modificados, en staging, adelante/atrás)
- Duración de comandos (para comandos lentos)
- Versiones de lenguaje (Node, Python, Rust, Go, Bun, etc.) cuando estás en un proyecto relevante. Para Node, puedes [gestionar versiones de Node con nvm.fish](/es/nvm-fish-shell/). El elemento `go` también se activa en workspaces `go.work` (v6.2.1).
- Hora, trabajos en segundo plano (jobs) y código de salida en el prompt derecho

Nerd Font recomendada: instala MesloLGS NF o cualquier Nerd Font para obtener el mejor soporte de iconos. Sin una, Tide recurre al modo de solo texto, que sigue viéndose bien. Tanto la [configuración de la terminal Ghostty](/es/terminal-ghostty/) como [WezTerm en macOS](/es/instalar-wezterm-mac/) renderizan bien las Nerd Fonts.

### Personalizar Tide

Después del asistente, ajusta configuraciones individuales:

```fish
# Change which items appear on the left and right
set --universal tide_left_prompt_items pwd git newline character
set --universal tide_right_prompt_items status cmd_duration context jobs node

# Change git status symbols
set --universal tide_git_icon ""

# Apply changes without restarting the shell
tide reload
```

<Notice type="info" title="Aplica los cambios al instante">
Después de cualquier cambio con `set --universal`, ejecuta `tide reload` para verlo de inmediato. No hace falta reiniciar el shell.
</Notice>

Ejecuta `set --universal | grep tide` para ver todas las variables de Tide. Algunas útiles:

- `tide_jobs_number_threshold`: muestra el número de trabajos solo por encima de N trabajos en segundo plano
- `tide_transient_prompt`: controla si los prompts antiguos se colapsan para ahorrar scrollback

### Tide en Fish 4.x

Fish 4.x (actualmente 4.9.3) está basado en Rust desde la reescritura de la versión 4.0. Tide v6.2.1 (noviembre de 2026) es principalmente una versión de compatibilidad con Fish 4. Corrige:

- Carácter del prompt en modo vi mostrando `❮` y `vi_mode` mostrando `D` con los atajos por defecto en Fish 4.3+
- Pánico `Broken pipe` al redimensionar la terminal
- Fallos del prompt en shells en ejecución tras actualizar Fish mediante Homebrew
- Pulsaciones de teclado perdidas mientras el prompt se renderiza en segundo plano

<Notice type="warning" title="Usuarios de Fish 4.3+">
Si usas Fish 4.3+ y ves caracteres extraños en modo vi o pánicos al redimensionar, actualiza Tide a v6.2.1+ antes de depurar cualquier otra cosa. Ejecuta `fisher update IlanCosman/tide` para obtener la última versión.
</Notice>

## Starship: el prompt multi-shell

[Starship](https://starship.rs) es un prompt multi-shell escrito en Rust. Funciona con Fish, Zsh, Bash, PowerShell y más. Con más de 60k estrellas en GitHub y mantenimiento activo, es la opción práctica si usas múltiples shells o quieres compartir la configuración del prompt con compañeros de equipo que usan shells distintos.

### Instalar Starship

```bash
curl -sS https://starship.rs/install.sh | sh
```

Añade a tu configuración de Fish:

```fish
# ~/.config/fish/config.fish
starship init fish | source
```

Verifica:

```bash
starship --version   # should be >= 1.27.0
```

<Notice type="warning" title="Actualización de seguridad">
Starship v1.27.0 (octubre de 2026) corrigió dos avisos de seguridad de gravedad media: GHSA-x486-6jjc-phfp (DoS por enlaces simbólicos durante el renderizado del prompt) y GHSA-679r-jwc5-r5m3 (omisión de comprobación de propiedad en git). Si instalaste Starship antes de octubre de 2026, actualízalo: `starship update` (para instalaciones con install.sh) o mediante tu gestor de paquetes.
</Notice>

Tengo una guía dedicada sobre [configurar Starship con Fish Shell](/es/fish-shell-configurar-starship/) con ejemplos de configuración y selección de presets. Si ya lo configuraste con Zsh (quizás siguiendo mi [guía de Starship y Ghostty](/es/terminal-starship-ghostty/)), el archivo de configuración TOML se transfiere directamente.

### Presets de Starship

Starship cuenta con un sistema de presets para aplicar temas rápidamente. Los presets actuales incluyen `bracketed-segments`, `catppuccin-powerline`, `gruvbox-rainbow`, `jetpack`, `nerd-font`, `no-empty-icons`, `no-nerd-font`, `no-runtimes`, `pastel-powerline`, `plain-text`, `pure-preset` y `tokyo-night`.

Uno que merece destacarse: `pure-preset` te da el aspecto minimalista de Pure dentro de Starship. Resulta muy útil si quieres la estética de Pure pero necesitas soporte multi-shell.

```bash
starship preset tokyo-night -o ~/.config/starship.toml
starship preset pure-preset -o ~/.config/starship.toml   # Pure look, cross-shell
```

<ListCheck>
<ul>
<li>¿Quieres el aspecto de Pure? → <code>pure-preset</code></li>
<li>¿Estilo Powerline? → <code>catppuccin-powerline</code> o <code>pastel-powerline</code></li>
<li>¿Sin Nerd Font? → <code>no-nerd-font</code> o <code>plain-text</code></li>
<li>¿Mostrar todo? → <code>nerd-font</code></li>
</ul>
</ListCheck>

La v1.27.0 también añadió módulos de Jujutsu VCS (`jj_status`, `jj_change` y otros; no están en el formato por defecto, añádelos manualmente o mediante el módulo `vcs`) y detección de `.tofu` de OpenTofu en el módulo de terraform.

### Starship vs Tide

Starship no tiene renderizado asíncrono, pero es lo suficientemente rápido como para que rara vez importe en repositorios de tamaño normal. La configuración es un único archivo TOML (`~/.config/starship.toml`) en lugar de variables universales, lo que algunas personas encuentran más fácil de versionar. Si `git status` va lento en repositorios enormes, `command_timeout` en starship.toml (por defecto 500 ms) es el ajuste clave. Starship descarta los comandos lentos en lugar de quedarse colgado indefinidamente.

Otra opción multi-shell que conviene conocer: Oh My Posh (más de 23k estrellas, con mantenimiento activo). Su configuración usa JSON/YAML en lugar de TOML. Si prefieres ese formato o necesitas sus funciones específicas, es una alternativa sólida a Starship.

## Pure: el prompt minimalista para Fish

[Pure](https://github.com/pure-fish/pure) es un port del popular prompt Pure de Zsh (consulta los [mejores plugins de Oh My Zsh](/es/mejores-plugins-oh-my-zsh/) si vienes de ese mundo). Es minimalista: solo tu directorio, rama de git y un carácter `❯` que se vuelve rojo después de un comando fallido. Actualmente va por la v4.19.2 (octubre de 2026), con soporte para Fish 3.x y 4.x.

### Instalar Pure

```fish
fisher install pure-fish/pure
```

Sin asistente de configuración. Funciona inmediatamente con valores por defecto razonables. Verifica con `fisher list | grep pure`. El nuevo prompt aparece al instante.

### Qué muestra Pure

- Directorio actual
- Rama de git y estado dirty/clean
- Duración de comandos (para comandos largos)
- Nombre de usuario y hostname por SSH
- Nombre de virtualenv de Python cuando está activo
- El carácter de prompt `❯`

Si te gusta un prompt limpio y discreto que no estorbe, es este. Pure no muestra versiones de lenguaje ni información en el lado derecho a menos que lo habilites. Es para quienes quieren menos en pantalla, no más.

### Personalizar Pure

Pure usa variables de Fish para la configuración:

```fish
set --universal pure_show_system_time true
set --universal pure_enable_single_line_prompt true
set --universal pure_show_jobs true

# Sub-second command duration (new in v4.19.2)
set --universal pure_threshold_command_duration 0
set --universal pure_show_subsecond_command_duration true
```

La v4.19.2 (octubre de 2026) añadió las variables de duración por debajo del segundo. Útil si quieres ver los tiempos de comandos rápidos, no solo de los lentos.

## Hydro: Git asíncrono, cero configuración

[Hydro](https://github.com/jorgebucaran/hydro) es todavía más minimalista que Pure. Está hecho por el autor de Fisher y muestra rama de git, duración de comandos y código de salida. Poco más.

```fish
fisher install jorgebucaran/hydro
```

El atractivo de Hydro es cero configuración y prácticamente cero sobrecarga. El estado de git se actualiza de forma asíncrona: el prompt se redibuja al instante y la información de la rama aparece un momento después, el mismo enfoque que Tide. Si solo quieres una rama de git en tu prompt sin complicarte, Hydro hace exactamente eso.

<Notice type="info" title="Estado de mantenimiento">
Hydro es software estable y de bajo cambio. El autor lo considera terminado, no abandonado. El último commit fue en febrero de 2026 ("Fix CJK branch name truncation"). No tiene versiones etiquetadas; Fisher sigue el repositorio directamente.
</Notice>

## Comparativa de prompts para Fish Shell

| | Tide | Starship | Pure | Hydro | Integrado |
|---|---|---|---|---|---|
| Renderizado asíncrono | Sí | No | Parcial | Sí (repintado asíncrono de git-status) | No |
| Asistente de configuración | Sí | No | No | No | Interfaz web |
| Multi-shell | No (solo Fish) | Sí | No (solo Fish) | No (solo Fish) | No |
| Formato de configuración | Variables universales | Archivo TOML | Variables universales | Mínimo | Interfaz web / vars |
| Nerd Font necesaria | Recomendada | Recomendada | No | No | No |
| Versiones de lenguaje | Sí | Sí | No | No | No |
| Integración con Git | Profunda | Buena | Básica | Básica | Ninguna |
| Prompt transitorio | Sí | No | No | No | No |
| Tiempo de configuración | 1 minuto | 2-3 minutos | 30 segundos | 10 segundos | 30 segundos |

## ¿Qué prompt de Fish Shell deberías usar?

**Tide** si Fish es tu único shell y quieres el prompt más vistoso e informativo sin lag. El asistente hace que la configuración sea fácil.

**Starship** si usas múltiples shells o quieres un archivo de configuración TOML que puedas versionar. Lo cubrí en profundidad en mi [guía de Starship + Fish](/es/fish-shell-configurar-starship/).

**Pure** si prefieres el minimalismo y un diseño probado (lleva años siendo popular en el mundo Zsh).

**Hydro** si quieres el prompt mínimo viable absoluto.

**Integrado** si no quieres instalar nada extra y los prompts por defecto te son suficientes.

Personalmente uso Starship porque alterno entre Fish y Zsh en distintas máquinas. Si solo usara Fish, probablemente elegiría Tide.

<ListCheck>
<ul>
<li>¿Solo Fish y quieres el máximo de funciones? → Tide</li>
<li>¿Múltiples shells o configuración bajo control de versiones? → Starship</li>
<li>¿Prompt minimalista y discreto? → Pure</li>
<li>¿Mínimo absoluto, cero configuración? → Hydro</li>
<li>¿No quieres instalar nada? → Temas integrados</li>
</ul>

## Verifica y revierte tu prompt

<Notice type="info" title="Cambiar es seguro">
Cambiar de prompt es seguro. Nada toca la configuración de tu shell más allá de una línea en config.fish o la lista de plugins de Fisher. Aquí tienes cómo comprobar qué está activo y deshacerlo.
</Notice>

**Verifica qué está sirviendo tu prompt:**

```fish
type fish_prompt
fish --version
starship --version
fisher --version
```

`type fish_prompt` te dice qué función está renderizando tu prompt. Si ves `starship`, Starship está activo. Si ves `fish_prompt` definido por Tide o Pure, eso es lo que se está ejecutando.

**Vuelve al prompt por defecto de Fish:**

```fish
fisher remove IlanCosman/tide    # or pure-fish/pure or jorgebucaran/hydro
fish_config prompt choose default
fish_config prompt save
```

Para Starship, elimina la línea `starship init fish | source` de `~/.config/fish/config.fish` y abre un nuevo shell.

Si quieres ir más allá del prompt y [crear funciones personalizadas de Fish Shell](/es/fish-shell-funciones-comandos-personalizados/), ese es el siguiente paso natural después de que tu prompt quede bien.

**Fallos comunes:**

<Accordion label="Cajas tofu / glifos extraños" group="troubleshooting">
Falta una Nerd Font. Tide y Starship usan glifos de Nerd Font para los iconos. Sin una, verás recuadros o signos de interrogación. Solución: instala MesloLGS NF (o cualquier Nerd Font) y configúrala en tu emulador de terminal. Hydro y Pure usan glifos planos y no se ven afectados.
</Accordion>

<Accordion label="Dos prompts peleándose entre sí" group="troubleshooting">
Están instalados al mismo tiempo el init de Starship y Tide. Gana el último en cargarse y resulta confuso de depurar. Solución: elimina uno. Ejecuta `fisher remove IlanCosman/tide` o borra la línea `starship init fish | source` de config.fish. Después abre un nuevo shell.
</Accordion>

<Accordion label="El prompt se queda colgado en repositorios grandes" group="troubleshooting">
Starship renderiza de forma síncrona. En repositorios enormes, `git status` puede detener el prompt hasta `command_timeout` (por defecto 500 ms). Solución: aumenta `command_timeout` en `~/.config/starship.toml`, o pásate a Tide (renderizado asíncrono; el prompt se pinta primero y la información de git se rellena después).
</Accordion>

<Accordion label="Errores de ruta en macOS/WSL tras actualizar" group="troubleshooting">
Las rutas con mayúsculas y minúsculas discordantes rompían versiones antiguas de Tide (error `set: --erase`). Tide v6.2.1 (#630) lo corrigió. Solución: `fisher update IlanCosman/tide`.
</Accordion>

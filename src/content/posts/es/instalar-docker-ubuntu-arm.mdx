Docker ha revolucionado la forma en que pensamos sobre el desarrollo y el despliegue de software. Con Docker, puedes empaquetar tu aplicación y sus dependencias en un contenedor, lo que facilita moverla y gestionarla. Docker Compose simplifica aún más las aplicaciones Docker de múltiples contenedores. En esta guía, te mostraremos cómo instalar Docker y Docker Compose en sistemas Ubuntu ARM.

ARM y x86 son dos de los principales tipos de arquitecturas de CPU que dominan distintos ámbitos de la computación. ARM, que significa Advanced RISC Machine, es conocida por su eficiencia energética y se usa predominantemente en dispositivos móviles, gadgets de IoT y, cada vez más, en servidores. Por otro lado, la arquitectura x86, desarrollada por Intel, ha sido durante mucho tiempo el estándar en la computación de escritorio y de servidores.

La diferencia clave está en su filosofía de diseño. ARM se basa en un conjunto de instrucciones más simple, lo que permite un menor consumo de energía, algo crucial para los dispositivos alimentados por batería. Las arquitecturas x86 ofrecen un amplio conjunto de instrucciones, optimizado para un alto rendimiento en tareas de computación complejas. Ambas tienen sus pros y sus contras, pero con la creciente presencia de ARM en los mercados de servidores y escritorio, es cada vez más importante saber trabajar con ambas.

## Pasos para Instalar Docker y Docker Compose en Sistemas Ubuntu ARM


> Si te interesa ver algunas aplicaciones autoalojadas, open source y gratuitas muy interesantes, puedes consultar la [sección de self-hosted de toolhunt.net](https://toolhunt.net/sh/).

### Paso 1: Actualizar la Lista de Paquetes

Empieza actualizando la lista de paquetes para asegurarte de tener la versión más reciente de los paquetes.

```bash
sudo apt-get update
```

- **sudo:** Ejecuta el comando como superusuario.
- **apt-get:** Utilidad de gestión de paquetes de Ubuntu.
- **update:** Obtiene la lista de paquetes del repositorio.

### Paso 2: Instalar los Paquetes Necesarios

Antes de instalar Docker, necesitarás instalar algunos paquetes esenciales.

```bash
sudo apt-get install ca-certificates curl gnupg lsb-release
```

- **ca-certificates:** Para la comunicación web segura.
- **curl:** Herramienta de línea de comandos para transferir datos.
- **gnupg:** Para la gestión de claves.
- **lsb-release:** Proporciona información sobre la distribución Linux.

### Paso 3: Crear el Directorio del Keyring

Crea un directorio para almacenar la clave GPG de Docker.

```bash
sudo mkdir -p /etc/apt/keyrings
```

- **mkdir:** Comando para crear directorios.
- **"-p":** Crea los directorios padre según sea necesario.

### Paso 4: Añadir la Clave GPG de Docker

Descarga y añade la clave GPG de Docker al directorio del keyring.

```bash
curl -fsSL https://download.docker.com/linux/debian/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
```

### Paso 5: Añadir el Repositorio de Docker

Añade el repositorio de Docker a tu lista de fuentes.

```bash
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  jammy stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

- **"dpkg --print-architecture":** Muestra la arquitectura del sistema.
- **tee:** Lee de la entrada estándar y escribe en la salida estándar y en archivos.

### Paso 6: Actualizar la Lista de Paquetes de Nuevo

Ejecuta una actualización de nuevo para obtener los paquetes del repositorio de Docker recién añadido.

```bash
sudo apt-get update
```

### Paso 7: Instalar Docker y Docker Compose

Por último, instala Docker y Docker Compose.

```bash
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin docker-compose
```

- **docker-ce:** Docker Community Edition.
- **docker-ce-cli:** CLI de Docker.
- **containerd.io:** Runtime de contenedores.
- **docker-compose-plugin:** Plugin de Compose para la CLI.
- **docker-compose:** Para definir y ejecutar aplicaciones Docker de múltiples contenedores.

A veces necesitas una lista simple de todas las URLs de tus entradas para un mapa de redirecciones, una auditoría SEO, una migración o simplemente para tenerla a mano. Hay varias formas de hacerlo. El método SQL de abajo es el más rápido si tienes acceso a phpMyAdmin. También he añadido alternativas con WP-CLI y un plugin al final.

## Pasos

### 1. Abre phpMyAdmin

Inicia sesión en el panel de control de tu hosting y haz clic en phpMyAdmin.

<Picture formats={["webp"]} fallbackFormat="webp" src={imgPhpMyAdmin} alt="enlace de phpMyAdmin en el panel de control del hosting" />

### 2. Selecciona tu base de datos y abre la pestaña SQL

Haz clic en tu base de datos de WordPress en la barra lateral izquierda y luego abre la pestaña **SQL**.

<Picture formats={["webp"]} fallbackFormat="webp" src={imgSqlTab} alt="pestaña SQL de phpMyAdmin" />

### 3. Ejecuta la consulta

Pega el siguiente SQL, sustituyendo el dominio por el tuyo:

```sql
SELECT post_title, CONCAT('https://yourdomain.com/', post_name)
FROM wp_posts
WHERE post_status = 'publish'
AND post_type = 'post';
```

Si el prefijo de tus tablas no es `wp_`, ajústalo en consecuencia (comprueba el nombre real de la tabla en la barra lateral izquierda).

Pulsa **Continuar**.

<Picture formats={["webp"]} fallbackFormat="webp" src={imgSqlGo} alt="Ejecutando la consulta SQL en phpMyAdmin" />

### 4. Exporta los resultados

Aparece una tabla con los títulos y las URLs de las entradas. Haz clic en **Exportar**.

<Picture formats={["webp"]} fallbackFormat="webp" src={imgExport} alt="botón Exportar de phpMyAdmin" />

Elige el formato de archivo (CSV funciona bien para hojas de cálculo), define el delimitador si es necesario y pulsa **Continuar**.

<Picture formats={["webp"]} fallbackFormat="webp" src={imgFormat} alt="selección del formato de exportación en phpMyAdmin" />

Obtendrás un archivo con el título de cada entrada publicada y su URL. Para incluir páginas o tipos de contenido personalizados, cambia `post_type = 'post'` a `post_type = 'page'` o elimina por completo la condición de post_type para obtenerlo todo.

## Alternativa: WP-CLI (si tienes acceso SSH)

Si tienes acceso SSH a tu servidor, WP-CLI es más rápido que phpMyAdmin para esto. Ejecuta:

```bash
wp post list --post_type=post --post_status=publish --fields=post_title,post_name --format=csv > posts.csv
```

Esto exporta los títulos y los slugs a un archivo CSV. El campo `post_name` es el slug de la URL, así que tendrías que anteponer tu dominio. Para obtener las URLs completas directamente:

```bash
wp post list --post_type=post --post_status=publish --fields=post_title,guid --format=csv > posts.csv
```

El campo `guid` contiene la URL completa. Puedes añadir `--fields=ID,post_title,post_date,guid` para incluir los IDs y las fechas de las entradas si los necesitas para una auditoría.

## Alternativa: el plugin Export All URLs

Si no quieres tocar SQL ni la línea de comandos, el plugin gratuito [Export All URLs](https://wordpress.org/plugins/export-all-urls/) lo hace desde el administrador de WordPress. Te permite filtrar por tipo de contenido, estado, rango de fechas y autor, y exporta a CSV. También incluye categorías, etiquetas y datos del autor si los necesitas. Instálalo, configúralo, exporta y luego desactívalo cuando termines.

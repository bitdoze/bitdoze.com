Ejecuta tus agentes de código en un VPS de 4-5 €/mes y contrólalos desde el móvil con la **app oficial gratuita Herdr Mobile** (iOS/Android por SSH/Tailscale hacia `herdr-core`) o con **Moshi + `moshi-hook v0.4.62`** (roaming Mosh UDP, aprobaciones en pantalla bloqueada y soporte para Herdr TUI y `herdr-core`).

Los agentes de programación no funcionan como una shell normal: lanzas un refactor, te alejas veinte minutos y el proceso se queda parado esperando un permiso de 5 segundos. Si viven en un servidor siempre encendido, cualquier portátil, tablet o móvil se convierte en una ventana desechable sobre la misma sesión.

El gran cambio respecto a septiembre de 2026: **Herdr ya tiene su propia app móvil oficial** para iPhone, iPad y Android. Aquí comparo ambos caminos y detallo cómo montarlos sin tropiezos.

<Notice type="info" title="Claude Code no se instala en tu teléfono">
Los agentes CLI, repositorios git y credenciales permanecen siempre en tu VPS o servidor doméstico. El teléfono actúa únicamente como terminal y timbre de avisos.
</Notice>

## Herdr Mobile oficial vs Moshi: ¿cuál te conviene?

Usa **Herdr Mobile** si corres `herdr-core` / Herdr Desktop y buscas un cliente oficial gratuito, sin cuenta y por SSH directo; usa **Moshi + `moshi-hook v0.4.62`** si trabajas en Herdr TUI (o ambos), necesitas transporte Mosh UDP en cobertura móvil inestable o quieres botones de Aprobar/Rechazar en la pantalla bloqueada y Chat View nativo.

| Característica | Herdr Mobile oficial | Moshi + `moshi-hook v0.4.62` |
|---|---|---|
| Precio | **Gratis** (App Store + Google Play) | Nivel SSH gratis; Pro `$7,99/mes` o `$69,99/año` (3 dispositivos) |
| Backend Herdr compatible | **Solo `herdr-core` (`hc`)** (sin Herdr TUI) | **Ambos**: Herdr TUI (`v0.9.5`) y `herdr-core` (`hc`) |
| Transporte | SSH directo / Tailscale SSH | SSH, Mosh (UDP), Eternal Terminal, Tailscale |
| Aprobación en pantalla bloqueada | Banner dentro de la app | Sí (push nativo + Live Activities vía `moshi-hook`) |
| Chat View nativo y diffs | Terminal real + compose + foto/voz | Terminal real + Chat View Tier-A (Claude/Codex/Hermes/Antigravity/OMP) + diffs |
| Crear git worktree desde móvil | Refleja espacios de escritorio | Crea worktrees desde un espacio Herdr (`v0.4.60+`) |
| Cuenta / relay | Ninguno (SSH directo) | Relay de avisos push (límite 256 caracteres; sin subir código) |

## Camino 1: Herdr Mobile oficial gratis + `herdr-core` en tu VPS

```bash
# En tu VPS Ubuntu/Debian
curl -fsSL https://releases.herdr.dev/core/install.sh | sh
sudo loginctl enable-linger $USER

# Arranca un agente en segundo plano
hc run --bg --name api claude
hc ls
```

Instala **Herdr** en [App Store](https://apps.apple.com/app/id6828898364) o [Google Play](https://play.google.com/store/apps/details?id=dev.herdr.app), añade tu VPS vía SSH o Tailscale SSH y gestiona todo desde la Inbox (deslizar derecha fija o marca leído; deslizar izquierda envía `Esc`; **compose** admite capturas, fotos y dictado en el propio teléfono sin redimensionar tu [Herdr Desktop](/es/herdr-app-layouts-y-mods/)).

## Camino 2: Moshi + Herdr TUI (o Core) con aprobaciones en pantalla bloqueada

![Arquitectura: servidor Herdr en VPS, cliente móvil Moshi sobre Mosh y moshi-hook enviando aprobaciones](@assets/images/26/09/herdr-moshi-architecture.webp)

![Moshi en iPhone ejecutando Claude Code sobre Mosh](@assets/images/26/09/moshi-dash.webp)

### Paso 1: Prepara el VPS (Herdr TUI + Mosh + UTF-8)

Un VPS de 2 vCPU / 4 GB en [Hetzner Cloud](https://go.bitdoze.com/hetzner) o [Hostinger VPS](https://go.bitdoze.com/hostinger-vps) sobra (ver [configuración de VPS para agentes IA](/es/vps-configuracion-codificacion-ia/) y [subidas de precios VPS](/es/subidas-precios-vps/)).

```bash
curl -fsSL https://herdr.dev/install.sh | sh
sudo ln -sf ~/.local/bin/herdr /usr/local/bin/herdr
herdr --version

sudo apt update && sudo apt install -y mosh tmux
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8

# Omite abrir puertos públicos si conectas solo por Tailscale
sudo ufw allow OpenSSH
sudo ufw allow 60000:61000/udp
```

Comprueba desde tu portátil que `ssh tu@vps 'command -v herdr'` imprime `/usr/local/bin/herdr` (si sale vacío, Moshi no detectará la pestaña Herdr).

### Paso 2: Empareja `moshi-hook` y activa linger

Copia el token desde **Moshi > Settings > Hooks** en tu teléfono:

```bash
curl -fsSL https://getmoshi.app/install.sh | sh
moshi-hook pair --token <TU_TOKEN>
moshi-hook install
sudo loginctl enable-linger $USER
moshi-hook serve
```

Desde `v0.4.34`, `moshi-hook` se actualiza solo cada 6 horas (`moshi-hook set auto-update ask` para confirmarlo manualmente). En `v0.4.62` (noviembre 2026) cubre tanto sesiones de Herdr TUI como espacios de `herdr-core`, y limita las notificaciones a 256 caracteres para no filtrar secretos.

![Flujo de aprobación: permiso del agente hacia moshi-hook, gateway Moshi, notificación en pantalla bloqueada y respuesta de vuelta al agente](@assets/images/26/09/moshi-hook-approval-flow.webp)

### Paso 3: Arranca agentes e integraciones

```bash
herdr
herdr integration install claude
herdr integration install codex
herdr session list --json
```

Combina Claude Code con [OpenCode](/es/guia-configuracion-opencode/) ([OpenCode Go](https://go.bitdoze.com/opencode-go)) o [Pi Agent](/es/guia-configuracion-pi-agent/) en pestañas separadas (en pantalla de móvil usa pestañas, no varios paneles divididos).

## Fallos típicos y soluciones rápidas

<ListCheck>
<ul>
<li><strong>Moshi no muestra la pestaña Herdr:</strong> ejecuta <code>sudo ln -sf ~/.local/bin/herdr /usr/local/bin/herdr</code> y comprueba que el servidor Herdr está activo.</li>
<li><strong><code>moshi-hook</code> muere al cerrar SSH:</strong> activa <code>sudo loginctl enable-linger $USER</code> y verifica con <code>moshi-hook status</code>.</li>
<li><strong>Herdr Mobile aparece vacío:</strong> asegúrate de lanzar los agentes dentro de <code>herdr-core</code> (<code>hc</code>), no dentro de <code>herdr</code> TUI, y sin tmux anidado.</li>
<li><strong>Desconectar vs detener:</strong> <code>Ctrl+B q</code> desconecta sin cortar nada; <code>herdr server stop</code> mata todos los procesos.</li>
</ul>
</ListCheck>

## Seguridad y preguntas frecuentes

Mantén claves SSH sin contraseña, bloqueo biométrico en el móvil y Tailscale (o [Headscale autoalojado](/es/headscale-tailscale-autoalojado/)) para evitar puertos abiertos. Consulta [seguridad en servidores con UFW](/es/informe-seguridad-bsi-docker-ufw/).

<Accordion label="¿Funciona la app oficial Herdr Mobile con Herdr TUI?" group="faq" expanded="true">
No. Herdr Mobile se conecta solo a `herdr-core` (`hc`). Si usas Herdr TUI (`v0.9.5`), elige Moshi, ColliePWA, Heeler o SSH/Mosh.
</Accordion>

<Accordion label="¿Merece la pena Moshi Pro si Herdr Mobile es gratis?" group="faq">
Si ya trabajas con `herdr-core` sobre Tailscale y no necesitas Mosh UDP ni aprobaciones en pantalla bloqueada, empieza con **Herdr Mobile** gratis. Pasa a **Moshi Pro** ($7,99/mes o $69,99/año) si cambias mucho entre Wi-Fi y 4G/5G, quieres Chat View nativo o combinas Herdr TUI y tmux con `herdr-core`.
</Accordion>

<Accordion label="¿Qué pasa si reinicio el VPS?" group="faq">
Los procesos en marcha se detienen. En Herdr TUI se restaura el layout y puedes reanudar sesiones por ID con `herdr integration install`. En `herdr-core v0.1.21`, activa `restore_screen = true` en `config.toml` para conservar la última pantalla visible tras reiniciar.
</Accordion>

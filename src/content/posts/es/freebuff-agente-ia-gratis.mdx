## ¿Qué es Freebuff?

Freebuff es el producto de codificación gratuito con publicidad construido sobre [Codebuff](https://github.com/CodebuffAI/freebuff), el framework multi-agente open source (Apache-2.0, ~13.6k estrellas en GitHub). Codebuff como framework es lo que impulsa la orquestación y el SDK; Freebuff es lo que realmente instalas. Los anuncios mostrados durante tu sesión pagan el tiempo de modelo.

Ya no es solo una herramienta de terminal. Ahora hay cinco productos:

| Producto | Qué hace |
| --- | --- |
| **Freebuff CLI** | El agente de terminal original: `npm install -g freebuff` |
| **Freebuff Desktop** | App para macOS, Windows y Linux que corre agentes en paralelo en workspaces aislados |
| **Freebuff Web** | Constructor prompt-to-app para apps full-stack en el navegador |
| **Freebuff Cloud** | Corre agentes sobre cualquier repositorio de GitHub conectado |
| **Freebuff Chat** | Chat general de investigación y razonamiento |

También hay una app Android ("Freebuff en tu bolsillo"), con iOS anunciada como próximamente. Los hilos viven en la nube, así que puedes empezar una tarea en tu escritorio, revisarla desde el móvil y terminarla en el navegador. Las integraciones cubren GitHub, Linear, Notion, Stripe, Vercel, Supabase, Sentry, PostHog y Resend.

En lugar de un solo modelo haciéndolo todo, Freebuff coordina nueve subagentes especializados: búsqueda de archivos, planificación, edición, revisión de código, uso del navegador, etc. También orquesta slash commands pulidos — `/interview` → `/plan` → implementar → `/review` te lleva de una idea vaga a un PR.

## Cómo funciona ahora el nivel gratuito

Esto cambió desde el lanzamiento, y conviene entenderlo antes de empezar. El uso se mide en **horas**, no en sesiones. Cada sesión dura una hora con mensajes ilimitados; un modelo con multiplicador 3x consume tres horas por sesión.

- **Plan gratuito**: 30 horas repuestas a diario, sin tarjeta. Las horas diarias se reinician a medianoche hora local y no se acumulan.
- **Modelos sin medición**: a acceso completo, GLM 5.3 Flash, DeepSeek V4.1 Flash, MiMo Fast, Solar Mini 4 y Solar Pro 4 no cuestan nada en absoluto.
- **Modo limitado** (regiones no soportadas o VPN): 5 horas al día, 4 sobre VPN, o 6 sesiones de una hora donde la app aún muestra sesiones.
- **Referidos y recompensas** dan sesiones extra encima de la asignación diaria.

Ahora existen planes de pago para uso más intensivo: Starter a $8/mes (50 h/día), Plus a $25/mes (80 h/día) y Pro a $60/mes (130 h/día), cada uno con un fondo de bonificación mensual y acceso a todos los modelos. El nivel gratuito sigue siendo el punto del producto — los planes de pago solo suben el techo. Las versiones antiguas de la app muestran el mismo saldo como Freebucks, cinco por hora.

<Notice type="warning" title="Gratis significa financiado por anuncios">

El trato por $0 son datos y atención. Freebuff muestra anuncios de texto en la sesión, usa tu uso para personalizarlos, y avisa de que algunos modelos o funciones pueden conservar los envíos para entrenamiento — lo dice antes de empezar cuando es el caso. Si trabajas con código propietario, lee el aviso de uso de datos en el selector antes de elegir modelo.

</Notice>

## Instalando Freebuff CLI

Un comando te pone en marcha:

```bash
npm install -g freebuff
```

Luego navega a tu proyecto y ejecútalo:

```bash
cd your-project
freebuff
```

En el primer arranque te pedirá iniciar sesión. Después eliges un modelo y empiezas a chatear. `freebuff --continue` reabre una sesión anterior, y `/export` escribe una transcripción a un archivo Markdown en el proyecto.

## Los otros productos Freebuff

**Freebuff Web** es el constructor prompt-to-app — una alternativa gratuita a Lovable, Bolt.new o v0. Describe lo que quieres o elige una plantilla y genera una app desplegada.

**Freebuff Cloud** se conecta a un repo de GitHub y corre agentes sobre él en sandboxes alojados, con flujos de previews y despliegue.

**Freebuff Desktop** es la adición más interesante para el día a día: corre varios agentes en paralelo, cada uno aislado en su propio workspace, y puede dirigir tu instalación local de Claude Code o Codex si ya pagas por alguno de esos.

## Prueba real: construyendo un sitio web con Astro

Puse a Freebuff a trabajar en una tarea real: crear un sitio web de una empresa de paneles solares con Astro. El prompt incluía requisitos específicos de páginas, estilos Tailwind y un layout profesional. Esta prueba corrió sobre el catálogo antiguo (MiMo V2.5 la manejó); los modelos actuales GLM 5.3 Flash y DeepSeek V4.1 Flash son más fuertes sobre el papel, pero el flujo de trabajo es el mismo.

Esto fue lo que pasó:

**Lo bueno:**

- Generó todas las páginas (index, about, services, contact) sin tropiezos grandes
- Los componentes eran limpios y bien estructurados con descripciones, títulos y meta tags adecuados
- El build completó con éxito después de que Freebuff arreglara automáticamente algunos errores de build
- Tiempo total de unos 10 minutos para un sitio completo de varias páginas
- El código generado estaba organizado con las convenciones adecuadas de Astro

**Los bordes ásperos:**

- No importó Tailwind CSS en el archivo de layout, lo que rompió los estilos. Tuve que añadir una línea manualmente.
- Quitó el componente SEO e incrustó los meta tags directamente en el layout. No ideal para un proyecto real.
- Las Google Fonts no se cargaron con el enfoque recomendado por Astro
- Aparecieron algunos problemas de accesibilidad con botones durante la revisión de código
- El subagente revisor de IA cazó algunos problemas y los arregló (como un favicon que faltaba), pero no todos

Tras un arreglo manual rápido del import de Tailwind, el sitio realmente se veía decente. Buen header con animaciones, navegación funcional, sección de testimonios y un footer apropiado. Para una herramienta gratuita produciendo esto en 10 minutos, no está mal.

## Cómo se compara con las herramientas de pago

Freebuff no reemplazará a Claude Code o Cursor para trabajo complejo de backend. Los modelos son capaces para tareas de front-end y codificación directa, pero topan con límites en proyectos más exigentes.

Dónde tiene sentido Freebuff:

| Caso de uso | Freebuff | Herramientas de pago |
| --- | --- | --- |
| Landing pages y sitios estáticos | Funciona bien | Excesivo |
| Aprender a programar con IA | Buen punto de partida | Demasiado caro para experimentos |
| Prototipos rápidos | Cumple | Más rápido pero cuesta dinero |
| Tareas paralelas en segundo plano | La app desktop lo maneja | Normalmente una sesión cada vez |
| Sistemas backend complejos | Le costará | Más adecuadas |
| Aplicaciones en producción | No recomendado | Más fiables |

El intento anterior de este modelo (AMP Code) duró unos meses antes de que el enfoque con publicidad resultara insostenible. Freebuff lleva funcionando bastante más de un año y ha crecido de un CLI a cinco productos, así que parece aguantar mejor — aunque los nuevos planes de pago sugieren que los anuncios solos no eran toda la respuesta.

## ¿Quién debería usar Freebuff?

**Principiantes** que quieren entender cómo funcionan los agentes de codificación IA sin gastar dinero. Coges el feel del flujo CLI, aprendes a hacer prompts efectivos, y ves lo que estas herramientas pueden hacer.

**Desarrolladores con presupuesto ajustado** que necesitan ayuda con tareas pequeñas. Si estás construyendo un proyecto personal o necesitas un prototipo rápido, Freebuff lo maneja bien.

**Cualquiera con curiosidad por la codificación con IA** que no quiere comprometerse con una suscripción de $20-50/mes solo por probar.

Si ya pagas por Claude Code o Cursor y dependes de ellos para trabajo de producción, Freebuff no va a reemplazar eso. Pero como herramienta gratuita en tu caja de herramientas — especialmente la app desktop para tareas paralelas en segundo plano — vale la pena probarla.

## Consejos para mejores resultados

Basado en mis pruebas, esto es lo que ayuda:

<ListCheck>

- **Sé específico en tus prompts** — dile exactamente qué páginas quieres, qué framework y qué enfoque de estilos
- **Proporciona documentación** — si usas un framework concreto como Astro, menciona los docs para que el agente use los patrones correctos
- **Elige el modelo correcto** — usa los sin medición (GLM 5.3 Flash, DeepSeek V4.1 Flash) para trabajo de volumen y guarda los modelos frontera medidos para problemas duros
- **Dale acceso web** — el agente solo está tan al día como los datos de entrenamiento del modelo. Yo lo combino con la [API Search + Fetch gratuita de TinyFish](/es/tinyfish-busqueda-web-gratis-agentes/) para que pueda traer docs en vivo e issues de GitHub en vez de adivinar — el nivel gratuito (30 búsquedas/min, 150 fetch/min) basta para el día a día, y una clave no cuesta nada en [tinyfish.ai](https://go.bitdoze.com/tinyfish)
- **Revisa el build** — Freebuff corre builds automáticamente, pero verifica la salida tú mismo
- **Arregla los problemas pequeños a mano** — a veces un import que falta es más rápido de arreglar tú que esperar al agente

</ListCheck>

## Referidos y recompensas

Freebuff sigue ofreciendo uso extra si refieres a otros usuarios, y hay un programa de recompensas encima. Las horas ganadas van a una cartera que se gasta después de que tu asignación diaria se agote, así que no se evaporan a medianoche como las horas diarias.

## FAQ

<Accordion label="¿Es Freebuff realmente gratis?" group="faq">

Sí. El plan gratuito repone 30 horas de uso a diario y se financia con anuncios de texto mostrados durante tus sesiones de codificación. Sin tarjeta, sin suscripción, sin claves API necesarias. Existen planes de pago ($8-60/mes) si quieres más horas y el catálogo completo de modelos, pero nada en el nivel gratuito los requiere.

</Accordion>

<Accordion label="¿Cuál es la diferencia entre Freebuff y Codebuff?" group="faq">

Codebuff es el framework multi-agente open source — la orquestación, las herramientas y el SDK sobre los que puedes construir. Freebuff es la familia de productos construida sobre él: el CLI, la app desktop, el constructor web, los agentes en la nube y el chat que instalas y usas. El mismo código debajo.

</Accordion>

<Accordion label="¿Puedo usar Freebuff para proyectos comerciales?" group="faq">

Puedes, pero revisa primero el aviso de uso de datos por modelo — Freebuff te advierte cuando un modelo o función puede conservar envíos para entrenamiento. Para trabajo de producción querrías probar la salida a fondo de todos modos, ya que los modelos del nivel gratuito están optimizados para velocidad sobre profundidad.

</Accordion>

<Accordion label="¿Cuánto puedo usarlo al día?" group="faq">

30 horas repuestas a diario a acceso completo, y cada sesión dura una hora con mensajes ilimitados. Los modelos frontera consumen más por hora que los rápidos. En modo limitado (región no soportada o VPN) son 5 horas al día, 4 sobre VPN. Algunos modelos no tienen medición y no tocan tu asignación en absoluto.

</Accordion>

<Accordion label="¿Funciona Freebuff sin conexión?" group="faq">

No. Necesita una conexión a internet para acceder a los modelos de IA. Tus archivos se editan localmente, pero el procesamiento de IA ocurre en los servidores de Freebuff.

</Accordion>

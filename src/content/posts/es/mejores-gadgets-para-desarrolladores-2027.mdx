Si sigues usando códigos TOTP de 6 dígitos para GitHub, Cloudflare, AWS o tu gestor de contraseñas, un proxy inverso de phishing puede capturarlos en tiempo real. Una llave FIDO2 verifica el dominio exacto en el navegador antes de firmar. Además, por **$29**, la [Yubico Security Key C NFC](/go/yubico-security-key-c-nfc/) soporta claves SSH nativas en OpenSSH 8.2+ (`ssh-keygen -t ed25519-sk`) para que nadie pueda conectarse a tu VPS sin tocar físicamente el token (consulta nuestra [guía de endurecimiento SSH en Linux](/es/securizar-servidor-ssh-linux/)). Si necesitas firmar commits de Git con OpenPGP en hardware (`gpg --card-status`), sube a la [YubiKey 5C NFC](/go/yubikey-5c-nfc/) de $58.

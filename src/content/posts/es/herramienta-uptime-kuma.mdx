## 🔭 Visión general de Uptime Kuma

[Uptime Kuma](https://github.com/louislam/uptime-kuma) es una herramienta de monitorización de código abierto diseñada para ayudarte a supervisar la disponibilidad y el tiempo de respuesta de tu sitio web o aplicación web. Con Uptime Kuma puedes monitorizar tus sitios web, API y servicios.

Uptime Kuma incluye una interfaz web sencilla e intuitiva que te permite configurar monitores fácilmente, ver informes y recibir alertas cuando se producen caídas o problemas de rendimiento. Es compatible con una amplia variedad de protocolos y servicios, como HTTP, HTTPS, DNS, TCP e ICMP.

## ❔ Por qué usar Uptime Kuma

> Si te interesa descubrir más aplicaciones autoalojadas de código abierto, gratuitas e interesantes, echa un vistazo a la [sección self-hosted de toolhunt.net](https://toolhunt.net/sh/).

Uptime Kuma es una herramienta de monitorización potente y flexible que te ayuda a garantizar que tu sitio web o aplicación web esté siempre disponible y rindiendo al máximo. Estas son algunas razones por las que deberías plantearte usar Uptime Kuma:

- **Fácil de usar:** Uptime Kuma incluye una interfaz web sencilla e intuitiva que facilita configurar monitores, ver informes y recibir alertas.
- **Monitorización personalizable:** con Uptime Kuma puedes ajustar la frecuencia de monitorización, los umbrales de tiempo de respuesta y las reglas de alerta según tus necesidades concretas.
- **Informes avanzados:** Uptime Kuma ofrece informes detallados que te permiten seguir las tendencias del tiempo de actividad y de respuesta a lo largo del tiempo, además de identificar áreas problemáticas.
- **Integraciones:** Uptime Kuma admite integraciones con servicios populares como Slack, Discord y PagerDuty, para que recibas las alertas por tu canal de comunicación preferido.
- **Código abierto:** Uptime Kuma es una herramienta de código abierto, lo que significa que tienes control total sobre el software y puedes personalizarlo para adaptarlo a tus necesidades.

## 📋 Características de Uptime Kuma

- Monitorización del tiempo de actividad de HTTP(s) / TCP / HTTP(s) Keyword / Ping / DNS Record / Push / Steam Game Server / contenedores Docker
- Notificaciones por Telegram, Discord, Gotify, Slack, Pushover, correo electrónico (SMTP) y más de 90 servicios de notificación
- Compatibilidad con proxy: puedes añadir un proxy a Uptime Kuma
- Página de estado: puedes tener una página de estado para ver el estado de los servicios
- Interfaz limpia: la interfaz es rápida y se ve bien, con acceso a gráficos y tiempos de respuesta
- Varios idiomas: puedes usar Uptime Kuma en varios idiomas
- Fácil de desplegar: puedes desplegarlo con un clic mediante Docker. Consulta: [Desplegar Uptime Kuma con un clic](/es/desplegar-uptime-kuma/)

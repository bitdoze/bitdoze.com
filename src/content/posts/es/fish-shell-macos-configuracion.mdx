macOS viene con Zsh como shell por defecto (Apple cambió de Bash en 2019). Fish no está incluido, pero está a un solo comando de Homebrew. Uso Fish tanto en mi Mac como en mis máquinas Linux, y la experiencia es casi idéntica en ambos, que es una de las cosas que me gustan.

Esta guía cubre la configuración completa de **Fish Shell en macOS**: instalación con Homebrew, hacer de Fish tu shell por defecto, configuración del emulador de terminal y las herramientas esenciales que instalo junto a él. Todo el contenido está actualizado para fish 4.9.x (fórmula de Homebrew comprobada en octubre de 2026), todas las herramientas de la guía son gratuitas y de código abierto, y el conjunto completo ocupa decenas de MB de disco.

<ListCheck>
<ul>
<li>Un Mac con macOS (Apple Silicon o Intel, ambos funcionan igual)</li>
<li>Homebrew instalado, o disposición a ejecutar el instalador de una línea</li>
<li>Un emulador de terminal (Ghostty, iTerm2, Alacritty o WezTerm)</li>
<li>Unos 15 minutos</li>
</ul>
</ListCheck>

## Instalar Fish Shell en macOS con Homebrew

Si todavía no tienes Homebrew:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Instala Fish:

```bash
brew install fish
```

Los bottles de Homebrew cubren Mac con Apple Silicon e Intel, con builds para macOS Sonoma hasta Tahoe. Comprueba la versión:

```bash
fish --version
```

Deberías ver `fish, version 4.9.3` o más reciente. Homebrew mantiene Fish actualizado. Ejecuta `brew upgrade fish` periódicamente.

## Verifica tu instalación de Fish Shell

Después de instalar, y de nuevo tras cambiar tu shell por defecto, ejecuta estas comprobaciones. Funcionan desde cualquier shell, así que puedes usarlas aunque tu terminal siga en Zsh.

<Notice type="info" title="Ejecuta estos comandos en cualquier shell">
Estos comandos funcionan en Zsh, Bash o Fish. Ejecútalos ahora para confirmar la instalación, y de nuevo tras el cambio de shell por defecto de la siguiente sección.
</Notice>

```bash
fish --version                            # expect: fish, version 4.9.3
echo $SHELL                               # after chsh: /opt/homebrew/bin/fish (Apple Silicon)
dscl . -read /Users/$USER UserShell       # authoritative login-shell record
```

`dscl` es la fuente de verdad: lee el registro del servicio de directorio de macOS de tu cuenta. Si muestra `/opt/homebrew/bin/fish` (o `/usr/local/bin/fish` en Intel), el cambio funcionó a nivel de sistema.

Para depurar problemas de completado más adelante:

```bash
echo $fish_complete_path
```

Esto muestra los directorios que Fish recorre para el completado con Tab. Si faltan los completados de las herramientas de Homebrew, esto es lo primero que debes revisar.

Si `echo $SHELL` sigue mostrando `/bin/zsh` después de ejecutar `chsh`, probablemente tu aplicación de terminal esté lanzando su propio shell. Consulta la sección de solución de problemas más abajo.

## Probar Fish sin cambiar de shell

Escribe `fish` en tu terminal actual para iniciar una sesión de Fish. Juega con las [autosugerencias y el completado con Tab](/es/fish-shell-autocompletado-sugerencias/) (empieza a escribir y observa las sugerencias grises que aparecen), y fíjate en cómo [funciona el resaltado de sintaxis](/es/fish-shell-resaltado-sintaxis/) mientras escribes. Escribe `exit` para volver a Zsh.

Un detalle útil para la migración: desde fish 4.6, el `|&` estilo bash (enviar stdout y stderr por la tubería) funciona directamente. La sintaxis propia de Fish es `&|`, pero no hace falta que reentrenes esa memoria muscular.

## Establecer Fish Shell como tu shell por defecto en macOS

macOS requiere que el shell esté listado en `/etc/shells` antes de poder configurarlo como predeterminado. Homebrew instala Fish en `/opt/homebrew/bin/fish` (Apple Silicon) o `/usr/local/bin/fish` (Intel).

```bash
# Find your Fish path
which fish

# Add it to allowed shells
echo (which fish) | sudo tee -a /etc/shells

# Set as default
chsh -s (which fish)
```

Abre una nueva ventana de terminal. Deberías estar en Fish. Verifícalo con el comando `dscl` de la sección anterior.

<Notice type="warning" title="Conserva Zsh">
Los scripts del sistema de macOS a veces esperan Zsh o Bash. No los elimines. Fish reemplaza tu shell interactivo, no la capa de scripting del sistema. Si decides que Fish no es para ti, quedarte en Zsh está perfectamente bien. Puedes [añadir resaltado de sintaxis a Zsh](/es/activar-resaltado-sintaxis-zsh/), [activar el autocompletado de comandos en Zsh](/es/activar-autocompletado-comandos-zsh/) y elegir entre los [mejores plugins de Oh My Zsh](/es/mejores-plugins-oh-my-zsh/) para conseguir una experiencia similar.
</Notice>

Para deshacer el cambio, ejecuta `chsh -s /bin/zsh`. Para eliminar Fish por completo: `brew uninstall fish` y borra la línea de Fish de `/etc/shells`. Tu configuración de Fish vive en `~/.config/fish/` y se puede borrar de forma independiente. Nada más del sistema se ve afectado. El radio de impacto se limita a `/etc/shells` y tu registro de shell de inicio de sesión.

## Configuración del emulador de terminal (Ghostty, iTerm2, Alacritty, WezTerm)

Fish funciona en cualquier terminal, pero la fuente importa. El paginador de completado de Fish y muchos temas de prompt usan caracteres especiales que necesitan una Nerd Font.

### Instalar una Nerd Font

```bash
brew install font-meslo-lg-nerd-font
```

Luego configúrala como la fuente de tu terminal. Así se hace en las opciones populares:

<Accordion label="Ghostty" group="terminals" expanded="true">
Añade a `~/.config/ghostty/config`:

```
font-family = MesloLGS Nerd Font
font-size = 14
```

Ghostty es un terminal rápido con aceleración GPU (v1.4.0 es la última versión a octubre de 2026). Tengo una [guía completa de configuración de Ghostty](/es/terminal-ghostty/) si quieres explorar sus funcionalidades.
</Accordion>

<Accordion label="iTerm2" group="terminals">
Ve a **Settings → Profiles → Text → Font** y selecciona "MesloLGS NF". Ajusta el tamaño a tu preferencia (yo uso 14).

También vale la pena habilitar en iTerm2:
- **Settings → Profiles → Terminal → Shell Integration**: permite hacer clic para seleccionar la salida de comandos
- **Settings → General → Selection → Applications in terminal may access clipboard**: para que las operaciones de copiado de Fish funcionen
</Accordion>

<Accordion label="Alacritty" group="terminals">
En `~/.config/alacritty/alacritty.toml`:

```toml
[font]
size = 14

[font.normal]
family = "MesloLGS Nerd Font"
```
</Accordion>

<Accordion label="WezTerm" group="terminals">
En `~/.wezterm.lua`:

```lua
config.font = wezterm.font("MesloLGS Nerd Font")
config.font_size = 14.0
```

Tengo una [guía de configuración de WezTerm](/es/instalar-wezterm-mac/) que cubre la integración con zoxide y tmux.
</Accordion>

Una vez que tengas el terminal y la fuente listos, considera un multiplexor para sesiones persistentes y paneles divididos. Preparé una comparación de los [mejores multiplexores de terminal para 2026](/es/mejores-multiplexores-terminal/), y si eliges tmux, aquí tienes cómo [instalar tmux en macOS y aprender lo básico](/es/tmux-comandos-basicos/).

## Configuración básica de Fish Shell (config.fish)

Crea tu archivo de configuración:

```fish
mkdir -p ~/.config/fish
nano ~/.config/fish/config.fish
```

Una configuración inicial práctica para macOS:

```fish
# ~/.config/fish/config.fish

# Homebrew environment (Apple Silicon paths; use /usr/local/bin/brew on Intel)
brew shellenv fish | source
# or the simple version:
# fish_add_path /opt/homebrew/bin
# fish_add_path /opt/homebrew/sbin

# Common paths
fish_add_path ~/bin
fish_add_path ~/.local/bin

# Suppress the greeting
set -g fish_greeting

# Editor
set -gx EDITOR "code --wait"  # or vim, nvim, etc.
```

`brew shellenv fish | source` define `HOMEBREW_PREFIX`, `HOMEBREW_CELLAR`, el PATH y el manpath en una línea. Si te da problemas, vuelve a las dos líneas de `fish_add_path`. Cumplen su función en la mayoría de las configuraciones.

<Accordion label="Solo si fish no viene de Homebrew" group="config">
La fórmula fish de Homebrew descubre automáticamente los completados gestionados por Homebrew (consulta la [documentación de Homebrew Shell Completion](https://docs.brew.sh/Shell-Completion)). Si instalaste fish desde el código fuente u otro gestor de paquetes, añade esto a `config.fish` para recoger los completados de las herramientas de Homebrew:

```fish
if test -d (brew --prefix)"/share/fish/vendor_completions.d"
    set -p fish_complete_path (brew --prefix)/share/fish/vendor_completions.d
end
```

Fish 4.7 también mejoró el descubrimiento de `vendor_completions.d` mediante los valores XDG por defecto, así que incluso las instalaciones que no son de Homebrew pueden encontrar los completados sin este bloque. Revisa `echo $fish_complete_path` para ver qué está buscando Fish.
</Accordion>

Cuando tengas lo básico en su sitio, el siguiente paso natural es escribir funciones personalizadas para los flujos de trabajo repetidos. Consulta [Funciones de Fish Shell y comandos personalizados](/es/fish-shell-funciones-comandos-personalizados/) para ver patrones y ejemplos.

## Personalizar el tema de Fish Shell sin plugins (fish_config)

Antes de instalar cualquier plugin o prompt, Fish incluye temas integrados que puedes explorar y aplicar desde la CLI:

```fish
fish_config theme list          # see all built-in themes
fish_config theme demo          # preview themes side by side
fish_config theme choose "TOMORROW_NIGHT"   # apply one (use any name from the list)
```

Añade `--color-theme=dark` o `--color-theme=light` a `theme choose` para ajustar el esquema de color base. Tu elección persiste entre sesiones.

Para los prompts, Fish también incluye prompts de ejemplo:

```fish
fish_config prompt list
fish_config prompt choose "Classic + Git"
```

<Notice type="info" title="Temas sin instalar nada">
Esta es la forma más rápida de conseguir un shell atractivo antes de instalar nada. Si los temas integrados no son suficientes, consulta mi [guía de temas y prompts de Fish Shell](/es/fish-shell-temas-prompts/) para opciones de terceros.
</Notice>

## Instalar herramientas esenciales (Fisher, Starship, zoxide, eza, fzf)

Este es mi conjunto estándar de herramientas complementarias para Fish en macOS. Todas gratuitas y de código abierto. Juntas añaden decenas de MB de disco, nada más.

```bash
brew install fisher      # plugin manager (or install via curl)
brew install starship    # cross-shell prompt
brew install zoxide      # smarter cd
brew install eza         # modern ls replacement
brew install fzf         # fuzzy finder
brew install bat         # better cat with syntax highlighting
brew install fd          # better find
brew install ripgrep     # better grep
```

### Configurar Fisher y los plugins de Fish

Si instalaste Fisher vía Homebrew, está listo. De lo contrario:

```fish
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
```

Ahora instala los plugins:

```fish
fisher install PatrickF1/fzf.fish           # fuzzy search integration (v11+ requires fish 4.x)
fisher install jorgebucaran/autopair.fish    # auto-close brackets
fisher install meaningful-ooo/sponge         # remove failed commands from history
```

<Notice type="warning" title="sponge tiene poco mantenimiento">
La última versión de sponge se publicó en 2022 y el repositorio lleva en silencio desde principios de 2024. Funciona en fish 4.9.x hoy, pero si alguna vez se rompe tras una actualización de fish, quitarlo con `fisher remove meaningful-ooo/sponge` es indoloro.
</Notice>

Consulta mi [guía de los mejores plugins de Fish Shell](/es/mejores-plugins-fish-shell/) para la lista completa.

### Configurar Starship (o Tide)

<Tabs>
<Tab name="Starship">
Añade a `config.fish`:

```fish
starship init fish | source
```

Starship (v1.27.0 a octubre de 2026) es un prompt multi-shell. La misma configuración funciona si también usas Zsh o Bash. Detalles completos de configuración en mi [guía de Starship + Fish](/es/fish-shell-configurar-starship/).
</Tab>
<Tab name="Tide">
Instálalo vía Fisher:

```fish
fisher install IlanCosman/tide@v6
tide configure
```

Tide (v6.2.0) es un prompt nativo de Fish con un asistente de configuración interactivo. Ejecuta `tide configure` tras la instalación para elegir tu estilo.
</Tab>
</Tabs>

### Configurar zoxide

Añade a `config.fish`:

```fish
zoxide init fish | source
```

Ahora usa `z` en lugar de `cd`: `z projects` te lleva a tu directorio de proyectos. Guía completa en mi [artículo sobre zoxide](/es/zoxide-tutorial/).

### Configurar alias de eza

```fish
# ~/.config/fish/conf.d/eza.fish
abbr -a ls eza
abbr -a ll "eza -la --icons --git"
abbr -a lt "eza -la --icons --tree --level=2"
```

## Abreviaturas específicas de macOS

```fish
# ~/.config/fish/conf.d/macos.fish

# Quick Look from terminal
abbr -a ql "qlmanage -p"

# Open current directory in Finder
abbr -a finder "open ."

# Flush DNS
abbr -a flushdns "sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder"

# Show/hide hidden files in Finder
abbr -a showhidden "defaults write com.apple.finder AppleShowAllFiles -bool true && killall Finder"
abbr -a hidehidden "defaults write com.apple.finder AppleShowAllFiles -bool false && killall Finder"
```

Fish 4.9 añadió una mejora de calidad de vida interesante: las abreviaturas ahora pueden llevar una descripción que se muestra en el paginador de completado. Ejecuta `abbr --help` en tu instalación para ver la sintaxis actual para añadir descripciones. Facilita recordar qué hacen tus abreviaturas personalizadas.

Cubro las abreviaturas vs alias en detalle en [Fish Shell abreviaturas vs alias](/es/fish-shell-abreviaturas-vs-alias/).

## Gestión de versiones de Node.js

El nvm basado en Bash no funciona en Fish. Usa nvm.fish en su lugar:

```fish
fisher install jorgebucaran/nvm.fish
nvm install lts
set --universal nvm_default_version lts
```

`nvm install latest` también funciona si quieres la versión más reciente en lugar de LTS. Guía completa paso a paso en mi [guía de NVM con Fish Shell](/es/nvm-fish-shell/). Si también mantienes una configuración de Zsh, mi guía de [instalación de Node.js con NVM en macOS y Ubuntu](/es/instalar-nodejs-nvm-macos-ubuntu/) cubre ambos shells.

Una alternativa que conviene conocer: `mise` es un gestor de versiones general (Node, Python, Ruby y más) que se integra con Fish mediante `mise activate fish | source`. Si gestionas varios runtimes de lenguajes, vale la pena echarle un vistazo.

## Problemas comunes de Fish Shell en macOS: solución de problemas

<Accordion label="El PATH de Homebrew no funciona" group="issues" expanded="true">
En los Mac con Apple Silicon, Homebrew se instala en `/opt/homebrew/` en lugar de `/usr/local/`. Asegúrate de que tu `config.fish` tenga el entorno de Homebrew al principio:

```fish
brew shellenv fish | source
# or manually:
# fish_add_path /opt/homebrew/bin
# fish_add_path /opt/homebrew/sbin
```

Pon estas líneas al principio de tu archivo de configuración, antes de cualquier cosa que dependa de las herramientas de Homebrew.
</Accordion>

<Accordion label="Variables de entorno de .zshrc ausentes" group="issues">
Fish no lee `.zshrc` ni `.bash_profile`. Mueve tus variables de entorno a `config.fish` usando `set -gx`:

```fish
set -gx JAVA_HOME (/usr/libexec/java_home)
set -gx ANDROID_HOME ~/Library/Android/sdk
fish_add_path $ANDROID_HOME/platform-tools
```
</Accordion>

<Accordion label="El agente SSH no reenvía" group="issues">
El agente SSH de macOS funciona con Fish, pero puede que necesites cargar tus claves:

```fish
# ~/.config/fish/conf.d/ssh.fish
if status is-interactive
    ssh-add --apple-use-keychain ~/.ssh/id_ed25519 2>/dev/null
end
```
</Accordion>

<Accordion label="Faltan completados con Tab para herramientas de Homebrew" group="issues">
Si las herramientas instaladas con brew no se completan con Tab, revisa qué está buscando Fish:

```fish
echo $fish_complete_path
```

Fish instalado vía Homebrew descubre los completados automáticamente. Si instalaste fish de otra forma, consulta el acordeón "Solo si fish no viene de Homebrew" en la sección de configuración de arriba.
</Accordion>

<Accordion label="Un plugin se rompe tras actualizar fish" group="issues">
Si un plugin deja de funcionar tras una actualización de fish, revisa sus requisitos. Por ejemplo, fzf.fish v11+ requiere fish 4.x (migró a la sintaxis de bindings de fish 4). Solución: `brew upgrade fish` primero, luego `fisher update` para traer las últimas versiones de los plugins.
</Accordion>

<Accordion label="Los colores se ven diferentes en scripts o por SSH" group="issues">
Desde fish 4.7, el tema de color por defecto ya no se aplica en shells no interactivos. Es intencionado: evita que los colores del tema se filtren a la salida de tuberías y scripts. Si quieres colores por SSH, defínelos explícitamente en tu `config.fish` remoto.
</Accordion>

<Accordion label="¿Qué es fish_frozen_theme.fish?" group="issues">
Tras actualizar desde versiones antiguas de fish, puedes encontrar `~/.config/fish/conf.d/fish_frozen_theme.fish`. Fish lo crea para fijar tu tema actual entre actualizaciones y que los colores no cambien inesperadamente. Es seguro dejarlo o borrarlo. Si lo borras, los valores por defecto del tema futuro se aplicarán en la próxima actualización.
</Accordion>

## Novedades de fish 4.6 a 4.9

Si vienes de una instalación antigua de fish, esto es lo que llegó en las últimas versiones (de la 4.6.0 a la 4.9.3, de marzo a septiembre de 2026):

<ListCheck>
<ul>
<li>**4.6.0**: se acepta `|&` estilo bash para enviar stdout+stderr por la tubería; corregido el arranque lento del terminal en macOS</li>
<li>**4.7.0**: los colores por defecto ya no se aplican en shells no interactivos; mejor descubrimiento de `vendor_completions.d`</li>
<li>**4.8.0**: `cd -L` / `cd -P` para controlar la resolución de enlaces simbólicos; las abreviaturas se completan en posición de argumento</li>
<li>**4.9.0**: descripciones de abreviaturas en el paginador de completado; corrección del completado con enlaces simbólicos lentos; indexación de listas anidadas</li>
</ul>
</ListCheck>

Detalles completos en los [releases de fish-shell](https://github.com/fish-shell/fish-shell/releases).

## Comprobación de estado y dónde vive el estado de Fish

Referencia rápida para verificar tu configuración y entender dónde guarda Fish sus datos:

<Accordion label="Comandos de comprobación de estado" group="ops">
```bash
fish --version                            # fish, version 4.9.3
echo $SHELL                               # /opt/homebrew/bin/fish
dscl . -read /Users/$USER UserShell       # UserShell: /opt/homebrew/bin/fish
echo $fish_complete_path                  # completion search paths
```

Si algo de esto se ve mal, la sección de solución de problemas de arriba cubre las correcciones habituales.
</Accordion>

Dónde guarda Fish su estado en macOS:

```
~/.config/fish/
├── config.fish              # main config (source order: first)
├── conf.d/
│   ├── eza.fish             # your abbreviation files
│   ├── macos.fish
│   └── ssh.fish
└── (fish variables, universal vars in fish_variables)

~/.local/share/fish/
├── fish_history             # command history
└── generated_completions/   # auto-generated completions
```

Esto es útil para copias de seguridad y para replicar tu configuración en una máquina Linux. Las mismas rutas funcionan allí. Consulta mi guía [Instalar Fish en Ubuntu](/es/instalar-fish-shell-ubuntu/) para la parte de Linux.

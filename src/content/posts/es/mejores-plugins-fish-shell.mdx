Fish ya hace bastante sin plugins. [Autosugerencias](/es/fish-shell-autocompletado-sugerencias/), [resaltado de sintaxis](/es/fish-shell-resaltado-sintaxis/) y completados de páginas man vienen integrados. Eso significa que los mejores plugins de fish shell son herramientas enfocadas, no parches para funcionalidades que faltan. El ecosistema es más pequeño que el de Zsh, pero cada plugin aquí se gana su lugar.

Esta guía está actualizada para Fish 4.x (la base actual desde la reescritura en Rust de febrero de 2025). Cubro gestores de plugins, prompts, herramientas de búsqueda y una configuración lista para copiar que puedes ejecutar esta misma noche.

Si eres nuevo en Fish, empieza con mi [guía de instalación para Ubuntu](/es/instalar-fish-shell-ubuntu/) primero.

## Primero: verifica tu versión de Fish

Antes de instalar cualquier cosa, confirma que estás en Fish 4. Varios plugins de abajo ahora lo requieren.

```fish
fish --version
```

Necesitas al menos `4.0.0`. fzf.fish v11 no funcionará en nada más antiguo. La versión estable actual es **4.9.3** (septiembre de 2026), y Tide funciona mejor en el último 4.x.

Si estás en Ubuntu y ejecutaste `sudo apt install fish`, probablemente tienes 3.7.x de los repositorios predeterminados. Es demasiado viejo. Usa el PPA de fish-shell en su lugar. Cubro los pasos exactos en mi guía para [instalar el último Fish Shell en Ubuntu desde el PPA oficial](/es/instalar-fish-shell-ubuntu/). En macOS, `brew install fish` te da una versión actual; mira mi [guía de configuración de Fish Shell en macOS](/es/fish-shell-macos-configuracion/) para el panorama completo.

<Notice type="info" title="Fish 4 es la base">
Varios plugins de abajo requieren Fish >= 4.0. Verifica tu versión antes de instalar cualquier cosa. Si estás en 3.x, actualiza primero o espera atajos de teclado rotos y fallos en el prompt.
</Notice>

## Gestores de plugins: Fisher vs Oh My Fish

Necesitas un gestor de plugins antes de poder instalar cualquier cosa. Hay tres opciones, pero la elección es sencilla.

### Fisher (recomendado)

[Fisher](https://github.com/jorgebucaran/fisher) es un gestor de plugins ligero escrito completamente en Fish. Instala los plugins copiando funciones y completados directamente en tu directorio de configuración de Fish. Sin framework, sin sobrecarga al iniciar. La versión actual es 4.4.8 (enero de 2026) y tiene mantenimiento activo.

Instálalo:

```fish
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
```

Verifica que funciona:

```fish
fisher list
```

Deberías ver `jorgebucaran/fisher` en la salida. Uso básico:

```fish
fisher install author/plugin    # instalar un plugin
fisher update                   # actualizar todos los plugins
fisher remove author/plugin     # eliminar un plugin
fisher list                     # listar plugins instalados
```

Fisher registra los plugins instalados en `~/.config/fish/fish_plugins`. Puedes poner este archivo bajo control de versiones y ejecutar `fisher update` en una máquina nueva para recrear tu configuración.

<ListCheck>
<ul>
<li>Instala Fisher con el comando de una línea de arriba</li>
<li>Ejecuta <code>fisher install author/plugin</code> para añadir plugins</li>
<li>Ejecuta <code>fisher list</code> para verificar que todo se instaló</li>
<li>Haz commit de <code>~/.config/fish/fish_plugins</code> en tu repo de dotfiles</li>
<li>Ejecuta <code>fisher update</code> en una máquina nueva para recrear tu configuración</li>
</ul>

### Oh My Fish

[Oh My Fish](https://github.com/oh-my-fish/oh-my-fish) (OMF) es un framework similar a Oh My Zsh. Tiene su propio repositorio de paquetes con temas y plugins, y proporciona una herramienta de línea de comandos (`omf`) para gestionarlos.

Instálalo:

```fish
curl https://raw.githubusercontent.com/oh-my-fish/oh-my-fish/master/bin/install | fish
```

Puedes verificar el checksum del instalador contra `bin/install.sha256` en el repo si quieres ser cuidadoso.

Uso:

```fish
omf install plugin-name    # instalar un plugin
omf theme theme-name       # aplicar un tema
omf update                 # actualizar todo
omf list                   # listar paquetes instalados
```

La opinión honesta: OMF v8 salió en abril de 2026 como una versión de compatibilidad con Fish 4. Refrescó la matriz de tests, mejoró el instalador y corrigió problemas de instalación de larga data. Pero el README sigue mostrando la advertencia de falta de mantenimiento ("maintainers have ran out of steam"), y algunos paquetes siguen rotos. El núcleo ahora corre en Fish 4, pero el ecosistema a su alrededor no es confiable. Yo no empezaría una instalación nueva de Fish con OMF hoy. Fisher tiene mantenimiento activo, es más rápido y puede incluso instalar plugins compatibles con OMF. Si aún quieres probarlo, tengo una guía de [temas y plugins de Oh My Fish](/es/oh-my-fish-instalar-temas-plugins/).

<Notice type="warning" title="Estado de Oh My Fish">
OMF v8 (abril de 2026) añadió compatibilidad con Fish 4, pero el repo sigue mostrando una advertencia de falta de mantenimiento y algunos paquetes están rotos. Para instalaciones nuevas, usa Fisher.
</Notice>

Una tercera opción es [Fundle](https://github.com/danhper/fundle), un gestor de plugins ligero configurado completamente en `config.fish`. Vale la pena echarle un vistazo si quieres cero herramientas externas.

## Plugins de prompt

Los prompts de Fish pueden mostrar estado de git, directorio, versiones de runtime y duración de comandos. Dos opciones sólidas abajo.

### Tide

[Tide](https://github.com/IlanCosman/tide) es el prompt nativo de Fish más popular. Renderiza de forma asíncrona (así que tu prompt nunca se ralentiza), tiene un asistente de configuración y muestra el estado de git, directorio actual, versiones de runtime y duración de comandos. La versión actual es v6.2.1.

```fish
fisher install IlanCosman/tide@v6
tide configure
```

El asistente te guía por las opciones de estilo: powerline vs. plano, iconos vs. texto, una línea vs. dos líneas. El resultado se ve pulido sin ninguna configuración manual. Para verificar, entra con `cd` a un repo de git y confirma que la rama aparece en tu prompt.

Tide necesita una [Nerd Font](https://www.nerdfonts.com/) para los iconos. Recomiendo MesloLGS NF, que es la que sugiere la documentación de Tide. Instala la fuente, configúrala en tu emulador de terminal, y listo.

Las versiones recientes de Tide añadieron items de workspace para `bun` y `go` (útil si trabajas con esos toolchains). La v6.2.1 también corrigió un carácter del prompt en modo vi en Fish 4.3+. Es prueba de que Tide sigue de cerca las versiones de Fish y hay que mantenerlo actualizado.

<Notice type="info" title="Mantén Tide actualizado">
Tide sigue a Fish de cerca. Después de actualizar Fish, ejecuta `fisher update` y vuelve a correr `tide configure` si el prompt se comporta mal.
</Notice>

Si quieres un prompt que funcione en Fish, Zsh y Bash, mira [Starship con Fish Shell](/es/fish-shell-configurar-starship/) en su lugar. Tide es solo para Fish pero está más profundamente integrado con las funcionalidades de Fish.

### Hydro

[Hydro](https://github.com/jorgebucaran/hydro) es un prompt minimalista hecho por el autor de Fisher. Muestra rama de git, duración de comandos y estado de salida con casi cero sobrecarga. Bueno si prefieres algo limpio y rápido antes que lleno de funcionalidades.

```fish
fisher install jorgebucaran/hydro
```

No necesita configuración. Los valores predeterminados son sensatos y se mantiene fuera del camino.

Para una comparación completa de opciones de prompt de Fish incluyendo Tide, Hydro, Starship y Pure, revisa mi [guía de temas y prompts de Fish Shell](/es/fish-shell-temas-prompts/).

## Plugins de búsqueda y navegación

La búsqueda difusa y la navegación inteligente de directorios son las mejoras de calidad de vida más grandes que puedes añadir a Fish.

### fzf.fish

[fzf.fish](https://github.com/PatrickF1/fzf.fish) agrega búsqueda difusa a tu Fish shell usando [fzf](https://github.com/junegunn/fzf). Obtienes búsqueda interactiva para historial de comandos, rutas de archivos, git log, git status, procesos y variables de shell.

<Notice type="warning" title="Las dependencias importan">
fzf.fish v11 requiere Fish >= 4.0 y fzf >= 0.33. El paquete fzf de apt en Ubuntu es demasiado viejo. Instala fzf desde su script de instalación de git o una release reciente. Verifica tus versiones antes de instalar.
</Notice>

<ListCheck>
<ul>
<li>Fish >= 4.0.0</li>
<li>fzf >= 0.33.0 (actual: v0.74.x)</li>
<li>fd >= 8.5.0 (para Search Directory)</li>
<li>bat >= 0.16.0 (para la vista previa de Search Directory)</li>
<li>Fisher instalado</li>
</ul>
</ListCheck>

Instala las dependencias primero, luego el plugin:

```fish
# Instalar fzf (consigue una build reciente, no la antigua de apt)
# Ver https://github.com/junegunn/fzf#installation

# Instalar fd y bat (Ubuntu)
sudo apt install fd-find bat

# En Ubuntu, fd y bat se instalan como fdfind y batcat, así que crea los symlinks:
# (asegúrate de que ~/.local/bin está en tu PATH o los symlinks no se encontrarán)
mkdir -p ~/.local/bin
ln -sf $(which fdfind) ~/.local/bin/fd
ln -sf $(which batcat) ~/.local/bin/bat

# Instalar el plugin de Fish
fisher install PatrickF1/fzf.fish
```

En macOS, usa `brew install fzf fd bat`. Los nombres de los binarios ya son correctos.

Atajos de teclado predeterminados:
- `Ctrl+R`: buscar en el historial de comandos (reemplaza la búsqueda integrada de Fish con una mejor)
- `Ctrl+Alt+F`: buscar rutas de archivos
- `Ctrl+Alt+L`: buscar en git log
- `Ctrl+Alt+S`: buscar en git status
- `Ctrl+Alt+P`: buscar procesos en ejecución
- `Ctrl+V`: buscar variables de shell (insertar en la línea de comandos)

Para inspeccionar o personalizar los atajos, ejecuta:

```fish
fzf_configure_bindings --help
```

Este es probablemente el plugin de Fish shell más útil que existe. Si no instalas nada más, instala este.

Una advertencia: fzf.fish es incompatible con otras integraciones de fzf para shell. Si tienes otro plugin de fzf para Fish instalado, elimínalo primero o los atajos de teclado entrarán en conflicto. El README de fzf.fish enlaza una página de wiki que cubre cómo eliminar las dos alternativas comunes.

### zoxide

[Zoxide](https://github.com/ajeetdsouza/zoxide) no es un plugin de Fish, es una herramienta independiente que reemplaza `cd` con una alternativa más inteligente. Aprende qué directorios visitas y te permite saltar a ellos con nombres parciales. Escribe `z proj` en lugar de `cd ~/Documents/work/projects`. La versión actual es v0.10.0 (julio de 2026), y funciona con Fish, Zsh y Bash.

```fish
# Instalar
sudo apt install zoxide  # o: brew install zoxide

# Agregar a tu configuración de Fish
# En ~/.config/fish/config.fish:
zoxide init fish | source
```

La v0.10 añadió completados Space-Tab que muestran y ejecutan el comando seleccionado, lo que hace el salto entre directorios aún más rápido. Tengo una guía completa sobre [zoxide](/es/zoxide-tutorial/) que cubre la configuración y el uso.

## Plugins de Git

Si usas Tide o Hydro, la información de git ya está en tu prompt. Pero si quieres abreviaturas y helpers de git independientes, el enfoque más simple es definir las tuyas propias:

```fish
# Agregar a ~/.config/fish/conf.d/git.fish
abbr -a gs git status
abbr -a ga git add
abbr -a gc git commit
abbr -a gp git push
abbr -a gl git log --oneline
abbr -a gco git checkout
abbr -a gb git branch
abbr -a gd git diff
```

Las abreviaturas se expanden cuando presionas espacio o enter, así que ves el comando completo en tu historial. Explico por qué esto importa en [abreviaturas vs alias de Fish Shell](/es/fish-shell-abreviaturas-vs-alias/).

Para helpers de git más complejos (funciones personalizadas que envuelven múltiples comandos), mira mi guía de [funciones y comandos personalizados de Fish Shell](/es/fish-shell-funciones-comandos-personalizados/).

## Gestión de Node y versiones

### nvm.fish

[nvm.fish](https://github.com/jorgebucaran/nvm.fish) es un gestor de versiones de Node.js creado para Fish. Es más ligero que el nvm basado en Bash e inicia más rápido porque se carga de forma diferida. La versión actual es 2.2.17. Tengo una [guía detallada de NVM con Fish Shell](/es/nvm-fish-shell/) que cubre la configuración y el uso.

```fish
fisher install jorgebucaran/nvm.fish
```

Uso:

```fish
nvm install lts       # instalar el último LTS
nvm install 22        # instalar Node 22
nvm use 22            # cambiar a Node 22
nvm list              # listar versiones instaladas
nvm current           # mostrar versión activa
```

También lee archivos `.nvmrc` y `.node-version` automáticamente cuando entras en un directorio.

## Otros plugins útiles

### done

[done](https://github.com/franciscolourenco/done) envía una notificación de escritorio (y móvil) cuando un comando de larga duración termina. Si ejecutas playbooks de Ansible, builds de Docker o tareas de CI que toman minutos, es una pequeña mejora de calidad de vida. Puedes cambiar a otra ventana y recibir un aviso cuando termine. Con mantenimiento activo (v1.21.1, diciembre de 2025).

```fish
fisher install franciscolourenco/done
```

Verifica: ejecuta `sleep 10` y confirma que aparece una notificación cuando termina.

### puffer-fish

[puffer-fish](https://github.com/nickeb96/puffer-fish) expande `..` a `../..` y `...` a `../../..` mientras escribes. Presiona `.` dos veces y sigue añadiendo referencias al directorio padre. Sigue activo (último push en noviembre de 2025).

```fish
fisher install nickeb96/puffer-fish
```

### autopair.fish

[autopair.fish](https://github.com/jorgebucaran/autopair.fish) cierra automáticamente corchetes, comillas y paréntesis mientras escribes. Presiona `(` e inserta `()` con el cursor entre medias.

```fish
fisher install jorgebucaran/autopair.fish
```

Estable pero sin mantenimiento desde 2022 (última release 1.0.4). No hay reportes de roturas en Fish 4, pero revisa el issue tracker si algo falla. [laughedelic/pisces](https://github.com/laughedelic/pisces) es una alternativa que vale la pena considerar.

### sponge

[sponge](https://github.com/meaningful-ooo/sponge) elimina automáticamente los comandos fallidos de tu historial de Fish. Si un comando sale con error, no contamina tu [historial y autosugerencias](/es/fish-shell-historial-persistencia/).

```fish
fisher install meaningful-ooo/sponge
```

Sin mantenimiento desde 2022 (última release 1.1.0). Algunos usuarios reportan que no filtra el historial en versiones nuevas de Fish. Revisa el issue tracker antes de confiar en él.

## Si los plugins se rompen después de una actualización de Fish

El modo de fallo más común con los plugins de Fish es la rotura después de una actualización de Fish. Los plugins siguen a Fish de cerca, así que los saltos de versión menores pueden causar fallos de renderizado del prompt o de atajos de teclado. La mayoría de los casos se resumen en tres arreglos.

<Accordion label="El prompt de Tide se ve mal después de una actualización de Fish" group="troubleshooting">
Ejecuta `fisher update` y luego vuelve a correr `tide configure`. Tide está fuertemente acoplado a las versiones de Fish. La v6.2.1 corrigió un bug de modo vi que solo aparecía en Fish 4.3+. Si el prompt sigue mal después de actualizar, revisa el issue tracker de Tide para reportes específicos de versión de Fish.
</Accordion>

<Accordion label="Los atajos de fzf.fish dejaron de funcionar" group="troubleshooting">
Primero, verifica `fish --version`. fzf.fish v11 necesita >= 4.0. Si estás en 3.x, ese es el problema. Ejecuta `fzf_configure_bindings --help` para ver qué está registrado. Si tienes otras integraciones de fzf para shell instaladas, elimínalas. fzf.fish es incompatible con ellas.
</Accordion>

<Accordion label="sponge no está filtrando mi historial" group="troubleshooting">
sponge está dormido desde 2022. Revisa su issue tracker para reportes de compatibilidad con Fish 4. Si no funciona en tu versión de Fish, considera eliminarlo. No hay arreglo en camino.
</Accordion>

La secuencia general de arreglo después de cualquier actualización de Fish:

```fish
fish --version          # confirma que estás en la versión esperada
fisher update           # actualizar todos los plugins
fisher list             # verificar que todo sigue instalado
# Si Tide está mal:
tide configure          # volver a correr el asistente
```

## Mi configuración recomendada

Si estoy configurando Fish en una máquina nueva, esto es lo que instalo:

```fish
# Verifica la versión primero
fish --version          # necesitas >= 4.0 (recomendado 4.9.x)

# Gestor de plugins
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher

# Prompt (elige uno)
fisher install IlanCosman/tide@v6
# O para cross-shell: instala Starship por separado

# Plugins imprescindibles
fisher install PatrickF1/fzf.fish
fisher install franciscolourenco/done
fisher install jorgebucaran/autopair.fish
fisher install meaningful-ooo/sponge
fisher install nickeb96/puffer-fish

# Verificar
fisher list
```

Más zoxide instalado por separado. Eso me da un shell rápido y funcional con búsqueda difusa, navegación inteligente de directorios, notificaciones de comandos terminados y un buen prompt. Toda la configuración lleva unos cinco minutos.

<ListCheck>
<ul>
<li>Verifica la versión de fish (<code>fish --version</code>)</li>
<li>Instala Fisher</li>
<li>Instala un prompt (Tide o Starship)</li>
<li>Instala fzf.fish + las dependencias fzf/fd/bat</li>
<li>Instala los plugins restantes (done, autopair, sponge, puffer-fish)</li>
<li>Ejecuta <code>fisher list</code> para verificar todo</li>
<li>Haz commit de <code>fish_plugins</code> en tu repo de dotfiles</li>
</ul>
</ListCheck>

Mantén `fish_plugins` en tu repo de dotfiles. En una máquina nueva, instala Fisher, clona tus dotfiles y ejecuta `fisher update` para recrear toda la configuración.

## Comparación con plugins de Zsh

Si vienes de Zsh y te preguntas cuáles son los equivalentes:

| Plugin/herramienta de Zsh | Equivalente en Fish |
|---|---|
| Oh My Zsh | Fisher (gestor de plugins) |
| Powerlevel10k | Tide |
| zsh-autosuggestions | Integrado en Fish |
| zsh-syntax-highlighting | Integrado en Fish |
| zsh-completions | Integrado en Fish (análisis de páginas man) |
| fzf (integración Zsh) | fzf.fish |
| zoxide (Zsh) | zoxide (misma herramienta, init para Fish) |
| nvm | nvm.fish |

Tengo una [comparación detallada de Fish vs Zsh](/es/fish-shell-vs-zsh-comparacion/) y un artículo más amplio de [Fish vs Bash vs Zsh](/es/fish-shell-vs-bash-vs-zsh-comparacion/) si quieres más contexto sobre las diferencias. Para usuarios de Zsh, también tengo una lista de los [mejores plugins de Oh My Zsh](/es/mejores-plugins-oh-my-zsh/) para comparar.

## Dónde encontrar más plugins

La lista curada canónica es [awsm.fish](https://github.com/jorgebucaran/awsm.fish), mantenida por el autor de Fisher. Cubre plugins, prompts y herramientas que vale la pena conocer.

<Button text="Explora la lista de plugins awsm.fish" link="https://github.com/jorgebucaran/awsm.fish" variant="outline" color="blue" size="md" icon="arrow-right" />

Si pasas tiempo editando archivos de configuración de Fish, [fish-lsp](https://github.com/ndonfris/fish-lsp) añade completados, hover, goto-definition, rename, diagnósticos y formateo a Neovim o VS Code. Instálalo con `npm install -g fish-lsp` (o `fisher install ndonfris/fish-lsp`). Hay un playground en [fish-lsp.dev](https://fish-lsp.dev).

El ecosistema de plugins de Fish es pequeño pero de alta calidad. Un puñado de plugins bien elegidos cubre la mayoría de las necesidades. No hace falta instalar todo.

## Novedades en el hosting PHP para 2025

### PHP 8.4 y el panorama de versiones

PHP 8.4 se lanzó el 21 de noviembre de 2024 con hooks de propiedades, visibilidad asimétrica, soporte para HTML5 y mejoras de rendimiento. PHP 8.3 es el estándar de producción actual al que apuntan la mayoría de las aplicaciones. PHP 8.2 es la versión mínima con soporte activo (parches de seguridad hasta diciembre de 2025). PHP 7.4 llegó al final de su vida útil en noviembre de 2022 — si tu hosting todavía lo ejecuta, muévete de inmediato.

| Versión | Lanzada | Soporte de seguridad hasta | Estado |
|---------|---------|----------------------------|--------|
| PHP 8.4 | Nov 2024 | Dic 2026 | Última versión |
| PHP 8.3 | Nov 2023 | Dic 2025 | Estándar de producción |
| PHP 8.2 | Dic 2022 | Dic 2025 | Mínimo soportado |
| PHP 8.1 | Nov 2021 | Dic 2024 | EOL |
| PHP 7.4 | Nov 2019 | Nov 2022 | EOL — riesgo de seguridad |

Muchos hostings administrados todavía se quedan en PHP 8.2 (Hostinger hPanel, Cloudways Flexible). Cloudways Autonomous soporta 8.3. Si necesitas la 8.4 hoy, un VPS no administrado con CloudPanel o una configuración manual es el camino más rápido.

### El cierre de 000webhost y lo que significa

<Notice type="warning" title="000webhost ya no existe">
000webhost (propiedad de Hostinger) dejó de aceptar usuarios nuevos el 8 de julio de 2024 y cerró por completo el 14 de octubre de 2024. Si lo ves recomendado en otros artículos, esa información está desactualizada. InfinityFree es la opción de hosting PHP gratuito que queda — con advertencias importantes que cubro más abajo.
</Notice>

## #1. Hetzner — el hosting cloud PHP con mejor relación calidad-precio

Hetzner es un proveedor de nube alemán que ofrece consistentemente el mejor hardware por el dinero. Llevo más de 4 años ejecutando servidores de producción en Hetzner y el rendimiento ha sido fiable. Un servidor con especificaciones comparables a Vultr o DigitalOcean suele costar la mitad.

Hetzner reorganizó por completo la estructura de sus planes en 2024-2025:

| Nivel de plan | Ejemplo | vCPU | RAM | Almacenamiento | Mensual (sin IPv4) |
|---------------|---------|------|-----|----------------|---------------------|
| Cost-Optimized (x86) | CX23 | 2 | 4GB | 40GB | ~€3.99 |
| Cost-Optimized (x86) | CX33 | 4 | 8GB | 80GB | ~€6.49 |
| Regular Performance | CPX22 | 2 | 4GB | 80GB | ~€5.49 |
| Regular Performance | CPX32 | 4 | 8GB | 160GB | ~€10.99 |
| ARM (Cost-Optimized) | CAX11 | 2 | 4GB | 40GB | ~€4.49 |

Los planes Cost-Optimized usan hardware más antiguo y funcionan bien para desarrollo, staging y sitios PHP moderados. Los planes Regular Performance ejecutan las últimas CPU AMD EPYC-Genoa para cargas de producción. Los planes ARM (CAX) ofrecen mejor rendimiento por euro para stacks cloud-native, y vale la pena probarlos si tu aplicación PHP no tiene dependencias específicas de x86. Consulta [rendimiento ARM vs x86 para cargas web](/es/comparativa-arm-vs-x86-vps/) para ver los benchmarks.

### Hosting PHP gratuito: lo que queda

**InfinityFree** es la principal opción de hosting PHP gratuito que queda. ### Alternativas de hosting gratuito (sitios estáticos)

Si en realidad no necesitas PHP —si tu sitio puede ser HTML, CSS y JavaScript estáticos— estas opciones de hosting gratuito son más rápidas y fiables que cualquier hosting PHP gratuito:

**Cloudflare Pages** — 500 despliegues/mes, ancho de banda ilimitado, SSL, CDN, protección DDoS. Se integra con Git para despliegues automáticos. 100 dominios personalizados por proyecto. El mejor hosting estático gratuito disponible.

**Netlify** — 100GB de ancho de banda/mes, 300 minutos de build, funciones serverless (125K peticiones/mes en el plan gratuito). Bueno para sitios JAMstack con necesidades ligeras de backend.

**Vercel** — el plan Hobby es gratis para uso personal y no comercial. HTTPS automático, despliegues de vista previa en cada git push. Los límites de uso se reinician mensualmente, pero excederlos obliga a esperar o subir de plan.

**GitHub Pages** — despliegue directo desde un repositorio de GitHub. Soporta dominios personalizados. El nivel gratuito está limitado a repositorios públicos. Sin límites de minutos de build, pero sin procesamiento del lado del servidor.

## Cómo verificar tu configuración de hosting PHP

Después de desplegar tu servidor e instalar PHP, verifica que todo funciona realmente antes de apuntar el DNS hacia él.

**Comprueba la versión de PHP:**

```bash
php -v
```

La salida esperada debería mostrar tu versión objetivo (8.2, 8.3 u 8.4). Si muestra 7.x, algo va mal.

**Comprueba las extensiones críticas:**

```bash
php -m | grep -E "mbstring|xml|curl|gd|mysql|zip"
```

La mayoría de aplicaciones PHP necesitan todas estas. La ausencia de `mbstring` o `curl` provocará fallos silenciosos en frameworks como Laravel y Symfony.

**Crea una página de prueba phpinfo:**

```bash
echo "<?php phpinfo(); ?>" > /var/www/html/info.php
```

Visita `http://tu-ip-del-servidor/info.php` en un navegador. Deberías ver la página completa de configuración de PHP. Esto confirma que PHP-FPM está procesando las peticiones correctamente.

<Notice type="warning" title="Elimina el phpinfo de inmediato">
Elimina el archivo de prueba justo después de verificar. Exponer phpinfo() públicamente filtra la configuración de tu servidor, los módulos instalados y las rutas de archivos, información útil para los atacantes.
</Notice>

```bash
rm /var/www/html/info.php
```

**Comprueba el estado de PHP-FPM:**

```bash
systemctl status php8.2-fpm
```

Sustituye `8.2` por tu versión instalada. El estado debería mostrar `active (running)`. Si aparece como failed o inactive, revisa `/var/log/php8.x-fpm.log` en busca de errores.

**Benchmark rápido de CPU (opcional):**

```bash
sysbench cpu --cpu-max-prime=20000 run
```

Esto te da una línea base para comparar tu VPS con otros. Consulta [cómo hacer benchmark a tu servidor cloud](/es/benchmark-servidores-cloud/) para pruebas más exhaustivas.

Después de verificar tu configuración y antes de salir a producción, [asegura tu VPS con CrowdSec](/es/crowdsec-servidor-seguro/) — es gratuito y bloquea ataques de fuerza bruta automáticamente.

## Costos ocultos a tener en cuenta

<Notice type="warning" title="Presupuesta el precio real">
El precio mensual anunciado rara vez es lo que pagarás. Estas son las trampas de costos que pillan a la gente desprevenida.
</Notice>

- **Recargo por IPv4 de Hetzner.** €0.50/mes en todos los planes compartidos. No incluido en el precio principal.
- **Precios de renovación de Hostinger.** El precio inicial de $2.99/mes salta a $7.99/mes al renovar. El compromiso de 48 meses te ata, pero la renovación golpea fuerte.
- **Plan de $2.50 de Vultr.** Solo IPv6, limitado a 2 instancias. Inutilizable para hosting PHP estándar con DNS y correo. El mínimo real es $3.50/mes.
- **Backups de DigitalOcean.** Los backups automáticos cuestan el 20% del precio del droplet. Un droplet de $6/mes pasa a $7.20/mes con backups.
- **Backups de Hetzner.** También el 20% del precio de la instancia.
- **Excesos de ancho de banda de Cloudways.** $0.02-$0.12/GB según el proveedor subyacente. Los sitios de alto tráfico pueden acumular cargos.
- **Bases de datos administradas de DigitalOcean.** Empiezan en $15/mes por la instancia PostgreSQL más pequeña. Autoalojar tu base de datos en el mismo droplet es más barato si puedes gestionarla.

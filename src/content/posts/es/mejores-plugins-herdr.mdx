## Qué son los plugins Herdr y cómo instalarlos sin riesgos

Un plugin TUI es una carpeta con un manifiesto `herdr-plugin.toml` y comandos argv; toda la CLI de `herdr` (vía `HERDR_BIN_PATH`) actúa como API. Guarda siempre credenciales y ajustes en `HERDR_PLUGIN_CONFIG_DIR`, nunca en `HERDR_PLUGIN_ROOT`.

![Diagrama de arquitectura de plugins Herdr con manifiesto, comandos argv y variables inyectadas](@assets/images/26/10/herdr-plugin-anatomy.webp)

<YouTubeEmbed url="https://youtube.com/embed/29KAoidwCUA" label="5 plugins destacados para Herdr" />

```bash
# Instalar con vista previa del manifiesto (nunca --yes la primera vez)
herdr plugin install persiyanov/herdr-reviewr

# Fijar la versión exacta revisada
herdr plugin install persiyanov/herdr-reviewr --ref v1.2.0

# Actualizar plugins de GitHub (nuevo desde Herdr v0.9.4)
herdr plugin update
herdr plugin update herdr-reviewr

# Verificar registro y logs
herdr plugin list --json
herdr plugin log list --plugin plugin.id --limit 20
```

<Notice type="success" title="Novedades en Herdr v0.9.4 y v0.9.5">
**`herdr plugin update`** llegó en `v0.9.4` (13 oct 2026): actualiza uno o todos los plugins de GitHub mientras los paneles activos siguen funcionando sin recargar configuración y respetando plugins enlazados localmente (`herdr plugin link`). `v0.9.5` corrigió además fallos de paneles en Windows y atajos de prefijo en Tern y Ghostty.
</Notice>

## Los 10 mejores plugins Herdr TUI que merecen la pena

Instala siempre con `owner/repo` completo para evitar colisiones de nombres.

![Mapa del marketplace Herdr agrupado por tarea con los 10 plugins recomendados](@assets/images/26/10/herdr-marketplace-by-job.webp)

1. **`persiyanov/herdr-reviewr`:** abre el diff del agente en un panel y devuelve comentarios por línea a Claude Code, Codex, OpenCode y Pi. Alternativa ligera: `jhochenbaum/herdr-hunk-diff`.
2. **`smarzban/herdr-file-viewer`:** explorador git de solo lectura con Markdown y diffs (o `alexarthurs/herdr-sidebar` si prefieres edición y git staging).
3. **`furkankly/zoetrope`:** grafo en tiempo real de sesiones de Claude Code y Codex.
4. **`levi-qiao/herdr-agent-usage`:** medidores de contexto, caché y gasto por agente (cuidado con el homónimo `senna-lang/herdr-agent-usage`). Alternativa: `hhdebb/herdr-radar`.
5. **`cloudmanic/herdr-plus`:** reconstruye espacios multipestaña desde archivos TOML en tus dotfiles + Quick Actions.
6. **`kryptamine/herdr-auto-title`:** nombra pestañas según rama git y sesión (alternativa en shell fácil de auditar: `qu8n/herdr-automatic-rename`).
7. **`thanhdat77/herdr-navigator`:** buscador difuso de espacios, agentes y máquinas remotas (buena pareja con [zoxide](/es/zoxide-tutorial/)).
8. **`ntindle/herdr-resurrect`:** instantáneas de espacios y pestañas tras reinicios (complementa tus copias con [Pluton / Restic](/es/pluton-backup-autoalojado/)).
9. **`speardragon/herdr-plugin-manager`:** gestor emergente (`prefix+p`) para explorar, activar y borrar plugins.
10. **`AltanS/collie`:** PWA móvil segura detrás de `tailscale serve`. Si usas `herdr-core`, revisa también la nueva app oficial Herdr Mobile en [mejores clientes Herdr](/es/mejores-clientes-herdr/).

## Lista de verificación de 5 minutos antes de instalar

![Flujograma de auditoría de plugins Herdr en cinco pasos](@assets/images/26/10/herdr-plugin-vetting-flow.webp)

<ListCheck>
<ul>
<li>Lee <code>herdr-plugin.toml</code> completo, en especial <code>[[build]]</code>, <code>[[startup]]</code> y <code>[[actions]]</code>.</li>
<li>Desconfía de wrappers de shell (<code>bash -c</code>) y revisa accesos a <code>~/.ssh</code>, <code>~/.aws</code> o <code>.env</code>.</li>
<li>Comprueba historial del autor y licencia (evita repos <code>NOASSERTION</code> en trabajo comercial).</li>
<li>Fija la etiqueta auditada con <code>--ref</code> y no uses <code>--yes</code> al instalar por primera vez.</li>
<li>Antes de abrir plugins remotos, aplica <a href="/es/informe-seguridad-bsi-docker-ufw/">endurecimiento de firewall</a> y usa Tailscale.</li>
</ul>
</ListCheck>

## Preguntas frecuentes

<Accordion label="¿Cómo actualizo los plugins de Herdr ahora?" group="faq" expanded="true">
En Herdr TUI `v0.9.4` o superior, ejecuta `herdr plugin update` para actualizar todos los plugins de GitHub o `herdr plugin update <nombre>` para uno concreto, sin recargar configuración.
</Accordion>

<Accordion label="¿Sirven los plugins de Herdr TUI en la Herdr Desktop App?" group="faq">
No. Los plugins (`herdr-plugin`) son para Herdr TUI; la app oficial `herdr-app` usa mods QuickJS (`herdr-mod`) y layouts JSON (`herdr-layout`) de `herdr.dev/gallery/`.
</Accordion>

<Accordion label="¿Qué diferencia hay entre un plugin Herdr y una Agent Skill?" group="faq">
Los plugins amplían el runtime de terminal (paneles, eventos, atajos); las skills dan instrucciones al modelo. Ver [mejores AI skills](/es/mejores-skills-ia-diseno-web/).
</Accordion>

Acortar enlaces tiene beneficios reales para cualquiera que gestione enlaces con regularidad:

- Hace que las URLs sean fáciles de usar y memorables

## Qué es Slash (un gestor autoalojado de marcadores y enlaces)

[Slash](https://github.com/yourselfhosted/slash) es una plataforma de código abierto y autoalojada de marcadores y enlaces compartidos. Está construida con Go en el backend y TypeScript/React en el frontend. La plataforma te permite organizar enlaces con etiquetas, compartirlos con URLs acortadas personalizadas y seguir su rendimiento mediante analíticas.

<li>Colecciones: agrupa atajos relacionados en carpetas virtuales (`c/collection-name`)</li>
<li>Analíticas: consulta referentes, navegadores, sistemas operativos y datos de clics</li>
<li>Modo oscuro: actívalo en Profile -> Preference -> Color Theme</li>
<li>Compartir en equipo: comparte bibliotecas de enlaces con compañeros</li>
<li>Tokens de acceso a la API: acceso programático a todas las funciones de Slash</li>
<li>Soporte de PostgreSQL: alternativa al SQLite predeterminado para despliegues más grandes</li>
<li>Extensiones de navegador: Chrome y Firefox para guardar enlaces directamente desde tu navegador</li>

La función **Collections** (añadida en v0.5.0) merece un vistazo más de cerca. Las colecciones son carpetas virtuales que agrupan atajos relacionados. Tienen su propio esquema de URL (`c/collection-name`), controles de visibilidad y pueden compartirse públicamente o con compañeros de equipo. Esta fue la mayor mejora respecto a la lista plana de enlaces que ofrecía la versión original.

Slash también soporta internacionalización (i18n) con traducción al chino desde v0.4.5, y tokens de acceso a la API para acceso programático desde v0.4.1.

## Despliega Slash con Docker Compose y Dockge

Esta guía usa Docker Compose para la contenedorización, [Dockge](/es/instalar-dockge/) para la gestión de stacks mediante GUI, y Cloudflare Tunnels para el acceso remoto seguro. La CLI moderna de Docker usa `docker compose` (con espacio). El antiguo `docker-compose` (con guion) se eliminó por completo en abril de 2025.

<YouTubeEmbed
  url="https://www.youtube.com/embed/HswSqueUAQc"

### 1. Requisitos previos

Antes de empezar, asegúrate de tener lo siguiente:

- Un VPS donde puedas alojar Slash. Puedes usar [Hetzner](https://go.bitdoze.com/hetzner), [Hostinger](https://go.bitdoze.com/hostinger-vps), o usar un [mini PC GMKtec M5 Ultra](/go/gmktec-m5-ultra/) como [servidor doméstico](/es/mejor-mini-pc-servidor-casa/)
- [Dockge instalado](/es/instalar-dockge/) en tu servidor para la gestión de Docker Compose
- Cloudflare Tunnels configurado para tu VPS (los detalles se cubren en el artículo de instalación de Dockge)

_Los precios de los VPS subieron en todo el mercado en 2026 — si estás reconsiderando un servidor alquilado, mira [qué cambió y cuándo gana un mini PC](/es/subidas-precios-vps/)._

<Notice type="warning" title="Docker Compose v1 ya no existe">
Docker Compose v1 (`docker-compose` con guion) se eliminó en abril de 2025. Usa `docker compose` (con espacio) en su lugar. El campo `version:` en los archivos compose también es obsoleto y debe eliminarse.
</Notice>

> También puedes [usar Traefik como proxy inverso](/es/traefik-proxy-docker/) para tus apps en lugar de Cloudflare Tunnels. Tengo un tutorial completo con la instalación de Dockge que cubre la configuración.

### 2. Añade el archivo Docker Compose en Dockge

Debajo está el archivo Docker Compose para Slash. Fíjate en que no hay línea `version:`. Ese campo es obsoleto en el Docker Compose moderno.

<Tabs>
<Tab name="Básico (SQLite)">

```yaml
services:
  slash:
    image: yourselfhosted/slash:latest
    container_name: slash
    ports:
      - 5006:5231
    volumes:
      - ./slash:/var/opt/slash
    restart: unless-stopped
```

Esto descarga la última imagen de Slash y crea un volumen en la ruta local donde se encuentra el stack de Dockge. Puedes cambiar el puerto `5006` por el que prefieras.

</Tab>
<Tab name="Con PostgreSQL">

```yaml
services:
  slash:
    image: yourselfhosted/slash:latest
    container_name: slash
    ports:
      - 5006:5231
    volumes:
      - ./slash:/var/opt/slash
    environment:
      - SLASH_DRIVER=postgres
      - SLASH_DSN=postgresql://user:password@db:5432/slash
    restart: unless-stopped
  db:
    image: postgres:16
    container_name: slash-db
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=slash
    volumes:
      - ./pgdata:/var/lib/postgresql/data
    restart: unless-stopped
```

El soporte de PostgreSQL se añadió en Slash v0.5.1. Es útil para despliegues más grandes o si ya ejecutas PostgreSQL. También puedes configurar estas opciones mediante flags de CLI: `--driver postgres --dsn 'postgresql://...'`. Consulta nuestra guía sobre cómo [configurar variables de entorno en Docker](/es/variables-entorno-docker/) para más detalles.

</Tab>
</Tabs>

Slash también mantiene un [docker-compose.yml oficial](https://github.com/yourselfhosted/slash/raw/main/docker-compose.yml) en el repositorio si quieres una referencia.

En Dockge, pulsa compose y guarda. Después, puedes elegir la red externa predeterminada de Dockge:

<Picture formats={["webp"]} fallbackFormat="webp" src={imag3} alt="Interfaz de Dockge mostrando el despliegue del stack Docker Compose de Slash" />

Pulsa guardar e inicia el contenedor. Debería arrancar sin problemas.

### 3. Configura Cloudflare Tunnels para un acceso seguro

Necesitas indicarle a Cloudflare Tunnel qué puerto usa Slash. Ve a tu panel de Cloudflare Zero Trust y configura el túnel:

<Notice type="info" title="Navegación actualizada">
La navegación del panel de Cloudflare Zero Trust se reestructuró. La nueva ruta es: **Zero Trust -> Networks -> Connectors -> Cloudflare Tunnels** (la antigua ruta "Access -> Tunnels" ya no existe).
</Notice>

Añade un hostname público que mapee un dominio o subdominio al puerto de tu contenedor Slash (5006 en nuestro ejemplo):

<Picture formats={["webp"]} fallbackFormat="webp" src={imag4} alt="Configuración del túnel de Cloudflare Zero Trust, añadiendo un hostname público para Slash" />

Introduce la IP de tu servidor y el puerto que elegiste en el archivo compose.

> También puedes consultar [CloudPanel como proxy inverso](/es/configurar-dockge-cloudpanel/) o [usar Traefik como proxy inverso](/es/traefik-proxy-docker/) como alternativas a Cloudflare Tunnels. Mira también nuestra [guía de Cloudreve con Docker](/es/instalar-cloudreve-docker/) para una configuración similar de Cloudflare Tunnel con otra app autoalojada.

### 4. Accede a Slash y organiza enlaces con colecciones

Accede a Slash usando el dominio que configuraste en Cloudflare. En la primera visita, se te pedirá crear una cuenta de administrador.

<Picture formats={["webp"]} fallbackFormat="webp"
  src={imag5}
  alt="Interfaz de Slash para añadir y organizar enlaces y colecciones"
/>

<ListCheck>
<ul>
<li>Crea tu cuenta de administrador en el primer inicio de sesión</li>
<li>Añade tu primer atajo con `s/shortcut-name`</li>
<li>Crea una colección con `c/collection-name` para agrupar enlaces relacionados</li>
<li>Instala la extensión de navegador para Chrome o Firefox</li>
<li>Activa el modo oscuro en Profile -> Preference -> Color Theme</li>
</ul>
</ListCheck>

Las colecciones son la función destacada desde la versión original de este artículo. Puedes crear colecciones como `c/dev-tools` o `c/social` para organizar enlaces en grupos lógicos. Cada colección tiene su propia URL, puede configurarse como pública o privada, y puede compartirse con compañeros de equipo.

## Conclusión

Slash ha madurado desde sus primeras versiones. Con más de 3.200 estrellas en GitHub, soporte de PostgreSQL, colecciones, tokens de acceso a la API y una comunidad activa en Discord, es una opción sólida para cualquiera que quiera un acortador de enlaces autoalojado con control total sobre sus datos.

El despliegue es sencillo: Docker Compose gestiona el contenedor, Dockge te da una interfaz web limpia para administrarlo, y Cloudflare Tunnels lo expone de forma segura sin abrir puertos en tu firewall. Slash también está disponible como despliegue de un clic en Coolify si prefieres ese flujo de trabajo.

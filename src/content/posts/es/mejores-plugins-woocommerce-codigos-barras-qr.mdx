Los códigos de barras y los QR en WooCommerce sirven para dos cosas distintas: gestión de inventario y pedidos en el backend, y pago o consulta de productos de cara al cliente. El plugin correcto depende de qué problema estás resolviendo.

Si tu problema mayor es la velocidad de gestión de productos más que el escaneo, quizá también te interese el [dashboard de administración de WooCommerce open-source](/es/dashboard-admin-woocommerce/) que construí para editar productos más rápido.

## 1. YITH WooCommerce Barcodes and QR Codes (de pago)

<Picture formats={["webp"]} fallbackFormat="webp" src={imgYith} alt="Plugin YITH WooCommerce Barcodes and QR Codes" />

[YITH Barcodes and QR Codes](https://yithemes.com/themes/plugins/yith-woocommerce-barcodes-and-qr-codes/) es el plugin generador de códigos de barras para WooCommerce más capaz de esta lista. Genera códigos de barras automáticamente para productos y pedidos, soporta 10 protocolos de código de barras y puede disparar acciones cuando se escanea un código, como reducir el stock o cambiar el estado del pedido.

Funciones destacables:
- Genera códigos automáticamente para todos los productos (incluidos los variables)
- Tipos de código de barras: ID de producto, SKU, campos personalizados
- Escanea y busca pedidos/productos por código de barras
- Imprime PDF con todos los códigos de producto (con recuentos de unidades en stock)
- Muestra códigos de barras en los emails de confirmación de pedido. Los códigos en los emails no sirven de nada si esos emails acaban en spam, así que [asegúrate de que tus emails de pedidos de WooCommerce llegan](/es/enviar-emails-wordpress-zoho-smtp-fluentsmtp/)

**Precio:** 89,99 $/año (precio de lista a noviembre de 2026; YITH hace rebajas frecuentes en todo el sitio, así que comprueba su web antes de comprar).

## 5. UPI QR Code Payment Gateway (gratis)

<Picture formats={["webp"]} fallbackFormat="webp" src={imgUpi} alt="Plugin UPI QR Code Payment Gateway" />

[UPI QR Code Payment Gateway](https://wordpress.org/plugins/upi-qr-code-payment-for-woocommerce/) añade UPI como opción de pago en el checkout para tiendas de India. Los clientes ven un código QR con los datos del pago; en móvil tienen un botón que abre directamente su app UPI instalada (BHIM, Google Pay, Paytm, PhonePe, WhatsApp Pay). Sin comisiones de pasarela, sin comisiones.

Esto es específico de India: solo es útil si tus clientes pagan por UPI.

El plugin lo mantiene ahora **KnitPay**. La v1.7.0 (21 de octubre de 2026) es una release de seguridad: el plugin ahora valida las subidas de capturas en el servidor (solo JPEG/PNG reales, con límite de tamaño), borra las capturas junto con el pedido e incluye los IDs de UPI/transacción en las herramientas de exportación/borrado de datos personales de WordPress. El flujo de subida de capturas del cliente es una superficie de ataque, así que no ejecutes versiones antiguas de este plugin.

v1.7.0 · 10.000 instalaciones activas · 96% de valoración (256 valoraciones) · probado hasta WP 7.2

### Vía de mejora: verificación automática con Knit Pay

El plugin UPI gratuito es manual: el cliente sube una captura del pago y tú la verificas a mano. **Knit Pay UPI** (`knit-pay-upi`) y **Knit Pay** (`knit-pay`), del mismo equipo, integran apps de negocio (Paytm Business, PhonePe Business, BharatPe, HDFC) para verificación automática de pagos. Ambos tienen conteos de instalaciones pequeños (unas 200 y 2.000 respectivamente), así que prueba en staging antes de comprometerte.

## Antes de instalar: 3 comprobaciones (HPOS, salud del plugin, copias)

<ListCheck>
  <ul>
    <li>El plugin declara compatibilidad con HPOS (o has verificado que funciona con HPOS activado)</li>
    <li>El plugin está sano en wp.org: no cerrado, actualizado recientemente</li>
    <li>Copia de seguridad y staging en marcha antes de instalar nada</li>
  </ul>
</ListCheck>

### Comprueba la compatibilidad con HPOS

El WooCommerce moderno usa High-Performance Order Storage. Los plugins que escriben datos de códigos de barras en los metadatos de pedidos deben declarar compatibilidad con HPOS. Comprobación rápida en cualquier tienda:

```bash
# ¿HPOS activado?
wp option get woocommerce_custom_orders_table_enabled   # true/false
# estado de sincronización (si migras)
wp option get woocommerce_hpos_data_syncing
```

Revisa también el readme de cada plugin o su aviso de admin buscando una declaración «HPOS compatible». No lo des por hecho. Ejecuta estas comprobaciones primero en staging. Si no tienes un entorno de staging, [levanta un sitio de pruebas de WordPress con Docker Compose](/es/instalar-wordpress-docker/).

### Comprueba la salud del plugin antes de instalar

El cierre de Payment QR WooCommerce es una lección útil: antes de instalar nada, mira en wp.org la «última actualización» y si el plugin ha sido cerrado. One-liner:

```bash
curl -s "https://api.wordpress.org/plugins/info/1.2/?action=plugin_information&request[slug]=wc-qr-payment" \
  | jq '{name, version, last_updated, active_installs}'
```

Una respuesta vacía o de error significa que el plugin probablemente está cerrado. Un plugin cerrado por seguridad deja las instalaciones existentes huérfanas: sin actualizaciones, sin parches, y puede que ni te enteres.

### Haz copia (y staging) antes de instalar

Haz copia de tu sitio antes de añadir o actualizar plugins. Mira los [mejores plugins gratuitos de copias de seguridad para WordPress](/es/mejores-plugins-gratuitos-backup-wordpress/) para opciones que no te costarán nada. Prueba en staging antes de tocar producción. Si tu hosting actual no tiene entorno de staging, un [hosting gestionado de WordPress con staging](https://go.bitdoze.com/cloudways) es la opción de bajo esfuerzo.

Ya que estás reforzando cosas: [asegura tu admin de WordPress con autenticación de dos factores](/es/securizar-wordpress-2fa/). Cada plugin instalado es una superficie de ataque.

## ¿Qué plugin de códigos de barras para WooCommerce deberías usar?

**Para gestión de inventario y pedidos** (escaneo, actualizaciones de stock, impresión de etiquetas PDF), YITH es la opción de pago más capaz, pero prueba primero el plugin gratuito Barcode Scanner. Cubre el flujo básico de escanear-para-actuar a coste cero. Paga YITH cuando necesites auto-generación, acciones de stock/pedido disparadas por escaneo y hojas de etiquetas PDF a volumen.

**Para imprimir etiquetas físicas**, el plugin gratuito Barcode Generator cubre etiquetas de producto y de pedido en impresoras A4 y térmicas. No hace falta pagar.

**Para entradas electrónicas, check-ins de eventos y reservas**, WooCommerce Order Barcodes está hecho a propósito. Solo lee primero esas reseñas.

**Para pagos con QR**, usa UPI QR Code Payment Gateway si estás en India (con la vía de mejora de Knit Pay para verificación automática), o QR Payment for WooCommerce para QR de transferencia bancaria por IBAN en otros lugares.

**Para cumplimiento de marketplaces** (códigos EAN/UPC/GTIN), el plugin EAN Barcode Generator es el camino sólido más barato. Su plan gratuito basta para la mayoría de catálogos.

**Para QR generales en cualquier página** (enlaces de producto, datos de contacto, URL), Kaya QR Code Generator es gratis y hace el trabajo.

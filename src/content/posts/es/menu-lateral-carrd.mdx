[Carrd.co](https://go.bitdoze.com/carrd) es una plataforma excelente para crear sitios web de una sola página, pero la navegación se complica en cuanto tienes más de unas pocas secciones. Un menú lateral resuelve esto manteniendo la navegación fuera de la pantalla hasta que el visitante la necesita. Sin desperdiciar espacio en pantalla, sin encabezados recargados.

Un menú lateral en Carrd funciona bien porque:

1. **Maximiza el espacio para el contenido.** La navegación permanece oculta hasta que el visitante toca el botón de hamburguesa, manteniendo el foco en tu contenido.
2. **Mejor organización** para sitios con múltiples secciones. Los visitantes pueden saltar a cualquier zona sin hacer scroll.
3. **Adaptado a móvil.** El panel deslizante usa objetivos táctiles cómodos (40px+) y gestiona correctamente el bloqueo de scroll en iOS.
4. **Posicionamiento personalizable.** Ábrelo desde la izquierda o la derecha, deja el botón flotante o fíjalo en un punto de la página.

## Cómo añadir el menú lateral en Carrd

El enfoque es sencillo: pega un bloque HTML/CSS/JS en un elemento Embed. Sin dependencias externas, sin claves de API, sin paso de compilación.

<Notice type="info" title="Publica para probar">
Los elementos Embed son invisibles en la vista previa del editor de Carrd. Después de añadir el código, publica tu sitio y abre la URL en vivo. Usa Ctrl+Shift+R (o Cmd+Shift+R en Mac) para hacer una recarga forzada y saltarte los estilos en caché.
</Notice>

### 1. Añade un elemento Embed (Type: Code, Style: Hidden, Body End)

Haz clic en el botón `+` del editor de Carrd, añade un elemento **Embed** y configura:

- **Type:** Code
- **Style:** Hidden, Body End

Esto inyecta tu código al final del `<body>` de la página, fuera del propio layout de Carrd, así que se carga en cada sección sin ocupar espacio en tu diseño. Evita Head aquí: el snippet contiene marcado visible (el botón y el panel), y `<head>` no es un lugar válido para él.

La captura muestra el desplegable de ubicación en Head; elige **Body End** en su lugar.

document.addEventListener('DOMContentLoaded', function() {
  // Get elements
  const toggleBtn = document.getElementById('sidebarToggle');
  const closeBtn = document.getElementById('sidebarClose');
  const overlay = document.getElementById('sidebarOverlay');
  const sidebar = document.getElementById('sidebarMenu');
  const body = document.body;
  let savedScrollTop = 0;

  // Get CSS variables
  const sidebarPosition = getComputedStyle(document.documentElement)
    .getPropertyValue('--sidebar-position').trim();
  const isFloating = getComputedStyle(document.documentElement)
    .getPropertyValue('--menu-button-floating').trim() === 'true';
  const floatPosition = getComputedStyle(document.documentElement)
    .getPropertyValue('--menu-button-float-position').trim();
  const floatSide = getComputedStyle(document.documentElement)
    .getPropertyValue('--menu-button-float-side').trim();

  // Set button positioning classes
  if (isFloating) {
    toggleBtn.classList.add('floating');
    if (floatPosition === 'bottom') {
      toggleBtn.classList.add('float-bottom');
    } else {
      toggleBtn.classList.add('float-top');
    }
    if (floatSide === 'right') {
      toggleBtn.classList.add('float-right');
    } else {
      toggleBtn.classList.add('float-left');
    }
  } else {
    toggleBtn.classList.add('static');
  }

  // Set data attributes for positioning
  toggleBtn.setAttribute('data-position', sidebarPosition);
  closeBtn.setAttribute('data-position', sidebarPosition);
  sidebar.setAttribute('data-position', sidebarPosition);

  // Open sidebar function
  function openSidebar() {
    sidebar.classList.add('active');
    overlay.classList.add('active');
    toggleBtn.classList.add('active');
    body.classList.add('sidebar-open');

    // Accessibility: update ARIA states
    toggleBtn.setAttribute('aria-expanded', 'true');
    toggleBtn.setAttribute('aria-label', 'Close menu');
    sidebar.removeAttribute('aria-hidden');

    // iOS scroll-lock: use position: fixed to prevent background scroll
    savedScrollTop = window.pageYOffset || document.documentElement.scrollTop;
    body.style.position = 'fixed';
    body.style.top = '-' + savedScrollTop + 'px';
    body.style.width = '100%';

    // Focus management: move focus into sidebar
    sidebar.focus({ preventScroll: true });
  }

  // Close sidebar function
  function closeSidebar() {
    sidebar.classList.remove('active');
    overlay.classList.remove('active');
    toggleBtn.classList.remove('active');
    body.classList.remove('sidebar-open');

    // Accessibility: update ARIA states
    toggleBtn.setAttribute('aria-expanded', 'false');
    toggleBtn.setAttribute('aria-label', 'Open menu');
    sidebar.setAttribute('aria-hidden', 'true');

    // iOS scroll-lock: restore scroll position
    body.style.position = '';
    body.style.top = '';
    body.style.width = '';
    // Jump straight back even if the site uses smooth scrolling
    const html = document.documentElement;
    html.style.scrollBehavior = 'auto';
    window.scrollTo(0, savedScrollTop);
    html.style.scrollBehavior = '';

    // Focus management: return focus to toggle button
    toggleBtn.focus({ preventScroll: true });
  }

  // Tab-key focus trap inside sidebar when open
  sidebar.addEventListener('keydown', function(e) {
    if (e.key === 'Tab' && sidebar.classList.contains('active')) {
      const focusable = sidebar.querySelectorAll(
        'a[href], button, [tabindex]:not([tabindex="-1"])'
      );
      const first = focusable[0];
      const last = focusable[focusable.length - 1];

      if (e.shiftKey && (document.activeElement === first || document.activeElement === sidebar)) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    }
  });

  // Event listeners
  toggleBtn.addEventListener('click', function(e) {
    e.stopPropagation();
    if (sidebar.classList.contains('active')) {
      closeSidebar();
    } else {
      openSidebar();
    }
  });

  closeBtn.addEventListener('click', closeSidebar);
  overlay.addEventListener('click', closeSidebar);

  // Close sidebar when clicking on navigation links
  const navLinks = document.querySelectorAll('.sidebar-nav a, .contact-button');
  navLinks.forEach(function(link) {
    link.addEventListener('click', function() {
      closeSidebar();
    });
  });

  // Close sidebar on Escape key
  document.addEventListener('keydown', function(e) {
    if (e.key === 'Escape' && sidebar.classList.contains('active')) {
      closeSidebar();
    }
  });

  // Handle window resize
  window.addEventListener('resize', function() {
    if (window.innerWidth > 768 && sidebar.classList.contains('active')) {
      closeSidebar();
    }
  });
});
</script>

### Opciones de posicionamiento del botón: flotante vs estático

**Modo flotante** (`--menu-button-floating: true`): el botón de hamburguesa usa `position: fixed` y permanece visible mientras el visitante hace scroll. Controlas en qué esquina se sitúa con `--menu-button-float-position` y `--menu-button-float-side`.

**Modo estático** (`--menu-button-floating: false`): el botón se posiciona en relación con el lugar de la página donde está el elemento Embed.

<Notice type="warning" title="El modo estático requiere un embed Inline">
Si configuras `--menu-button-floating: false`, el botón solo se integra en tu layout cuando el elemento Embed usa **Style: Inline** (no Hidden). Un embed Hidden, Body End coloca el código después de todo el contenido de Carrd, así que un botón estático acabaría al final de la página. Además, un embed Inline solo se muestra en la sección donde lo colocas. Para la mayoría de configuraciones, mantén el modo flotante activado y usa el embed Hidden, Body End.
</Notice>

### 3. Haz que los enlaces del menú apunten a la sección correcta

Este es el paso que la mayoría de la gente pasa por alto. Los enlaces de tu menú lateral usan hashes de anclaje (`#about`, `#services`, etc.), pero solo funcionan si tu sitio Carrd tiene nombres de sección coincidentes.

<Notice type="info" title="Los nombres de sección deben coincidir con tus valores href">
En el editor de Carrd, añade un elemento **Control** (haz clic en `+`) y selecciona **Section Break**. Dale un nombre que coincida con tu enlace. Por ejemplo, llámalo `about` para el enlace `#about`. Los nombres de sección deben ser **solo letras minúsculas, números y guiones** (sin espacios, sin mayúsculas).
</Notice>

Así funcionan las secciones y los anclajes en Carrd:

1. **Los Section Breaks crean secciones con nombre.** Añade uno vía `+` → Control → Section Break. El nombre se convierte en el destino del anclaje.
2. **La primera sección se llama `home` automáticamente.** Por eso `#home` funciona directamente en la mayoría de sitios Carrd.
3. **Los sitios de una sola sección** pueden usar **Scroll Points** en su lugar. Inserta un control Scroll Point y enlázalo con `#nombre-del-scroll-point`.
4. **Los enlaces profundos funcionan.** Comparte `tusitio.carrd.co/#services` y aterrizará en la sección correcta.
5. **Si los enlaces no saltan**, comprueba que los nombres de los Section Breaks en el editor coinciden exactamente con tus valores `href`. Una errata o una mayúscula romperá el enlace silenciosamente.

Para el comportamiento de desplazamiento suave al hacer clic en enlaces de anclaje, consulta el [tutorial de desplazamiento suave y enlaces de anclaje en Carrd](https://www.bitdoze.com/es/desplazamiento-suave-carrd/).

### 4. Personaliza los elementos del menú

Edita el bloque `<ul class="sidebar-nav">` para que coincida con las secciones de tu sitio:

```html
<ul class="sidebar-nav">
  <li><a href="#home">Home</a></li>
  <li><a href="#about">About</a></li>
  <li><a href="#services">Services</a></li>
  <li><a href="#portfolio">Portfolio</a></li>
  <li><a href="#testimonials">Testimonials</a></li>
  <li><a href="#blog">Blog</a></li>
</ul>
```

Añade o elimina entradas `<li><a href="#section">Nombre de la sección</a></li>`. Cada `href` debe apuntar a un nombre de Section Break real en tu sitio Carrd.

### 5. Personaliza el botón de contacto

El botón de contacto en la parte inferior del menú lateral:

```html
<a href="#contact" class="contact-button">Contact Us</a>
```

Cambia el `href` a cualquier URL (anclaje interno o enlace externo) y actualiza el texto del botón según tus necesidades.

## Características principales

### Optimización para móvil

El menú lateral es totalmente responsive con breakpoints en 768px y 480px. En pantallas más pequeñas, el menú lateral se estrecha, los tamaños de fuente disminuyen y el botón se encoge, pero se mantiene por encima de 40px para los objetivos táctiles.

- Tamaños de botón táctiles (mínimo 40px en el breakpoint más pequeño)
- Espaciado optimizado para pantallas móviles
- Scroll interno en viewports bajos (el menú lateral usa `overflow-y: auto`)

<Notice type="warning" title="Bloqueo de scroll en iOS Safari">
`overflow: hidden` por sí solo no evita el scroll del fondo en iOS Safari. Es un bug conocido de WebKit abierto desde 2014. El código de arriba usa `position: fixed` en el elemento body como solución alternativa, además de `touch-action: none` en la clase `body.sidebar-open`, que cubre la mayoría de los casos. Nota: iOS 26 tiene una regresión reportada con el bloqueo de scroll en overlays. Prueba en un dispositivo físico.
</Notice>

### Animaciones suaves

El menú lateral incluye varios efectos de animación:

- Transiciones de entrada/salida (velocidad configurable vía `--sidebar-animation-speed`)
- Transformación del icono de hamburguesa en una X cuando el menú está abierto
- Efectos hover en los elementos del menú con un resaltado de borde izquierdo de acento
- Efectos de escala y sombra del botón al pasar el cursor

### Accesibilidad

El código incluye atributos ARIA apropiados y soporte de teclado:

- El **botón de alternancia** tiene `aria-label` (alterna entre "Open menu" / "Close menu"), `aria-expanded` y `aria-controls`
- El **menú lateral** usa `aria-hidden="true"` cuando está cerrado, y se elimina cuando está abierto
- Los **spans de la hamburguesa** están marcados con `aria-hidden="true"` (decorativos, no se anuncian)
- El **botón de cierre** tiene `aria-label="Close menu"`
- La **trampa de foco con Tab** mantiene el foco dentro del menú lateral mientras está abierto
- **Retorno del foco:** al cerrar el menú lateral, el foco vuelve al botón de alternancia
- La **tecla Escape** cierra el menú lateral
- Opciones de color de **alto contraste** mediante variables CSS

### Compatibilidad entre navegadores

El código usa funciones CSS modernas (custom properties, flexbox, transiciones) soportadas por todos los navegadores actuales. Si el menú lateral aparece detrás de otros elementos de Carrd, sube los valores de z-index: `.sidebar-overlay` (999 por defecto), `.sidebar-menu` (1000 por defecto), `.sidebar-menu-toggle` (1001 por defecto).

## Solución de problemas

<Accordion label="Mi sitio publicado aparece en blanco" group="troubleshooting">

Un error de sintaxis de JavaScript romperá todo el sitio de Carrd. Abre las DevTools del navegador (F12), revisa la Consola en busca de errores, corrige la sintaxis en tu elemento Embed y republica. La documentación de Carrd afirma que «incluso un simple error de sintaxis romperá el sitio».

</Accordion>

<Accordion label="El botón del menú no aparece" group="troubleshooting">

Probablemente estás usando el modo estático (`--menu-button-floating: false`) con un embed Hidden. Los botones estáticos solo se integran en tu layout desde embeds **Inline**; desde un embed Hidden, Body End el botón acaba al final de la página. Cambia al modo flotante (`--menu-button-floating: true`) o cambia el estilo del embed a Inline.

</Accordion>

<Accordion label="Los enlaces del menú lateral no saltan a las secciones" group="troubleshooting">

Los nombres de tus Section Breaks no coinciden con tus valores `href`. En el editor de Carrd, revisa el nombre de cada Section Break. Debe contener solo letras minúsculas, números y guiones. Por ejemplo, si tu enlace es `#about`, la sección debe llamarse exactamente `about` (no `About`, ni `about-us` a menos que la sección se llame `about-us`). Consulta el [paso de anclajes](#3-haz-que-los-enlaces-del-menú-apunten-a-la-sección-correcta) de arriba.

</Accordion>

<Accordion label="El menú lateral aparece detrás de otros elementos" group="troubleshooting">

Conflicto de z-index. El menú lateral usa z-index 1000, el overlay usa 999 y el botón usa 1001. Si elementos de Carrd u otros embeds tienen valores de z-index más altos, sube estos números en el CSS. El overlay debe estar siempre por debajo del menú lateral, y el botón siempre encima.

</Accordion>

<Accordion label="El fondo hace scroll en iPhone" group="troubleshooting">

Es el bug de WebKit en iOS Safari. `overflow: hidden` en `<body>` no evita el scroll. El código usa `position: fixed` en el body más `touch-action: none` en `body.sidebar-open` como solución alternativa. Si aún así hace scroll, comprueba que ambos sigan en tu copia del código. Prueba en un iPhone físico, no solo en el simulador.

</Accordion>

<Accordion label="Los cambios no aparecen tras guardar" group="troubleshooting">

Los elementos Embed no se renderizan en la vista previa del editor de Carrd. Debes publicar el sitio para ver los cambios. Tras publicar, haz una recarga forzada con Ctrl+Shift+R (Cmd+Shift+R en Mac) para saltarte la caché del navegador.

</Accordion>

## Conclusión

Un menú lateral en Carrd le da a tu sitio de una página una navegación profesional sin sacrificar espacio para el contenido. El enfoque requiere Carrd Pro Standard (19 $/año) como mínimo: un elemento Embed, un pegado de código, y listo.

Las variables CSS facilitan adaptarlo a tu imagen de marca, los atributos ARIA lo mantienen accesible y los breakpoints móviles se encargan de las pantallas pequeñas. Guarda una copia del código en un lugar seguro: como se ejecuta en cada sección del sitio, un error de sintaxis puede dejar todo el sitio caído hasta que lo corrijas y republiques.

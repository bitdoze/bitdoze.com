[Herdr](https://herdr.dev/) es un runtime gratuito bajo licencia Apache-2.0 para agentes de código con más de 52.000 estrellas en GitHub, dividido hoy en dos productos oficiales: **Herdr TUI (`v0.9.5`)** dentro de tu terminal y las nuevas apps nativas **Herdr Desktop (`v0.1.16`) + Mobile** sobre `herdr-core` (`v0.1.21`).

Cuando ejecutas tres, cinco o diez agentes a la vez (Claude Code en un panel, [Codex](/es/codex-app-cualquier-modelo/) en otro, OpenCode o Pi en un tercero), las pestañas sueltas se convierten en caos. Nunca sabes qué agente sigue trabajando y cuál lleva veinte minutos esperando un permiso. Herdr resuelve eso con una barra lateral de estado en tiempo real (`working`, `blocked`, `done`, `idle`), sesiones persistentes y soporte multi-máquina por SSH.

Ha cambiado muchísimo desde mi primera reseña en julio de 2026. Entonces era un proyecto individual de 15.000 estrellas bajo AGPL. Hoy cuenta con respaldo de Y Combinator y una ronda semilla de $6M liderada por Bessemer Venture Partners, cambió a licencia **Apache-2.0** y ofrece una app de escritorio nativa además de apps gratuitas para iPhone, iPad y Android.

<Notice type="info" title="Ahora hay dos productos Herdr con daemons separados">
**Herdr TUI (`herdr` v0.9.5)** corre en tu terminal con su propio servidor. **Herdr Desktop (`herdr-app` v0.1.16)** y **Herdr Mobile** funcionan sobre **`herdr-core` (`hc` v0.1.21)** con el protocolo abierto OSC 7501. **No comparten agentes**: los paneles abiertos en `herdr` TUI no aparecen en `herdr-app` ni en la app oficial Herdr Mobile.
</Notice>

## Qué es Herdr y en qué se diferencian sus dos versiones

Herdr mantiene vivos tus agentes en un servidor en segundo plano para que cerrar el terminal, perder el SSH o suspender el portátil nunca corte una ejecución, mientras agrupa en una sola barra qué agentes necesitan tu intervención en máquinas locales y remotas.

| Línea | Binario / repo | Última versión (nov 2026) | Ideal para | Extensiones | App móvil oficial |
|---|---|---|---|---|---|
| **Herdr TUI** | `herdr` (`herdrdev/herdr`, 52K+ estrellas) | `v0.9.5` (14 oct 2026) | Usuarios de terminal, VPS por SSH, Ghostty/Kitty/WezTerm | Plugins TUI (`herdr plugin install` + `herdr plugin update`) | No (usa Moshi, ColliePWA o SSH) |
| **Herdr App + Core** | `herdr-app` + `hc` (`herdrdev/herdr-app`, `herdrdev/herdr-core`) | `v0.1.16` / `v0.1.21` (nov 2026) | Ventana GPU nativa, UIs personalizadas por agentes, control móvil oficial | 312+ layouts y 576+ mods JS (`herdr.dev/gallery`) | Sí (gratis en iOS, iPadOS y Android vía SSH/Tailscale) |

![Arquitectura de Herdr mostrando el modelo cliente-servidor con servidor de sesiones, paneles PTY, barra de estado y API por socket](@assets/images/26/07/herdr-architecture.webp)

Ambas líneas comparten el mismo núcleo conceptual: PTYs reales en un daemon local, clientes ligeros conectados por socket o SSH, cero intermediarios en la nube y código Apache-2.0. Herdr TUI sigue siendo un único binario Rust de ~11 MB dentro de tu terminal. Herdr App envuelve `herdr-core` en una ventana nativa Rust/GPUI (con el motor de terminal de Ghostty) cuyos layouts y mods en JavaScript puede reescribir tu propio agente.

![Bandeja de entrada oficial de Herdr Mobile en iPhone mostrando agentes ordenados por Needs you, Done, Working e Idle](@assets/images/26/11/herdr-mobile-inbox.webp)

Si comparas [herramientas de codificación con IA](/es/herramientas-codificacion-ia/) o entornos como [FreeBuff](/es/freebuff-agente-ia-gratis/) y [Zcode](/es/resena-zcode-ai/), Herdr se sitúa una capa por debajo: aloja tus CLI reales sin encerrarte en un proveedor. Orca y T3 Code trabajan en esa misma capa; los enfrenté en [Orca vs T3 Code](/es/orca-vs-t3-code/).

## Cómo instalar Herdr (TUI o Desktop + Core)

Elige Herdr TUI si trabajas en Ghostty, WezTerm, Kitty o SSH puro; elige Herdr Desktop (`herdr-app`) si quieres la ventana nativa, la galería de layouts y la app oficial Herdr Mobile.

<Tabs>
<Tab name="Herdr TUI (Linux / macOS)">

```bash
curl -fsSL https://herdr.dev/install.sh | sh
# o: brew install herdr
# o: mise use -g herdr

herdr --version
```

`herdr update` actualiza el binario y avisa qué servidores en marcha siguen en una versión anterior.

</Tab>
<Tab name="Herdr TUI (Windows / Nix)">

```powershell
# Windows PowerShell
irm https://herdr.dev/install.ps1 | iex
```

Para Nix, `herdrdev/herdr-nix` publica binarios precompilados en Cachix para evitar compilar Rust + Zig desde cero en cada instalación.

</Tab>
<Tab name="Herdr Desktop App + Core">

```bash
# macOS (Apple Silicon)
brew install --cask herdr-app

# Linux (x86_64 y ARM64, requiere Vulkan)
curl -fsSL https://releases.herdr.dev/app/install.sh | sh

# herdr-core (hc) independiente en un VPS Linux sin entorno gráfico
curl -fsSL https://releases.herdr.dev/core/install.sh | sh
```

</Tab>
</Tabs>

### Primeros pasos y acceso remoto por SSH

Arranca una sesión con nombre en TUI con `herdr session attach work`. Los atajos clásicos (`Ctrl+B` + `v` / `-` / `q`) conviven con ratón completo. En `v0.9.5`, vuelve a ejecutar `herdr integration install codex` si actualizaste desde una versión previa (Herdr eliminó los hooks ruidosos de turno de Codex y volvió a detección de pantalla):

```bash
herdr integration install claude
herdr integration install codex
herdr integration install copilot
```

![Flujo SSH remoto de Herdr conectando portátil a VPS con servidor de sesiones](@assets/images/26/07/remote-ssh-workflow.webp)

```bash
# Barra multi-máquina en TUI (v0.9.0+)
herdr machine add workbox --label "Build box"
herdr --remote workbox

# Máquina remota en herdr-core (v0.1.21+)
hc machine add box@my-server
hc run --on my-server --bg claude
hc ls
```

<Notice type="warning" title="Mantén vivos los agentes Linux tras cerrar SSH">
Si systemd mata tus procesos al desconectarte, ejecuta `sudo loginctl enable-linger $USER` en el VPS. Desde `herdr-core v0.1.21`, `hc machine add` y `hc server status` lo detectan y muestran el comando exacto.
</Notice>

## Orquestación entre agentes

Tanto Herdr TUI como `herdr-core` permiten que un agente principal lance ayudantes, espere a que terminen o pidan permiso y lea su salida sin copiar nada manualmente.

![Diagrama de orquestación donde un agente principal crea ayudantes, monitoriza estados y lee resultados por API](@assets/images/26/07/orchestration-flowchart.webp)

```bash
# En herdr-core (hc)
hc run --bg --name review codex "review src/x.rs. Done: hc send $HC_TERMINAL_ID"
hc wait review
hc read --lines 60 review
hc send review "revisa también los tests"
```

Cualquier agente aprende toda la sintaxis leyendo `hc --skill`. Para flujos con tablero persistente, compáralo con [Hermes Kanban](/es/guia-kanban-hermes/).

## Herdr vs tmux vs Zellij

| Característica | Herdr TUI (`v0.9.5`) | Herdr App + Core (`v0.1.16`) | tmux | Zellij |
|---|---|---|---|---|
| Barra de estado de agentes | Sí (hooks + pantalla) | Sí (protocolo OSC 7501) | No | No |
| Orquestación (`wait`/`send`) | Sí (`herdr`) | Sí (`hc`) | Solo scripting | Solo plugins |
| Interfaz con ratón | Sí | Ventana GPU nativa (GPUI) | Requiere config | Sí |
| Multi-máquina por SSH | Sí (`herdr machine add`) | Sí (`hc machine add`) | SSH manual | SSH manual |
| App móvil oficial | No (Moshi / ColliePWA / SSH) | Sí (iOS, iPadOS, Android) | No | No |
| Sandboxing de plugins | No (código de confianza) | No (mods JS de confianza) | No | Sí (WASM) |
| Licencia | Apache-2.0 | Apache-2.0 | ISC | MIT |

Para una comparativa amplia con [Superlogical Rex](/es/superlogical-rex/) y [Tern](/es/terminal-tern/), consulta [mejores multiplexores de terminal](/es/mejores-multiplexores-terminal/).

## Advertencias honestas antes de migrar

<ListCheck>
<ul>
<li><strong>Dos daemons distintos:</strong> lo que arrancas en <code>herdr</code> TUI no se ve en <code>herdr-app</code> ni en Herdr Mobile. Elige un runtime por flujo.</li>
<li><strong>Ritmo pre-1.0:</strong> tanto <code>0.9.x</code> como <code>0.1.x</code> evolucionan rápido y pueden cambiar APIs de mods o hooks.</li>
<li><strong>Sin sandbox:</strong> plugins TUI y mods JS corren con tus permisos de usuario; revísalos antes de instalar.</li>
<li><strong>Telemetría por defecto en Desktop:</strong> Herdr TUI tiene cero telemetría; <code>herdr-app</code> la trae activada en builds de release (se apaga en Settings &gt; Privacy).</li>
<li><strong>Reinicios del servidor:</strong> cerrar el cliente no corta nada, pero reiniciar el host sí detiene procesos. Activa <code>restore_screen = true</code> en <code>herdr-core</code> si quieres ver la última pantalla tras reiniciar.</li>
</ul>
</ListCheck>

## Preguntas frecuentes

<Accordion label="¿Herdr es gratis y open source?" group="faq" expanded="true">
Sí. Herdr TUI, Herdr Desktop App y `herdr-core` tienen licencia **Apache-2.0** (cambiaron desde AGPL-3.0 en 2026). La app oficial Herdr Mobile en iOS y Android también es gratuita y no exige cuenta.
</Accordion>

<Accordion label="¿Empiezo con Herdr TUI o con la app de escritorio?" group="faq">
Empieza por **Herdr Desktop App** (`herdr-app`) si quieres ventana GPU nativa, la galería de 312+ layouts y 576+ mods y la app oficial Herdr Mobile. Elige **Herdr TUI** (`herdr`) si prefieres seguir dentro de Ghostty, WezTerm o Kitty con el ecosistema de plugins TUI.
</Accordion>

<Accordion label="¿Por qué mis sesiones de Herdr TUI no salen en Herdr Desktop o Mobile?" group="faq">
Usan servidores distintos: Herdr TUI usa el daemon `herdr`, mientras Desktop y Mobile hablan con `herdr-core` (`hc`). Pueden convivir en la misma máquina, pero no comparten paneles.
</Accordion>

Herdr cuenta ya con una **app oficial de escritorio** (`herdr-app v0.1.16` para macOS, Linux y Windows) y una **app móvil oficial gratuita** (iPhone, iPad y Android) sobre `herdr-core`, junto a **Herdr TUI (`v0.9.5`, más de 52K estrellas)**. Sigue sin haber interfaz web oficial, por lo que los paneles de navegador continúan en manos de la comunidad.

Esto cambia por completo la decisión frente a octubre de 2026: primero eliges si trabajas sobre **Herdr App + `herdr-core`** (apps oficiales de escritorio y móvil, más Moshi) o sobre **Herdr TUI** (tu terminal actual más ColliePWA, Heeler, `herdr-web-ui`, `herdrm`, Herdr UI y Moshi). Si empiezas de cero con el runtime, lee primero nuestra [reseña de Herdr](/es/herdr-multiplexor-agentes/).

<Notice type="warning" title="Las apps oficiales y la TUI usan daemons separados">
**Herdr Desktop (`herdr-app` v0.1.16)** y **Herdr Mobile** hablan con **`herdr-core` (`hc` v0.1.21)**. **Herdr TUI (`herdr` v0.9.5)** y los clientes comunitarios de TUI (ColliePWA, `herdr-web-ui`, Heeler, `herdrm`, `penso/herdr-gpui`) hablan con el **daemon TUI**. Solo **Moshi (`moshi-hook v0.4.62`)** conecta ambos mundos hoy.
</Notice>

## ¿Qué cliente Herdr deberías elegir?

Elige **Herdr Desktop + Herdr Mobile** para un stack oficial gratuito sobre `herdr-core` por SSH/Tailscale; elige **Herdr TUI + ColliePWA o Moshi** si prefieres Ghostty/WezTerm/Kitty con plugins TUI y acceso web o Mosh.

| Escenario | Mejor cliente | Daemon | Exposición | Piezas extra |
|---|---|---|---|---|
| Ventana de escritorio nativa + layouts | **Herdr Desktop oficial (`herdr-app`)** | `herdr-core` (`hc`) | Local + SSH | Una app nativa |
| Control móvil/tablet oficial gratis | **Herdr Mobile oficial** (iOS/Android) | `herdr-core` (`hc`) | SSH directo / Tailscale | Sin cuenta ni relay |
| Terminal clásico en tu equipo | **Herdr TUI (`herdr`)** | Herdr TUI (`v0.9.5`) | Ninguna | Un binario Rust |
| Móvil con cobertura inestable + aprobaciones | **Moshi** + `moshi-hook v0.4.62` | **Ambos** (TUI y `herdr-core`) | SSH / Mosh / Tailscale | Daemon `moshi-hook` |
| PWA Android / navegador sobre TUI | **ColliePWA** o `devswha/herdr-web-ui` | Herdr TUI | Loopback + `tailscale serve` | 1 servicio o plugin |
| Consola nativa iPhone (libghostty) | **Heeler** | Herdr TUI | SSH StreamLocal | 1 plugin TUI |
| Ventana macOS/Linux sobre daemon TUI | **herdrm** o **Herdr UI** (`herdr-gpui`) | Herdr TUI | Local / SSH | App nativa |
| TUI completo en navegador | `kcosr/herdr-web` | Herdr TUI | Loopback (`:8787`) | Puente Rust |

## Clientes oficiales de Herdr: Desktop, Mobile y TUI

- **Herdr Desktop App (`v0.1.16`):** app nativa Rust/GPUI con motor Ghostty y más de **312 layouts y 576 mods JS** editables por tu agente. Ver el [tour de layouts y mods de Herdr App](/es/herdr-app-layouts-y-mods/).
- **Herdr Mobile (iOS, iPadOS, Android):** gratuita en [App Store](https://apps.apple.com/app/id6828898364) y [Google Play](https://play.google.com/store/apps/details?id=dev.herdr.app), sin cuenta ni servidor intermedio. Ordena todos los agentes por `Needs you`, `Done`, `Working` e `Idle`, incluye terminal real, barra **compose** (texto, capturas, fotos y dictado local) y vista dividida en iPad y plegables.
- **Herdr TUI (`v0.9.5`):** binario único en tu terminal con `herdr machine add`, `herdr --remote` y ahora `herdr plugin update` (desde `v0.9.4`). Recuerda que `Ctrl+B q` desconecta sin matar procesos, mientras `herdr server stop` sí los detiene.

## Mejores web UIs comunitarias (para Herdr TUI)

Ninguna web UI es oficial y todas escuchan en `127.0.0.1` sin autenticación completa por defecto:

- **ColliePWA (`AltanS/collie`):** mejor modelo de seguridad (cabecera `Tailscale-User-Login` + `COLLIE_TRUSTED_USER` + emparejamiento por dispositivo), push web, respuestas rápidas y vista de diffs.
- **`devswha/herdr-web-ui`:** se instala con `herdr plugin install devswha/herdr-web-ui` en `:7317`, mostrando aprobaciones estilo chat con QR de Tailscale.
- **`sarathsp06/herdrweb`:** un único binario Go en `:7331` con bandeja limpia, diffs Shiki y RPCs reales.
- **`kcosr/herdr-web` y `alecuba16/herdr-webui`:** terminal fiel con Ghostty WASM (experimental, depende de internals) o interfaz tipo IDE con git (`--backend-mode external-herdr`).

## Apps móviles y de escritorio comunitarias: Moshi, Heeler, herdrm y Herdr UI

- **[Moshi](https://getmoshi.app) (iOS, Android y Desktop):** el único cliente pulido que soporta **Herdr TUI y `herdr-core`** gracias a `moshi-hook v0.4.62` (incluye creación de git worktrees desde espacios Herdr, transporte Mosh UDP, aprobaciones en pantalla bloqueada y Chat View nativo). Consulta nuestra [guía móvil con Herdr Mobile y Moshi](/es/controlar-agentes-ia-desde-telefono-moshi-herdr/).
- **[Heeler](https://heeler.bybee.dev) (iPhone):** app SwiftUI + `libghostty` sobre SSH StreamLocal con emparejamiento QR y Live Activities.
- **[herdr-remote](https://github.com/dcolinmorgan/herdr-remote):** barra de menú en macOS y aprobaciones en Telegram.
- **[herdrm](https://github.com/missuo/herdrm) (macOS) y [Herdr UI](https://herdrui.dev) (`penso/herdr-gpui`):** ventanas nativas conectadas directamente al daemon **Herdr TUI** sin puertos abiertos.

## Seguridad y arquitectura de referencia en VPS

Toda web UI de Herdr equivale a una shell de root sobre tu código y credenciales. Nunca expongas `0.0.0.0` ni uses `tailscale funnel`: enlaza siempre `127.0.0.1` y publica por `tailscale serve` (el mismo patrón que en [Dockge](/es/instalar-dockge/)).

## Preguntas frecuentes

<Accordion label="¿Existe ya una app oficial de escritorio, móvil o web UI de Herdr?" group="faq" expanded="true">
Sí para escritorio (`herdr-app v0.1.16`) y móvil (**Herdr Mobile**, gratis en iOS y Android), ambas sobre `herdr-core`. Sigue sin haber web UI oficial; ColliePWA y `herdr-web-ui` son proyectos comunitarios para Herdr TUI.
</Accordion>

<Accordion label="¿Qué cliente funciona tanto con Herdr TUI como con Herdr Core?" group="faq">
**Moshi** con `moshi-hook v0.4.62` es hoy el único cliente móvil y de escritorio que detecta y controla tanto sesiones de Herdr TUI como espacios de `herdr-core`.
</Accordion>

<Accordion label="¿Es seguro exponer una web UI de Herdr a internet?" group="faq">
No. Enlaza siempre `127.0.0.1` y accede solo mediante `tailscale serve` o un túnel SSH. Nunca uses `0.0.0.0` ni `tailscale funnel`.
</Accordion>

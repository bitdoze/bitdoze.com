## ¿Qué son las herramientas y asistentes de codificación con IA?

Las herramientas de codificación con IA usan grandes modelos de lenguaje para ayudarte a escribir, revisar, depurar y entregar código. En 2026 han evolucionado en cuatro categorías distintas, aunque las fronteras entre ellas se han difuminado. Cursor tiene agentes en la nube, Copilot tiene agentes en la nube y Codex se distribuye tanto como CLI como servicio en la nube.

### 1. Herramientas web

Plataformas basadas en el navegador para construir aplicaciones sin configuración local. Van desde herramientas rápidas de prototipado hasta constructores full-stack que gestionan bases de datos, autenticación y despliegue.

**Ejemplos:** v0.dev, bolt.new, lovable.dev, Replit, Tempo, Databutton

### 2. Extensiones de VS Code

Agentes de IA que se ejecutan dentro de VS Code o forks de VS Code. Aquí es donde la mayoría de los desarrolladores profesionales interactúan con la IA a diario: autocompletado inline, paneles de chat y modos de edición autónoma.

**Ejemplos:** GitHub Copilot, Cline, Kilo Code, Augment Code, [Amp Code (agente de codificación con IA gratuito)](/amp-code-free-ai-coding-agent/)

### 3. IDEs dedicados AI-first

Editores construidos expresamente con integración profunda de IA. Están optimizados para flujos de trabajo asistidos por IA y suelen tener la integración de modelos más ajustada.

**Ejemplos:** Cursor, [Devin Desktop (antes Windsurf)](https://go.bitdoze.com/windsurf), Trae, Zed, [Kiro, el IDE de IA de Amazon](/kiro-ai-ide/)

### 4. CLIs de terminal y agénticos

La categoría más caliente de 2026. Estas herramientas se ejecutan en tu terminal, editan en todo tu codebase, corren tests y algunas levantan VMs en la nube para producir PRs. Las fronteras entre «CLI» y «agente en la nube» se han difuminado: Codex tiene tanto un CLI local como agentes en segundo plano en la nube, Copilot tiene un agente en la nube y Claude Code ejecuta subagentes en paralelo.

**Ejemplos:** Claude Code, OpenAI Codex, Google Antigravity, Aider, Goose, [OpenCode (alternativa open-source a Claude Code)](/es/guia-configuracion-opencode/), [Factory Droid CLI](https://go.bitdoze.com/droid-cli)

| Categoría | Ideal para | Usuarios típicos |
|-----------|------------|------------------|
| Herramientas web | Prototipos, MVPs, apps full-stack | Fundadores, equipos de producto, no programadores |
| Extensiones de VS Code | Codificación diaria, flujos de trabajo existentes | Desarrolladores profesionales |
| IDEs dedicados | Desarrollo asistido por IA a tiempo completo | Equipos con integración profunda de IA |
| CLIs de terminal y agénticos | Ediciones autónomas, CI/headless, flujos git | Devs de backend, DevOps, ingenieros de terminal |

## ¿Qué deberías buscar en herramientas de código con IA?

Los criterios de evaluación han cambiado. La calidad del código y el soporte de lenguajes siguen importando, pero dos factores nuevos dominan la decisión en 2026: cómo funciona la facturación y cuánto trabajo de revisión te genera la herramienta.

### 1. Generación de código y capacidades agénticas

- **Calidad del resultado:** ¿Qué tan preciso y mantenible es el código generado?
- **Soporte de lenguajes y frameworks:** ¿Cubre tu stack?
- **Comprensión del contexto:** ¿Puede trabajar en todo tu codebase, no solo en el archivo abierto?
- **Ediciones autónomas multiarchivo:** ¿Puede refactorizar entre archivos sin supervisión constante?
- **Subagentes y tareas en paralelo:** ¿Puede ejecutar trabajos en segundo plano o levantar VMs en la nube?
- **Modo headless / CI:** ¿Puede correr en pipelines sin GUI?

### 2. Integración y flujo de trabajo

| Característica | Por qué importa |
|----------------|-----------------|
| Integración con el IDE | Funciona dentro de tu editor actual |
| Soporte de Git | Commits, ramas y PRs gestionados por el agente |
| Edición multiarchivo | Maneja refactorizaciones complejas |
| Agente en la nube | Levanta VMs en segundo plano para producir PRs (Codex Cloud, agente cloud de Copilot, Cursor Bugbot) |
| Acceso CLI | Flujos de trabajo de terminal para servidores y CI |

### 3. Modelo de IA y rendimiento

- **Calidad del modelo:** GPT-5.5, Claude Opus 4.8, Gemini 2.5 y sus variantes más baratas (Haiku, GPT mini, Flash).
- **Cambio entre modelos:** Copilot, Cursor y Cline te permiten elegir modelos. Esto importa cuando quieres modelos baratos para ediciones rutinarias y potentes para refactorizaciones complejas.
- **Ventana de contexto:** El contexto de 1M de tokens de Claude Code es un diferenciador real para codebases grandes.
- **Tiempo de respuesta:** Codex Cloud corre a ~240 tokens/segundo, aproximadamente 2.5 veces más rápido que Claude Opus.

### 4. Seguridad y privacidad

- **Privacidad del código:** ¿Adónde va tu código? ¿Se usa para entrenamiento?
- **Exclusión del entrenamiento:** GitHub Copilot Free/Pro/Pro+ entrena con tu código por defecto (desde abril de 2026). Los planes Business y Enterprise no entrenan. Cursor tiene modo privacidad. Los planes Business de Augment tampoco entrenan. Es un diferenciador concreto y accionable. Revisa la configuración.
- **Salida de red:** Agentes en sandbox (Codex CLI bloquea la red por defecto) frente a agentes abiertos que pueden llamar a cualquier endpoint.

Para más información sobre cómo proteger tu sitio de los scrapers de IA, consulta nuestra guía sobre [bloquear crawlers de IA](/block-ai-crawlers/).

### 5. Coste y facturación por uso

Este es el mayor cambio de 2026. La mayoría de las herramientas han pasado de suscripciones planas a facturación por créditos o tokens:

- **GitHub Copilot** pasó a «GitHub AI Credits» (1 crédito = $0.01) el 1 de junio de 2026.
- **OpenAI Codex** pasó a facturación por tokens el 2 de abril de 2026.
- **Augment Code** cambió a créditos en octubre de 2025.
- **Cursor** tiene facturación por uso bajo demanda además de las suscripciones.
- **Replit** usa precios basados en esfuerzo/créditos.

<Notice type="warning" title="Vigila tu consumo de tokens">
La codificación agéntica quema 3-4 veces más tokens que el autocompletado. Claude Code en particular usa significativamente más tokens que Codex para tareas similares. Si estás en facturación por API, define un límite de gasto estricto en la página de facturación del proveedor. Prefiere los planes Max de tarifa plana para uso intensivo. Son mucho más baratos que la facturación por API equivalente. Para [alternativas más baratas a GitHub Copilot](/es/alternativas-github-copilot-2026/), considera Cline o Kilo Code con tus propias claves de API.
</Notice>

Consejos concretos:
- Activa **alertas de presupuesto.** Copilot tiene alertas al 75/90/100% de tu presupuesto. Actívalas.
- Prefiere planes de tarifa plana (Copilot Max $100, Claude Max $100-200) frente a facturación por API para uso intensivo.
- Usa modelos baratos para tareas rutinarias: Haiku, GPT mini, Gemini Flash para autocompletado y ediciones de estilo. Reserva Opus/GPT-5.5 para refactorizaciones complejas.
- Los agentes sin supervisión pueden quemar 10-50 veces más tokens que las sesiones interactivas. No dejes a los agentes correr sin control.

### 6. Carga de revisión y verificación

Aquí está la verdad incómoda: los agentes de codificación con IA rompen cosas. Un estudio de 2026 encontró que el 75% de los agentes de codificación con IA rompieron código que funcionaba durante flujos de CI. La tasa de merge de PRs del 67% declarada por Devin cayó a un 15% de éxito real en pruebas independientes (Answer.AI, 20 tareas).

### 7. Requisitos empresariales

- **Gestión de equipos:** Roles, permisos, límites de asientos
- **Pistas de auditoría:** Registro de actividad para cumplimiento
- **SSO / SAML:** Obligatorio para la mayoría de las organizaciones
- **Residencia de datos:** Las opciones UE/EE. UU. importan para el GDPR

### Herramientas web

#### [v0.dev](https://v0.dev) (⭐⭐⭐⭐½)

v0 ha evolucionado de generador de componentes de UI a constructor de aplicaciones full-stack. Ahora gestiona bases de datos, tareas y aplicaciones completas, no solo componentes de React. El modelo de créditos usa los niveles de modelos v0 Mini/Pro/Max, y obtienes $5 en créditos al mes en el plan gratuito con un límite de 7 mensajes/día.

**Precios (ago 2026):**
- **Gratis:** $0, $5 en créditos/mes, 7 mensajes/día
- **Team:** $30/usuario/mes
- **Business:** $100/usuario/mes
- **Enterprise:** Personalizado

El antiguo nivel «Premium» de $20 ya no existe. Si necesitas más que el nivel gratuito, saltas a $30/usuario para Teams.

**Ideal para:** Prototipado rápido de UI, generación de apps full-stack, no programadores construyendo MVPs.

#### [bolt.new](https://bolt.new) (⭐⭐⭐⭐)

bolt.new de StackBlitz te permite generar con prompts, ejecutar, editar y desplegar apps full-stack directamente en el navegador. Los precios se han simplificado. Los antiguos niveles Pro 50/100/200 han desaparecido.

**Precios (ago 2026):**
- **Gratis:** 300K tokens diarios (1M mensuales)
- **Pro:** $25/mes (10M de tokens)
- **Teams:** $30/miembro/mes
- **Enterprise:** Personalizado

Los tokens se acumulan durante un mes. Un buen detalle para uso intermitente.

**Ideal para:** Startups construyendo MVPs, desarrolladores en solitario, proyectos de prueba de concepto.

#### [lovable.dev](https://lovable.dev) (⭐⭐⭐⭐)

Lovable pasó a un modelo basado en créditos. El «Plan Mode» usa 1 crédito por mensaje. Los créditos caducan a los 2 meses, así que no los acumules.

**Precios (ago 2026):**
- **Gratis:** 5 créditos/día (~30/mes)
- **Pro:** $25/mes (100 créditos)
- **Business:** $50/mes
- **Enterprise:** Personalizado

**Ideal para:** Desarrolladores full-stack, agencias, prototipado rápido con colaboración en equipo.

#### [Replit](https://replit.com/ai) (⭐⭐⭐½)

El mayor cambio de precios de cualquier herramienta de este artículo. Replit Core pasó de $25 a $20/mes, y el nuevo nivel Replit Pro a $100/mes apunta a usuarios avanzados. Replit Agent usa créditos basados en esfuerzo.

**Precios (ago 2026):**
- **Starter:** Gratis
- **Core:** $20/mes ($18 anual)
- **Pro:** $100/mes ($90 anual)
- **Enterprise:** Personalizado

**Ideal para:** Estudiantes, educadores, prototipado rápido, codificación colaborativa.

#### [Tempo](https://tempo.new) (⭐⭐⭐⭐)

Tempo pivotó de «constructor React» a «agentes de IA que convierten feedback e issues en PRs revisados». Es un cambio significativo. Ahora compite con las herramientas agénticas más que con los constructores web.

**Precios (ago 2026):**
- **Gratis:** 30 prompts (5/día)
- **Pro:** $30/mes (150 prompts)
- **Scale:** $50/mes (250 prompts)
- **Ultimate:** $100/mes (555 prompts)
- **Agent+:** $4.500/mes

**Ideal para:** Equipos que quieren flujos automatizados de issue a PR.

#### [Databutton](https://databutton.com) (⭐⭐⭐⭐)

Databutton ahora estructura su oferta en torno al acceso al agente más distintos niveles de soporte humano.

**Precios (ago 2026):**
- **Agent + Community:** $20/mes
- **Agent + Human advisor:** $699/mes
- **Agent + Human devs:** $1.999/mes

El salto de $20 a $699 es pronunciado. Pagas por experiencia humana, no solo por la IA.

**Ideal para:** Apps basadas en datos, paneles de analítica, backends Python/FastAPI.

### Extensiones de VS Code

#### [GitHub Copilot](https://github.com/features/copilot) (⭐⭐⭐⭐½) — buque insignia

GitHub Copilot es ahora la opción con más funciones de esta categoría. El nivel gratuito está disponible para todos (no solo estudiantes/OSS), y la herramienta ha pasado del autocompletado a una plataforma agéntica completa con agentes en la nube, revisión de código e integración de agentes de terceros.

**Funciones clave:**
- Soporte multimodelo (Claude, GPT, Gemini — tú eliges por tarea)
- Modo agente para ediciones autónomas multiarchivo
- Agente en la nube (levanta VMs en segundo plano para tareas complejas)
- Copilot CLI (`gh copilot suggest "add rate limiting"`)
- Revisión de código en pull requests
- Integración de agentes de terceros (Claude Code, Codex)
- Archivo `AGENTS.md` para instrucciones a nivel de repo

**Precios (ago 2026):**
- **Gratis:** $0 — 2.000 autocompletados + 50 solicitudes premium/mes (para todos)
- **Pro:** $10/mes
- **Pro+:** $39/mes
- **Max:** $100/mes
- **Business:** $19/usuario/mes
- **Enterprise:** $39/usuario/mes

Copilot pasó a facturación por uso con «GitHub AI Credits» (1 crédito = $0.01) el 1 de junio de 2026. Si eres un usuario intensivo, el [plan GitHub Copilot Pro](/github-copilot-complete-guide/) a $10 sigue siendo el mejor punto de entrada. Para uso más intensivo, mira Max a $100 o considera [alternativas más baratas a GitHub Copilot](/es/alternativas-github-copilot-2026/) como Cline.

**Nota de privacidad:** Copilot Free/Pro/Pro+ entrena con tus interacciones por defecto desde abril de 2026. Desactívalo en la configuración. Los planes Business y Enterprise no entrenan.

**Ideal para:** Desarrolladores individuales, equipos empresariales, cualquiera que quiera el conjunto de funciones más amplio en una sola herramienta.

#### [Cline](https://cline.bot) (⭐⭐⭐⭐½)

Cline sigue siendo gratuito y open-source (Apache-2.0, ~66k estrellas en GitHub). Se posiciona como un «agente de codificación autónomo» disponible como SDK, extensión de IDE o asistente CLI. Solo pagas por los tokens de API que uses.

<Notice type="info" title="Cline es gratis">
Cline es gratuito — solo pagas por los tokens de API que uses. Apúntalo a Ollama para coste cero. Soporta los modos Plan/Act para edición autónoma controlada.

**Funciones clave:**
- Generación autónoma de código con control humano en el bucle
- Edición multiarchivo y refactorización de todo el proyecto
- Ejecución de comandos de terminal y automatización del navegador
- Creación de herramientas personalizadas vía Model Context Protocol (MCP)
- Modos Plan/Act para operación paso a paso o totalmente autónoma

**Ideal para:** Desarrolladores profesionales que quieren el máximo control, autoalojadores que ejecutan modelos locales, cualquiera alérgico a las suscripciones.

#### [Kilo Code](https://kilo.ai) (⭐⭐⭐⭐) — nuevo, sustituye a Roo Code

Roo Code cerró el 15 de mayo de 2026 (repo archivado en solo lectura). Kilo Code es el fork sucesor open-source — un reemplazo directo. Extensión gratuita, pagas la API del modelo al coste sin margen.

**Ideal para:** Antiguos usuarios de Roo Code, desarrolladores que quieren un agente gratuito para VS Code con BYOK (trae tu propia clave).

Si quieres ejecutarlo con [alternativas open-source de LLM para codificación económicas](/es/mejores-llms-opensource-alternativa-claude/), Kilo Code combina bien con modelos locales.

#### [Augment Code](https://augmentcode.com) (⭐⭐⭐⭐)

Augment cambió a facturación por créditos en octubre de 2025. Está certificado SOC 2 Tipo II y los planes Business garantizan que no se entrena IA con tu código.

**Precios (ago 2026):**
- **Gratis (prueba):** Limitado
- **Indie:** $20/mes
- **Business:** $100/mes fijo (hasta 50 asientos)

**Ideal para:** Equipos empresariales que gestionan codebases grandes, organizaciones que necesitan cumplimiento SOC 2.

#### [Amp Code](https://ampcode.com) (⭐⭐⭐⭐) — nuevo

Amp Code es un agente de codificación con IA gratuito que funciona directamente en tu editor. Buena opción de nivel gratuito si quieres una experiencia agéntica sin pagar otra suscripción.

Consulta nuestra [guía completa de Amp Code](/amp-code-free-ai-coding-agent/) para la configuración y las funciones.

**Ideal para:** Desarrolladores que quieren una experiencia de agente gratuita en su editor.

**Ideal para:** Desarrolladores que quieren la integración IA-IDE más ajustada, equipos que hacen desarrollo asistido por IA a tiempo completo.

Windsurf fue adquirido por Cognition (la empresa de Devin) a finales de 2025 (~$250M, según CNBC) y renombrado a Devin Desktop el 2 de junio de 2026. La URL `windsurf.com/pricing` ahora redirige a `devin.ai/pricing`. Combina la experiencia de IDE con las capacidades del agente en la nube de Devin.

**Precios (ago 2026):**
- **Gratis:** $0
- **Pro:** $20/mes
- **Max:** $200/mes
- **Teams:** $80/mes + $40/asiento
- **Enterprise:** Personalizado

Las funciones cloud de Devin usan facturación por ACU (Agent Compute Units). Si solo usas el IDE en local, el nivel Pro de $20 cubre la mayoría de las necesidades.

**Ideal para:** Desarrolladores full-stack, equipos que quieren IDE + agente en la nube en una sola herramienta.

#### [Trae](https://trae.ai) (⭐⭐⭐⭐)

La entrada de ByteDance en el espacio de los IDE de IA. Los precios son agresivos — $3/mes para Lite y $10/mes para Pro lo convierten en el IDE de IA de pago más barato.

**Precios (ago 2026):**
- **Gratis:** ~5.000 autocompletados/mes + modelos premium
- **Lite:** $3/mes
- **Pro:** $10/mes (más de 600 solicitudes premium)
- **Enterprise:** Personalizado

**Ideal para:** Desarrolladores con presupuesto ajustado, cualquiera que quiera funciones de IDE de IA sin los $20/mes de Cursor.

#### [Zed](https://zed.dev) (⭐⭐⭐⭐)

El editor en sí es gratuito y open-source, construido en Rust. Zed AI es la capa de pago opcional.

**Precios (ago 2026):**
- **Editor:** Gratis, open-source
- **Zed AI:** $10/mes (predicciones de edición ilimitadas + $5 en tokens, por uso a partir de ahí)
- **Business:** $30/asiento/mes

**Ideal para:** Desarrolladores enfocados al rendimiento, entusiastas del terminal, colaboradores de open-source.

#### [Amazon Kiro](https://kiro.dev) (⭐⭐⭐⭐) — nuevo

Kiro es el IDE agéntico dirigido por especificaciones de Amazon, construido sobre Code OSS. Sustituye a Amazon Q Developer (que dejó de aceptar registros nuevos el 15 de mayo de 2026). Kiro llegó a GA en marzo de 2026.

El enfoque dirigido por especificaciones es interesante — escribes specs y Kiro genera planes de implementación antes de escribir código. Lee más en nuestro análisis en profundidad de [Amazon Kiro AI IDE](/kiro-ai-ide/).

**Precios (ago 2026):**
- **Gratis:** 50 créditos/mes
- **Pro:** $20/mes (1.000 créditos)
- **Pro+:** $40/mes
- **Pro Max:** $100/mes
- **Power:** $200/mes
- **Enterprise:** Personalizado

**Ideal para:** Equipos centrados en AWS, desarrolladores que quieren flujos de IA estructurados/dirigidos por especificaciones.

<Accordion label="Cursor vs Devin Desktop vs Kiro — ¿qué IDE debería elegir?" group="faq">
Cursor es la opción madura y con más funciones, con el mayor ecosistema. Devin Desktop trae capacidades de agente en la nube (PRs autónomos) al IDE. El enfoque dirigido por especificaciones de Kiro encaja con equipos que quieren un desarrollo con IA estructurado y planificado primero. Para la mayoría de desarrolladores en solitario, Cursor Pro a $20 es la elección por defecto. Para equipos ya en AWS, vale la pena probar primero el nivel gratuito de Kiro.
</Accordion>

### CLIs de terminal y agénticos

Esta es la categoría más caliente de 2026. Estas herramientas corren en tu terminal, editan en todo tu codebase, ejecutan tests y algunas levantan VMs en la nube para producir PRs. Si pasas la mayor parte del día en una terminal, aquí es donde están las verdaderas ganancias de productividad.

#### [Claude Code](https://docs.anthropic.com/en/docs/claude-code) (⭐⭐⭐⭐½) — nuevo, buque insignia

El agente terminal-first de Anthropic. Claude Code tiene una ventana de contexto de 1M de tokens, maneja refactorizaciones multiarchivo y puede lanzar subagentes para tareas en paralelo. Claude Opus 4.8 obtuvo 88.6% en SWE-bench Verified (una de las puntuaciones publicadas más altas).

**Funciones clave:**
- Ventana de contexto de 1M de tokens (la mayor de su clase)
- Refactorizaciones multiarchivo con comprensión completa del proyecto
- Subagentes para ejecución de tareas en paralelo
- Archivo `CLAUDE.md` para reglas a nivel de repo
- Modo headless/CI: `claude -p "fix the failing tests" --output-format json`

**Precios (ago 2026):**
- **Gratis:** Limitado (con topes semanales)
- **Pro:** $20/mes (uso ligero, incluido con la suscripción a Claude)
- **Max 5x:** $100/mes
- **Max 20x:** $200/mes
- **API:** Pago por uso (Opus 4.8 ≈ $5/M entrada, $25/M salida)

<Notice type="warning" title="Consumo de tokens de Claude Code">
Claude Code usa 3–4 veces más tokens que Codex para tareas similares. Si estás en facturación por API, define un límite de gasto estricto en la página de facturación de Anthropic. Para uso intensivo, los planes Max son mucho más baratos que la facturación por API equivalente.
</Notice>

**Instalar y empezar:**

```bash
npm install -g @anthropic-ai/claude-code
cd your-project
claude                    # interactive mode
claude -p "explain this repo" --output-format json   # headless/CI
```

Auth: `claude` pide el login de Claude Pro/Max, o define `ANTHROPIC_API_KEY` para facturación por API.

**Ideal para:** Desarrolladores de terminal, refactorizaciones multiarchivo complejas, codebases grandes.

#### [OpenAI Codex](https://github.com/openai/codex) (⭐⭐⭐⭐½) — nuevo, buque insignia

La oferta dual de OpenAI: un CLI open-source (`openai/codex`, Apache-2.0, ~105k estrellas en GitHub, escrito en Rust) y Codex Cloud (VMs en segundo plano en paralelo que producen PRs a ~240 tokens/segundo). GPT-5.5 obtiene 88.8% en Terminal-Bench 2.1.

**Funciones clave:**
- CLI open-source (Apache-2.0)
- Codex Cloud: VMs en segundo plano que producen PRs
- ~240 tok/s de throughput (aproximadamente 2.5 veces más rápido que Claude Opus)
- Red de sandbox desactivada por defecto (Docker/LocalStack bloqueados salvo que se activen explícitamente)
- `codex exec` para uso no interactivo / CI

**Precios (ago 2026):**
- **Go:** $8/mes
- **Plus:** $20/mes (incluido con ChatGPT Plus, topes de 5 horas)
- **Pro 5x:** $100/mes
- **Pro 20x:** $200/mes
- **Business:** $25/usuario/mes
- Facturación por tokens desde el 2 de abril de 2026

**Instalar y empezar:**

```bash
npm install -g @openai/codex
cd your-project
codex                       # interactive TUI
codex exec "fix the failing tests"   # non-interactive / CI
```

Auth: `codex login` (inicio de sesión con ChatGPT) o define `OPENAI_API_KEY`.

También puedes [usar la app de Codex con cualquier modelo](/codex-app-any-model/) para más flexibilidad.

**Ideal para:** Desarrolladores que quieren flexibilidad CLI + agente en la nube, equipos ya en el ecosistema OpenAI, pipelines de CI/CD.

#### [Google Antigravity](https://antigravity.google) (⭐⭐⭐⭐) — nuevo

Google liberó Gemini CLI como open-source y luego lo sustituyó por Antigravity CLI el 18 de junio de 2026. Antigravity es el IDE/CLI agéntico de Google, integrado en el ecosistema de Google.

**Precios (ago 2026):**

- **AI Pro:** $20/mes
- **AI Ultra:** $100–$200/mes
- **Enterprise:** Personalizado

**Ideal para:** Desarrolladores en el ecosistema Google, equipos que usan Google Cloud, cualquiera que quiera un CLI agéntico gratuito.

#### [Aider](https://aider.chat/) (⭐⭐⭐⭐½)

Sigue siendo la mejor opción sin suscripción y con tu propia clave. Aider es gratuito, open-source y se combina con cualquier LLM al que tengas acceso por API. El fork comunitario `aider-ce` también gana tracción.

**Instalar y empezar:**

```bash
pipx install aider-chat
cd your-project
aider --model sonnet --watch-files
```

**Ideal para:** Usuarios avanzados de terminal, desarrolladores centrados en git, cualquiera que no quiera otra suscripción.

#### [Goose](https://goose-docs.ai) (⭐⭐⭐⭐)

Block donó Goose a la Linux Foundation (AI Application Foundation). El repo se movió a `aaif-goose/goose` (~52k estrellas en GitHub). Sigue siendo gratuito y open-source (Apache-2.0), con app de escritorio, CLI y API.

**Ideal para:** Equipos preocupados por la seguridad, desarrolladores empresariales, ingenieros DevOps, flujos de trabajo local-first.

#### [OpenCode](https://opencode.ai) (⭐⭐⭐⭐) — nuevo

OpenCode es el agente de codificación open-source con más estrellas (~193k en GitHub). Soporta más de 75 proveedores, tiene licencia MIT y funciona como agente de terminal, escritorio o IDE. Perfecto para el público autoalojado y DIY.

**Ideal para:** Autoalojadores, desarrolladores que quieren máxima flexibilidad de proveedores, flujos sin dependencia de un único proveedor.

## Control de costes para agentes de codificación con IA

Esta es la sección que me hubiera gustado que existiera cuando empecé a usar herramientas agénticas. El cambio a facturación por uso significa que tu factura mensual puede multiplicarse por 10–50 si dejas que los agentes corran sin supervisión. Así es como mantener los costes bajo control.

**Define límites de gasto estrictos.** OpenAI y Anthropic te permiten fijar topes mensuales en la página de facturación. Hazlo antes de empezar. Copilot tiene alertas integradas al 75/90/100% de tu presupuesto — actívalas.

**Prefiere planes de tarifa plana para uso intensivo.** Si eres usuario diario, los planes Max ($100–200/mes) son mucho más baratos que la facturación por API equivalente. Las cuentas solo salen a tu favor con facturación por API si eres un usuario ligero y ocasional.

**Usa modelos baratos para tareas rutinarias.** Reserva Opus 4.8 y GPT-5.5 para refactorizaciones complejas. Para autocompletado, ediciones de estilo y boilerplate, usa Haiku, GPT mini o Gemini Flash. La mayoría de las herramientas te permiten cambiar de modelo por tarea.

**Enruta entre modelos.** Si quieres acceso unificado a Claude Code, Codex y Gemini CLI desde una sola interfaz, [Agent Router](https://go.bitdoze.com/agentrouter) puede ayudar — una clave de API, varios backends.

**Vigila los agentes sin supervisión.** Un agente corriendo en segundo plano puede quemar tokens rápido. Revísalo con frecuencia. Define límites de tiempo. No dejes que los agentes iteren sobre fallos indefinidamente.

<Notice type="success" title="Stack de coste cero para autoalojadores">
Ejecuta Cline u [OpenCode](https://go.bitdoze.com/opencode-go) + Ollama + un modelo local (Qwen 3.6, Llama 4) en tu propio hardware. Cero suscripción, cero costes de tokens. Solo pagas hardware y electricidad. Consulta nuestra guía sobre [alternativas open-source de LLM para codificación económicas](/es/mejores-llms-opensource-alternativa-claude/) para recomendaciones de modelos. También puedes explorar [dejar que un asistente de IA despliegue apps Docker](/ai-docker-deploy-skill/) desde tu setup autoalojado.
</Notice>

**Stack autoalojado / sin suscripción:**
- **Aider, Cline, OpenCode, Goose, Kilo Code, Continue** + Ollama = coste de suscripción cero
- Apúntalos a modelos locales vía `OLLAMA_API_BASE` o la configuración del proveedor
- Funciona muy bien para ediciones rutinarias; cambia a modelos en la nube para refactorizaciones complejas

## ¿Por qué deberías usar herramientas de asistente de codificación con IA?

La versión corta: te hacen más rápido, pero no te hacen peor — siempre que verifiques.

### Ganancias de productividad

Los datos de GitHub muestran que los desarrolladores que usan Copilot son hasta un 55% más productivos en ciertas tareas. Esa cifra viene de estudios controlados y sigue siendo el benchmark más citado del sector. En la práctica, las ganancias dependen mucho de la tarea: boilerplate, tests y documentación ven las mayores aceleraciones. ¿Decisiones de arquitectura novedosas? No tanto.

### Calidad del código

Las herramientas de IA estandarizan patrones, detectan bugs pronto y generan documentación que de otro modo omitirías. Son particularmente buenas escribiendo tests — una tarea en la que la mayoría de los desarrolladores invierten de menos.

### Aprendizaje y desarrollo de habilidades

Trabajar con herramientas de IA te expone a patrones, librerías y enfoques que quizá no descubrirías por tu cuenta. Es como programar en pareja con alguien que ha leído todas las páginas de documentación (pero que ocasionalmente alucina).

### Rentabilidad

Con niveles gratuitos ahora disponibles de Copilot, Cline, Kilo Code y otros, la barrera de entrada es cero. Para autoalojadores, el stack Ollama + agente open-source no cuesta nada más allá del hardware. Compara eso con los $150–300/año que cobran la mayoría de los planes de pago.

### Las desventajas honestas

Los agentes de codificación con IA rompen cosas. Un estudio de 2026 encontró que el 75% de los agentes rompieron código que funcionaba durante flujos de CI. La carga de revisión es real — aún necesitas leer cada línea que escribe el agente. Los costes de tokens pueden sorprenderte si no prestas atención. Y las preocupaciones de privacidad son legítimas: algunas herramientas entrenan con tu código por defecto.

<Accordion label="¿Merecen la pena las herramientas de codificación con IA a pesar de los riesgos?" group="faq">
Sí, pero solo con disciplina de verificación y controles de coste. Úsalas para boilerplate, tests, documentación y prototipado rápido. Para código de producción, trata el resultado del agente como el PR de un desarrollador junior — revísalo línea por línea, ejecuta la suite de tests completa y no hagas merge en piloto automático. Las ganancias de productividad son reales, pero también lo son los modos de fallo.
</Accordion>

## Conclusiones

Ninguna herramienta lo gana todo. Aquí está mi recomendación por defecto para cada caso de uso:

- **Mejor opción gratuita:** GitHub Copilot Free (para todos) o Cline/Kilo Code + un modelo gratuito.
- **Mejor para codificación agéntica:** Claude Code u OpenAI Codex — elige según tu preferencia de ecosistema (Anthropic vs OpenAI).
- **Mejor IDE económico:** Cursor Pro ($20) o Trae Pro ($10).
- **Mejor para autoalojadores:** [OpenCode](https://go.bitdoze.com/opencode-go) o Aider + Ollama.
- **Mejor herramienta web:** v0.dev (full-stack) o bolt.new (prototipado).

El resaltado de sintaxis en Fish Shell es una de las principales razones por las que me pasé de [Zsh a Fish](/es/fish-shell-vs-zsh-comparacion/). En Zsh, necesitas el [plugin zsh-syntax-highlighting](/es/activar-resaltado-sintaxis-zsh/) y algo de configuración para que los comandos se coloreen mientras escribes. En Fish, funciona desde el primer arranque, sin [plugins de Fish Shell](/es/mejores-plugins-fish-shell/) que instalar ni nada que configurar.

El shell colorea tu línea de comandos en tiempo real. Los comandos válidos aparecen en un color, los inválidos se ponen rojos, las cadenas entre comillas tienen su propio color y las rutas de archivo que existen aparecen subrayadas. Detectas errores tipográficos antes de pulsar Enter.

Esta guía cubre cómo funciona el resaltado de sintaxis de Fish Shell en Fish 4.x, cómo personalizar los colores para comandos, errores y rutas, cómo gestionar temas y cómo resolver los problemas que suelen dar guerra.

## Qué resalta Fish (valores por defecto de Fish 4.x)

Fish colorea distintas partes de la línea de comandos según su significado. Estos son los valores por defecto en fish 4.x:

| Elemento | Aspecto por defecto | Variable |
|---|---|---|
| Comandos válidos | Color normal del terminal (`--reset`) | `fish_color_command` |
| Comandos inválidos | Rojo brillante (`brred`) | `fish_color_error` |
| Parámetros/argumentos | Cian | `fish_color_param` |
| Opciones (flags que empiezan con `-`) | Toma el valor de `fish_color_param` (cian) | `fish_color_option` |
| Cadenas entre comillas | Amarillo | `fish_color_quote` |
| Redirecciones (`>`, `>>`, `\|`) | Cian, negrita | `fish_color_redirection` |
| Rutas de archivo válidas | Subrayado | `fish_color_valid_path` |
| Comentarios (`# ...`) | Rojo | `fish_color_comment` |
| Secuencias de escape (`\n`, `\t`) | Cian brillante (`brcyan`) | `fish_color_escape` |
| Autosugerencias | Negro brillante (`brblack`) | `fish_color_autosuggestion` |
| Selección (modo visual de vi) | Blanco sobre negro brillante, negrita | `fish_color_selection` |
| Coincidencias de búsqueda | Blanco sobre negro brillante, negrita | `fish_color_search_match` |
| Comandos integrados (fish 4.8.1+) | Toma el valor de `fish_color_command` | `fish_color_builtin` |
| Funciones definidas por el usuario (fish 4.8.1+) | Toma el valor de `fish_color_command` | `fish_color_function` |

Cuando una variable no está definida, fish recurre a una cascada predecible. `fish_color_builtin`, `fish_color_function` y `fish_color_keyword` recurren todos a `fish_color_command`. `fish_color_option` recurre a `fish_color_param`. `fish_color_valid_path` combina sus modificadores (como el subrayado) con el color que le correspondería al token subyacente.

La parte más útil: la validación de comandos ocurre mientras escribes. Escribe `gti` en lugar de `git` y se pone rojo al instante. No necesitas ejecutar el comando para saber que algo está mal.

![Anatomía de una línea de comandos de fish mostrando tokens coloreados: comando, opción, cadena entre comillas, ruta válida, redirección y error](@assets/images/26/02/fish-syntax-highlighting-anatomy.svg)

<Notice type="info" title="Por qué tu Fish sigue mostrando los comandos en azul">
Si instalaste fish antes de la versión 4.0 y actualizaste, tu antiguo esquema de colores sobrevive en un archivo de tema congelado. Fish dejó de usar azul para comandos válidos desde la versión 4.0.0. Ahora el valor por defecto es el color normal de texto del terminal. Vuelve a ejecutar `fish_config theme choose default` para obtener el esquema actual. Las capturas antiguas de internet pueden seguir mostrando el azul anterior.
</Notice>

## Conoce primero tu versión de Fish

Varias funciones de esta guía dependen de la versión. Comprueba cuál estás ejecutando antes de preguntarte por qué algo no funciona:

```bash
fish --version
```

Conviene tener fish 4.x, idealmente 4.8.1 o posterior para todo lo que cubre esta guía. Los temas adaptativos requieren 4.3.0+, `fish_color_builtin` y `fish_color_function` requieren 4.8.1+ y los estilos de subrayado requieren 4.0+.

<ListCheck>
<ul>
<li>fish 4.x instalado (ejecuta `fish --version`, idealmente 4.8.1 o posterior)</li>
<li>Un terminal con true-color: Ghostty, iTerm2, WezTerm, Alacritty o Kitty</li>
<li>Acceso a `~/.config/fish/config.fish`</li>
</ul>
</ListCheck>

Los paquetes de las distribuciones van por detrás. Ubuntu 24.04 (noble) incluye fish 3.7.0, así que las nuevas variables simplemente no existirán ahí. Ubuntu 25.10 trae la 4.0.6. Homebrew trae la 4.9.3. En Ubuntu, usa el PPA de fish-shell o las compilaciones oficiales para mantenerte al día (consulta la guía para [instalar Fish Shell en Ubuntu](/es/instalar-fish-shell-ubuntu/)). En Mac, [Fish Shell en macOS](/es/fish-shell-macos-configuracion/) cubre el camino con Homebrew.

Fish es libre y de código abierto. La única cuestión a vigilar es mantenerlo actualizado. Los paquetes obsoletos de las distros te impiden usar las variables de color más nuevas y los temas adaptativos.

## Cómo cambiar los colores de Fish shell

Hay dos caminos: la interfaz web visual para probar cosas y `config.fish` para una configuración permanente y reproducible.

### Usa la interfaz web fish_config

La forma más rápida de explorar colores:

```bash
fish_config
```

Esto abre una herramienta en el navegador con vista previa en vivo. En la pestaña «Colors», puedes hacer clic en cada elemento de sintaxis y cambiar su color. Cuando estés satisfecho, haz clic en «Set Theme» y los cambios se aplican al instante a tu sesión actual.

Sirve bien para experimentar. Para una configuración que quieras conservar, la vía de `config.fish` de abajo es la que recomienda fish.

### Fija los colores de forma permanente en config.fish

Desde fish 4.3.0, la forma recomendada de hacer permanentes los colores es añadir una línea en `~/.config/fish/config.fish`. Fish define las variables `fish_color_*` en ámbito global por defecto, y `config.fish` se ejecuta cada vez que arranca el shell, así que una línea `set -g` ahí resulta permanente a efectos prácticos:

```bash
# ~/.config/fish/config.fish

# Pick a theme first (order matters: overrides below this line win)
fish_config theme choose dracula

# Then tweak individual colors
set -g fish_color_command 5fd700           # bright green
set -g fish_color_error ff5f5f --bold      # bold red
set -g fish_color_quote ff8700             # orange
set -g fish_color_comment 6c7086           # grey
set -g fish_color_autosuggestion 555555    # dim
```

Abre un terminal nuevo para ver los cambios. Comprueba con `echo $fish_color_command`. Debería imprimir tu valor.

<Notice type="warning" title="set -U y theme save son métodos heredados">
La documentación de fish marca `fish_config theme save` como «(not recommended)»: guarda los colores en variables universales, que no siguen los cambios entre modo claro y oscuro de tu terminal. Las variables universales (`set -U`) siguen funcionando como opción manual, pero `config.fish` con `set -g` es el método soportado para fish 4.3+. Si escribes `set -g` en una sesión puntual sin guardarlo en `config.fish`, el ajuste no sobrevivirá al siguiente reinicio.
</Notice>

![De dónde obtiene fish tus colores: flujo de resolución de config.fish con ruta de migración desde el antiguo set -U](@assets/images/26/02/fish-color-resolution-flow.svg)

Nota de migración: si actualizaste desde fish 3.x, es posible que fish 4.3+ haya migrado tus antiguas variables universales de color a `~/.config/fish/conf.d/fish_frozen_theme.fish`. El consejo oficial es borrar ese archivo y definir tu tema en `config.fish`. Fish 4.8.0+ omite crear este archivo cuando tu tema coincide con el valor histórico por defecto.

### Colores disponibles, modificadores y estilos de subrayado

Fish acepta colores con nombre, códigos hexadecimales y un conjunto de modificadores:

<Tabs>
<Tab name="Colores con nombre">

Los 16 colores estándar de terminal: `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`, más sus variantes brillantes (`brblack`, `brred`, `brgreen`, `bryellow`, `brblue`, `brmagenta`, `brcyan`, `brwhite`). También `normal` (el predeterminado del terminal) y `reset`.

```bash
set -g fish_color_command green
set -g fish_color_error brred --bold
set -g fish_color_quote bryellow
```

</Tab>
<Tab name="Colores hexadecimales">

Códigos hexadecimales de tres o seis dígitos. Útiles cuando quieres colores exactos de una paleta:

```bash
set -g fish_color_command 5fd700           # bright green
set -g fish_color_quote ff8700 --italics   # italic orange
set -g fish_color_comment 6c7086 --dim     # dim grey
set -g fish_color_error ff5f5f --bold      # bold red
```

Los colores hexadecimales necesitan un terminal true-color. La mayoría de terminales modernos lo soportan de serie.

</Tab>
<Tab name="Modificadores y subrayado">

Conjunto completo de modificadores: `--foreground=`, `--background=`, `--bold`, `--dim`, `--italics`, `--reverse`, `--strikethrough`, `--underline`, `--underline-color=`.

Estilos de subrayado (fish 4.0+): `--underline=single` (por defecto), `double`, `curly`, `dotted`, `dashed` u `off`.

```bash
# Curly underline for options
set -g fish_color_option --underline=curly

# Underlined paths with a distinct underline color
set -g fish_color_valid_path --underline --underline-color=brgreen

# Strikethrough for deprecated flags
set -g fish_color_param --strikethrough
```

Ten en cuenta que `fish_color_valid_path` fusiona sus modificadores con el color que recibiría normalmente el token de la ruta. Desde fish 4.7.0 también respeta colores de fondo y de subrayado. Un flag `--reset` que detiene la fusión y da a la ruta su propio color completo ya está en `master` y llegará en una próxima versión.

Novedades de `set_color` en versiones recientes de fish: `--strikethrough` (4.4), `--foreground`/`-f`, `--reset` y conmutadores por modo `=off` como `--italics=off` (4.6).

</Tab>
</Tabs>

## Novedad en Fish 4.8.1: fish_color_builtin y fish_color_function

Fish 4.8.1 (julio de 2026) añadió dos variables que te permiten distinguir los comandos integrados de los comandos externos y resaltar tus propias funciones de forma distinta:

```bash
# in config.fish, after your theme choose line
set -g fish_color_builtin magenta   # builtins like cd, set, test
set -g fish_color_function brblue   # your own functions
```

Ambas recurren a `fish_color_command` cuando no están definidas, así que los temas existentes se ven igual hasta que decides activarlas. Nada se rompe al actualizar.

Las reglas completas de respaldo:

| Variable | Toma el valor de |
|---|---|
| `fish_color_builtin` | `fish_color_command` |
| `fish_color_function` | `fish_color_command` |
| `fish_color_keyword` | `fish_color_command` |
| `fish_color_option` | `fish_color_param` |
| `fish_color_valid_path` | fusiona sus modificadores en el color del token subyacente |

<Notice type="info" title="Solo en Fish 4.8.1+">
En versiones anteriores de fish, `fish_color_builtin` y `fish_color_function` no hacen nada. Ejecuta `fish --version` para comprobarlo. Si quieres [crear tus propias funciones en Fish Shell](/es/fish-shell-funciones-comandos-personalizados/), darles su propio color hace que destaquen de los comandos externos a simple vista.
</Notice>

## Temas integrados de Fish shell (fish_config theme)

Fish incluye 25 temas de color. Los subcomandos de `fish_config theme` son la interfaz:

```bash
fish_config theme list              # names of all built-in themes
fish_config theme show dracula      # preview a theme without applying
fish_config theme demo              # sample text in your current theme
fish_config theme choose dracula    # apply now
fish_config theme dump > ~/.config/fish/themes/my.theme   # export current
```

Para hacer permanente un tema, pon la línea `choose` en `config.fish`:

```bash
# ~/.config/fish/config.fish
fish_config theme choose dracula
```

<ListCheck>
<ul>
<li>`dracula` es un tema oscuro con tonos morados y rosas</li>
<li>`nord` usa tonos azules fríos agradables para la vista</li>
<li>`catppuccin-mocha` es un tema oscuro pastel (también frappe y macchiato)</li>
<li>`solarized` es adaptativo y cambia con el modo claro/oscuro de tu terminal</li>
<li>`none` desactiva casi todo el resaltado, algo útil para depurar</li>
<li>`default-rgb` es la variante true-color del tema por defecto</li>
</ul>
</ListCheck>

La lista completa de temas integrados: `ayu`, `ayu-mirage`, `base16-default`, `base16-eighties`, `bay-cruise`, `catppuccin-frappe`, `catppuccin-macchiato`, `catppuccin-mocha`, `coolbeans`, `default`, `default-rgb`, `dracula`, `fairground`, `just-a-touch`, `lava`, `mono-lace`, `mono-smoke`, `none`, `nord`, `old-school`, `seaweed`, `snow-day`, `solarized`, `tomorrow`, `tomorrow-night-bright`.

<Notice type="warning" title="catppuccin-latte no viene integrado">
Con fish solo se incluyen las variantes oscuras de Catppuccin: frappe, macchiato y mocha (desde la 4.4.0). El tema claro `catppuccin-latte` es un archivo `.theme` de terceros que tendrás que añadir tú mismo. Además, `solarized` es un único tema adaptativo (no archivos `-dark` y `-light` separados), y en la familia tomorrow `tomorrow` es la variante clara mientras que `tomorrow-night-bright` es la oscura.
</Notice>

Los colores del prompt van aparte de los colores de sintaxis. Si quieres personalizar tu prompt, consulta [temas y prompts de Fish Shell](/es/fish-shell-temas-prompts/) o la guía de [prompt Starship con Fish Shell](/es/fish-shell-configurar-starship/).

### Temas adaptativos claro y oscuro

Desde fish 4.3.0, los archivos de tema pueden incluir secciones `[light]`, `[dark]` y `[unknown]`. Fish vigila `fish_terminal_color_theme` y vuelve a aplicar la variante correspondiente cuando tu terminal cambia entre modo claro y oscuro. El tema integrado `solarized` es el ejemplo de referencia.

<Tabs>
<Tab name="Seguir al terminal">

```bash
# Just choose the theme: fish picks the right variant
fish_config theme choose solarized
```

Fish detecta el esquema de colores de tu terminal y aplica automáticamente la sección `[light]` o `[dark]`.

</Tab>
<Tab name="Forzar oscuro">

```bash
fish_config theme choose solarized --color-theme=dark
```

Usa siempre la variante oscura independientemente de lo que informe el terminal.

</Tab>
<Tab name="Forzar claro">

```bash
fish_config theme choose solarized --color-theme=light
```

Usa siempre la variante clara independientemente de lo que informe el terminal.

</Tab>
</Tabs>

Esta es una de las razones por las que el antiguo enfoque de `set -U` / `theme save` es incorrecto para temas adaptativos. Las variables universales congelan una única variante y no pueden seguir los cambios del terminal.

## Crea un archivo de tema personalizado en Fish

En lugar de un muro de líneas `set -U`, la forma limpia de construir tu propio tema es un archivo `.theme`:

```bash
# 1. Dump your current colors as a starting point
fish_config theme dump > ~/.config/fish/themes/my.theme

# 2. Edit the file
nano ~/.config/fish/themes/my.theme

# 3. Apply it
fish_config theme choose my
```

Un archivo `.theme` es texto plano. Acepta únicamente variables `fish_color_*` y `fish_pager_color_*`. Nada más pertenece aquí. Un ejemplo completo con ese formato:

```
# name: my-theme
# preferred_background: 1e1e2e

fish_color_normal normal
fish_color_command 5fd700
fish_color_keyword 5fd700
fish_color_quote ff8700
fish_color_redirection 87d7ff
fish_color_end 87d7ff
fish_color_error ff5f5f --bold
fish_color_param 87d7ff
fish_color_option --underline=curly
fish_color_comment 6c7086
fish_color_selection --background=3a3a5c
fish_color_operator ff87d7
fish_color_escape ff87d7
fish_color_autosuggestion 555555
fish_color_valid_path --underline --underline-color=brgreen
fish_color_cwd 5fd7ff
fish_color_cwd_root red
fish_color_user 87d7ff
fish_color_host normal
fish_color_host_remote ff8700
fish_color_status red
fish_color_cancel -r
fish_color_search_match --background=555555
```

También puedes añadir secciones `[light]` y `[dark]` para variantes adaptativas. Pon los colores compartidos fuera de las secciones y las anulaciones de modo claro/oscuro dentro de ellas.

<Notice type="info" title="Formato del archivo de tema">
Solo las variables `fish_color_*` y `fish_pager_color_*` van en los archivos `.theme`. Todo lo demás (alias, funciones, abreviaturas) va en `config.fish`.
</Notice>

Desde fish 4.3.2, los destinos de redirección también se validan: `> file.txt` resalta el destino con `fish_color_valid_path` cuando el archivo ya existe. Es un aviso visual de que estás a punto de sobrescribir algo.

Para deshacerlo: borra `~/.config/fish/themes/my.theme` y ejecuta `fish_config theme choose default`.

## Colores del pager (menú de completado)

El paginador de completado con Tab tiene su propio conjunto de colores, separado de los colores de sintaxis de la línea de comandos:

```bash
set -g fish_pager_color_completion normal                      # completion text
set -g fish_pager_color_description yellow --italics            # description text
set -g fish_pager_color_prefix --bold --underline               # matched prefix
set -g fish_pager_color_progress brwhite --background=cyan --bold  # progress bar
set -g fish_pager_color_selected_background -r                  # selection (reverse)
```

Estos controlan lo que ves cuando pulsas Tab y navegas por las opciones de completado. Si quieres entender el propio sistema de completado, consulta la [guía de autocompletado y sugerencias de Fish Shell](/es/fish-shell-autocompletado-sugerencias/).

Una variable que conviene conocer: `fish_color_history_current` controla el color de la coincidencia actual al navegar por el historial de directorios con `dirh`/`cdh`.

## Resaltado de sintaxis en Fish vs Zsh vs Bash

<Tabs>
<Tab name="Bash">

Bash no tiene resaltado de sintaxis en absoluto. Lo que escribes es texto plano hasta que lo ejecutas. Existen proyectos de terceros (como `ble.sh`), pero no hay nada integrado.

</Tab>
<Tab name="Zsh">

Zsh necesita el [plugin zsh-syntax-highlighting](/es/activar-resaltado-sintaxis-zsh/). Funciona bien una vez instalado, pero es una dependencia externa que tienes que gestionar y actualizar. El plugin soporta patrones de resaltado personalizados, lo que te da flexibilidad a costa de configuración. Para una visión más amplia, consulta la [comparación entre Fish, Bash y Zsh](/es/fish-shell-vs-bash-vs-zsh-comparacion/).

</Tab>
<Tab name="Fish">

Fish lo hace de forma nativa. El resaltado forma parte del propio shell, se ejecuta en cada pulsación de tecla y valida comandos contra tu PATH en tiempo real. Nada que instalar, nada que quede desactualizado. Este es uno de los argumentos centrales a favor de [Fish frente a Zsh](/es/fish-shell-vs-zsh-comparacion/): la función vive en el shell, así que no hay ningún plugin que fijar, actualizar o depurar.

</Tab>
</Tabs>

## Solución de problemas del resaltado de sintaxis en Fish shell

<Notice type="error" title="Aviso de consejo obsoleto">
Las guías escritas antes de 2026 suelen recomendar `set -U` para ajustar colores. Eso está desfasado para fish 4.3+. Usa `config.fish` con `set -g` en su lugar. Consulta la sección [cómo cambiar los colores de Fish shell](#cómo-cambiar-los-colores-de-fish-shell) de arriba.
</Notice>

<Accordion label="Los colores se ven mal o apagados" group="faq">
Puede que tu terminal no soporte true color. Compruébalo con:

```bash
set_color ff8700; echo "This should be orange"; set_color normal
```

Si no aparece en naranja, tu terminal necesita otro ajuste de modo de color. La mayoría de terminales modernos (Ghostty, iTerm2, WezTerm, Alacritty, Kitty) soportan true color de serie. Si usas un terminal más antiguo, revisa los ajustes de su perfil de color. Consulta la [guía de configuración del terminal Ghostty](/es/terminal-ghostty/) si quieres un terminal moderno que gestione esto bien.
</Accordion>

<Accordion label="Los colores se reinician tras reiniciar" group="faq" expanded="true">
Este es el problema más habitual desde fish 4.3. La solución: tu ajuste de color debe estar en `~/.config/fish/config.fish` (o en un archivo `.theme` elegido desde allí). Si escribiste `set -g fish_color_command ...` en una sesión interactiva sin guardarlo en `config.fish`, no persistirá.

Revisa también si quedó un archivo `~/.config/fish/conf.d/fish_frozen_theme.fish`. Si actualizaste desde fish 3.x, es posible que fish 4.3+ haya migrado tus antiguas variables universales a ese archivo, y oculta la configuración de tu `config.fish`. Bórralo y define tu tema en `config.fish`.
</Accordion>

<Accordion label="El tema no se aplica a todas las sesiones" group="faq">
`fish_config theme choose` se aplica a la sesión actual y a las nuevas. Las sesiones ya abiertas no se actualizan solas. Si quieres que todas las sesiones recojan un cambio de tema en vivo, usa este patrón en `config.fish`:

```bash
function apply-my-theme --on-variable=my_theme
    fish_config theme choose $my_theme
end
```

Luego, desde cualquier sesión:

```bash
set -U my_theme dracula
```

Todas las sesiones en ejecución recogen el cambio. Es un truco avanzado opcional; la mayoría de personas no lo necesitan.
</Accordion>

<Accordion label="Las variables nuevas no hacen nada (fish_color_builtin, fish_color_function)" group="faq">
Estas variables requieren fish 4.8.1 o posterior. Ejecuta `fish --version` para comprobarlo. Los paquetes de las distros van por detrás: Ubuntu 24.04 incluye fish 3.7.0, y esas variables simplemente no existen ahí. Instala desde el PPA de fish-shell o usa Homebrew. Consulta [instalar Fish Shell en Ubuntu](/es/instalar-fish-shell-ubuntu/).

Los temas adaptativos claro/oscuro requieren fish 4.3.0+. Los estilos de subrayado requieren fish 4.0+.
</Accordion>

<Accordion label="Mi tema se ve distinto al de las capturas online" group="faq">
Fish cambió su esquema de colores por defecto en la versión 4.0.0. Los comandos válidos ya no son azules. Si instalaste fish antes de la 4.0 y actualizaste, tu esquema antiguo sobrevive en un archivo de tema congelado. Vuelve a ejecutar `fish_config theme choose default` para obtener el aspecto actual. Las capturas de artículos antiguos mostrarán el esquema anterior con comandos en azul.
</Accordion>

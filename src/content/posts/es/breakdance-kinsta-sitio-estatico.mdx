Los sitios estáticos cargan más rápido, no tienen superficie de ataque para exploits de WordPress y cuestan casi nada de alojar. La contrapartida es que pierdes las funciones dinámicas, lo que hace que este enfoque sea ideal para sitios de presentación, portafolios y páginas de aterrizaje que no necesitan inicios de sesión ni datos en vivo.

**Actualización (febrero de 2026):** Kinsta trasladó su alojamiento de sitios estáticos a una plataforma separada llamada [Sevalla](https://sevalla.com/) el 2 de febrero de 2026. Tus datos, configuraciones y precios existentes se mantienen. Puedes iniciar sesión en Sevalla con tus credenciales de MyKinsta. El nivel gratuito y el flujo de trabajo son los mismos, solo que en un panel diferente.

Este tutorial cubre cómo convertir un sitio WordPress creado con Breakdance en un sitio estático y desplegarlo en el nivel gratuito de alojamiento estático de Sevalla.

## ¿Por qué pasarse a lo estático?

Un sitio WordPress estándar necesita PHP, una base de datos y procesos de servidor ejecutándose constantemente. Un sitio estático es solo HTML, CSS y JavaScript servidos desde una CDN. Ventajas:

- Cargas de página mucho más rápidas (sin consultas a la base de datos en cada petición)
- Sin vulnerabilidades de WordPress que parchear
- El alojamiento estático de Sevalla es gratis para uso básico (hasta 100 sitios, 600 minutos de compilación al mes, 100 GB de ancho de banda)
- Sin mantenimiento de servidor

Esto funciona mejor para sitios que no cambian con frecuencia: páginas de empresa, portafolios, documentación.

## Qué necesitas

- Un sitio WordPress creado con [Breakdance](https://go.bitdoze.com/breakdance) (o cualquier maquetador)
- Una cuenta de [Sevalla](https://sevalla.com/) (puedes usar tus credenciales existentes de MyKinsta)
- Un repositorio en GitHub/GitLab/Bitbucket para el despliegue
- El plugin [Simply Static](https://wordpress.org/plugins/simply-static/)

## Pasos

### 1. Optimiza WordPress para la exportación estática

Breakdance ya elimina gran parte del código innecesario por defecto. Ve a **Settings → Performance** dentro de Breakdance y desactiva el editor Gutenberg, los oEmbeds y cualquier función que no uses. Menos recursos = una salida estática más pequeña.

### 2. Configura Simply Static

Instala el plugin [Simply Static](https://wordpress.org/plugins/simply-static/). Configúralo para:
- Exportar a un directorio local o a un ZIP
- Establecer la URL de destino a la URL de tu sitio estático en Sevalla
- Excluir todo lo dinámico (URLs de administración, endpoints de comentarios)

### 3. Genera los archivos estáticos

Pulsa Generate en Simply Static. Para un sitio pequeño esto termina en segundos; incluso un sitio mediano de 50–100 páginas tarda menos de un minuto.

### 4. Sube los cambios a tu repositorio

```bash
git add .
git commit -m "static content update"
git push --force -u origin main
```

Conecta el repositorio a Sevalla Static Site Hosting. Sevalla desplegará automáticamente con cada push a la rama que especifiques.

### 5. Añade tu dominio

En Sevalla, ve a tu sitio estático y añade un dominio personalizado. Verifica la propiedad del dominio y luego añade un registro CNAME en tu DNS que apunte al edge de Sevalla (impulsado por la CDN de Cloudflare con más de 260 ubicaciones).

### 6. Gestiona los formularios

El maquetador de formularios integrado de Breakdance no funcionará en un sitio estático: no hay PHP para procesar los envíos. Usa un servicio de formularios externo en su lugar. [AIDAForm](https://aidaform.com/) tiene un nivel gratuito y genera un código de inserción que puedes pegar directamente en Breakdance. Formspree y Netlify Forms también tienen niveles gratuitos que funcionan bien.

## Resultado

El sitio estático exportado se ve idéntico al original de WordPress, incluidas las animaciones de Breakdance y las secciones dinámicas que funcionan con JavaScript. La velocidad de carga mejora notablemente, ya que no hay procesamiento del servidor en cada petición.

Para sitios de presentación pequeños, esta configuración es casi gratuita: WordPress se ejecuta localmente o en un VPS barato solo para la edición, y el sitio público vive en la CDN de Sevalla. Si superas los límites del nivel gratuito, los excedentes son de $0.05/min en compilaciones y $0.10/GB de ancho de banda, lo que sigue siendo barato para la mayoría de los sitios.

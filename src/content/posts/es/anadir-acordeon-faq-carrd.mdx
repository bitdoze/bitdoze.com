### 3. Pega el código y personaliza tus ítems de FAQ

Pega el código completo en el campo Code del elemento Embed. Luego edita el contenido del FAQ. Cada ítem de acordeón sigue este patrón:

```html
<button class="accordion" aria-expanded="false">Your question here?</button>
<div class="panel">
  <p>Your answer goes here. You can include multiple paragraphs, lists, or inline HTML.</p>
</div>
```

El atributo `aria-expanded="false"` es parte del setup de accesibilidad cubierto más abajo. Añadirlo ahora no cuesta nada y deja el markup listo.

El botón y su panel deben quedar adyacentes: el script abre el elemento que sigue inmediatamente al botón clicado.

```html
<style>

  .accordion {
    background-color: #868e99; /* Accordion color */
    color: #eeebeb; /* Accordion text color */
    cursor: pointer;
    padding: 18px;
    width: 100%;
    border: none;
    text-align: left;
    outline: none;
    transition: 0.4s;
    border-radius: 10px;
    margin-bottom: 10px;
    font-size: 2.1rem;
  }
  .accordion:before {
    content: "\002B";
    color: #4d514d; /* Plus sign color */
    font-weight: bold;
    float: right;
    margin-left: 5px;
    border-radius: 50%;
    padding: 5px;
    transition: transform 0.3s ease-in-out;
  }
  .accordion.active:before {
    transform: rotate(45deg);
    background-color: #4d514d; /* Close (x) icon background */
    color: #d91a1a; /* Close (x) icon color */
  }
  .accordion.active,
  .accordion:hover {
    background-color: #4d514d; /* Hover and open tab color */
    border-radius: 10px;
  }
  .panel {
    padding: 0 18px;
    background-color: #eeebeb; /* Answer panel background */
    max-height: 0;
    overflow: hidden;
    transition: max-height 0.2s ease-out;
    border-radius: 10px;
  }
  .panel p {
    margin: 0;
    padding: 10px 10px;
    font-size: 2.1rem;
  }
</style>
```

Cambia los valores hexadecimales de color para que encajen con la paleta de tu sitio. Los comentarios en el código facilitan encontrar cada propiedad.

<Notice type="warning" title="Revisa el selector .active">
Si tu copia descargada tiene una regla que empieza con <code>.active, .accordion:hover</code>, cámbiala a <code>.accordion.active, .accordion:hover</code> como arriba. Carrd pone una clase <code>active</code> en la sección actualmente en pantalla, así que un selector <code>.active</code> pelado pinta toda tu sección del color de hover del acordeón. Acotado a <code>.accordion.active</code>, solo da estilo al ítem abierto.
</Notice>

## Haz el acordeón accesible (aria-expanded)

El markup ya usa elementos `<button>` reales, así que el soporte de teclado viene gratis. Lo que falta es estado: los lectores de pantalla no pueden saber si una pregunta está abierta. Dos líneas lo arreglan.

El handler de clic actualmente hace `this.classList.toggle("active")` e ignora el resultado. Captura el nuevo estado y refléjalo en `aria-expanded`:

<Tabs>
<Tab name="Script base">

```html
<script>
  // Accordion script
  var acc = document.getElementsByClassName("accordion");
  for (var i = 0; i < acc.length; i++) {
    acc[i].addEventListener("click", function () {
      this.classList.toggle("active");
      var panel = this.nextElementSibling;
      if (panel.style.maxHeight) {
        panel.style.maxHeight = null;
      } else {
        panel.style.maxHeight = panel.scrollHeight + "px";
      }
    });
  }
</script>
```

</Tab>
<Tab name="Accesible (aria-expanded)">

```html
<script>
  // Accordion script (accessible)
  var acc = document.getElementsByClassName("accordion");
  for (var i = 0; i < acc.length; i++) {
    acc[i].addEventListener("click", function () {
      var open = this.classList.toggle("active");
      this.setAttribute("aria-expanded", open);
      var panel = this.nextElementSibling;
      panel.style.maxHeight = open ? panel.scrollHeight + "px" : null;
    });
  }
</script>
```

</Tab>
<Tab name="Seguro multi-embed">

```html
<script>
  // Accordion script (multi-embed safe)
  var acc = document.getElementsByClassName("accordion");
  for (var i = 0; i < acc.length; i++) {
    if (acc[i].dataset.bound) continue; // already wired by another copy
    acc[i].dataset.bound = "1";
    acc[i].addEventListener("click", function () {
      this.classList.toggle("active");
      var panel = this.nextElementSibling;
      if (panel.style.maxHeight) {
        panel.style.maxHeight = null;
      } else {
        panel.style.maxHeight = panel.scrollHeight + "px";
      }
    });
  }
</script>
```

</Tab>
</Tabs>

Con el script accesible, cada `<button class="accordion">` también necesita `aria-expanded="false"` en el markup (ya añadido en el paso 3). `classList.toggle` devuelve el nuevo estado, así que el mismo clic que abre el panel pone el atributo a `true`, y el siguiente clic lo devuelve.

<Notice type="info" title="No probado en vivo">
Esta variante de dos líneas no ha pasado por una publicación real en Carrd a octubre de 2026. Es un cambio pequeño sobre el script base, así que verifícalo en tu sitio publicado: haz clic en una pregunta e inspecciona el botón en devtools para confirmar que <code>aria-expanded</code> alterna entre false y true.
</Notice>

## Incrustar varias secciones de acordeón en la misma página

Si necesitas dos o más grupos de FAQ separados en un sitio Carrd, añade un Inline Embed por grupo. Hay una trampa: el script del plugin adjunta un handler de clic a cada botón `.accordion` de la página, no solo a los de su propio embed. Con el código completo pegado dos veces, los botones del primer grupo obtienen dos handlers. Cada clic abre el panel e inmediatamente lo cierra otra vez, así que ese grupo parece muerto.

El arreglo es usar esta versión del bloque `<script>` en cada copia. Salta botones que otra copia ya haya cableado. Si también quieres el comportamiento de `aria-expanded`, el guardia queda arriba del bucle y las dos líneas de aria van dentro del listener, así:

```html
<script>
  // Accordion script (multi-embed safe + accessible)
  var acc = document.getElementsByClassName("accordion");
  for (var i = 0; i < acc.length; i++) {
    if (acc[i].dataset.bound) continue; // already wired by another copy
    acc[i].dataset.bound = "1";
    acc[i].addEventListener("click", function () {
      var open = this.classList.toggle("active");
      this.setAttribute("aria-expanded", open);
      var panel = this.nextElementSibling;
      panel.style.maxHeight = open ? panel.scrollHeight + "px" : null;
    });
  }
</script>
```

El bloque `<style>` puede quedar duplicado en cada embed; reglas CSS idénticas no conflictúan. Cada botón sigue necesitando su `<div class="panel">` directamente después, porque el script abre el elemento que sigue inmediatamente al botón clicado.

## Troubleshooting: el acordeón de Carrd no funciona

Si tu acordeón de Carrd no funciona tras publicar, la causa es casi siempre una de estas.

Si el acordeón no aparece tras publicar, comprueba que el Type del elemento Embed es Code y su Style es Inline, y que está en la sección donde lo esperas. Confirma también que tu plan de Carrd soporta embeds (Pro Standard o superior).

Si no ves el elemento Embed en Add Element, el plan está por debajo de Pro Standard. El tier gratis topa en 3 sitios y excluye embeds por completo. Actualiza, o usa la prueba de Pro de 7 días para probar primero.

Si el acordeón se ve roto o sin estilos, asegúrate de que pegaste el código completo, incluyendo el bloque `<style>` de arriba, en el campo Code.

Si toda la sección se pone gris, tu copia usa un selector `.active` pelado que casa con la sección activa de Carrd. Cámbialo a `.accordion.active` (ver paso 4).

Si hacer clic en una pregunta no hace nada, abre la consola del navegador y busca errores de JavaScript. Si pegaste el código completo en dos embeds, los botones del primer grupo obtienen dos handlers de clic que se cancelan mutuamente. Usa el script de la sección de acordeones múltiples de arriba.

Si el texto es demasiado pequeño en móvil, añade un override de font-size en la sección de estilo del código. Por ejemplo: `.accordion { font-size: 16px; }` y `.panel p { font-size: 15px; }`.

Si el enlace de descarga muestra una página de Cloudflare o intersticial, ábrelo en un navegador normal. El enlace está detrás de un reto de bots para herramientas automatizadas; la página del plugin está viva y alcanzable a mano.

Para deshacerlo todo: borra el elemento Embed y republica. Nada más en Carrd se toca, así que el rollback es así de simple.

## Alternativas al enfoque de embed de código

Si prefieres no gestionar código crudo, o quieres un estilo visual diferente, hay otras tres rutas. Mi opción por defecto sigue siendo el snippet de CarrdMe de arriba: gratis, sin branding, totalmente editable, y el menor impacto en peso de página.

### Opción sin JavaScript: `<details>/<summary>`

Como el Inline Embed acepta HTML arbitrario, `<details>/<summary>` nativo te da un acordeón funcional con cero JavaScript. El navegador maneja abrir y cerrar:

```html
<details class="faq">
  <summary>What is your refund policy?</summary>
  <p>Full refund within 30 days. Contact support@example.com to start the process.</p>
</details>

<details class="faq">
  <summary>How do I contact support?</summary>
  <p>Email us at support@example.com. We respond within 24 hours.</p>
</details>
```

Da estilo a `summary` como la barra `.accordion` (fondo, padding, border-radius, cursor) y cambia el icono de más por una regla `summary::before`. El compromiso es la animación: no hay transición max-height suave por defecto. El CSS más nuevo con `interpolate-size` y `transition-behavior: allow-discrete` puede animarlo, pero el soporte de navegadores sigue irregular a octubre de 2026, así que yo saltaría la animación aquí.

La versión JS está animada y acepta la mejora de aria. `<details>/<summary>` es a prueba de balas pero sin animar.

<Notice type="info" title="No probado en vivo">
Esta variante no ha pasado por una publicación real en Carrd a octubre de 2026. El embed acepta HTML arbitrario así que debería renderizar, pero compruébalo en tu sitio publicado antes de servirlo a visitantes.
</Notice>

### Widget de acordeón de Common Ninja

Un servicio de widgets alojado que genera el acordeón por ti y te da un snippet de embed. Precios a octubre de 2026:

- Tier gratis: 0 $, gratis para siempre, sin tarjeta requerida
- Essentials: 24 $/año (2 $/mes facturado anualmente)
- Pro: 38,40 $/año (3,20 $/mes facturado anualmente)
- Ultimate: 62,40 $/año (5,20 $/mes facturado anualmente)

Todos los tiers facturan anualmente; los precios de lista excluyen IVA. El tier gratis ha ido históricamente con branding de Common Ninja, y los tiers de pago son los que lo quitan. Ten en cuenta que es un widget alojado: un script de terceros carga en tu página y tienes menos control sobre la salida que con el snippet de CarrdMe.

<Notice type="warning" title="Precios comprobados en oct 2026">
Los precios de widgets envejecen rápido. Comprueba [commoninja.com/pricing](https://www.commoninja.com/pricing) antes de comprometerte.

### Jason's Plugins para Carrd

[plugins.carrd.co](https://plugins.carrd.co/) aloja dos variantes de acordeón, y ambas son gratis ("introduce 0 $, o cualquier propina que desees"):

- Accordion FAQs drop-down: ligero y minimal con iconos chevron animados. Demo: [accordionfaqs.carrd.co](https://accordionfaqs.carrd.co/).
- Animated accordion FAQs drop-down: el mismo desplegable con una animación de rebote en vez del chevron. Demo: [animatedaccordionfaqs.carrd.co](https://animatedaccordionfaqs.carrd.co/).

Dos cosas cambian el flujo aquí. Primero, llegan como plantillas de Carrd: tras descargar vas al dashboard de Carrd, eliges **New site**, abres la pestaña **My Templates** y seleccionas la plantilla. Luego copias el código de ese sitio plantilla y lo fusionas en el tuyo. Segundo, la variante animada carga Vue.js desde un CDN. En un sitio de una página donde cuentas kilobytes, eso es notablemente más pesado que el snippet de JS vainilla de CarrdMe.

<Notice type="info" title="Instalación basada en plantillas">
Los plugins de Jason llegan como sitios plantilla, no como bloques de código listos para pegar. Presupuesta un paso extra para importar la plantilla y copiar las piezas que necesitas.
</Notice>

Si te gusta el enfoque de CarrdMe y quieres la misma técnica para contenido con pestañas, el [plugin de tabs de Carrd](https://go.carrdme.com/tabs) funciona igual: un Inline Embed, sin framework.

## ¿Mostrará Google mi FAQ de acordeón como rich result?

Respuesta corta: probablemente no. A octubre de 2026, Google muestra rich results de FAQ solo para sitios web gubernamentales y de salud conocidos y autoritativos, y los rich results de How-to han desaparecido por completo.

El schema en sí es inofensivo y sigue siendo útil para semántica y otros buscadores. Solo no añadas JSON-LD de FAQPage (vía un embed Hidden → Head) esperando listados de FAQ expandibles en la SERP de Google.

<Notice type="warning" title="No esperes rich snippets">
Google restringió los rich results de FAQ a sitios gubernamentales y de salud autoritativos. Mira los [docs de datos estructurados de FAQPage de Google](https://developers.google.com/search/docs/appearance/structured-data/faqpage) para la política actual antes de molestarte con el markup.
</Notice>

Haz el snapshot. Si tienes un sitio en producción con pedidos o tráfico en vivo, el snapshot es lo que te separa de un mal día.

## Espera antes de actualizar

A menos que un bug te esté afectando activamente, espera 1-2 semanas después de un lanzamiento antes de actualizar servidores de producción. Deja que otros encuentren primero los casos límite. Puedes seguir el [changelog de CloudPanel](https://www.cloudpanel.io/docs/v2/changelog/) y el [foro de CloudPanel](https://cloudpanel.forum/) para ver si alguien reporta problemas con una nueva versión.

## Paso 1: Haz un snapshot consistente

Detén primero tus servicios para que el snapshot capture un estado limpio:

```bash
sudo service nginx stop
sudo service mysql stop
```

Apaga el VPS desde la consola de Hetzner:

<Picture formats={["webp"]} fallbackFormat="webp" src={imgPowerOff} alt="Botón de apagado del VPS de Hetzner" />

Ve a **Snapshots → Take snapshot**:

<Picture formats={["webp"]} fallbackFormat="webp" src={imgSnapshot} alt="Botón Take snapshot de Hetzner" />

Vuelve a encender el servidor. Ya tienes un punto de restauración.

## Paso 2: Ejecuta la actualización de CloudPanel

Conéctate al servidor por SSH y ejecuta:

```bash
clp-update
```

Eso es todo: un solo comando actualiza CloudPanel a la última versión.

## Paso 3: Reinicia

```bash
sudo service nginx stop
sudo service mysql stop
reboot
```

## Paso 4: Verifica

Después del reinicio, comprueba el panel de administración de CloudPanel → pestaña **Instance**. Todos los servicios deberían aparecer en ejecución:

<Picture formats={["webp"]} fallbackFormat="webp" src={imgServices} alt="Estado de los servicios de CloudPanel, todos en ejecución" />

Luego abre uno de tus sitios en un navegador y confirma que carga. Revisa los logs de errores del sitio en CloudPanel si algo no parece correcto.

Si algo salió mal y necesitas volver atrás, restaura el snapshot desde la consola de Hetzner y tu servidor volverá a su estado anterior a la actualización.

## Actualiza también el SO

Mientras haces mantenimiento, actualiza también los paquetes de Ubuntu:

```bash
sudo apt update && sudo apt upgrade -y
```

CloudPanel soporta actualmente Ubuntu 24.04, Ubuntu 22.04, Debian 12 y Debian 11. Si todavía estás en Ubuntu 22.04, seguirá funcionando, pero las instalaciones nuevas deberían usar 24.04.

No ejecutes `do-release-upgrade` para cambiar de versión de Ubuntu en un servidor CloudPanel en producción. Si necesitas pasarte a un SO más nuevo, monta un servidor nuevo y migra tus sitios.

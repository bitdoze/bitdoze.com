Los sitios web de una página funcionan bien para portfolios, landing pages, currículums y sitios de pequeños negocios. Cargan rápido, son fáciles de navegar en móvil y sencillos de mantener.

El problema: crear y alojar un sitio web suena caro. Los desarrolladores web cobran cientos o miles de dólares. Los planes de hosting gestionado añaden costes recurrentes. Pero en realidad no necesitas nada de eso para un sitio de una sola página.

Esta guía cubre tres formas asequibles de crear un sitio web de una página con poco presupuesto, desde completamente gratis hasta menos de 20 $/año. Cada opción tiene diferentes compromisos en cuanto a personalización, habilidad técnica requerida y coste.

## Opción 1: Astro

[Astro](https://astro.build/) es un framework de sitios estáticos construido para la velocidad. Genera HTML, CSS y JavaScript planos sin sobrecarga en runtime. Astro 7.0 (lanzado en junio de 2026) usa Vite 8 e incluye un compilador basado en Rust para compilaciones más rápidas.

Astro soporta React, Svelte, Vue y su propia sintaxis de componentes. Puedes mezclar frameworks en el mismo proyecto. Para un sitio web de una página, probablemente no necesitarás ningún framework. El sistema de plantillas integrado de Astro es suficiente.

**Cuánto cuesta:** Gratis. Astro en sí es open source. Puedes alojar el resultado compilado en Cloudflare Pages, Vercel o Netlify gratis.

**Habilidad técnica necesaria:** Moderada. Necesitas saber HTML y CSS. Algo de JavaScript ayuda. Usarás la línea de comandos para crear el proyecto y hacer push a Git.

### Por qué Astro funciona para sitios de una página

- Genera HTML estático, no se necesita servidor en runtime
- Tiempos de compilación rápidos con el compilador Rust en Astro 7
- Cientos de plantillas gratuitas en el [directorio de temas de Astro](https://astro.build/themes/)
- Despliega en Cloudflare Pages con ancho de banda ilimitado gratis

### Hosting gratis para Astro

| Plataforma | Ancho de banda gratis | Builds gratis | Dominios personalizados |
|----------|---------------|-------------|----------------|
| Cloudflare Pages | Ilimitado | 500/mes | Ilimitados |
| Vercel (Hobby) | 100 GB | 6.000 minutos/mes | Ilimitados |
| Netlify | 100 GB | 300 minutos/mes | Ilimitados |

Cloudflare Pages es la mejor opción gratuita para sitios estáticos. El ancho de banda ilimitado significa que no habrá facturas sorpresa, y las más de 300 ubicaciones edge sirven tu sitio rápido en todo el mundo.

### Primeros pasos con Astro

1. Instala Node.js (se requiere v22.12.0+)
2. Ejecuta `npm create astro@latest` y elige una plantilla
3. Personaliza la plantilla con tu contenido
4. Sube el proyecto a GitHub
5. Conecta el repo a Cloudflare Pages, Vercel o Netlify
6. Tu sitio está en línea

## Opción 2: WordPress Estático

WordPress impulsa millones de sitios web, pero normalmente necesita un servidor PHP y una base de datos. Para un sitio de una página, eso es excesivo y cuesta más de lo necesario.

WordPress estático resuelve esto. Construyes el sitio en WordPress (usando el editor de bloques o un page builder) y luego lo conviertes a archivos HTML planos. Los archivos estáticos se alojan en una plataforma gratuita sin servidor que gestionar.

**Cuánto cuesta:** Gratis si alojas localmente durante el desarrollo y despliegas en Kinsta Static, Cloudflare Pages o Netlify. Kinsta Static ofrece 100 sitios gratis con 100 GB de ancho de banda al mes.

**Habilidad técnica necesaria:** Baja. Si sabes usar WordPress, puedes hacerlo. El paso de conversión usa un plugin llamado Simply Static.

### Cómo funciona

1. Instala WordPress en local (LocalWP o similar) o en un hosting barato
2. Construye tu sitio de una página usando el editor de bloques o un tema
3. Instala el plugin [Simply Static](https://wordpress.org/plugins/simply-static/)
4. Genera los archivos HTML estáticos
5. Despliega en Kinsta Static, Cloudflare Pages o Netlify

### Hosting Kinsta Static (gratis)

El hosting estático gratuito de Kinsta es generoso:

- 100 sitios estáticos por cuenta
- 100 GB de ancho de banda al mes
- 600 minutos de build al mes
- Certificados SSL gratuitos
- Soporte para dominios personalizados
- Sitios alojados en las más de 300 ubicaciones edge de Cloudflare

Puedes conectar un repo de GitHub, GitLab o Bitbucket. Kinsta detecta automáticamente la configuración de build de los generadores de sitios estáticos más populares.

## Opción 3: Carrd

[Carrd](https://try.carrd.co/bitdoze) es un constructor drag-and-drop hecho específicamente para sitios web de una página. No requiere código. Eliges una plantilla, la personalizas con el editor visual y publicas.

**Cuánto cuesta:** Gratis para uso básico. Los planes de pago empiezan en 19 $/año por 10 sitios con dominios personalizados.

**Habilidad técnica necesaria:** Ninguna. Si sabes usar un ratón, puedes construir un sitio con Carrd.

### Precios de Carrd

| Plan | Coste/año | Sitios | Dominios personalizados | Quitar branding |
|------|-----------|-------|----------------|-----------------|
| Gratis | 0 $ | 3 | No | No |
| Pro Lite | 9 $ | 3 | No | Sí |
| Pro Standard | 19 $ | 10 | Sí | Sí |
| Pro Plus | 49 $ | 25 | Sí | Sí |

Pro Standard a 19 $/año es el punto óptimo. Obtienes 10 sitios con dominios personalizados, formularios y la posibilidad de incrustar código personalizado. Eso son unos 1,58 $/mes por sitio.

### En qué destaca Carrd

- Landing pages y portfolios
- Sitios de negocios sencillos con formularios de contacto
- Páginas de link-in-bio
- Sitios de currículum o CV

### Qué no puede hacer Carrd

- Posts de blog o contenido dinámico
- E-commerce (limitado a botones de Stripe/PayPal)
- Navegación multipágina
- Layouts complejos con muchas secciones (el plan gratis tiene un límite de 50 elementos)

## ¿Cuál opción deberías elegir?

Depende de lo que más te importe:

**Elige Astro si** sabes HTML y CSS y quieres control total sobre el diseño. La curva de aprendizaje es más pronunciada, pero el resultado es un sitio rápido alojado gratis sin costes recurrentes. Ideal para desarrolladores o cualquiera dispuesto a aprender.

**Elige WordPress estático si** te manejas bien con WordPress pero quieres hosting gratis. El flujo de trabajo añade un paso de conversión, pero obtienes el editor de WordPress que ya conoces. Bueno para no desarrolladores que quieren más flexibilidad que Carrd.

**Elige Carrd si** quieres algo en línea en 10 minutos sin conocimientos técnicos. El plan gratis funciona para sitios básicos, y Pro Standard a 19 $/año es barato para lo que ofrece. Ideal para usuarios no técnicos que necesitan una presencia online sencilla y rápida.

## Conclusiones

Crear un sitio web de una página con poco presupuesto es más fácil que nunca. Tienes tres opciones sólidas según tu nivel técnico y lo que necesitas:

- **Astro + Cloudflare Pages** = 0 $, rápido, amigable para desarrolladores
- **WordPress estático + Kinsta Static** = 0 $, flujo de trabajo familiar de WordPress
- **Carrd** = de 0 $ a 19 $/año, sin código, en línea en minutos

Las tres opciones producen sitios rápidos y adaptados a móvil. La diferencia principal es cuánto control quieres sobre el diseño y cuánto trabajo técnico estás dispuesto a hacer.

Hermes Agent de Nous Research es el agente de IA open source que más rápido crece en GitHub, con más de 214K estrellas. El agente principal es CLI-first: se ejecuta desde tu terminal con `hermes` o en una TUI completa con `hermes --tui`. Es ideal para desarrolladores que viven en la terminal. Pero también necesitas consultar a tu agente desde una pestaña del navegador en el trabajo, un teléfono en el sofá o una tablet en una cafetería.

El ecosistema ha respondido con paneles web, apps de escritorio, apps de Android, apps de iOS e integraciones de mensajería. Ya existen más de 10 formas de interactuar con Hermes Agent fuera de la terminal. Esta guía compara todas las opciones principales para que elijas la adecuada para tu flujo de trabajo.

<Notice type="info" title="¿Nuevo en Hermes Agent?">
Si aún no has instalado Hermes, empieza con [nuestra guía de configuración de Hermes Agent](/es/guia-configuracion-hermes-agent/). Cubre la instalación, la configuración del modelo y los primeros pasos antes de elegir un panel.
</Notice>

## Mejores paneles web de Hermes Agent

Los paneles web se ejecutan en un navegador y son ideales para la gestión remota desde cualquier dispositivo. Puedes autoalojarlos en un VPS, ejecutarlos localmente o tunelizarlos a través de SSH. Las opciones principales a continuación cubren desde el panel oficial integrado hasta espacios de trabajo completos estilo IDE.

### Panel web oficial de Hermes

El panel integrado forma parte del paquete principal de Hermes (incluido desde Hermes Agent v0.16+). Lánzalo con `hermes dashboard` y obtienes un backend FastAPI/Uvicorn con un frontend React 19 + TypeScript + Tailwind en el puerto 9119.

**Lo que obtienes:**

- **Página de estado:** vista general en vivo con autoactualización cada 5 segundos
- **Chat:** TUI integrada con PTY vía WebSocket, experiencia de terminal completa en el navegador
- **Editor de configuración:** editor YAML basado en formularios que cubre más de 150 campos; se acabó editar archivos a mano
- **Sesiones:** explora, busca (FTS5), exporta y limpia el historial de conversaciones
- **Logs:** registros del agente, del gateway y de errores con filtrado por nivel/componente y tail en vivo
- **Analíticas:** uso de tokens a 7/30/90 días, seguimiento de costes, desglose por modelo
- **Cron jobs:** programa, pausa/reanuda, ejecuta y edita tareas programadas
- **Skills y MCP:** explora, busca y activa skills; añade, prueba, habilita y deshabilita servidores MCP
- **Perfiles:** crea, cambia, clona y gestiona perfiles del agente
- **API Keys:** gestor de variables de entorno con valores ocultos
- **Salud del gateway:** monitoriza el estado de más de 20 conexiones de plataformas de mensajería

Las opciones de autenticación incluyen OAuth vía Nous Portal, usuario/contraseña y OIDC autoalojado. Incluye seis temas integrados, además de un sistema de temas personalizados.

Requisitos previos: instala primero los extras web y PTY.

```bash
pip install -e ".[web,pty]"
```

<Tabs>

```bash
# Default — opens browser, port 9119
hermes dashboard

# Custom port, server mode (no browser auto-open)
hermes dashboard --port 9120 --no-open

hermes dashboard --host 0.0.0.0 --no-open

```
</Tab>

El panel oficial tiene una API REST completa, así que puedes programar por script cualquier operación de gestión. Si quieres la configuración más sencilla sin dependencias adicionales, esta es la opción. Para la configuración de seguridad completa, incluidos túneles SSH y proxy inverso, consulta nuestra [guía de configuración del panel de Hermes Agent](/es/guia-panel-hermes/).

### Hermes WebUI de nesquena

<Button text="Repositorio en GitHub" link="https://github.com/nesquena/hermes-webui" variant="solid" color="blue" size="md" />

El panel comunitario más popular, con más de 16K estrellas en GitHub (MIT). Su rasgo distintivo: cero dependencias. Sin Node.js, sin bundler, sin framework. Solo el servidor HTTP de la biblioteca estándar de Python y JavaScript puro. Activo a julio de 2026 con más de 1.200 releases.

<ListCheck>
<ul>
<li>Chat con streaming vía SSE y soporte de modelos multiproveedor</li>
<li>Gestión de sesiones: fijar, archivar, proyectos, etiquetas, búsqueda, exportar/importar</li>
<li>Diseño responsive para móvil (sidebar tipo hamburguesa, áreas táctiles de 44px)</li>
<li>Entrada de voz vía Web Speech API</li>
<li>Explorador de archivos del workspace con detección de git</li>
<li>Tablero Kanban para gestión de tareas</li>
<li>Puente de sesiones CLI (importa sesiones desde la terminal)</li>
<li>Más de 6 temas con sistema de skins</li>
<li>Sistema de extensiones para inyectar scripts y estilos personalizados</li>
<li>Autenticación por contraseña, WebAuthn/passkeys y OIDC</li>
<li>Soporte de Docker y Nix</li>
<li>~11.500 tests en ~1.150 archivos</li>
</ul>
</ListCheck>

Comandos de lanzamiento:

```bash
# Clone first, then bootstrap (recommended)
git clone https://github.com/nesquena/hermes-webui.git
cd hermes-webui
python3 bootstrap.py

# Or use the shell script after clone
./start.sh

# Docker
docker pull ghcr.io/nesquena/hermes-webui:latest
docker run -d -p 8787:8787 -v ~/.hermes:/home/hermeswebui/.hermes \
  ghcr.io/nesquena/hermes-webui:latest
# Opens http://localhost:8787
```

El diseño responsive lo convierte en el mejor panel web para acceder desde el teléfono: el sidebar tipo hamburguesa y las áreas táctiles están diseñados para ello. También tiene un tablero Kanban integrado (consulta la [guía de configuración de Hermes Kanban](/es/guia-kanban-hermes/) para más detalles) y capacidades de búsqueda web que combinan bien con [la búsqueda gratuita de TinyFish para agentes de codificación IA](/es/tinyfish-busqueda-web-gratis-agentes/).

Si quieres ampliar Hermes con búsqueda web y obtención de páginas para tu agente, la [API de búsqueda web de TinyFish](https://go.bitdoze.com/tinyfish) se integra sin fricción. Le da a tu agente 30 búsquedas/min y 150 fetch/min gratis, lo que complementa las capacidades de extracción integradas del WebUI.

**Ideal para:** usuarios que quieren una interfaz web ligera y sin dependencias que funcione en navegadores móviles sin configuración adicional.

### Hermes Workspace

<Button text="Repositorio en GitHub" link="https://github.com/outsourc-e/hermes-workspace" variant="solid" color="green" size="md" />

Hermes Workspace es la opción estilo IDE: chat, terminal integrada, explorador de archivos, visor de memoria, hub de skills, gestión de MCP y orquestación multi-agente en una sola interfaz React/TypeScript. 6,1K estrellas, licencia MIT.

Las funciones Conductor / Swarm son únicas aquí. Describes una tarea compleja y el workspace la divide en subtareas, despacha agentes especializados y fusiona los resultados. Ningún otro panel de esta lista incluye esa interfaz de orquestación como superficie de primera clase.

<ListCheck>
<ul>
<li>Terminal web integrada (xterm.js): shell completo sin una sesión SSH aparte</li>
<li>Explorador de archivos/workspace con soporte de edición</li>
<li>Descomposición de tareas multi-agente con Conductor / Swarm</li>
<li>Hub de skills y catálogo/marketplace completo de MCP</li>
<li>PWA móvil + acceso remoto compatible con Tailscale</li>
<li>Múltiples temas (Hermes, Nous, Bronze, Slate, Mono)</li>
</ul>
</ListCheck>

```bash
# Docker Compose (recommended)
git clone https://github.com/outsourc-e/hermes-workspace.git
cd hermes-workspace
docker compose up -d
# Workspace on port 3000, Hermes gateway on 8642
```

**Ideal para:** usuarios que quieren una consola completa de operaciones del agente (terminal + archivos + multi-agente), no solo chat.

### Hermes Studio de EKKOLearnAI

<Button text="Repositorio en GitHub" link="https://github.com/EKKOLearnAI/hermes-studio" variant="solid" color="purple" size="md" />

La opción más rica en funciones. 9,1K estrellas. Construido con Vue 3 + TypeScript + Vite + Naive UI, con un backend Koa y Socket.IO para chat en tiempo real. El repositorio se renombró de `hermes-web-ui` a `hermes-studio`; el paquete npm sigue siendo `hermes-web-ui`.

**Lo que lo diferencia:**

- **Canales de plataforma:** configura 8 plataformas (Telegram, Discord, Slack, WhatsApp, Matrix, Feishu, WeChat, WeCom) desde la interfaz
- **Chat grupal:** salas multi-agente con enrutamiento por @mención entre agentes
- **Integraciones de agentes de código:** integración con Codex y Claude Code incorporada
- **Terminal web:** node-pty + xterm.js, terminal completa en el navegador
- **Voz/TTS/STT:** Web Speech del navegador, Edge TTS, compatible con OpenAI, MiMo
- **Explorador de archivos:** soporta backends locales, Docker, SSH y Singularity
- **Gestión de modelos:** descubre proveedores automáticamente, añade/actualiza/elimina modelos
- **Multi-perfil:** clona, exporta e importa perfiles
- **Analíticas de uso:** uso de tokens, costes, gráficos de distribución por modelo
- **Tablero Kanban:** gestión de tareas consciente del perfil (ver la [guía de configuración de Hermes Kanban](/es/guia-kanban-hermes/))

Comandos de lanzamiento:

```bash
# npm global install
npm install -g hermes-web-ui && hermes-web-ui start   # Port 8648

# Docker
WEBUI_IMAGE=ekkoye8888/hermes-web-ui docker compose up -d   # Port 6060
```

<Notice type="warning" title="Nota sobre la licencia">
Hermes Studio usa la licencia BSL-1.1, no MIT. Para uso personal no hay problema. Para uso comercial, revisa los términos de la licencia. BSL-1.1 suele convertirse a MIT tras un periodo determinado (a menudo de 2 a 4 años), pero las restricciones de uso comercial aplican durante el periodo BSL.
</Notice>

**Ideal para:** usuarios avanzados y equipos que quieren el conjunto de funciones más completo, especialmente las salas multi-agente y la gestión de canales de plataforma.

### Hermes Control Interface (HCI)

<Button text="Repositorio en GitHub" link="https://github.com/xaspx/hermes-control-interface" variant="solid" color="green" size="md" />

HCI es el panel de administración centrado en la seguridad. 800 estrellas, MIT, JS puro + Vite + Express (mínima superficie de framework frontend). Prioriza RBAC, CSRF, rate limiting y auditabilidad por encima del acabado visual.

**Lo que obtienes:**

- Puerta de acceso con contraseña con hashing bcrypt, CSRF en endpoints mutantes, rate limiting
- ~20 permisos repartidos en roles admin / viewer / personalizados
- Terminal en el navegador (xterm.js), explorador de archivos, sesiones, cron, métricas del sistema
- Monitor de enjambre multi-agente / Office con vistas de tareas tipo kanban
- PWA instalable en la pantalla de inicio

```bash
git clone https://github.com/xaspx/hermes-control-interface.git
cd hermes-control-interface
cp .env.example .env   # set HERMES_CONTROL_PASSWORD + HERMES_CONTROL_SECRET
npm install && npm run build
node server.js         # http://localhost:10274
```

Requiere Node.js 20+ y el CLI `hermes` en el PATH de la misma máquina.

**Ideal para:** equipos que necesitan control de acceso granular y una superficie de administración endurecida, más que una interfaz de chat bonita.

### Panel Scarf: nativo de macOS

<Button text="Repositorio en GitHub" link="https://github.com/awizemann/scarf" variant="solid" color="purple" size="md" />

Una app nativa de macOS (Swift/SwiftUI) que lee el SQLite de Hermes directamente para datos en tiempo real. 727 estrellas, licencia MIT, requiere macOS 14.6+ (Sonoma). Las últimas releases se distribuyen como binarios universales notarizados desde [GitHub Releases](https://github.com/awizemann/scarf/releases) (no desde la App Store, porque Scarf necesita acceso sin sandbox a `~/.hermes/` y al binario `hermes`).

**Funciones:** panel, analíticas, explorador de sesiones, feed de actividad, chat en vivo (Rich ACP o terminal), editor de memoria, explorador de skills, GUI de plataformas, personalidades, gestor de cron, monitorización de salud, control del gateway y paneles de proyecto personalizados que los agentes pueden autogenerar mediante widgets JSON.

El soporte multiventana permite monitorizar varios servidores Hermes a la vez (local + remoto por SSH). Un icono de estado en la barra de menús mantiene la salud del agente siempre visible. ScarfGo es el compañero para iOS (cubierto en la sección de móvil).

**Ideal para:** usuarios de macOS que quieren una experiencia de app nativa en lugar de una pestaña del navegador. No es un panel web en el sentido tradicional: es una aplicación de macOS en toda regla que resulta hacer todo lo que hace un panel.

## Mejores apps de escritorio de Hermes Agent

Las apps de escritorio ofrecen una integración más profunda con el sistema operativo que los paneles de navegador. Tienen iconos en la bandeja del sistema, notificaciones nativas, atajos de teclado y acceso offline a datos en caché. Algunas herramientas (Hermes Studio, Scarf) aparecen tanto en la sección de paneles web como en la de escritorio porque se distribuyen en ambos formatos.

### Hermes Desktop oficial

La app de escritorio oficial basada en Electron, disponible desde Hermes v0.16. Lánzala con `hermes desktop`. Está integrada en el paquete principal.

<YouTubeEmbed url="https://www.youtube.com/embed/YBp_PXBbe80" label="Recorrido por la app de escritorio de Hermes Agent" />

Sigue de cerca las releases de Hermes, así que siempre tienes las últimas funciones. La documentación está en [hermes-agent.nousresearch.com/docs/user-guide/desktop](https://hermes-agent.nousresearch.com/docs/user-guide/desktop).

**Ideal para:** usuarios que quieren la experiencia de escritorio oficial, mantenida por Nous Research.

### Hermes One de fathah

<Button text="Repositorio en GitHub" link="https://github.com/fathah/hermes-desktop" variant="solid" color="blue" size="md" />

La app de escritorio comunitaria más popular, con 13,3K estrellas, licencia MIT, funciona en Windows, macOS y Linux. Repo: `fathah/hermes-desktop`. Sitio del producto: [hermesone.org](https://hermesone.org/). No afiliada a Nous Research.

<Notice type="info" title="Sin afiliación con Nous Research">
Hermes One está mantenida por la comunidad. Usa el script oficial de instalación de Hermes internamente, pero es un desarrollo independiente de fathah.
</Notice>

<ListCheck>
<ul>
<li>Instalación guiada en el primer arranque con seguimiento del progreso</li>
<li>Soporte de backend local o remoto (URL de API + API key)</li>
<li>Chat con streaming vía SSE con progreso de herramientas y renderizado markdown</li>
<li>Seguimiento de uso de tokens con estimaciones de coste en vivo</li>
<li>22 comandos slash para acciones rápidas</li>
<li>Gestión de sesiones con búsqueda de texto completo FTS5</li>
<li>14 conjuntos de herramientas con cambio de perfil</li>
<li>Editor del sistema de memoria y editor de persona (SOUL.md)</li>

<li>Copia de seguridad/importación/volcado de depuración</li>
<li>Proveedor de secretos (KeePassXC, 1Password, Bitwarden, GnuPG, pass)</li>
<li>Autoactualización vía electron-updater</li>
<li>Soporta proveedores locales: LM Studio, Ollama, vLLM, llama.cpp</li>
</ul>
</ListCheck>

**Ideal para:** usuarios de escritorio multiplataforma que quieren la experiencia de escritorio independiente más completa con soporte de modelos locales.

### Hermes Studio de escritorio (Electron)

Hermes Studio también se distribuye como app de escritorio Electron. Guarda los datos de Hermes Agent en la ubicación nativa (`~/.hermes`) y proporciona shims de comandos gestionados: `hermes-studio cli`, `hermes-studio web` y `hermes-studio-mcp`.

La autoactualización funciona a través de endpoints de descarga de Cloudflare con GitHub como respaldo. Consulta [Hermes Studio de EKKOLearnAI](#hermes-studio-de-ekkolearnai) para la lista completa de funciones. La versión de escritorio tiene las mismas capacidades que el panel web.

**Ideal para:** usuarios que quieren el conjunto de funciones de Hermes Studio en una ventana de escritorio independiente.

## Mejores apps móviles de Hermes Agent para Android

La apertura de Android la convierte en la plataforma móvil más rica para Hermes. Hay dos tipos de apps: runtimes completos de Hermes que ejecutan el agente directamente en el dispositivo, y clientes ligeros que se conectan a una instancia remota de Hermes a través de la red.

### Hermes Agent Android (Google Play)

De Hen Works. [Ficha de Google Play](https://play.google.com/store/apps/details?id=com.hermesagent.android): 4,5 estrellas con 1,98K reseñas y más de 10K descargas. Gratuita con una compra dentro de la app (Hermes Pro) para eliminar los anuncios.

<Notice type="info" title="Runtime completo, no un cliente">
Esta app ejecuta el Hermes Agent completo en tu dispositivo Android. No se conecta a un servidor: ES el servidor. Necesitas tu propia API key y unos 200 MB de almacenamiento para la configuración inicial.
</Notice>

**Qué hace:**

- Soporte multimodelo: OpenAI, Anthropic, Google, OpenRouter, LiteRT para modelos locales
- Terminal Linux integrada (bash, Python, git)
- Ejecución de código directamente en el dispositivo
- Gateway multiplataforma (Telegram, Slack, Discord)
- Búsqueda web y extracción de páginas
- Generación de imágenes con IA vía Fal.ai
- Texto a voz vía Edge TTS
- Sistema de memoria entre conversaciones
- Gestión de sesiones con reanudación
- Panel web para monitorización
- Opción Chat Skin (Labs): interfaz de terminal o burbujas de chat con tarjetas de herramientas y adjuntos de fotos

**Ideal para:** usuarios de Android que quieren la experiencia completa de Hermes sin un servidor aparte.

### Hermes Android Client de rusty4444

<Button text="Repositorio en GitHub" link="https://github.com/rusty4444/hermes-android" variant="solid" color="blue" size="md" />

Un cliente ligero en Flutter/Dart (88 estrellas, MIT, v1.0.10+) que se conecta a una instancia remota de Hermes vía la Gateway API (puerto 8642) y la API del panel (puerto 9119). Descarga los APK desde [GitHub Releases](https://github.com/rusty4444/hermes-android/releases).

```
Android app (Flutter)
├─ Gateway API Server, port 8642
│  ├─ GET /api/sessions
│  ├─ GET /api/sessions/{id}/messages
│  └─ POST /v1/chat/completions (SSE streaming)
└─ Hermes dashboard, port 9119
   ├─ /api/memory
   ├─ /api/cron/jobs
   ├─ /api/skills
   └─ /api/model/*
```

Las funciones incluyen chat de voz (dictado por micrófono + respuestas TTS), respuestas SSE en streaming, selector de tema (Oscuro/Claro/Sistema), gestión completa de cron (CRUD), explorador de skills, visor de memoria, soporte de Tailscale para acceso remoto y conexiones HTTPS.

También gestiona paneles protegidos con contraseña (flujo de login basic-auth) y prefijos de ruta de proxy inverso.

**Ideal para:** usuarios que ya tienen Hermes ejecutándose en un servidor o escritorio y quieren un cliente Android ligero.

### Tareas de larga duración y notificaciones push

No existe una app independiente de «Hermes Dispatch» ampliamente adoptada con una vía de instalación pública comparable a los paneles principales de arriba. Para trabajo en segundo plano y notificaciones al teléfono, usa en su lugar el stack oficial:

- **Hermes Kanban / subagentes asíncronos** en el servidor para trabajos de larga duración que sobreviven a las desconexiones del teléfono (ver la [guía de configuración de Hermes Kanban](/es/guia-kanban-hermes/))
- **ntfy** como canal de mensajería de Hermes para alertas push en Android/iOS ([documentación oficial de ntfy](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/ntfy))
- **Gateway de Telegram / Discord** para mensajes de tareas de tipo «envía y olvida» sin instalar otro cliente

Si necesitas que el agente controle un dispositivo Android (control remoto estilo ADB), mira proyectos puente de la comunidad como [raulvidis/hermes-android](https://github.com/raulvidis/hermes-android). Es un puente de control de dispositivos, no un panel de chat.

**Ideal para:** trabajos largos en el servidor con alertas al teléfono, sin depender de un producto de nicho solo para móvil.

## Mejores apps móviles de Hermes Agent para iOS

<Notice type="warning" title="Limitación de iOS">
El sandboxing de iOS impide ejecutar Hermes Agent directamente en un iPhone o iPad. Todas las apps de iOS son clientes que se conectan a una instancia remota de Hermes vía SSH o API. Primero necesitas Hermes ejecutándose en otro lugar. Si necesitas una API key gratuita para empezar, mira cómo configurar [Hermes Agent con modelos gratuitos en Nous Portal](/es/hermes-agent-mimo-v2-pro/).
</Notice>

### ScarfGo

**Ideal para:** usuarios que ya ejecutan Scarf en macOS y quieren la misma experiencia en iPhone. La app de macOS y el compañero de iOS están diseñados para funcionar juntos.

### Onepilot

Una app nativa de iOS en la App Store (freemium): [Onepilot: AI agents & SSH](https://apps.apple.com/am/app/onepilot-ai-agents-ssh/id6759485908). Compatible con iPhone y iPad. Documentación: [onepilotapp.com/agents/hermes](https://onepilotapp.com/agents/hermes). Es lo más parecido a una cabina de desarrollo completa en iOS.

Como dicen los desarrolladores: «no existe una app oficial de Hermes». Onepilot se posiciona como la mejor alternativa. El túnel SSH te da acceso completo al host (archivos, shell, git), así que puedes hacer más que chatear con el agente.

**Ideal para:** usuarios de iOS que quieren un entorno de desarrollo completo en su teléfono o tablet, no solo una interfaz de chat.

## Acceso móvil vía canales de mensajería

La forma más sencilla de tener Hermes en tu teléfono: usar el gateway de mensajería integrado. Sin apps extra que instalar; solo chatea con tu agente a través de Telegram, Discord, WhatsApp, Signal o Slack.

<Notice type="info" title="El camino más rápido al acceso móvil">
Telegram es la forma más rápida de tener Hermes en tu teléfono. La configuración lleva menos de 5 minutos y obtienes sincronización entre dispositivos, notas de voz y la misma app de chat que probablemente ya tienes abierta.
</Notice>

| Canal | Configuración | Ventajas | Desventajas |
|---|---|---|---|
| Telegram | Baja | El camino más rápido, notas de voz, sincronización entre dispositivos | Vista de una sola sesión, retardo en la cola de mensajes |
| Discord | Baja | Reacciones, hilos, un canal por tema | Más configuración que Telegram |
| WhatsApp | Media | Todo el mundo lo tiene | Requiere número de teléfono y emparejamiento |
| Signal | Media | Centrada en la privacidad | Menos funciones |
| Slack | Media | Amigable para equipos, canales | Requiere workspace |

La configuración es sencilla:

```bash
# Configure the messaging gateway
hermes gateway setup
# Follow prompts for your platform (e.g., Telegram bot token)

# Start the gateway
hermes gateway start
```

**Limitaciones de Telegram** que conviene conocer (según el feedback de la comunidad): solo tienes una vista de sesión única, hay retardo en la cola de mensajes, no se muestra el conteo de tokens ni la información del modelo, y los reinicios de la ventana de contexto no se comunican. Para uso casual está genial. Para trabajo de desarrollo intensivo, usa un panel o una app de escritorio en condiciones.

## Consideraciones de seguridad para el acceso remoto

Cualquier panel o app móvil expuesta a la red necesita seguridad adecuada. Esto no es negociable: un panel de Hermes sin autenticación da a cualquiera control total sobre tu agente, tus API keys y potencialmente tu servidor.

<Notice type="error" title="Nunca expongas sin autenticación">
Ejecutar `hermes dashboard --host 0.0.0.0` sin habilitar la autenticación es una puerta trasera abierta. Acompaña siempre los paneles expuestos al público con autenticación y HTTPS.
</Notice>

### Túneles SSH (lo más fácil)

El enfoque seguro más simple es tunelizar el puerto del panel a través de SSH:

```bash
# Tunnel WebUI (port 8787)
ssh -N -L 8787:127.0.0.1:8787 user@your-server

# Tunnel Official Dashboard (port 9119)
ssh -L 9119:localhost:9119 user@your-vps

# Then open http://localhost:8787 or http://localhost:9119 locally
```

### Tailscale (lo más seguro para uso habitual)

Instala Tailscale en tu servidor y en tu teléfono/portátil. Accede al panel vía la IP de Tailscale. Ningún puerto expuesto a internet público. Hermes Android Client tiene soporte de Tailscale integrado.

### Protección con contraseña

```bash
# Password protect the official dashboard
cat >> ~/.hermes/.env <<'EOF'
HERMES_DASHBOARD_BASIC_AUTH_USERNAME=admin
HERMES_DASHBOARD_BASIC_AUTH_PASSWORD=your-strong-password
HERMES_DASHBOARD_BASIC_AUTH_SECRET=$(openssl rand -base64 32)
EOF
chmod 600 ~/.hermes/.env
hermes dashboard --host 0.0.0.0 --no-open
```

### Soporte de autenticación por panel

| Panel | Contraseña | OIDC | WebAuthn/Passkeys |
|---|---|---|---|
| Panel oficial | Sí | Sí (autoalojado) | No |
| Hermes WebUI | Sí | Sí | Sí |
| Hermes Studio | Sí | No | No |
| Hermes Workspace | Sí | Varía según el despliegue | No |
| Hermes Control Interface | Sí (bcrypt + RBAC) | No | No |
| Scarf | Llavero de macOS | No | No |

Para la configuración de seguridad completa, incluida la configuración del proxy inverso Caddy y la red de Docker, consulta nuestra [guía de configuración del panel de Hermes Agent](/es/guia-panel-hermes/).

## Preguntas frecuentes

<Accordion label="¿Existe una app móvil oficial de Hermes Agent?" group="faq" expanded="true">
No. Nous Research no tiene una app móvil oficial. Todo el ecosistema móvil está construido por la comunidad. Los canales oficiales son el CLI, el panel web (`hermes dashboard`) y la app de escritorio (`hermes desktop`). Todas las apps de Android e iOS listadas en esta guía son proyectos de terceros.
</Accordion>

<Accordion label="¿Puedo ejecutar Hermes Agent en mi teléfono?" group="faq">
En Android, sí. Hermes Agent Android (Google Play) ejecuta el runtime completo de Hermes directamente en el dispositivo. Necesitas tu propia API key y unos 200 MB de almacenamiento. En iOS, no. El sandboxing de iOS impide ejecutar Hermes directamente. Todas las apps de iOS se conectan a una instancia remota de Hermes vía SSH o API.
</Accordion>

<Accordion label="¿Cuál es el mejor panel gratuito de Hermes?" group="faq">
El panel oficial integrado (`hermes dashboard`) y Hermes WebUI de nesquena son gratuitos y excelentes. El panel oficial es el más sencillo de configurar, ya que viene incluido con Hermes. Hermes WebUI es más ligero en recursos (sin paso de compilación, sin framework) y tiene mejor respuesta en móvil. Si además necesitas una API key gratuita, mira cómo configurar [Hermes Agent con modelos gratuitos en Nous Portal](/es/hermes-agent-mimo-v2-pro/).
</Accordion>

<Accordion label="¿Cómo accedo a mi panel de Hermes de forma remota?" group="faq">
Tres opciones, de la más fácil a la más compleja: (1) Túnel SSH: `ssh -L 9119:localhost:9119 user@your-vps` y luego abre localhost:9119. (2) Tailscale: instálalo en ambos dispositivos y accede vía la IP de Tailscale. (3) Proxy inverso con autenticación: Caddy o Nginx con HTTPS y basic auth u OIDC. Nunca expongas un panel públicamente sin autenticación.
</Accordion>

<Accordion label="¿Qué panel de Hermes usa menos recursos?" group="faq">
Hermes WebUI de nesquena. Usa el servidor HTTP de la biblioteca estándar de Python y JavaScript puro, sin Node.js, sin bundler y sin framework. El arranque es rápido y el uso de memoria es mínimo comparado con las alternativas basadas en React/Vue.
</Accordion>

<Accordion label="¿Puedo usar varios paneles al mismo tiempo?" group="faq">
Sí. Los paneles son aplicaciones web independientes que se ejecutan en puertos diferentes. Puedes ejecutar el panel oficial en el puerto 9119, Hermes WebUI en 8787, Hermes Studio en 8648, Hermes Workspace en 3000 y HCI en 10274 simultáneamente. Todos leen del mismo directorio de datos de Hermes, así que las sesiones, la configuración y los perfiles se comparten.
</Accordion>

<Accordion label="¿Es un problema la licencia BSL-1.1 de Hermes Studio?" group="faq">
Para uso personal, no. Para uso comercial, revisa los términos de la licencia. BSL-1.1 (Business Source License) suele restringir el uso comercial durante un periodo determinado (a menudo de 2 a 4 años), tras el cual se convierte a MIT. Si necesitas un panel con licencia MIT completa para uso comercial, elige el panel oficial o Hermes WebUI.
</Accordion>

## Conclusión

No hay una única «mejor» interfaz de Hermes Agent. La elección correcta depende de tu dispositivo, tu flujo de trabajo y cuánto control necesitas. Aquí va la versión corta:

<ListCheck>
<ul>
<li>El panel oficial es el punto de partida más seguro: gratuito, integrado, bien mantenido</li>
<li>Hermes WebUI es la opción web más ligera con excelente respuesta en móvil (16K estrellas)</li>
<li>Hermes Studio concentra más funciones, incluidos el chat grupal y las salas multi-agente (9,1K)</li>
<li>Hermes Workspace es el mejor workspace completo (terminal + archivos + Conductor/Swarm, 6,1K)</li>
<li>Hermes Control Interface es la elección cuando importan más RBAC y una administración endurecida</li>
<li>Para macOS, Scarf es la experiencia nativa pulida; Hermes One gana en escritorio multiplataforma</li>
<li>Para Android, Hermes Agent Android te da el runtime completo en el dispositivo; el cliente de rusty4444 es lo mejor para servidores remotos</li>
<li>Para iOS, Onepilot es la cabina de desarrollo más capaz; ScarfGo y Hermes Mobile son clientes de chat más ligeros</li>
<li>El gateway de Telegram es el camino más rápido al acceso móvil, sin necesidad de ninguna app extra</li>
<li>La seguridad no es opcional: usa siempre autenticación, túneles SSH o Tailscale para el acceso remoto</li>
</ul>
</ListCheck>

Elige una opción, configúrala e itera. La mayoría de estas herramientas son gratuitas o tienen niveles gratuitos, así que experimentar no cuesta nada.

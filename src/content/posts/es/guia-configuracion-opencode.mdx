## Qué es OpenCode realmente

OpenCode es un agente de programación en terminal open source y agnóstico de proveedor. Lee tu código, planifica cambios, edita archivos, ejecuta comandos e itera ante errores igual que Claude Code, pero conectado a más de 300 proveedores mediante el catálogo de [models.dev](https://models.dev): Anthropic, OpenAI, Google, Alibaba, MiniMax, DeepSeek, Xiaomi, Moonshot y modelos locales en Ollama.

La diferencia práctica frente a Claude Code es la libertad de modelo: usa DeepSeek V4.1 Flash a $0,15/M de entrada para trabajo diario, sube a GLM-5.3 para refactors complejos y controla el presupuesto en cada tarea. La línea v2 también incluye una app de escritorio en beta y una interfaz web puntual con `opencode pair`.

## Instalar OpenCode v2 en un VPS

### Requisitos previos

<ListCheck>
<ul>
<li>Un VPS Linux con 1 GB+ de RAM (el cliente es ligero; el modelo corre en la API)</li>
<li><code>curl</code> instalado (no hace falta Node.js para el instalador oficial ni binarios standalone)</li>
<li>Una clave API de proveedor o suscripción a OpenCode Go</li>
<li>Un terminal moderno (opcional para arrastrar capturas, como <a href="/es/instalar-wezterm-mac/">WezTerm</a>)</li>
</ul>
</ListCheck>

Si aún necesitas preparar el servidor, empieza por la [configuración segura de VPS para agentes IA](/es/vps-configuracion-codificacion-ia/).

### Instalar con el script de v2

<Notice type="warning" title="El instalador antiguo ahora instala OpenCode v1">
`https://opencode.ai/install` apunta a la rama heredada v1. El comando de v2 usa `/v2/install`. Ambas líneas instalan el binario `opencode` y **no pueden convivir**: elimina antes `opencode-ai` si tenías v1.

| Línea | Comando de instalación | Paquete npm |
|---|---|---|
| **v2 (actual)** | `curl -fsSL https://opencode.ai/v2/install \| bash` | `@opencode/cli` |
| v1 (heredado) | `curl -fsSL https://opencode.ai/install \| bash` | `opencode-ai` |
</Notice>

```bash
curl -fsSL https://opencode.ai/v2/install | bash
opencode --version
```

La salida esperada es `2.x` (`2.3.2` a noviembre de 2026). Si ves `1.x`, elimina el binario anterior (`npm rm -g opencode-ai`) y repite con la URL de v2.

La configuración vive en `~/.config/opencode/opencode.json` (o `.opencode.jsonc`) y el binario en `~/.opencode/bin/opencode`. Para desinstalarlo por completo, ejecuta `opencode uninstall`.

## Configurar proveedores de modelos y Ollama local

En v2 el método oficial es ejecutar `/connect` dentro de la TUI o declarar proveedores en `opencode.jsonc` con `{env:VAR}`. No te fíes del antiguo archivo `~/.config/opencode/.env` de v1, que no está documentado en v2.

- **OpenCode Console (antes Zen):** crea una clave en [opencode.ai/console](https://opencode.ai/console/login), ejecuta `/connect` y elige `opencode`. Incluye modelos gratuitos (ocúltalos con `OPENCODE_DISABLE_FREE_MODELS=1`).
- **OpenRouter:** acceso a 300+ modelos con una sola clave vía `/connect` o `opencode.jsonc`:

```jsonc
// opencode.jsonc (raíz del proyecto o ~/.config/opencode/)
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/deepseek/deepseek-v4.1-flash",
  "providers": {
    "openrouter": {
      "settings": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

- **Claves directas y ChatGPT:** exporta `MINIMAX_API_KEY` ([MiniMax](https://go.bitdoze.com/minimax)), `ZAI_API_KEY` ([Z.AI / GLM](https://go.bitdoze.com/glm)), `MIMO_API_KEY` ([Xiaomi MiMo](https://go.bitdoze.com/mimo)), `DEEPSEEK_API_KEY` o `MOONSHOT_API_KEY`, o inicia sesión con **Sign in with ChatGPT** en planes Plus/Pro.
- **Ollama local (autodetección en v2):** OpenCode consulta `http://127.0.0.1:11434` y añade tus modelos a `/models` sin configuración extra. Sigue la [guía de Ollama en Docker](/es/ollama-docker-instalacion/) si lo montas en servidor.

## Flujo diario, MCP y ejecución en VPS

- **`AGENTS.md`:** crea un `AGENTS.md` en la raíz del proyecto con convenciones y estructura (en v1 lo generaba `/init`; en v2 es mejor mantenerlo directamente en git).
- **Plan vs Build:** alterna con `Shift+Tab` (o `Tab` / `Ctrl+X, A` / `/agents`). Revisa siempre el plan antes de dejar al agente editar archivos.
- **Atajos diarios:** `@archivo#20-45` para señalar rangos, `/undo` y `/redo`, `!comando` para modo shell, `/btw` para preguntas paralelas sin interrumpir la tarea, `F2` para cambiar modelo y `@general` para el subagente en segundo plano.
- **Memoria persistente y herramientas MCP:** añade [Hindsight](/es/desplegar-hindsight-docker/) o [Composio MCP](/es/guia-composio-mcp/) en la sección `"mcp"` de `opencode.jsonc`.
- **En un VPS con SSH:** ejecútalo dentro de [tmux](/es/tmux-comandos-basicos/) o uno de los [mejores multiplexores de terminal](/es/mejores-multiplexores-terminal/) en un [VPS Hetzner Cloud](https://go.bitdoze.com/hetzner) de $6/mes. Recuerda que v2 usa un servicio compartido por usuario (`opencode service restart` o `opencode --standalone` para aislar una sesión), `opencode run --model ... "..."` sirve para cron/CI y `opencode pair` abre una interfaz web temporal con enlace de 5 minutos.

## Resolución de problemas y FAQ

| Problema | Causa | Solución |
|---|---|---|
| `opencode: command not found` | PATH sin recargar | Ejecuta `source ~/.bashrc` o abre nueva sesión SSH |
| `opencode --version` muestra `1.x` | Instalador v1 o paquete antiguo | `npm rm -g opencode-ai` y reinstala con `/v2/install` |
| No carga la clave API | Hábito `.env` de v1 | Usa `/connect` o `{env:VAR}` en `opencode.jsonc` |
| Falta modelo en `/models` | Ollama apagado o modelos gratis ocultos | Inicia Ollama o revisa `OPENCODE_DISABLE_FREE_MODELS` |
| Servicio compartido colgado | Conflicto del daemon | `opencode service restart` o `opencode --standalone` |

GitHub Copilot Pro sigue costando **$10 al mes**, y sigue siendo la forma más barata que conozco de conseguir un agente de código con modelo frontera, completado en línea, una CLI y soporte para Zed en una sola suscripción. Lo que cambió es lo que esos $10 te compran.

El 1 de junio de 2026, GitHub reemplazó las unidades de solicitudes premium por **GitHub AI Credits**, que se consumen según el uso real de tokens. El completado sigue siendo gratis. Las sesiones de chat y de agente ahora gastan un saldo que se agota. Ese único cambio convierte la historia de «IA ilimitada por diez dólares» en una cuestión operativa: ¿cómo evitas que una sesión de agente se coma tu mes?

<Notice type="warning" title="Qué cambió desde la primera versión de esta guía">

**El modelo antiguo:** 300 solicitudes premium al mes, coste fijo por modelo y cambio automático a un modelo más barato cuando se agotaban.

**El modelo de 2026:**

- Pro sigue costando **$10 al mes**, pero ahora obtienes **1.500 AI Credits** por ciclo — 1.000 base más una asignación flexible de 500 (1 crédito = $0,01 de uso medido)
- Los créditos se consumen a las **tarifas por token publicadas de la API** para el modelo que elijas
- **Sin fallback.** Cuando el saldo llega a cero, el chat y el trabajo del agente se detienen hasta que compres más o se reinicie el ciclo
- **El completado y las sugerencias de Next Edit siguen incluidos** en todos los planes y consumen cero créditos
- **Copilot Max a $100 al mes** existe para quienes ejecutan sesiones de agente largas

</Notice>

Si quieres el desglose completo del cambio de facturación en sí, escribí un artículo aparte sobre [los precios de Copilot basados en uso y cinco alternativas más baratas](/es/alternativas-github-copilot-2026/). ## Cuánto cuesta Copilot Pro en 2026

Los precios de los planes no se movieron. Las asignaciones de créditos sí.

| Plan | Precio | Qué obtienes |
|------|-------|--------------|
| Copilot Free | $0 | 2.000 completados/mes, acceso limitado a chat y agente, disponible para todos |
| **Copilot Pro** | **$10/mes** | 1.500 AI Credits (1.000 base + 500 flexibles), completados ilimitados, CLI, modo agente |
| Copilot Pro+ | $39/mes | 7.000 AI Credits (3.900 base + 3.100 flexibles), todo lo de Pro |
| Copilot Max | $100/mes | 20.000 AI Credits, pensado para ejecuciones de agente largas |
| Copilot Business | $19/usuario/mes | Mismas herramientas, sin entrenamiento con tu código |
| Copilot Enterprise | $39/usuario/mes | Controles de Business más políticas empresariales |

Dos detalles que conviene saber antes de pagar:

- **La revisión de código consume minutos de GitHub Actions además de AI Credits.** Si activas la revisión de Copilot en cada PR de un repo con mucho movimiento, pagas dos veces: una en créditos y otra en minutos de CI.
- **Los titulares de planes anuales siguen en el sistema antiguo de solicitudes premium hasta que el plan expire**, pero los multiplicadores de modelo subieron el 1 de junio. Cuando termina el plazo anual, caes a Copilot Free y tienes que elegir un plan mensual.

GitHub también tuvo una promoción de transición de junio a agosto de 2026 que elevó Business a $30 en créditos y Enterprise a $70. Esa ventana ya cerró, así que esos planes volvieron a sus cantidades estándar.

### Qué es lo que realmente gasta los $10

El gasto de créditos es gasto de tokens. Este es el orden de magnitud, usando las tarifas publicadas como base:

| Tarea | Clase de modelo | Coste aproximado en créditos |
|------|-------------|-------------------|
| Completado en línea | modelo pequeño/rápido | $0,00 (incluido) |
| Pregunta de chat sobre un archivo | modelo medio | ~$0,02 |
| Refactorización multiarchivo | modelo frontera | ~$0,50 |
| Sesión de agente, ~1 hora | modelo frontera | ~$5 a $8 |
| Sesión de agente, ~4 horas | modelo frontera | ~$25 a $40 |

Lee esa última fila dos veces. **Una sola sesión larga de agente con un modelo frontera cuesta más que todo el plan Pro.** Dos o tres de esas al mes y estarás comprando créditos extra o cambiando a un modelo más barato.

GitHub cambia la lista de modelos con frecuencia, y cada modelo tiene su propia tarifa en la [página de modelos y precios de Copilot](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing). Consulta esa página antes de lanzar una ejecución de agente de varias horas, no después.

### Mis ajustes para mantenerme en $10

<Notice type="success" title="Mantén el plan predecible">

**El completado se queda en un modelo pequeño.** No cambies tu modelo de completado a uno frontera. Ganas poco y pagas por cada solicitud de ese tipo.

**Enruta según la tarea.** Modelo pequeño para refactorizaciones y código repetitivo; modelo frontera para las dos o tres cosas realmente difíciles de esa semana.

**Limita las sesiones de agente a un ticket.** Un prompt vago («limpia la base de código») es cómo una sesión de $5 se convierte en una de $30.

**Escribe el archivo de instrucciones.** Un archivo de instrucciones a nivel de repo evita que el agente vuelva a deducir tus comandos de build, test y lint en cada sesión.

**Activa las alertas de presupuesto.** Copilot admite alertas al 75/90/100 % de tus créditos. Activa las tres en la configuración de facturación de Copilot.

</Notice>

El archivo de instrucciones es lo más valioso de esa lista. Pon esto en la raíz del repo como `.github/copilot-instructions.md`:

```markdown
# Project instructions

- Package manager: pnpm. Never run npm install.
- Build: pnpm build
- Test: pnpm test --run
- Lint: pnpm lint
- Type check: pnpm typecheck
- Framework: Astro 7 + Tailwind 4. Do not add new dependencies without asking.
- Never edit files under dist/ or .astro/.
- Migrations live in db/migrations. Do not write ad-hoc SQL against the dev database.
```

VS Code también lee un `AGENTS.md` plano si prefieres un solo archivo que cualquier agente pueda usar. En cualquier caso, el punto es el mismo: menos conjeturas erróneas significan menos idas y vueltas, es decir, menos tokens.

## Zed + Copilot: la configuración rápida

Zed es el editor al que recurso cuando quiero que el completado aparezca al instante y la interfaz no me estorbe. Está escrito en Rust, no es Electron, y la integración de Copilot vive en el panel del agente junto a sus propias funciones de IA.

Configuración, en orden:

1. Instala Zed (`brew install --cask zed` en macOS)
2. Abre el panel del agente y elige **GitHub Copilot** como proveedor
3. Inicia sesión con GitHub cuando te lo pida
4. Elige tu modelo en el selector del panel

**Verifica:** con un archivo abierto, escribe la firma de una función y haz una pausa. El texto fantasma debería aparecer en uno o dos segundos. Si no aparece nada, comprueba primero que tu plan de Copilot está activo en el lado de GitHub. Una suscripción caducada o vencida se ve exactamente igual que un editor roto.

Atajos de teclado que vale la pena memorizar:

- `Tab` - aceptar una sugerencia
- `Alt + ]` / `Alt + [` - ir a la sugerencia siguiente o anterior
- `Cmd/Ctrl + Shift + P` → «agent» abre el panel del agente
- `Cmd/Ctrl + Enter` - enviar el prompt en el panel

### No pagues por IA dos veces en Zed

Esto confunde a mucha gente. Zed tiene su propia suscripción, **Zed AI, a $10 al mes** (predicciones de edición ilimitadas más una pequeña asignación de tokens, con facturación por uso a partir de ahí) y **Business a $30 por puesto**. Si tu suscripción a Copilot Pro ya cubre el trabajo con agente, no necesitas Zed AI para la vía de Copilot. Elige una.

Mi opción por defecto: Copilot Pro para el agente de código y la CLI, y omitir Zed AI a menos que quieras específicamente el enrutado de modelos propio de Zed y sus funciones de predicción de edición. Dos suscripciones de $10 que hacen el mismo trabajo son $240 al año de solapamiento.

Zed también habla el Agent Client Protocol, que te permite ejecutar agentes externos como Claude Code o una CLI basada en Gemini como agentes del panel. Eso es otra configuración y otra factura. Consulta [usar las suscripciones de Claude, Codex y Gemini con cualquier editor](/es/guia-vibeproxy-suscripciones-ia/) si vas por esa ruta.

## Copilot CLI

La nueva Copilot CLI es un agente, no un buzón de sugerencias. Lee archivos, ejecuta comandos y hace cambios en tu árbol de trabajo.

```bash
# Install (Node 20+)
npm install -g @github/copilot

# Interactive session
copilot

# Non-interactive, good for scripts and CI
copilot -p "find every place we call the legacy billing API and list the files"
```

En el día a día, esto es para lo que la uso:

```bash
# Scoped changes on a branch
git switch -c fix/rotation-lock
copilot -p "the secret rotation job double-fires when the lock expires; add a guard and a test"

# Repo-shaped questions before I touch anything
copilot -p "which services read from the legacy queue directly, and where are the consumers?"

# Commit and PR plumbing
copilot -p "stage the changes in src/, write a conventional commit, push the branch"
```

También está la extensión antigua de `gh`, que solo hace sugerencias y explicaciones de una línea y no toca tus archivos:

```bash
gh extension install github/gh-copilot
gh copilot suggest -t shell "find files larger than 100MB"
gh copilot explain "find . -name '*.log' -mtime +7 -delete"
```

**Verifica:** ejecuta `copilot -p "print the current git branch name"`. Debería responder con la rama real. Si se cuelga o da error de autenticación, ejecuta `copilot` en modo interactivo y usa `/login`.

**Fallos con los que me topé primero:**

- **`command not found` después de instalar** - el directorio bin global de npm no está en tu `PATH`. Comprueba `npm bin -g` y añádelo.
- **Versión de Node demasiado antigua** - la CLI necesita Node 20 o superior. `node -v` primero, no último.
- **El agente edita el repo equivocado** - inicia `copilot` desde la raíz del repo, no desde tu directorio home. El directorio de trabajo es el mundo del agente.

## Agentes de código y revisión de código

Dos funciones separadas, fáciles de confundir:

**Agente en la nube.** Asigna un issue de GitHub a `@copilot`. Levanta un sandbox, trabaja el issue y abre un pull request. Revisas el PR como el de cualquier otro colaborador. Un issue, un PR, créditos facturados por los tokens que consume la ejecución.

**Revisión de código.** Pídele a Copilot que revise un PR abierto. Útil para una primera pasada en un diff grande. Recuerda que también consume minutos de Actions, así que no es gratis ni con cero créditos.

Guardarraíles que mantienen esto bajo control:

<ListCheck>

- Un issue por ejecución. No le entregues una épica al agente.
- Exige una suite de tests en verde en el PR antes de mirarlo.
- Lee el diff. El agente se muestra seguro tanto si acierta como si no.
- Mantén los secretos fuera de su alcance. Un token con alcance limitado y cero credenciales de producción vale más que un prompt ingenioso.

</ListCheck>

<Notice type="info" title="No construyas tu propia infraestructura de agentes">

El patrón de infraestructura de agente independiente (conectar tus propios runners en GitHub Actions para llamar a la API del agente) no merece la complejidad. Acabas manteniendo lógica de disparo, un runner y gestión de secretos para un trabajo que el agente en la nube integrado ya hace.

Mi opción por defecto: usa el agente en la nube integrado para el trabajo de issue a PR, la CLI para cambios locales multiarchivo y omite por completo la opción casera. Mismo resultado, sin fontanería adicional que mantener parcheada.

</Notice>

## Modelos: a cuál recurrir

Copilot es multimodelo. La lista rota, pero la forma del coste es estable:

| Clase de modelo | Ejemplos | Consumo relativo | Uso |
|-------------|----------|---------------|---------|
| Pequeño / rápido | modelos GPT de clase mini | céntimos por sesión | Completado, ediciones pequeñas, mensajes de commit |
| Medio | Claude de clase Sonnet, Gemini actual | dólares por sesión larga | La mayoría de refactorizaciones, escritura de tests, pasadas de revisión |
| Frontera | Claude de clase Opus | varios dólares por hora de trabajo de agente | Arquitectura, depuración espinosas, problemas difíciles puntuales |

La regla que uso: **empieza cada sesión en un modelo medio o pequeño, y escala solo cuando el modelo medio fracase visiblemente dos veces.** Escalar pronto se siente productivo y cuesta mucho más por el mismo diff.

**Nota de privacidad:** Copilot Free, Pro y Pro+ entrenan con tus interacciones por defecto. Business y Enterprise no. Si estás en Pro y trabajas con código de cliente, abre Settings → Copilot y desactiva la opción de compartir datos. Es un solo interruptor y viene en el lado equivocado por defecto para mucha gente.

## Modos de fallo y trampas habituales

<Accordion label="Los créditos se agotan a mitad de tarea" group="troubleshooting" expanded="true">

El chat y el trabajo del agente se detienen hasta que compres créditos o se reinicie el ciclo. El completado sigue funcionando, lo que hace fácil pasar por alto el fallo real: un agente que se ha detenido a mitad de una refactorización mientras las sugerencias en línea siguen fluyendo.

**Solución:** activa las alertas de presupuesto al 75/90/100 % y revisa el medidor de uso en el resumen de facturación antes de empezar una ejecución larga.

</Accordion>

<Accordion label="El modelo que quiero no aparece" group="troubleshooting">

La elección de modelo está detrás de un interruptor en la configuración para los nuevos lanzamientos, y algunos planes van con retraso en los modelos frontera más recientes.

**Solución:** activa la elección de modelo en https://github.com/settings/copilot/features y luego reinicia el editor. Si sigue sin aparecer, el modelo no está disponible en tu nivel de plan.

</Accordion>

<Accordion label="El agente rompió código que funcionaba" group="troubleshooting">

Este es el riesgo real del trabajo con agentes, no la factura. Las ejecuciones largas tocan archivos que no tenían nada que ver con el ticket.

**Solución:** trabaja en una rama, exige que los tests pasen antes de revisar y mantén el ticket acotado. Un `copilot-instructions.md` que diga «nunca toques archivos bajo db/migrations» previene toda una clase de incidentes.

</Accordion>

<Accordion label="Errores de autenticación tras un cambio de token" group="troubleshooting">

Rotar tu contraseña de GitHub, activar SSO en una organización o una sesión de editor largamente inactiva rompen la autenticación de una forma que parece una instalación rota.

**Solución:** cierra sesión y vuelve a entrar desde el editor, y vuelve a ejecutar `/login` en la CLI. No empieces a reinstalar extensiones.

</Accordion>

## Deshacer y limpiar

Nada de esto te ata. Para revertir:

1. **Cancela o baja de plan:** Settings → Billing → Copilot. Los planes anuales tienen que agotarse; el mensual se puede cancelar de inmediato y caes a Free.
2. **Detén el gasto de créditos:** elimina cualquier método de pago guardado para créditos extra, para que un agente desbocado no pueda recargarse solo.
3. **Elimina la CLI:** `npm uninstall -g @github/copilot`
4. **Elimina la extensión:** `code --uninstall-extension GitHub.copilot` y `GitHub.copilot-chat`
5. **Limpia la configuración del repo:** borra `.github/copilot-instructions.md` si otras herramientas lo leen ahora y se confunden con las reglas específicas de Copilot.

Conserva tu `AGENTS.md` si escribiste uno. Es agnóstico de herramientas y funciona con lo que uses para reemplazar Copilot.

## Preguntas frecuentes

<Accordion label="¿Desaparecieron las solicitudes premium para siempre?" group="faq" expanded="true">

Sí, para los planes mensuales. Desde el 1 de junio de 2026, Copilot usa GitHub AI Credits en lugar de unidades de solicitudes premium. Los créditos se consumen por token a las tarifas publicadas de cada modelo. Los titulares de planes anuales mantienen el sistema antiguo hasta que termine su plazo.

</Accordion>

<Accordion label="¿Copilot Pro sigue valiendo $10?" group="faq">

Si usas sobre todo el completado y un chat ocasional, sí. El completado está incluido en todos los planes y no consume créditos, y tu gasto de chat será pequeño. El valor empeora cuanto más dependas de sesiones de agente largas, porque esas se facturan por consumo de tokens en lugar de una asignación fija.

</Accordion>

<Accordion label="¿Qué pasa cuando uso todos mis créditos?" group="faq">

Las funciones de chat y agente se detienen hasta que compres créditos adicionales o se reinicie tu ciclo. El completado y las sugerencias de Next Edit siguen funcionando. Ya no hay un descenso automático a un modelo más barato, que es como se comportaba el antiguo sistema de solicitudes premium.

</Accordion>

<Accordion label="¿Qué es Copilot Max?" group="faq">

Un nivel de $100 al mes orientado al uso intensivo de agentes. Existe porque la asignación de $10 de Pro es fácil de agotar con sesiones de agente largas. Si compras créditos extra en Pro de forma constante, Max es la vía más barata. Consulta la página de precios actual antes de comprometerte, ya que GitHub ha estado ajustando estos niveles.

</Accordion>

<Accordion label="¿Puedo usar Copilot en Zed gratis?" group="faq">

Necesitas un plan de Copilot para usar Copilot dentro de Zed, pero Copilot Free ahora está disponible para todos, no solo para estudiantes y mantenedores de open source. Te da 2.000 completados y 50 solicitudes de chat al mes, suficiente para evaluar la integración con el editor antes de pagar.

</Accordion>

<Accordion label="¿Copilot envía mi código a servidores externos?" group="faq">

Los prompts, el contexto y el contenido de archivo que el agente necesita se envían a GitHub y al proveedor del modelo para generar sugerencias. Tu repositorio completo no sale de tu máquina. En Free, Pro y Pro+, tus interacciones se usan para entrenamiento por defecto a menos que lo desactives en Settings → Copilot. Los planes Business y Enterprise no entrenan con tu código.

</Accordion>

<Accordion label="¿Puedo cancelar en cualquier momento?" group="faq">

Los planes mensuales, sí. Cancela en Settings → Billing → Copilot y caes al nivel Free. Los planes anuales se cumplen hasta el plazo; luego pasas a Free y eliges un plan mensual o te vas.

</Accordion>

## ¿Qué es Perplexity? El motor de respuestas con IA que está cambiando la búsqueda

Perplexity es un motor de respuestas con IA, no un chatbot ni un buscador tradicional. Haces una pregunta, busca en la web en tiempo real, lee múltiples fuentes y sintetiza una respuesta con citas. Cada afirmación enlaza con su fuente.

Esto es completamente distinto de cómo funciona Google (una lista de 10 enlaces azules que tienes que ir abriendo) y de cómo funciona ChatGPT (una respuesta conversacional que puede o no estar fundamentada en la web). Perplexity te da la respuesta con citas en línea para que puedas verificar cada afirmación.

El flujo: **tu pregunta, Perplexity busca en la web, lee N fuentes y sintetiza una respuesta con citas**. Un concepto simple, pero la calidad de ejecución es lo que hace que la gente siga pagando.

El nombre viene de una métrica de modelos de lenguaje: la «perplexity» (perplejidad) mide lo bien que un modelo predice texto. Una perplejidad menor significa mejores predicciones. Un nombre apropiado para un producto que hace que las predicciones de la IA estén más ancladas a la realidad.

## Perplexity Pro Search: razonamiento en varios pasos con citas

La antigua marca «Copilot» ha desaparecido. Lo que antes se llamaba modo Copilot ahora es **Pro Search**: y es mejor.

Pro Search razona en varios pasos: descompone preguntas complejas, busca varias veces, lee distintas fuentes, hace preguntas aclaratorias de seguimiento cuando es necesario y produce una respuesta completa con citas. Es la función que separa a Perplexity de «otro chatbot de IA más con un botón de búsqueda».

**Cómo funcionan los límites en la práctica:**

| Plan | Límite de Pro Search |
|---|---|
| Gratis | 3 al día |
| Pro | Límites semanales («uso medio»; no se publica la cifra exacta) |
| Max | Ilimitado |

Cuando alcanzas el límite de Pro Search, la respuesta sigue llegando, pero usa la búsqueda básica de Sonar en lugar del razonamiento en varios pasos. No es un bloqueo total, lo cual es mejor que chocar contra un muro.

Mi consejo práctico: reserva Pro Search para preguntas de investigación complejas. La búsqueda básica de Sonar maneja bien las consultas fácticas sencillas.

## Modelos de IA disponibles en Perplexity (2026)

Perplexity funciona con un sistema de modelos de dos capas. Entenderlo es clave para sacar el máximo partido a la plataforma.

### Familia Sonar: los modelos propietarios de Perplexity

Los modelos Sonar son propios de Perplexity, construidos sobre Llama y optimizados para velocidad y anclaje en citas:

- **Sonar**: el predeterminado para la mayoría de consultas. Rápido, fundamentado, suficiente para el 80 % de las búsquedas
- **Sonar Pro**: más capaz, maneja consultas complejas
- **Sonar Reasoning Pro**: razonamiento en varios pasos para problemas más difíciles
- **Sonar Deep Research**: modelo dedicado a la función Deep Research (ver abajo)

Sonar es lo que más usarás. Es rápido, las citas son fiables y para preguntas fácticas es difícil de superar.

### Modelos de terceros: GPT-5.2, Claude, Gemini y más

Los usuarios Pro y Max pueden cambiar entre modelos de terceros:

| Modelo | Plan | Ideal para |
|---|---|---|
| GPT-5.2 (OpenAI) | Pro | Razonamiento general, programación |
| Claude Sonnet 4.6 (Anthropic) | Pro | Escritura extensa, análisis |
| Claude Opus 4.6 (Anthropic) | Max | Razonamiento complejo, tareas agénticas |
| Gemini 3.1 Pro (Google) | Pro | Multimodal, contexto largo |
| Nemotron 3 Super 120B (NVIDIA) | Pro | Respuestas concisas y rápidas |

**Qué modelo usar para cada tarea:** usa Sonar para preguntas fácticas con citas. Cambia a GPT-5.2 o Claude Sonnet cuando necesites un razonamiento más profundo o textos más largos. Gemini 3.1 Pro destaca en consultas multimodales (análisis de imágenes). Claude Opus en Max es para los problemas más difíciles.

La familia Sonar se basa en Llama. Si te interesan las [alternativas open source a Claude y GPT](/es/mejores-llms-opensource-alternativa-claude/), los modelos Sonar son un buen ejemplo de lo que Llama ajustado puede hacer a escala.

El **Writing Mode** sigue existiendo. Te permite chatear directamente con el modelo elegido sin búsqueda web. Ojo: Writing Mode desactiva la búsqueda por completo. Las respuestas vienen solo de los datos de entrenamiento, sin citas. Es útil para escritura creativa o lluvia de ideas, pero no esperes respuestas con fuentes.

## Perplexity Deep Research: informes en minutos

La mayor novedad desde que se publicó este artículo. Lanzada en febrero de 2025, Deep Research realiza decenas de búsquedas, lee cientos de fuentes y produce un informe completo en 2-4 minutos.

**Rendimiento en benchmarks:** 21,1 % en Humanity's Last Exam, 93,9 % en SimpleQA. Esas cifras importan porque muestran que el modelo maneja tanto razonamiento difícil como precisión fáctica.

**Acceso según el plan:**
- Gratis: acceso limitado (suficiente para probarlo)
- Pro: una asignación generosa para uso regular
- Max: ilimitado

**Para qué sirve:**
- Comparativas de tecnología y decisiones de stack
- Análisis de mercado para un proyecto nuevo
- Aprender un dominio nuevo rápidamente
- Resolver problemas técnicos complejos para los que normalmente tendrías 20 pestañas abiertas

**Para qué no sirve:** prompts vagos. «Cuéntame sobre la IA» produce un informe genérico. «Compara Docker y Podman para autoalojar un clúster de PostgreSQL en ARM con 4 GB de RAM» produce algo realmente útil. Sé específico.

## API de Perplexity: Sonar, Agent y Search API

La API ha evolucionado mucho más allá del modelo de «$5 de crédito mensual» de 2024. Perplexity ahora ofrece cuatro API distintas:

**Sonar API**: respuestas de LLM fundamentadas en búsqueda. Es la API que la mayoría de desarrolladores usará.

| Modelo | Entrada (por 1M de tokens) | Salida (por 1M de tokens) |
|---|---|---|
| Sonar | $1 | $1 |
| Sonar Pro | $3 | $15 |
| Sonar Deep Research | $2 | $8 |

**Agent API**: acceso a modelos de terceros (OpenAI, Anthropic, Google, xAI) a precios de proveedor sin recargo.

**Search API**: resultados de búsqueda web en bruto a $5 por 1.000 peticiones.

**Embeddings API**: para búsqueda semántica/RAG, $0,004-$0,05 por 1M de tokens.

Hay SDK oficiales para Python y TypeScript. También existe un MCP Server para Claude Desktop, Cursor y VS Code.

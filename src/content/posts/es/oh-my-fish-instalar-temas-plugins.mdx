Oh My Fish (OMF) es un framework para Fish Shell, similar a lo que Oh My Zsh es para Zsh. Te ofrece una herramienta de línea de comandos (`omf`) para instalar temas y plugins desde un repositorio curado: los temas de Oh My Fish se encargan del prompt y los plugins de Oh My Fish cubren huecos como la interoperabilidad con Bash y el salto entre directorios. Lo usé brevemente antes de pasarme a Fisher, y voy a ser directo sobre por qué.

<Notice type="warning" title="Estado de mantenimiento de OMF (actualizado nov 2026)">
Oh My Fish estuvo inactivo desde 2020 hasta abril de 2026, cuando salió la v8 con soporte para Fish 4. El mantenimiento se ha reanudado, con correcciones publicadas hasta septiembre de 2026, pero el README del proyecto sigue advirtiendo que algunos temas y paquetes están rotos. Funciona bien en muchas configuraciones. Para instalaciones nuevas [Fisher](/es/mejores-plugins-fish-shell/) sigue siendo la opción por defecto más segura, y esta guía cubre ambos.
</Notice>

## Novedades de Oh My Fish v8 (abril de 2026)

OMF v8, publicada el 2026-04-07, es la primera versión desde la v7 del 2020-04-11. Son seis años de diferencia. Las notas de la versión la describen como una puesta al día para el Fish moderno: compatibilidad con Fish 4+ (mínimo fish 3.0, la CI cubre de 4.0.2 a 4.8), correcciones en el instalador para modo sin conexión, tarballs y manejo de ramas, mejor activación de temas, hooks de desinstalación, carga mejorada de bundles y descubrimiento de paquetes con `OMF_CONFIG`.

Siguieron llegando commits tras el lanzamiento: una renovación de la suite de tests, correcciones de códigos de salida en el instalador, arreglos de `omf list` y `omf theme` en sistemas sin `column` y una corrección de `omf version` para instalaciones desde tarball. Último push en master en esta actualización: 2026-09-30. Sobre el papel la salud del repositorio es decente: 11.417 estrellas, 7 issues y pull requests abiertos en total, no archivado.

Sin embargo, el aviso del README sobre paquetes rotos sigue ahí. Trata OMF como usable con precaución, no como un ecosistema de paquetes completamente sano.

### Actualizar una instalación existente de OMF a v8

Si ya ejecutas una instalación de la época de v7, actualiza mediante el canal `stable`:

```fish
omf update          # everything, or:
omf update omf      # core only
```

Después verifica:

```fish
omf version         # expect 8.x
omf doctor          # sanity check after a major update
```

`omf version` solía no imprimir nada en instalaciones desde tarball (corregido el 2026-09-30). Si ahora muestra «unknown», estás en una instalación sin git, no en una rota. Confirma el canal con `omf channel stable`.

## Instalar Oh My Fish

<ListCheck>
<ul>
<li>Fish Shell ≥ 3.0. En Ubuntu consulta <a href="/es/instalar-fish-shell-ubuntu/">cómo instalar Fish Shell en Ubuntu</a>; en Mac revisa la <a href="/es/fish-shell-macos-configuracion/">guía de configuración de Fish Shell en macOS</a></li>
<li>git ≥ 1.9.5</li>
<li>Una terminal con Nerd Font, solo si quieres temas estilo Powerline como bobthefish</li>
<li>No requiere acceso root. OMF se instala en tu directorio personal</li>
</ul>
</ListCheck>

El comando de una línea documentado:

```fish
curl https://raw.githubusercontent.com/oh-my-fish/oh-my-fish/master/bin/install | fish
```

OMF queda repartido en dos sitios: el código en `~/.local/share/omf/` (respeta `$XDG_DATA_HOME`) y la configuración en `~/.config/omf/` (respeta `$XDG_CONFIG_HOME`). Conocer esta división importa más adelante: el directorio de código es prescindible, el de configuración es tuyo.

Para verificar:

```fish
omf version
omf list
```

Ambos deberían mostrar salida sin errores. `omf version` imprime un número de versión (8.x en una instalación actual) y `omf list` muestra tus paquetes instalados y el tema activo.

### Verificar el instalador antes de pasarlo al shell

Estás enviando código remoto directamente a tu shell de inicio de sesión. El README documenta un paso de suma de verificación que toma diez segundos:

```fish
curl -sL https://raw.githubusercontent.com/oh-my-fish/oh-my-fish/master/bin/install.sha256 | shasum -a 256 --check
```

<Notice type="info" title="curl-pipe-to-shell">
Cómodo, pero ejecuta código remoto sin verificar. El paso de suma de verificación de arriba es un seguro barato.
</Notice>

### Instalación automatizada o sin conexión

El instalador tiene flags distintos para instalaciones desde origen local y sin conexión. No son lo mismo.

<Tabs>
<Tab name="Desde un checkout de git">

Instala desde el origen local. El instalador sigue descargando plugins a través de la red.

```fish
git clone https://github.com/oh-my-fish/oh-my-fish
cd oh-my-fish
bin/install --local-source
```

</Tab>
<Tab name="Desde un tarball de lanzamiento">

```fish
fish install --local-source=omf.tar.gz
```

</Tab>
<Tab name="Totalmente sin conexión (sin red)">

Implica `--local-source` y omite por completo la descarga de plugins. Ejecuta `omf install` más tarde cuando vuelva la red.

```fish
bin/install --offline
```

</Tab>
</Tabs>

Para servidores e instalaciones automatizadas, el flujo que automatizaría en un VPS nuevo (los míos corren en [Hetzner Cloud](https://go.bitdoze.com/hetzner)) es: descargar el instalador, ejecutar la comprobación de requisitos y luego verificar el código de salida de cada paso.

```fish
curl -sL https://raw.githubusercontent.com/oh-my-fish/oh-my-fish/master/bin/install > install
fish install --check                # readiness check only
fish install --yes --noninteractive # scripted install
```

Otros flags que conviene conocer: `--channel=stable|dev`, `--path=`, `--config=`, `--uninstall`, `--verbose`.

<Notice type="warning" title="Comprueba los códigos de salida al automatizar">
Un error del instalador anterior a la v8 hacía que los abortos en la comprobación del entorno salieran con código 0 (corregido el 2026-08-30). Usa `--check` primero y falla de forma explícita en tus scripts.
</Notice>

Todo aquí tiene licencia MIT y es gratuito. El único coste real es confiar en un ecosistema de paquetes de terceros.

## Conceptos básicos de OMF: comandos esenciales de omf

Toda la gestión se realiza mediante el comando `omf`. Fish cubre mucho terreno de forma nativa, así que antes de añadir paquetes revisa el [autocompletado y las sugerencias de Fish Shell](/es/fish-shell-autocompletado-sugerencias/) para ver las funciones integradas que OMF no necesita tocar.

### Instalar un paquete o tema

```fish
omf install bobthefish
omf install z
omf install bass
```

`omf install` también acepta URLs y el formato `usuario/repo`:

```fish
omf install https://github.com/oh-my-fish/theme-bobthefish
omf install oh-my-fish/theme-bobthefish
```

### Buscar paquetes

Búsqueda difusa en la base de datos de paquetes. El repositorio oficial `oh-my-fish/packages-main` tiene unas 254 entradas (último push del repo: 2026-05-14).

```fish
omf search z
omf search -t bobthefish    # themes only
omf search -p bass          # plugins only
```

### Aplicar un tema

```fish
omf theme bobthefish
```

Para ver qué hay disponible:

```fish
omf theme
```

Hay capturas de pantalla de la mayoría de los temas en la [documentación de temas de Oh My Fish](https://github.com/oh-my-fish/oh-my-fish/blob/master/docs/Themes.md).

### Actualizar y eliminar

```fish
omf update          # update everything
omf update omf      # core only
omf remove z        # remove a package
```

<Notice type="warning" title="Editar bundle no desinstala">
Borrar una línea de `~/.config/omf/bundle` no desinstala el paquete. Ejecuta `omf remove <name>`.
</Notice>

### Doctor, reload y canales

```fish
omf doctor                          # first-line troubleshooter
omf reload                          # exec-based safe reload of OMF and plugins
omf channel                         # show current channel (stable|dev)
omf channel dev                     # switch to the dev channel
omf repositories list               # list package repositories
omf repositories add user/repo      # add a third-party repo
```

`omf doctor` es el primer paso documentado ante cualquier problema, y es lo que yo ejecutaría antes de abrir una issue. `omf reload` reinicia OMF en caliente sin abrir una terminal nueva. El repositorio de paquetes por defecto es `oh-my-fish/packages-main`.

### Desinstalar OMF completamente

```fish
omf destroy
```

El instalador también acepta `--uninstall`. Esta es la vía para deshacer toda la guía: `omf destroy` elimina OMF y sus paquetes. No revierte nada que hayas modificado a mano en `~/.config/fish/config.fish`.

## Temas populares de Oh My Fish

Una advertencia antes de explorar: algunos temas de OMF no tienen mantenimiento o están rotos. El aviso del README es real. Revisa el repositorio de cada tema antes de comprometerte con él. Empieza con estos cuatro.

### bobthefish: el tema insignia

El tema más popular de OMF, y sigue mantenido (último push del repo: 2026-05-20, 1.530 estrellas). Prompt estilo Powerline con estado de git, entornos virtuales, versión de Node y más. Necesita una Nerd Font o fuente Powerline.

```fish
omf install bobthefish
```

Configúralo en `~/.config/omf/init.fish`:

```fish
set -g theme_nerd_fonts yes
set -g theme_color_scheme dracula
set -g theme_display_git yes
set -g theme_show_exit_status yes
set -g theme_display_user ssh
set -x VIRTUAL_ENV_DISABLE_PROMPT 1   # avoid double virtualenv prompt
```

Esa última línea importa si usas virtualenvs de Python. Sin ella, tanto bobthefish como virtualenv dibujan un segmento en el prompt y obtienes un prompt duplicado. Si el tema no cambia tras instalarlo, casi siempre es por falta de una Nerd Font (consulta Solución de problemas).

### agnoster, clearance y lambda

**agnoster** es un port del tema Agnoster de Zsh. Prompt de dos líneas con caracteres Powerline, información de git y soporte para virtualenv.

```fish
omf install agnoster
```

**clearance** es limpio y minimalista. No necesita fuentes especiales.

```fish
omf install clearance
```

**lambda** es un tema minimalista con el carácter λ en el prompt.

```fish
omf install lambda
```

Previsualiza más temas en la [documentación de temas de Oh My Fish](https://github.com/oh-my-fish/oh-my-fish/blob/master/docs/Themes.md).

Si prefieres un prompt multi-shell con mantenimiento activo en lugar de un tema de OMF, [configura el prompt Starship con Fish Shell](/es/fish-shell-configurar-starship/). Los usuarios de Mac que usen Ghostty pueden combinarlo con la [configuración de terminal Starship + Ghostty](/es/terminal-starship-ghostty/).

## Plugins útiles de Oh My Fish

Fish gestiona el [resaltado de sintaxis](/es/fish-shell-resaltado-sintaxis/) de forma nativa, así que no necesitas un paquete de OMF para ello. Los plugins de abajo cubren carencias reales.

### bass

Ejecuta scripts de Bash y captura sus cambios en las variables de entorno. Útil para herramientas que solo traen configuración en Bash:

```fish
omf install bass
bass source ~/.nvm/nvm.sh
```

Es el paquete de OMF más genuinamente útil. Tiende un puente entre la [sintaxis no POSIX de Fish](/es/fish-shell-vs-bash-vs-zsh-comparacion/) y las herramientas exclusivas de Bash. Si nvm es la razón por la que buscas bass, considera también [nvm.fish para usar NVM con Fish Shell](/es/nvm-fish-shell/) como alternativa nativa.

### z

Salto entre directorios similar a [zoxide](/es/zoxide-tutorial/). Registra los directorios que visitas y te permite saltar a ellos usando nombres parciales:

```fish
omf install z
z projects
```

Yo elegiría zoxide antes que este. Es más rápido, funciona en varios shells y tiene mantenimiento activo. Pero si quieres gestionarlo todo desde OMF, el plugin z funciona.

### fish-spec

Un framework de testing para funciones de Fish. Útil si escribes plugins de Fish o funciones complejas:

```fish
omf install fish-spec
```

### extract

Una herramienta universal de extracción de archivos, para usar `extract file.tar.gz` en lugar de memorizar los flags de tar:

```fish
omf install extract
```

## Archivos de configuración y dotfiles de Oh My Fish

La configuración de OMF vive en `$OMF_CONFIG` (por defecto `~/.config/omf/`). La mayoría de guías mencionan dos archivos. Hay más:

- **`bundle`** lista los paquetes instalados y el tema activo
- **`theme`** guarda el nombre del tema actual
- **`channel`** guarda el canal de actualización (`stable` o `dev`)
- **`init.fish`** se ejecuta al inicio, después de cargar los plugins
- **`before.init.fish`** (opcional) se ejecuta antes de cargar los plugins
- **`key_bindings.fish`** (opcional) guarda atajos de teclado personalizados
- **`conf.d/`** (opcional) se carga en orden del sistema de archivos. Un archivo llamado `a_script.fish` se ejecuta después de `omf.fish`, así que pon prefijos `00_` o `xx_` cuando necesites un orden explícito

**`~/.config/omf/bundle`** tiene este aspecto:

```
package bass
package z
theme bobthefish
```

**`~/.config/omf/init.fish`** es donde va la configuración del tema:

```fish
# ~/.config/omf/init.fish
set -g theme_nerd_fonts yes
set -g theme_color_scheme dracula
```

<Notice type="warning" title="Editar bundle no es desinstalar">
Eliminar una línea de `bundle` no desinstala el paquete. Ejecuta `omf remove <name>` y deja que OMF reescriba el archivo.
</Notice>

Compartir `~/.config/omf/` entre máquinas replica tu configuración. Guárdalo en git: esa es la copia de seguridad de tu shell, y no cuesta nada. Para personalizaciones que van más allá de la configuración de OMF, consulta [cómo crear funciones personalizadas en Fish Shell](/es/fish-shell-funciones-comandos-personalizados/).

## Oh My Fish vs Fisher

Así se comparan a finales de 2026:

| | Oh My Fish | Fisher |
|---|---|---|
| Estado | Revivido (v8, abril 2026); el aviso del README sigue activo | Mantenimiento activo |
| Última versión | v8 (2026-04-07) | 4.4.8 (2026-01-25) |
| Estrellas en GitHub | 11.417 | 9.463 |
| Enfoque | Framework (tiene su propio init) | Solo gestor de plugins |
| Impacto en el arranque | Añade algo de sobrecarga | Cero sobrecarga |
| Formato de plugins | Paquetes específicos de OMF | Plugins estándar de Fish |
| Compatibilidad | Solo paquetes de OMF | Paquetes de OMF y cualquier plugin de Fish |
| Configuración | Comandos `omf` y archivos de configuración | Comandos `fisher` y archivo fish_plugins |
| Temas | Sistema de temas integrado | Instalar plugins de prompt directamente |

Fisher es más rápido, tiene mantenimiento activo y puede instalar paquetes compatibles con OMF. Ese último punto figura literalmente en el README de Fisher. La razón principal para usar OMF hoy es si ya tienes una configuración de OMF funcionando y no quieres migrar.

Una salvedad de Fisher que conviene saber antes de cambiar: Fisher expande los plugins dentro de tu directorio de configuración de fish y sobrescribe archivos por defecto. `$fisher_path` (consulta el [issue #640 de Fisher](https://github.com/jorgebucaran/fisher/issues/640)) cambia dónde terminan los plugins.

### Migrar de OMF a Fisher

Si quieres cambiar:

1. Anota tus paquetes instalados: `omf list`
2. Instala Fisher:
   ```fish
   curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
   ```
3. Instala los equivalentes mediante Fisher. La mayoría de paquetes de OMF se instalan directamente:
   ```fish
   fisher install oh-my-fish/theme-bobthefish
   ```
4. Desinstala OMF: `omf destroy`

Fisher instala paquetes del repositorio de OMF usando el prefijo `oh-my-fish/`. No todos los paquetes funcionan, pero los populares sí.

Para verificar la migración: `fisher list` muestra tus paquetes, y un nuevo shell carga tu prompt sin errores.

## Crear paquetes de OMF

Para generar la plantilla de tu propio paquete o tema:

```fish
omf new plugin my-plugin
omf new theme my-theme
```

Esto crea una estructura base en `~/.config/omf/pkg/my-plugin/` o `~/.config/omf/themes/my-theme/`.

Estructura del plugin:

```
my-plugin/
├── completions/
│   └── my-plugin.fish
├── functions/
│   └── my-plugin.fish
├── init.fish
└── uninstall.fish
```

`init.fish` se ejecuta cuando se carga el plugin. `uninstall.fish` se ejecuta cuando se elimina. Para distribuirlo, envía el repositorio a `oh-my-fish/packages-main` o añade un repositorio personal con `omf repositories add`. Si lo único que necesitas es un atajo en lugar de un plugin completo, [abreviaturas vs alias en Fish Shell](/es/fish-shell-abreviaturas-vs-alias/) cubre opciones más ligeras.

## Solución de problemas en Oh My Fish

Ejecuta `omf doctor` primero. Es la herramienta de diagnóstico documentada y detecta la mayoría de los problemas de configuración antes de que empieces a adivinar.

**Comandos de OMF no encontrados.** Reinicia tu shell después de la instalación, o ejecuta `source ~/.config/fish/conf.d/omf.fish`.

**El tema no cambia.** Algunos temas necesitan una Nerd Font. Instala una (MesloLGS NF funciona) y configúrala en tu emulador de terminal. Si el prompt sigue viéndose mal, confirma que el nombre del tema coincide con lo que lista `omf theme`.

**Errores en plugins tras actualizar.** Algunos paquetes se rompen, y la advertencia del README es real. Revisa el repositorio del plugin en busca de issues abiertos o parches, o pásate a una alternativa compatible con Fisher.

**`omf list` o `omf theme` salen con código 127 en contenedores mínimos.** Falta la utilidad `column` (común en imágenes Alpine). Corregido en los commits de la era v8 (2026-09-30) con una salida plana de respaldo. Actualiza OMF o instala el paquete: `apk add util-linux`.

**`omf version` imprime «unknown».** Estás en una instalación desde tarball u otro origen sin git. Versiones anteriores tenían este bug; una corrección del 2026-09-30 lo resuelve. No significa que OMF esté roto.

**La instalación automatizada sale con código 0 a pesar de abortar.** Un bug del instalador anterior a la v8 (corregido el 2026-08-30). Usa `--check` primero y comprueba los códigos de salida en tus scripts.

**bobthefish muestra un prompt de virtualenv duplicado.** Añade `set -x VIRTUAL_ENV_DISABLE_PROMPT 1` a tu configuración.

Para revertirlo por completo, `omf destroy` (o el flag `--uninstall` del instalador) elimina OMF por completo. No se toca nada fuera de `~/.local/share/omf/` y `~/.config/omf/`.

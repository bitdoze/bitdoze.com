September 2026 reset the proprietary bar twice in three weeks. Anthropic shipped [Claude Opus 5.5](https://www.anthropic.com/claude-opus-5-5) on September 22 at $4/$20 per million tokens, claiming it performs at Claude Fable 5.1's level on most work while costing 40% less to run than Opus 5. OpenAI answered the same day with GPT-6 Sol and Luna, the cheaper tiers of the [GPT-6 Astra](https://openai.com/index/gpt-6-astra/) flagship that launched September 3 at $10/$50.

The open models moved faster. In the last six weeks alone we got GLM-5.3 and GLM-5.3-Flash from Z.ai, DeepSeek-V4.1-Flash, open weights for Qwen3.8-Max's 2.4T core, and MiMo-V2.6-Pro from Xiaomi, which now sits at the top of Artificial Analysis' open-weights index. I have been running these against the paid frontier on real coding work. The gap is smaller than the price difference suggests.

<Notice type="info" title="Cost Comparison Overview">

Claude Opus 5.5 costs $4–20 per million tokens. Fable 5.1 and GPT-6 Astra cost $10–50. The open models in this guide range from $0.15 to $3.00 per million input tokens, so depending on the model and your cache hit rate you can cut spend by roughly 70–97%.

</Notice>

## Why consider open source LLM alternatives?

The short version: the open field caught up on coding, and it did it while getting cheaper.

<ListCheck>

- **Cost**: Most models here run $0.15–$3 per million input tokens
- **Open weights**: Every model on this list has downloadable weights, so you can self-host, fine-tune, or pin a version forever
- **Performance**: MiMo-V2.6-Pro, GLM-5.3, and DeepSeek-V4.1-Flash post scores that beat older frontier models on several agentic coding suites
- **Flexibility**: Provider APIs, OpenRouter, or your own GPU cluster
- **Pace**: Six open releases since mid-August alone

</ListCheck>

### What to evaluate

- **Coding**: Generate, debug, and refactor across a real repo
- **Agentic work**: Tool calling, long multi-step runs, not losing the thread at step 200
- **Context length**: How much of a codebase fits in one shot
- **Cost per useful result**: Not just sticker price per million tokens
- **Weight availability**: "Open" ranges from MIT to licenses with revenue clauses

## The proprietary bar: Opus 5.5, Fable 5.1, GPT-6

Quick look at what the open models are chasing.

### Claude Opus 5.5

Released September 22. $4 input / $20 output per million tokens, 1M context, 128K max output. Anthropic's pitch is Fable 5.1-class work at 40% lower running cost than Opus 5, and the system card says it matches or beats Fable 5.1 and Mythos 5.1 on many internal evals. Two things worth knowing: adaptive thinking is always on (you control depth with the effort parameter, and `thinking: disabled` now returns a 400 error), and forced tool use is gone. If your agent stack was built on Opus 5, read the migration notes before switching. Claude Haiku 5.5 is announced for the coming weeks.

### Claude Fable 5.1

Still the top of Anthropic's line at $10/$50. On Artificial Analysis Intelligence Index v4.3 it ties GPT-6 Astra at 53, the highest score published. This is the model the open field is actually chasing on hard agentic work, not Opus.

### GPT-6 Astra, Sol, and Luna

OpenAI split the lineup into three tiers:

<ListCheck>

- **GPT-6 Astra** (Sept 3): Flagship at $10/$50, cached input $1. AA Intelligence 53, tied with Fable 5.1. First OpenAI model rated "Critical" for cyber capability under their Preparedness Framework, which is why rollout was gated to enterprises first. Requests over 272K input tokens reprice to $20/$75.
- **GPT-6 Sol** (Sept 22): $2/$10, cached input $0.20. Roughly GPT-5.6 Sol intelligence (AA 48) at half the price, and 57 on AA's Coding Agent Index, up 2 points. DeepSWE 68.8 at max effort. Same 272K repricing rule.
- **GPT-6 Luna** (Sept 22): $0.10/$0.50. The one proprietary model that undercuts most of the open field on sticker price. You give up weights and self-hosting, but on raw API spend it competes with the cheapest options below.

</ListCheck>

## 2. GLM-5.3: The open coding workhorse

## 3. DeepSeek-V4.1-Flash: The efficiency king

**[DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash)** shipped September 10 under MIT, and it is the most interesting architecture on this list. It uses a Causal Encoder-Decoder design: 552B total parameters, but only 8B active while reading your input and 16B while generating output. Combined with FP4 KV caching, its working KV cache is about 890 bytes per token, roughly a quarter of its predecessor. In plain terms: it is built to make million-token agent loops cheap to serve.

The vendor-reported numbers are aggressive: Terminal-Bench 2.1 at 90.6% (the highest score I have seen published on that suite) and DeepSWE 74.2, above Fable 5's 70.0 and GPT-5.6 Sol's 73.0. Treat those as DeepSeek's own runs until more third-party verification lands. The odd part: Artificial Analysis scores it at 39 on the Intelligence Index, well below its coding results, because that index rewards breadth and V4.1-Flash is a specialist.

## 4. GLM-5.3-Flash: The value monster

**[GLM-5.3-Flash](https://huggingface.co/zai-org/GLM-5.3-Flash)** released August 26 under MIT, and it quietly rearranged the budget tier. 320B total, 18B active, with a hybrid attention stack that interleaves 34 KDA linear-attention layers with 11 sparse-attention layers in a 3:1 pattern. That cuts attention compute roughly 3x and KV cache roughly 4.4x versus GLM-5.3. It is also the first natively multimodal GLM-5 model, with image and video input.

The punchline is the price: $0.15/M input and $0.50/M output, with $0.03 cached. It scores 84.3% on Terminal-Bench 2.1, 63.4 on DeepSWE, and holds AA Intelligence 42, fourth among open models. Fun detail: before launch it circulated on OpenRouter and OpenCode as the anonymous "Ox Alpha" model people were trying to identify.

## Getting started

### Step 1: Choose access

<ListCheck>

- **OpenRouter**: One key, every model on this list, fastest way to compare
- **Direct provider APIs**: Better rate limits and plan pricing (Z.ai, DeepSeek, Xiaomi MiMo, Qwen, Kimi)
- **Self-hosting**: GLM-5.3-Flash (320B) is the realistic single-node option; K3 and Qwen 2.4T want a cluster
- **Agent tools**: OpenCode, Claude Code-compatible endpoints, Hermes, Codex any-model configs

</ListCheck>

### Step 2: Environment (OpenRouter example)

```bash
# Install OpenAI SDK
pip install openai

# Set environment variables
export OPENROUTER_API_KEY="your_api_key_here"
export OPENROUTER_BASE_URL="https://openrouter.ai/api/v1"
```

### Step 3: Basic call

```python
import openai

client = openai.OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key="your_openrouter_api_key"
)

# GLM-5.3 for everyday agent coding
response = client.chat.completions.create(
    model="z-ai/glm-5.3",
    messages=[
        {"role": "system", "content": "You are a helpful coding assistant."},
        {"role": "user", "content": "Create a Python web scraper for product prices"}
    ]
)

print(response.choices[0].message.content)
```

## Tips and common mistakes

### What works

<ListCheck>

- **Match model to task**: GLM-5.3-Flash or DeepSeek for volume, MiMo Pro or GLM-5.3 for hard agent runs, K3 for research agents
- **Use off-peak windows**: DeepSeek halves prices outside its two daily peak windows; GLM Coding Plan halves points off-peak and on weekends
- **Prompt per model**: Each family still has its own instruction quirks
- **Measure in your domain**: Vendor benches are marketing with a methodology section; run your own evals
- **Keep a fallback**: Provider hiccups happen; OpenRouter makes switching one line of config

</ListCheck>

### What to avoid

- Routing every task to the most expensive model by default
- Trusting vendor-reported benchmarks without independent runs (DeepSeek V4.1-Flash's numbers are mostly self-reported so far)
- Letting agents run without permission scoping, especially given how fast cyber capability is climbing in these releases
- Ignoring the license fine print: MIT is clean, GLM-5.3 has a $10B MaaS clause, Qwen and Kimi use custom terms

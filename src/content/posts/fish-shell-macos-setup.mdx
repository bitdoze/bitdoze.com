macOS ships with Zsh as the default shell (Apple switched from Bash back in 2019). Fish isn't included, but it's a single Homebrew command away. I run Fish on both my Mac and Linux machines, and the experience is nearly identical on both, which is one of the things I like about it.

This guide covers the complete **Fish Shell on macOS** setup: installation with Homebrew, making Fish your default shell, terminal emulator configuration, and the essential tools I install alongside it. Everything here is current for fish 4.9.x (Homebrew formula checked October 2026), and every tool in the guide is free and open source, and the whole set takes tens of MB of disk.

<ListCheck>
<ul>
<li>A Mac running macOS (Apple Silicon or Intel, both work the same)</li>
<li>Homebrew installed, or willingness to run the one-line installer</li>
<li>A terminal emulator (Ghostty, iTerm2, Alacritty, or WezTerm)</li>
<li>About 15 minutes</li>
</ul>
</ListCheck>

## Install Fish Shell on macOS with Homebrew

If you don't have Homebrew yet:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Install Fish:

```bash
brew install fish
```

Homebrew bottles cover Apple Silicon and Intel Macs, with builds for macOS Sonoma through Tahoe. Check the version:

```bash
fish --version
```

You should see `fish, version 4.9.3` or newer. Homebrew keeps Fish up to date. Run `brew upgrade fish` periodically.

## Verify your Fish Shell install

After installing, and again after you switch your default shell, run these checks. They work from any shell, so you can run them even if your terminal is still on Zsh.

<Notice type="info" title="Run these in any shell">
These commands work in Zsh, Bash, or Fish. Run them now to confirm the install, and again after the default-shell switch in the next section.
</Notice>

```bash
fish --version                            # expect: fish, version 4.9.3
echo $SHELL                               # after chsh: /opt/homebrew/bin/fish (Apple Silicon)
dscl . -read /Users/$USER UserShell       # authoritative login-shell record
```

`dscl` is the source of truth: it reads the macOS directory service record for your account. If it shows `/opt/homebrew/bin/fish` (or `/usr/local/bin/fish` on Intel), the switch worked at the system level.

To debug completion issues later:

```bash
echo $fish_complete_path
```

This shows the directories Fish searches for tab completions. If Homebrew tool completions are missing, this is the first thing to check.

If `echo $SHELL` still shows `/bin/zsh` after running `chsh`, your terminal app is probably launching its own shell override. Check the troubleshooting section below.

## Try Fish without switching

Type `fish` in your current terminal to start a Fish session. Play around with [autosuggestions and tab completion](/fish-shell-autocomplete-suggestions/) (just start typing and watch the gray suggestions appear), and notice how [syntax highlighting works](/fish-shell-syntax-highlighting/) as you type. Type `exit` to go back to Zsh.

One migration nicety: as of fish 4.6, bash-style `|&` (pipe stdout and stderr) works out of the box. Fish's own spelling is `&|`, but you don't have to retrain that muscle memory.

## Set Fish Shell as Your Default Shell on macOS

macOS requires the shell to be listed in `/etc/shells` before you can set it as default. Homebrew installs Fish to `/opt/homebrew/bin/fish` (Apple Silicon) or `/usr/local/bin/fish` (Intel).

```bash
# Find your Fish path
which fish

# Add it to allowed shells
echo (which fish) | sudo tee -a /etc/shells

# Set as default
chsh -s (which fish)
```

Open a new terminal window. You should be in Fish. Verify with the `dscl` command from the previous section.

<Notice type="warning" title="Keep Zsh around">
macOS system scripts sometimes expect Zsh or Bash. Don't remove them. Fish replaces your interactive shell, not the system scripting layer. If you decide Fish isn't for you, staying on Zsh is perfectly fine. You can [add syntax highlighting to Zsh](/enable-syntax-highlighting-zsh/), [enable command autocomplete in Zsh](/enable-command-autocomplete-in-zsh/), and pick from the [best Oh My Zsh plugins](/best-oh-my-zsh-plugins/) to get a similar experience.
</Notice>

To undo the switch, run `chsh -s /bin/zsh`. To remove Fish entirely: `brew uninstall fish` and delete the Fish line from `/etc/shells`. Your Fish config lives in `~/.config/fish/` and can be deleted independently. Nothing else on the system is touched. The blast radius is limited to `/etc/shells` and your login-shell record.

## Terminal emulator setup (Ghostty, iTerm2, Alacritty, WezTerm)

Fish works in any terminal, but your font matters. Fish's completion pager and many prompt themes use special characters that need a Nerd Font.

### Install a Nerd Font

```bash
brew install font-meslo-lg-nerd-font
```

Then set it as your terminal's font. Here's how for the popular options:

<Accordion label="Ghostty" group="terminals" expanded="true">
Add to `~/.config/ghostty/config`:

```
font-family = MesloLGS Nerd Font
font-size = 14
```

Ghostty is a fast, GPU-accelerated terminal (v1.4.0 is the latest as of October 2026). I have a [full Ghostty setup guide](/ghostty-terminal/) if you want to explore its features.
</Accordion>

<Accordion label="iTerm2" group="terminals">
Go to **Settings → Profiles → Text → Font** and select "MesloLGS NF". Set the size to your preference (I use 14).

Also worth enabling in iTerm2:
- **Settings → Profiles → Terminal → Shell Integration**: gives you click-to-select command output
- **Settings → General → Selection → Applications in terminal may access clipboard**: so Fish's copy operations work
</Accordion>

<Accordion label="Alacritty" group="terminals">
In `~/.config/alacritty/alacritty.toml`:

```toml
[font]
size = 14

[font.normal]
family = "MesloLGS Nerd Font"
```
</Accordion>

<Accordion label="WezTerm" group="terminals">
In `~/.wezterm.lua`:

```lua
config.font = wezterm.font("MesloLGS Nerd Font")
config.font_size = 14.0
```

I have a [WezTerm setup guide](/install-wezterm-mac/) that covers integration with zoxide and tmux.
</Accordion>

Once your terminal and font are sorted, consider a multiplexer for persistent sessions and split panes. I put together a comparison of the [best terminal multiplexers for 2026](/best-terminal-multiplexers/), and if tmux is your pick, here's how to [install tmux on macOS and learn the basics](/tmux-basics/).

## Basic Fish Shell configuration (config.fish)

Create your config file:

```fish
mkdir -p ~/.config/fish
nano ~/.config/fish/config.fish
```

A practical starting config for macOS:

```fish
# ~/.config/fish/config.fish

# Homebrew environment (Apple Silicon paths; use /usr/local/bin/brew on Intel)
brew shellenv fish | source
# or the simple version:
# fish_add_path /opt/homebrew/bin
# fish_add_path /opt/homebrew/sbin

# Common paths
fish_add_path ~/bin
fish_add_path ~/.local/bin

# Suppress the greeting
set -g fish_greeting

# Editor
set -gx EDITOR "code --wait"  # or vim, nvim, etc.
```

`brew shellenv fish | source` sets `HOMEBREW_PREFIX`, `HOMEBREW_CELLAR`, the PATH, and manpath in one line. If it gives you trouble, fall back to the two `fish_add_path` lines. They do the job for most setups.

<Accordion label="Only if fish isn't from Homebrew" group="config">
Homebrew's fish formula discovers Homebrew-managed completions automatically (see the [Homebrew Shell Completion docs](https://docs.brew.sh/Shell-Completion)). If you installed fish from source or another package manager, add this to `config.fish` to pick up Homebrew tool completions:

```fish
if test -d (brew --prefix)"/share/fish/vendor_completions.d"
    set -p fish_complete_path (brew --prefix)/share/fish/vendor_completions.d
end
```

Fish 4.7 also improved `vendor_completions.d` discovery via XDG defaults, so even non-Homebrew installs may find completions without this block. Check `echo $fish_complete_path` to see what Fish is searching.
</Accordion>

Once your basics are in place, the natural next step is writing custom functions for repeated workflows. See [Fish Shell functions and custom commands](/fish-shell-functions-custom-commands/) for patterns and examples.

## Theme Fish Shell without plugins (fish_config)

Before installing any plugin or prompt, Fish ships with built-in themes you can browse and apply from the CLI:

```fish
fish_config theme list          # see all built-in themes
fish_config theme demo          # preview themes side by side
fish_config theme choose "TOMORROW_NIGHT"   # apply one (use any name from the list)
```

Add `--color-theme=dark` or `--color-theme=light` to `theme choose` to adjust the base color scheme. Your choice persists across sessions.

For prompts, Fish also ships sample prompts:

```fish
fish_config prompt list
fish_config prompt choose "Classic + Git"
```

<Notice type="info" title="Zero-install theming">
This is the fastest way to get a good-looking shell before installing anything. If the built-in themes aren't enough, see my [Fish Shell themes and prompts guide](/fish-shell-themes-prompts/) for third-party options.
</Notice>

## Install essential tools (Fisher, Starship, zoxide, eza, fzf)

Here's my standard set of companion tools for Fish on macOS. All free and open source. Together they add tens of MB of disk, nothing more.

```bash
brew install fisher      # plugin manager (or install via curl)
brew install starship    # cross-shell prompt
brew install zoxide      # smarter cd
brew install eza         # modern ls replacement
brew install fzf         # fuzzy finder
brew install bat         # better cat with syntax highlighting
brew install fd          # better find
brew install ripgrep     # better grep
```

### Set up Fisher and Fish plugins

If you installed Fisher via Homebrew, it's ready. Otherwise:

```fish
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
```

Now install plugins:

```fish
fisher install PatrickF1/fzf.fish           # fuzzy search integration (v11+ requires fish 4.x)
fisher install jorgebucaran/autopair.fish    # auto-close brackets
fisher install meaningful-ooo/sponge         # remove failed commands from history
```

<Notice type="warning" title="sponge is lightly maintained">
sponge's last release was in 2022 and the repo has been quiet since early 2024. It works on fish 4.9.x today, but if it ever breaks after a fish upgrade, removing it with `fisher remove meaningful-ooo/sponge` is painless.
</Notice>

See my [best Fish Shell plugins guide](/best-fish-shell-plugins/) for the full list.

### Set up Starship (or Tide)

<Tabs>
<Tab name="Starship">
Add to `config.fish`:

```fish
starship init fish | source
```

Starship (v1.27.0 as of October 2026) is a cross-shell prompt. The same config works if you also use Zsh or Bash. Full setup details in my [Starship + Fish guide](/fish-shell-starship-prompt/).
</Tab>
<Tab name="Tide">
Install via Fisher:

```fish
fisher install IlanCosman/tide@v6
tide configure
```

Tide (v6.2.0) is a Fish-native prompt with an interactive configuration wizard. Run `tide configure` after install to pick your style.
</Tab>
</Tabs>

### Set up zoxide

Add to `config.fish`:

```fish
zoxide init fish | source
```

Now use `z` instead of `cd`: `z projects` jumps to your projects directory. Full guide in my [zoxide article](/zoxide/).

### Set up eza aliases

```fish
# ~/.config/fish/conf.d/eza.fish
abbr -a ls eza
abbr -a ll "eza -la --icons --git"
abbr -a lt "eza -la --icons --tree --level=2"
```

## macOS-specific abbreviations

```fish
# ~/.config/fish/conf.d/macos.fish

# Quick Look from terminal
abbr -a ql "qlmanage -p"

# Open current directory in Finder
abbr -a finder "open ."

# Flush DNS
abbr -a flushdns "sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder"

# Show/hide hidden files in Finder
abbr -a showhidden "defaults write com.apple.finder AppleShowAllFiles -bool true && killall Finder"
abbr -a hidehidden "defaults write com.apple.finder AppleShowAllFiles -bool false && killall Finder"
```

Fish 4.9 added a nice quality-of-life improvement: abbreviations can now carry a description that shows in the completion pager. Run `abbr --help` on your install to see the current syntax for adding descriptions. It makes it easier to remember what your custom abbreviations do.

I cover abbreviations vs aliases in detail in [Fish Shell abbreviations vs aliases](/fish-shell-abbreviations-vs-aliases/).

## Node.js version management

The Bash-based nvm doesn't work in Fish. Use nvm.fish instead:

```fish
fisher install jorgebucaran/nvm.fish
nvm install lts
set --universal nvm_default_version lts
```

`nvm install latest` works too if you want the newest release instead of LTS. Full walkthrough in my [NVM with Fish Shell guide](/nvm-fish-shell/). If you also keep a Zsh setup, my [install Node.js with NVM on macOS and Ubuntu](/install-nodejs-using-nvm-macos-ubuntu/) guide covers both shells.

One alternative worth knowing: `mise` is a general version manager (Node, Python, Ruby, and more) that integrates with Fish via `mise activate fish | source`. If you manage multiple language runtimes, it's worth a look.

## Common Fish Shell issues on macOS: troubleshooting

<Accordion label="Homebrew PATH not working" group="issues" expanded="true">
On Apple Silicon Macs, Homebrew installs to `/opt/homebrew/` instead of `/usr/local/`. Make sure your `config.fish` has the Homebrew environment at the top:

```fish
brew shellenv fish | source
# or manually:
# fish_add_path /opt/homebrew/bin
# fish_add_path /opt/homebrew/sbin
```

Put these at the very top of your config file, before anything that depends on Homebrew tools.
</Accordion>

<Accordion label="Environment variables from .zshrc missing" group="issues">
Fish doesn't read `.zshrc` or `.bash_profile`. Move your environment variables to `config.fish` using `set -gx`:

```fish
set -gx JAVA_HOME (/usr/libexec/java_home)
set -gx ANDROID_HOME ~/Library/Android/sdk
fish_add_path $ANDROID_HOME/platform-tools
```
</Accordion>

<Accordion label="SSH agent not forwarding" group="issues">
macOS's SSH agent works with Fish, but you may need to load your keys:

```fish
# ~/.config/fish/conf.d/ssh.fish
if status is-interactive
    ssh-add --apple-use-keychain ~/.ssh/id_ed25519 2>/dev/null
end
```
</Accordion>

<Accordion label="Tab completions missing for Homebrew tools" group="issues">
If brew-installed tools don't tab-complete, check what Fish is searching:

```fish
echo $fish_complete_path
```

Fish installed via Homebrew auto-discovers completions. If you installed fish some other way, see the "Only if fish isn't from Homebrew" accordion in the config section above.
</Accordion>

<Accordion label="Plugin breaks after upgrading fish" group="issues">
If a plugin stops working after a fish upgrade, check its requirements. For example, fzf.fish v11+ requires fish 4.x (it migrated to fish 4 binding syntax). Fix: `brew upgrade fish` first, then `fisher update` to pull the latest plugin versions.
</Accordion>

<Accordion label="Colors look different in scripts or over SSH" group="issues">
Since fish 4.7, the default color theme is no longer set in non-interactive shells. This is intentional: it prevents theme colors from leaking into piped output and scripts. If you want colors over SSH, set them explicitly in your remote `config.fish`.
</Accordion>

<Accordion label="What is fish_frozen_theme.fish?" group="issues">
After upgrading from older fish versions, you may find `~/.config/fish/conf.d/fish_frozen_theme.fish`. Fish creates it to pin your current theme across upgrades so colors don't change unexpectedly. It's safe to leave in place or delete. If you delete it, future theme defaults will apply on the next upgrade.
</Accordion>

## What changed in fish 4.6 to 4.9

If you're coming from an older fish install, here's what landed in the last few releases (4.6.0 through 4.9.3, March to September 2026):

<ListCheck>
<ul>
<li>**4.6.0**: bash-style `|&` accepted for piping stdout+stderr; fixed slow terminal startup on macOS</li>
<li>**4.7.0**: default colors no longer set in non-interactive shells; better `vendor_completions.d` discovery</li>
<li>**4.8.0**: `cd -L` / `cd -P` for symlink resolution control; abbreviations complete in argument position</li>
<li>**4.9.0**: abbreviation descriptions shown in completion pager; slow-symlink tab-completion fix; nested list indexing</li>
</ul>
</ListCheck>

Full details in the [fish-shell releases](https://github.com/fish-shell/fish-shell/releases).

## Health check & where Fish state lives

Quick reference for verifying your setup and understanding where Fish stores its data:

<Accordion label="Health check commands" group="ops">
```bash
fish --version                            # fish, version 4.9.3
echo $SHELL                               # /opt/homebrew/bin/fish
dscl . -read /Users/$USER UserShell       # UserShell: /opt/homebrew/bin/fish
echo $fish_complete_path                  # completion search paths
```

If any of these look wrong, the troubleshooting section above covers the usual fixes.
</Accordion>

Where Fish stores its state on macOS:

```
~/.config/fish/
├── config.fish              # main config (source order: first)
├── conf.d/
│   ├── eza.fish             # your abbreviation files
│   ├── macos.fish
│   └── ssh.fish
└── (fish variables, universal vars in fish_variables)

~/.local/share/fish/
├── fish_history             # command history
└── generated_completions/   # auto-generated completions
```

This is useful for backups and for mirroring your setup to a Linux box. The same paths work there. See my [Install Fish on Ubuntu](/install-fish-shell-ubuntu/) guide for the Linux side.

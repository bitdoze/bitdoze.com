## What the accordion plugin gives you

- **Customizable colors** — change the background, text, and hover colors to match your site's design.
- **Unlimited tabs** — add as many FAQ items as you need by duplicating a simple HTML block.
- **Mobile responsive** — the accordion looks good on both desktop and mobile screens.
- **Animated toggle** — smooth open/close animation with a plus icon that rotates into an x.

The plugin is plain HTML, CSS, and a few lines of vanilla JavaScript in a single embed block. No framework or external script loads. You don't need to install anything separately — just paste the code into a Carrd Embed element.

## How to add the accordion FAQ to Carrd

### 1. Download the accordion code

Grab the free code from [carrdme.com](https://go.carrdme.com/accordion). It's a single block of HTML, CSS, and JavaScript that you'll paste into Carrd.

### 2. Add an Embed element in Carrd

Open your Carrd site in the editor. In the section where you want the FAQ, click **Add Element** and select **Embed**. Set the following:

- **Type:** Code
- **Style:** Inline (the accordion is visible content, and Inline places it exactly where the Embed element sits in your layout. Hidden would inject it into the page's head or body edges instead)

For more details on how Carrd's embed system works, see the [official Carrd embed documentation](https://carrd.co/docs/building/embedding-custom-code).

### 3. Paste the code and customize your FAQ items

Paste the full code into the Embed element's Code field. Then edit the FAQ content. Each accordion item follows this pattern:

```html
<button class="accordion">Your question here?</button>
<div class="panel">
  <p>Your answer goes here. You can include multiple paragraphs, lists, or inline HTML.</p>
</div>
```

Add more items by repeating the same block:

```html
<button class="accordion">What is your refund policy?</button>
<div class="panel">
  <p>We offer a full refund within 30 days of purchase. Contact support@example.com to start the process.</p>
</div>

<button class="accordion">How do I contact support?</button>
<div class="panel">
  <p>Email us at support@example.com or use the contact form on our website. We respond within 24 hours.</p>
</div>

<button class="accordion">Do you offer custom plans?</button>
<div class="panel">
  <p>Yes. Reach out with your requirements and we'll put together a tailored package.</p>
</div>
```

Replace the Lorem ipsum placeholder text with your actual questions and answers. Duplicate or remove blocks to match your FAQ count.

### 4. Customize the colors

The code includes a `<style>` section at the top with a comment next to each color. You can replace that whole `<style>` block with this one:

```html
<style>
  /* Accordion styles */
  .accordion {
    background-color: #868e99; /* Accordion color */
    color: #eeebeb; /* Accordion text color */
    cursor: pointer;
    padding: 18px;
    width: 100%;
    border: none;
    text-align: left;
    outline: none;
    transition: 0.4s;
    border-radius: 10px;
    margin-bottom: 10px;
    font-size: 2.1rem;
  }
  .accordion:before {
    content: "\002B";
    color: #4d514d; /* Plus sign color */
    font-weight: bold;
    float: right;
    margin-left: 5px;
    border-radius: 50%;
    padding: 5px;
    transition: transform 0.3s ease-in-out;
  }
  .accordion.active:before {
    transform: rotate(45deg);
    background-color: #4d514d; /* Close (x) icon background */
    color: #d91a1a; /* Close (x) icon color */
  }
  .accordion.active,
  .accordion:hover {
    background-color: #4d514d; /* Hover and open tab color */
    border-radius: 10px;
  }
  .panel {
    padding: 0 18px;
    background-color: #eeebeb; /* Answer panel background */
    max-height: 0;
    overflow: hidden;
    transition: max-height 0.2s ease-out;
    border-radius: 10px;
  }
  .panel p {
    margin: 0;
    padding: 10px 10px;
    font-size: 2.1rem;
  }
</style>
```

Change the hex color values to match your site's palette. The comments in the code make it straightforward to find each property.

<Notice type="warning" title="Check the .active selector">
If your downloaded copy has a rule that starts with `.active, .accordion:hover`, change it to `.accordion.active, .accordion:hover` as shown above. Carrd puts an `active` class on the section currently on screen, so a bare `.active` selector paints your whole section in the accordion's hover color.
</Notice>

### 5. Publish and test

Save your changes and publish the site. You can only preview the accordion after publishing — Carrd's editor doesn't render embedded JavaScript in the builder.

Check these things on the live site:

- Open the site on your phone. Is the text readable and the tap targets large enough?
- Do the colors match your design?

## Embedding multiple accordion sections on the same page

If you need two or more separate FAQ groups on one Carrd site, add one Inline Embed per group. There's one catch: the plugin's script attaches a click handler to every `.accordion` button on the page, not just the ones in its own embed. With the full code pasted twice, the first group's buttons get two handlers. Each click opens the panel and immediately closes it again, so that group looks dead.

The fix is to use this version of the `<script>` block in every copy. It skips buttons that another copy already wired up:

```html
<script>
  // Accordion script
  var acc = document.getElementsByClassName("accordion");
  for (var i = 0; i < acc.length; i++) {
    if (acc[i].dataset.bound) continue; // already wired by another copy
    acc[i].dataset.bound = "1";
    acc[i].addEventListener("click", function () {
      this.classList.toggle("active");
      var panel = this.nextElementSibling;
      if (panel.style.maxHeight) {
        panel.style.maxHeight = null;
      } else {
        panel.style.maxHeight = panel.scrollHeight + "px";
      }
    });
  }
</script>
```

The `<style>` block can stay duplicated in each embed; identical CSS rules don't conflict. Every button still needs its `<div class="panel">` directly after it, because the script opens the element that immediately follows the clicked button.

## Troubleshooting

**Accordion doesn't appear after publishing:** Make sure the Embed element's Type is **Code** and its Style is **Inline**, and that it sits in the section where you expect it. Also confirm your Carrd plan supports Embeds (Pro Standard or higher).

**Accordion looks broken or unstyled:** Make sure you pasted the full code, including the `<style>` block at the top, into the **Code** field.

**The whole section turns grey:** Your copy uses a bare `.active` selector that matches Carrd's active section. Change it to `.accordion.active` (see step 4).

**Clicking a question does nothing:** Open your browser console and look for JavaScript errors. If you pasted the full code into two embeds, the first group's buttons get two click handlers that cancel each other out. Use the script from the multiple-accordion section above.

**Text is too small on mobile:** Add a font-size override in the style section of the code. For example: `.accordion { font-size: 16px; }` and `.panel p { font-size: 15px; }`.

## Alternatives to the code embed approach

If you'd rather not manage raw code, there are two other options:

- **Common Ninja** — a third-party widget service that generates an embeddable accordion. Their free tier includes branding. Paid plans start at around $5/month to remove it.
- **Jason's Plugins for Carrd** ([plugins.carrd.co](https://plugins.carrd.co/)) — offers a free animated accordion plugin with a different visual style. Also a code embed, but with different default styling.

The CarrdMe accordion used in this tutorial is free, has no branding, and gives you full control over the code. For most use cases, it's the better choice.

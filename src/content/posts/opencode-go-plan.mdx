## What OpenCode Go is

<YouTubeEmbed
  url="https://www.youtube.com/embed/XGQIBn1i1uw"
  label="Stop Paying $20/mo! Best Unlimited AI Coding Plan for $5?"
/>

OpenCode Go is a flat subscription from the OpenCode team: one API key, 31 models, $10/month — or $40/month for Go Plus, which raises the per-model limits. No per-token math. No separate accounts at every model provider.

Models are served from the US, EU, and Singapore. Most providers claim zero retention, so your code is not supposed to train anyone's next model. The exceptions are worth knowing: Grok 4.7/4.6, GPT 6 Luna, GPT 5.6 Luna, Claude Haiku 5.5, and Cat Jam Free keep logs for 30 days, and the two Contributor models (Gemini 4 Argon, Muse Spark 1.2/1.3) are cheaper precisely **because they train on your prompts**. That matters if you ship proprietary work.

You do not need OpenCode the IDE to use Go. Point any compatible client at the endpoint: [Hermes Agent](/hermes-agent-setup-guide/), [OpenClaw](/clawdbot-setup-guide/), [Pi Agent](/pi-coding-agent-setup-guide/), [Mastra](/build-ai-agent-mastra/), Agno, Codex, Claude Code, ZCode, whatever you already run.

## Usage limits

Go is not unlimited, but the limits work differently now. Each model has its own monthly dollar allowance — $15 for the premium tier, $60 for most of the roster, $80 for DeepSeek V4.1 Flash, and unlimited for the free promos. The 5-hour and weekly caps are slices of that monthly figure:

| Limit | Share of monthly allowance |
|-------|----------------------------|
| Per 5 hours | 20% |
| Per week | 50% |
| Per month | 100% |

So a $60-tier model gives you $12 per 5 hours and $30 per week — same math as the old flat caps — while a $15-tier model like GLM-5.3 or Kimi K3 gives you $3 per 5 hours. Go Plus ($40/month) raises each model's monthly allowance, roughly 2-4x depending on the model.

If you have credits on your Console balance, you can enable the "Use balance" option. When Go limits run out, it falls back to pay-as-you-go instead of blocking requests. And if you hit a paid model's cap, the free preview models (LongCat 2.5, Cat Jam) still work.

## Setting it up

The setup takes about two minutes.

1. Go to [opencode.ai/auth](https://go.bitdoze.com/opencode-go) and create an account
2. Subscribe to Go (or Go Plus) in the Console and copy your API key
3. In OpenCode, run `/connect`
4. Select `OpenCode Go` and paste your key
5. Run `/models` to see the available models

One thing that changed since launch: there is no single base URL anymore. The endpoint now depends on the model's wire protocol:

| Endpoint | Models |
|----------|--------|
| `https://opencode.ai/inference/go/openai/v1/chat/completions` | GLM, Kimi, DeepSeek, MiMo, LongCat, Hy, Space Bunny, free previews |
| `https://opencode.ai/inference/go/openai/v1/responses` | Grok, GPT Luna models, Muse Spark |
| `https://opencode.ai/inference/go/anthropic/v1/messages` | Claude Haiku 5.5, MiniMax, Qwen3.8/3.7 |

Fetch the live model list and IDs with:

```bash
curl https://opencode.ai/inference/go/v1/models
```

### Using Go with other agents

OpenCode now publishes a list of clients it has validated against Go — Hermes, Claude Code, Codex, ZCode, Pi, jcode, and Kilo Code CLI all pass session headers properly. A few (DeepSeek Harness, GitHub Copilot Chat, Kimi Code, MiMo Code) have incomplete session-header support that can degrade routing. Whatever client you use, set a real user agent and keep a stable `x-opencode-session` ID per conversation — Go uses it for prompt caching and routing.

One thing Go doesn't give your agent is live web access. For search and page fetching I pair it with [TinyFish](/tinyfish-free-search-coding-agents/) — 30 searches and 150 fetches per minute on the free tier, which covers "read the current docs" and "find that GitHub issue" without spending Go credits on stale guesses. A key is free at [tinyfish.ai](https://go.bitdoze.com/tinyfish).

## Who this is for

Go makes sense if:

- You do not want to manage multiple API keys and billing dashboards
- You are based outside the US and want low-latency access to models (the Singapore and EU endpoints help)
- You want a predictable monthly cost instead of per-token billing
- You use multiple agents (OpenCode + Pi + Hermes + Mastra + ZCode) and want one key for all of them

Go does not make sense if:

- You only use one or two models and already have cheap API access
- You need models not on the list (like Claude Sonnet/Opus or GPT Pro tiers — Haiku 5.5 is the only Claude)
- You are doing heavy production work that needs unlimited or very high limits — though Go Plus at $40/month softens that
- Your client is on the unsupported list (DeepSeek Harness, Copilot Chat, Kimi Code, MiMo Code have session-header gaps)

## How it compares to managing your own keys

I ran the numbers for my own usage. I typically use MiniMax M2.7 and DeepSeek V4 Pro through their direct APIs. My monthly cost with direct API keys was around $15-20 depending on how much I used agents that month.

With Go at $10/month, I get access to those same models plus others I would not have bothered setting up. Months in, the limits still have not bitten me on normal daily use — the only times I touched a cap were deliberate Grok and Kimi K3 sessions.

The trade-off is control. With direct API keys, I can switch providers if one goes down. With Go, I am relying on the OpenCode team to handle failover. In practice, I have not had any downtime issues, but it is worth noting.

<Accordion label="How does Go compare to OpenRouter?" group="faq">
OpenRouter is a pay-per-token aggregator. You load credits and pay for what you use. Go is a flat monthly subscription with usage caps. If you use a lot of tokens, Go is cheaper. If you use very few tokens, OpenRouter might be cheaper. Go also includes models from providers that are not on OpenRouter.
</Accordion>

<Accordion label="Can I use Go with tools other than OpenCode?" group="faq">
Yes. The Go endpoints speak OpenAI-compatible, Responses, and Anthropic protocols depending on the model. Any tool that supports custom endpoints in one of those protocols can use it — Hermes, OpenClaw, Pi Agent, Mastra, Claude Code, Codex, and ZCode are all validated. Set the base URL to the matching `https://opencode.ai/inference/go/...` endpoint and use your Go API key.
</Accordion>

<Accordion label="What happens if I hit the usage limits?" group="faq">
Requests get blocked until the limit resets. The 5-hour limit resets on a rolling basis, the weekly one every 7 days. If you have credits on your Console balance, you can enable "Use balance" to keep going past Go limits. The free preview models (LongCat 2.5, Cat Jam) stay available either way.
</Accordion>

<Accordion label="Is my code used for training?" group="faq">
Mostly no, with real exceptions. Most models keep zero retention and are not trained on. Grok 4.7/4.6, GPT 6 Luna, GPT 5.6 Luna, Claude Haiku 5.5, and Cat Jam Free keep logs for 30 days for abuse monitoring. The Contributor models — Gemini 4 Argon and Muse Spark 1.2/1.3 — are discounted because your prompts and completions can be used for training. DeepSeek's zero-retention agreement renews monthly. That is OpenCode's published policy; I have not independently audited it.
</Accordion>

## My take after months of use

If you already have cheap direct keys and only use one model, Go is optional. Nice, not life-changing. For me the win is simplicity: one invoice, one key, and it works in every agent I already run. The roster nearly doubled since I signed up, and Go Plus exists if the $10 tier ever feels tight.

If you are still pasting five API keys around, the $10 month is easy to justify. I leave Grok, GLM-5.3, and Kimi K3 for the hard stuff, MiniMax M3 or GLM-5.3-Flash for normal agent sessions, and DeepSeek V4.1 Flash or MiMo when I just need volume.

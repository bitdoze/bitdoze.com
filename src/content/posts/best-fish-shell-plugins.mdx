Fish already does a lot without plugins. [Autosuggestions](/fish-shell-autocomplete-suggestions/), [syntax highlighting](/fish-shell-syntax-highlighting/), and man page completions are all built in. That means the best fish shell plugins are focused tools, not patches for missing features. The ecosystem is smaller than Zsh's, but every plugin here earns its place.

This guide is updated for Fish 4.x (the current baseline since the February 2025 Rust rewrite). I cover plugin managers, prompts, search tools, and a ready-to-copy setup you can run tonight.

If you're new to Fish, start with my [installation guide for Ubuntu](/install-fish-shell-ubuntu/) first.

## First: check your Fish version

Before installing anything, confirm you're on Fish 4. Several plugins below now require it.

```fish
fish --version
```

You want at least `4.0.0`. fzf.fish v11 won't work on anything older. The current stable is **4.9.3** (September 2026), and Tide works best on the latest 4.x.

If you're on Ubuntu and ran `sudo apt install fish`, you probably have 3.7.x from the default repos. That's too old. Use the fish-shell PPA instead. I cover the exact steps in my guide to [install the latest Fish Shell on Ubuntu from the official PPA](/install-fish-shell-ubuntu/). On macOS, `brew install fish` gives you a current version; see my [Fish Shell on macOS setup guide](/fish-shell-macos-setup/) for the full picture.

<Notice type="info" title="Fish 4 is the baseline">
Several plugins below require Fish >= 4.0. Check your version before installing anything. If you're on 3.x, upgrade first or expect broken keybindings and prompt glitches.
</Notice>

## Plugin managers: Fisher vs Oh My Fish

You need a plugin manager before you can install anything. There are three options, but the choice is straightforward.

### Fisher (recommended)

[Fisher](https://github.com/jorgebucaran/fisher) is a lightweight plugin manager written in pure Fish. It installs plugins by copying functions and completions directly into your Fish config directory. No framework, no startup overhead. The current release is 4.4.8 (January 2026) and it's actively maintained.

Install it:

```fish
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
```

Verify it's working:

```fish
fisher list
```

You should see `jorgebucaran/fisher` in the output. Basic usage:

```fish
fisher install author/plugin    # install a plugin
fisher update                   # update all plugins
fisher remove author/plugin     # remove a plugin
fisher list                     # list installed plugins
```

Fisher tracks installed plugins in `~/.config/fish/fish_plugins`. You can version-control this file and run `fisher update` on a new machine to recreate your setup.

<li>Install Fisher with the one-liner above</li>
<li>Run <code>fisher install author/plugin</code> to add plugins</li>
<li>Run <code>fisher list</code> to verify everything installed</li>

### Oh My Fish

[Oh My Fish](https://github.com/oh-my-fish/oh-my-fish) (OMF) is a framework similar to Oh My Zsh. It has its own package repository with themes and plugins, and it provides a command-line tool (`omf`) for managing them.

Install it:

```fish
curl https://raw.githubusercontent.com/oh-my-fish/oh-my-fish/master/bin/install | fish
```

You can verify the installer checksum against `bin/install.sha256` in the repo if you want to be careful.

Usage:

```fish
omf install plugin-name    # install a plugin
omf theme theme-name       # apply a theme
omf update                 # update everything
omf list                   # list installed packages
```

The honest take: OMF v8 shipped in April 2026 as a Fish-4 compatibility release. It refreshed the test matrix, improved the installer, and fixed long-standing install issues. But the README still carries the unmaintained warning ("maintainers have ran out of steam"), and some packages remain broken. The core runs on Fish 4 now, but the ecosystem around it is unreliable. I wouldn't start a new Fish setup with OMF today. Fisher is actively maintained, faster, and can even install OMF-compatible plugins. If you still want to try it, I have a guide to [Oh My Fish themes and plugins](/oh-my-fish-install-themes-plugins/).

<Notice type="warning" title="Oh My Fish status">
OMF v8 (April 2026) added Fish 4 compatibility, but the repo still carries an unmaintained warning and some packages are broken. For new setups, go with Fisher.
</Notice>

A third option is [Fundle](https://github.com/danhper/fundle), a lightweight plugin manager configured entirely in `config.fish`. It's worth a look if you want zero external tooling.

## Prompt plugins

Fish prompts can show git status, directory, runtime versions, and command duration. Two solid options below.

### Tide

[Tide](https://github.com/IlanCosman/tide) is the most popular Fish-native prompt. It renders asynchronously (so your prompt never lags), has a configuration wizard, and shows git status, current directory, runtime versions, and command duration. The current release is v6.2.1.

```fish
fisher install IlanCosman/tide@v6
tide configure
```

The wizard walks you through style options: powerline vs. plain, icons vs. text, one-line vs. two-line. The result looks polished without any manual configuration. To verify, `cd` into a git repo and confirm the branch shows in your prompt.

Tide needs a [Nerd Font](https://www.nerdfonts.com/) for icons. I recommend MesloLGS NF, which Tide's documentation suggests. Install the font, set it in your terminal emulator, and you're good.

Recent Tide releases added `bun` and `go` workspace items (useful if you work with those toolchains). v6.2.1 also fixed a vi-mode prompt character on Fish 4.3+. That's proof Tide tracks Fish versions closely and needs to be kept in sync.

<Notice type="info" title="Keep Tide updated">
Tide tracks Fish closely. After a Fish upgrade, run `fisher update` and re-run `tide configure` if the prompt misbehaves.
</Notice>

If you want a prompt that works across Fish, Zsh, and Bash, check out [Starship with Fish Shell](/fish-shell-starship-prompt/) instead. Tide is Fish-only but more deeply integrated with Fish's features.

### Hydro

[Hydro](https://github.com/jorgebucaran/hydro) is a minimal prompt made by Fisher's author. It shows git branch, command duration, and exit status with almost zero overhead. Good if you prefer something clean and fast over feature-rich.

```fish
fisher install jorgebucaran/hydro
```

No configuration needed. The defaults are sensible and it stays out of the way.

For a full comparison of Fish prompt options including Tide, Hydro, Starship, and Pure, check my [Fish Shell themes and prompts guide](/fish-shell-themes-prompts/).

## Search and navigation plugins

Fuzzy search and smart directory navigation are the biggest quality-of-life upgrades you can add to Fish.

### fzf.fish

[fzf.fish](https://github.com/PatrickF1/fzf.fish) adds fuzzy search to your Fish shell using [fzf](https://github.com/junegunn/fzf). You get interactive searching for command history, file paths, git log, git status, processes, and shell variables.

<Notice type="warning" title="Dependencies matter">
fzf.fish v11 requires Fish >= 4.0 and fzf >= 0.33. The Ubuntu apt fzf package is far too old. Install fzf from its git install script or a recent release. Check your versions before installing.
</Notice>

<ListCheck>
<ul>
<li>Fish >= 4.0.0</li>
<li>fzf >= 0.33.0 (current: v0.74.x)</li>
<li>fd >= 8.5.0 (for Search Directory)</li>
<li>bat >= 0.16.0 (for Search Directory preview)</li>
<li>Fisher installed</li>
</ul>
</ListCheck>

Install dependencies first, then the plugin:

```fish
# Install fzf (get a recent build, not the ancient apt one)
# See https://github.com/junegunn/fzf#installation

# Install fd and bat (Ubuntu)
sudo apt install fd-find bat

# On Ubuntu, fd and bat install as fdfind and batcat, so symlink them:
# (make sure ~/.local/bin is on your PATH or the symlinks won't be found)
mkdir -p ~/.local/bin
ln -sf $(which fdfind) ~/.local/bin/fd
ln -sf $(which batcat) ~/.local/bin/bat

# Install the Fish plugin
fisher install PatrickF1/fzf.fish
```

On macOS, use `brew install fzf fd bat`. The binary names are already correct.

Default keybindings:
- `Ctrl+R`: search command history (replaces Fish's built-in search with a better one)
- `Ctrl+Alt+F`: search file paths
- `Ctrl+Alt+L`: search git log
- `Ctrl+Alt+S`: search git status
- `Ctrl+Alt+P`: search running processes
- `Ctrl+V`: search shell variables (insert into the command line)

To inspect or customize bindings, run:

```fish
fzf_configure_bindings --help
```

This is probably the single most useful Fish shell plugin. If you install nothing else, install this one.

One caveat: fzf.fish is incompatible with other fzf shell integrations. If you have another fzf Fish plugin installed, remove it first or the keybindings will conflict. The fzf.fish README links a wiki page covering how to remove the two common alternatives.

### zoxide

[Zoxide](https://github.com/ajeetdsouza/zoxide) isn't a Fish plugin, it's a standalone tool that replaces `cd` with a smarter alternative. It learns which directories you visit and lets you jump to them with partial names. Type `z proj` instead of `cd ~/Documents/work/projects`. The current release is v0.10.0 (July 2026), and it works with Fish, Zsh, and Bash.

```fish
# Install
sudo apt install zoxide  # or: brew install zoxide

# Add to your Fish config
# In ~/.config/fish/config.fish:
zoxide init fish | source
```

v0.10 added Space-Tab completions that display and run the selected command, which makes directory jumping even faster. I have a full guide on [zoxide](/zoxide/) that covers setup and usage.

## Git plugins

If you use Tide or Hydro, git information is already in your prompt. But if you want standalone git abbreviations and helpers, the simplest approach is to define your own:

```fish
# Add to ~/.config/fish/conf.d/git.fish
abbr -a gs git status
abbr -a ga git add
abbr -a gc git commit
abbr -a gp git push
abbr -a gl git log --oneline
abbr -a gco git checkout
abbr -a gb git branch
abbr -a gd git diff
```

Abbreviations expand when you press space or enter, so you see the full command in your history. I explain why this matters in [Fish Shell abbreviations vs aliases](/fish-shell-abbreviations-vs-aliases/).

For more complex git helpers (custom functions that wrap multiple commands), see my [Fish Shell functions and custom commands](/fish-shell-functions-custom-commands/) guide.

## Node and version management

### nvm.fish

[nvm.fish](https://github.com/jorgebucaran/nvm.fish) is a Node.js version manager built for Fish. It's lighter than the Bash-based nvm and starts faster because it loads lazily. The current release is 2.2.17. I have a [detailed NVM with Fish Shell guide](/nvm-fish-shell/) covering setup and usage.

```fish
fisher install jorgebucaran/nvm.fish
```

Usage:

```fish
nvm install lts       # install the latest LTS
nvm install 22        # install Node 22
nvm use 22            # switch to Node 22
nvm list              # list installed versions
nvm current           # show active version
```

It also reads `.nvmrc` and `.node-version` files automatically when you enter a directory.

## Other useful plugins

### done

[done](https://github.com/franciscolourenco/done) sends a desktop (and mobile) notification when a long-running command finishes. If you run Ansible playbooks, Docker builds, or CI tasks that take minutes, this is a small quality-of-life win. You can switch to another window and get pinged when it's done. Actively maintained (v1.21.1, December 2025).

```fish
fisher install franciscolourenco/done
```

Verify: run `sleep 10` and confirm a notification appears when it finishes.

### puffer-fish

[puffer-fish](https://github.com/nickeb96/puffer-fish) expands `..` to `../..` and `...` to `../../..` as you type. Press `.` twice and it keeps adding parent directory references. Still active (last push November 2025).

```fish
fisher install nickeb96/puffer-fish
```

### autopair.fish

[autopair.fish](https://github.com/jorgebucaran/autopair.fish) auto-closes brackets, quotes, and parentheses as you type. Press `(` and it inserts `()` with the cursor between them.

```fish
fisher install jorgebucaran/autopair.fish
```

Stable but unmaintained since 2022 (last release 1.0.4). No reported breakage on Fish 4, but check the issue tracker if something acts up. [laughedelic/pisces](https://github.com/laughedelic/pisces) is an alternative worth considering.

### sponge

[sponge](https://github.com/meaningful-ooo/sponge) automatically removes failed commands from your Fish history. If a command exits with an error, it doesn't pollute your [history and autosuggestions](/fish-shell-history-persistence/).

```fish
fisher install meaningful-ooo/sponge
```

Unmaintained since 2022 (last release 1.1.0). Some users report it doesn't filter history on newer Fish versions. Check the issue tracker before relying on it.

## If plugins break after a Fish upgrade

The most common failure mode with Fish plugins is breakage after a Fish upgrade. Plugins track Fish closely, so minor version bumps can cause prompt rendering glitches or keybinding failures. Most cases come down to three fixes.

<Accordion label="Tide prompt looks wrong after a Fish update" group="troubleshooting">
Run `fisher update` then re-run `tide configure`. Tide is tightly coupled to Fish versions. v6.2.1 fixed a vi-mode bug that only appeared on Fish 4.3+. If the prompt is still wrong after updating, check Tide's issue tracker for Fish-version-specific reports.
</Accordion>

<Accordion label="fzf.fish keybindings stopped working" group="troubleshooting">
First, check `fish --version`. fzf.fish v11 needs >= 4.0. If you're on 3.x, that's the problem. Run `fzf_configure_bindings --help` to see what's registered. If you have other fzf shell integrations installed, remove them. fzf.fish is incompatible with them.
</Accordion>

<Accordion label="sponge isn't filtering my history" group="troubleshooting">
sponge is dormant since 2022. Check its issue tracker for Fish 4 compatibility reports. If it's not working on your Fish version, consider removing it. There's no fix coming.
</Accordion>

The general fix sequence after any Fish upgrade:

```fish
fish --version          # confirm you're on the expected version
fisher update           # update all plugins
fisher list             # verify everything is still installed
# If Tide is wrong:
tide configure          # re-run the wizard
```

## My recommended setup

If I'm setting up Fish on a new machine, here's what I install:

```fish
# Check version first
fish --version          # need >= 4.0 (4.9.x recommended)

# Plugin manager
curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher

# Prompt (pick one)
fisher install IlanCosman/tide@v6
# OR for cross-shell: install Starship separately

# Must-have plugins
fisher install PatrickF1/fzf.fish
fisher install franciscolourenco/done
fisher install jorgebucaran/autopair.fish
fisher install meaningful-ooo/sponge
fisher install nickeb96/puffer-fish

# Verify
fisher list
```

Plus zoxide installed separately. That gives me a fast, functional shell with fuzzy search, smart directory navigation, command-done notifications, and a good prompt. The whole setup takes about five minutes.

## Comparison with Zsh plugins

If you're coming from Zsh and wondering what the equivalents are:

| Zsh plugin/tool | Fish equivalent |
|---|---|
| Oh My Zsh | Fisher (plugin manager) |
| Powerlevel10k | Tide |
| zsh-autosuggestions | Built into Fish |
| zsh-syntax-highlighting | Built into Fish |
| zsh-completions | Built into Fish (man page parsing) |
| fzf (Zsh integration) | fzf.fish |
| zoxide (Zsh) | zoxide (same tool, Fish init) |
| nvm | nvm.fish |

I have a detailed [Fish vs Zsh comparison](/fish-shell-vs-zsh/) and a broader [Fish vs Bash vs Zsh](/fish-shell-vs-bash-vs-zsh/) article if you want more context on the differences. For Zsh users, I also have a list of the [best Oh My Zsh plugins](/best-oh-my-zsh-plugins/) for comparison.

## Where to find more plugins

The canonical curated list is [awsm.fish](https://github.com/jorgebucaran/awsm.fish), maintained by Fisher's author. It covers plugins, prompts, and tools worth knowing about.

<Button text="Browse the awsm.fish plugin list" link="https://github.com/jorgebucaran/awsm.fish" variant="outline" color="blue" size="md" icon="arrow-right" />

If you spend time editing Fish config files, [fish-lsp](https://github.com/ndonfris/fish-lsp) adds completions, hover, goto-definition, rename, diagnostics, and formatting to Neovim or VS Code. Install it via `npm install -g fish-lsp` (or `fisher install ndonfris/fish-lsp`). There's a playground at [fish-lsp.dev](https://fish-lsp.dev).

The Fish plugin ecosystem is small but high quality. A handful of well-chosen plugins covers most needs. There's no need to install everything.

## Why Add a WhatsApp Button to Your Carrd Site

A few reasons this works:

1. **Instant connection** - Visitors can message you right away instead of waiting for email replies.

2. **Higher conversion** - People are more likely to reach out when it's this easy.

3. **Mobile-friendly** - WhatsApp is already on their phone. One tap and they're chatting.

4. **Pre-filled messages** - You can set a default message so visitors don't have to think about what to write.

5. **Global reach** - WhatsApp has over 3 billion monthly users (as of 2025). In many countries, it's the primary way people message a business.

A simple floating button covers most cases. If you want a "WhatsApp chat widget for Carrd" with a message preview before the chat opens, Option 3 below is built for that. Service businesses, local shops, and freelancers tend to get the most out of it.

## How to Add a WhatsApp Button to Carrd

Three steps: build your `wa.me` link, add one Embed element, paste one of the four code styles below. Everything is inline HTML, CSS, and SVG. No widget script, no external font, and (generally) no cookie-consent burden from the code itself.

### Step 1: Get Your WhatsApp Chat Link (wa.me)

WhatsApp's click-to-chat link format is:

```
https://wa.me/YOURNUMBER
```

Replace `YOURNUMBER` with your phone number in international format, no `+`, spaces, or dashes. For example:
- US number: `12125551234`
- UK number: `447911123456`

To add a pre-filled message:

```
https://wa.me/YOURNUMBER?text=Hi,%20I%20found%20you%20on%20your%20website
```

Spaces need to be `%20` in URLs. Use `%0A` for line breaks.

<Notice type="info" title="Phone number format is the #1 failure">
No <code>+</code>, spaces, dashes, parentheses, or leading zeros. <code>12125551234</code>, not <code>+1 (212) 555-1234</code>. WhatsApp rejects anything else with "phone number shared via url is invalid".
</Notice>

Two more official variants, both documented in WhatsApp's [click to chat help page](https://faq.whatsapp.com/5913398998672934):

- **Numberless pick-a-chat link** - `https://wa.me/?text=Hi!%20Quick%20question` opens WhatsApp and lets the visitor choose who to send it to.
- **WhatsApp Business short link** - `https://wa.me/message/YOURSHORTLINKCODE` hides your phone number from the page source. I cover this properly in the privacy section below.

`wa.me` is the only format in the current official docs. Don't use the old `api.whatsapp.com/send?phone=` links, they're no longer documented. Worth re-checking the official click-to-chat page once in a while if WhatsApp changes the format.

### Step 2: Add an Embed Element in Carrd

This requires Pro Standard or higher. Click the `+` sign and add an Embed element:

- Type: Code
- Style: Hidden

<Picture formats={["webp"]} fallbackFormat="webp" src={imag1} alt="Carrd embed element settings with Type set to Code and Style set to Hidden" />

Hidden has three locations in current Carrd: **Head**, **Body Top**, and **Body End**. Rule of thumb:

- **Head** - Options 1, 2, and 4 (pure CSS and markup)
- **Body End** - Option 3 (its script queries the DOM, so you want the widget markup parsed first)
- **Body Top** - available, not needed here

If the Elements panel is getting crowded, Carrd shipped an Elements Panel in August 2026 (More Actions → Elements) that makes embedded code easier to find in the builder.

## Customize Your WhatsApp Button

Small CSS and URL tweaks after the button is live.

### Change Position

Move the button to a different corner:

```css
/* Bottom left */
bottom: 25px;
left: 25px;
right: auto;

/* Top right */
top: 25px;
right: 25px;
bottom: auto;
```

Whatever corner you pick, make sure it does not sit on top of Carrd's own floating elements (see the overlap fix in Troubleshooting).

### Change Size

Adjust the button dimensions:

```css
.whatsapp-float {
  width: 50px;  /* Smaller */
  height: 50px;
}

/* Or larger */
.whatsapp-float {
  width: 70px;
  height: 70px;
}
```

Keep at least a 48px touch target on mobile. Below that, taps start to miss.

### Disable Pulse Animation

Remove the `::before` pseudo-element or set `animation: none`:

```css
.whatsapp-float::before {
  display: none;
}
```

### Custom Pre-filled Message

Customize what shows up when visitors open the chat:

```
https://wa.me/12125551234?text=Hi!%20I'm%20interested%20in%20your%20web%20design%20services.%20My%20name%20is%20___
```

Use `%20` for spaces and `%0A` for line breaks.

Two ops tricks worth using: put your reply hours in the message ("I usually reply within 2 hours") so expectations are set before the first message, and tag the source ("found you on your website") so you know which channel converts.

## Troubleshooting: WhatsApp Button Not Working in Carrd

Check these in order. The first two solve most cases.

### Button doesn't appear at all

Cause: the Embed Style is not set to Hidden, your plan does not include Embeds (free or Pro Lite), or you saved without republishing.

Fix: set the Embed to Type: Code, Style: Hidden, confirm you are on Pro Standard or higher, publish again, then hard-refresh the live page. If it still collides with another fixed element, the same stacking rules apply to a [floating menu on Carrd](https://www.bitdoze.com/carrd-floating-menu/) or a [sticky header to Carrd](https://www.bitdoze.com/add-stickey-header-carrd/).

### "Phone number shared via url is invalid"

Cause: the number in the `wa.me` href is not in full international format.

Fix: strip `+`, spaces, dashes, parentheses, and leading zeros. `12125551234`, not `+1 (212) 555-1234`. Check every `wa.me` href if you pasted the multi-chat option.

### Popup widget won't open (Option 3)

Cause: the script ran before the DOM was ready, or the element IDs don't match.

Fix: use the DOMContentLoaded-guarded script from Option 3 and move the embed from Head to Body End. Keep the IDs `waButton` and `waPopup` as in the snippet. Re-publish.

### Button overlaps other floating elements

Cause: two fixed elements fighting for the same corner and `z-index`.

Fix: lower the WhatsApp `z-index` (for example `9999` → `999`) or move it to another corner (see Change Position). The same collision shows up with floating menus and sticky headers on Carrd.

## Privacy Tip: Hide Your Number with a WhatsApp Business Short Link

<Notice type="warning" title="Your number is public once you publish">
A plain <code>wa.me/YOURNUMBER</code> link puts your phone number in the page source. Scrapers pick it up, and you should expect some spam calls and WhatsApp messages. This is not a Carrd problem, it is how the link format works.
</Notice>

Two mitigations:

1. **Use a dedicated business number** instead of your personal one. Cheap SIM, separate WhatsApp account, clean separation.
2. **Use the WhatsApp Business short link** - `https://wa.me/message/YOURSHORTLINKCODE`, generated in the business tools of the free WhatsApp Business app (labels vary by version). It does not reveal the number.

Drop-in href swap for any of the four options:

```html
<a href="https://wa.me/message/YOURSHORTLINKCODE" class="whatsapp-float" target="_blank" rel="noopener" aria-label="Chat on WhatsApp">
```

You lose the `?text=` pre-filled message with short links, so pick: hidden number or pre-filled message. For most solo operators, the pre-filled message wins and the number is already on the contact page anyway.

On cookie consent: because this code is a plain `<a>` with inline CSS and SVG and no third-party JavaScript, it generally doesn't add a cookie or consent burden by itself. That is general guidance, not legal advice. If you run analytics scripts (including the click-tracking snippets above), that is a separate conversation and you may need [a cookie notice on your Carrd site](https://www.bitdoze.com/add-cookie-notice-carrd/).

@media (min-width: 769px) {

  }

Option 2 already collapses to an icon under 600px. Whatever style you use, keep the touch target at least 48-60px so thumbs hit it reliably.

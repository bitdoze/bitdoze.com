## What HyperFrames Studio actually is

Before the desktop app existed, HyperFrames was a CLI and a set of `SKILL.md` skills that taught coding agents how to write HTML, CSS, and GSAP animations and render them frame-by-frame into deterministic MP4s. If you have read our guide on the [best AI skills for web design](/best-ai-skills-for-web-design/), it uses the exact same portable skill pattern, just aimed at video instead of landing pages.

HyperFrames Studio wraps that workflow in a native desktop editor for **macOS** (Apple Silicon and Intel), **Windows** (64-bit), and **Linux** (`.deb` and AppImage). You sign in with a free HeyGen account, pick an agent, and describe the video you want.

<Picture src={studioHome} alt="HyperFrames Studio Home screen with Make, Reference, Script tabs and Remix from inspiration feed" formats={["webp"]} fallbackFormat="webp" />

What makes it different from browser-based AI video generators is that the project lives on your disk as real HTML, CSS, JS, and media files. You are not stuck waiting for a black-box cloud render to guess what you meant.

## My real test: turning a blog post into a Short

To give it a fair test against my usual Python scripts, I gave HyperFrames Studio a real job instead of a toy demo.

I connected **Antigravity** running **Gemini 4 Hydrogen**, pointed it at my [HolyArrs Docker guide](/holyarrs-docker-guide/) (a Go app that replaces six containers for Jellyfin, Plex, and Emby), and asked it to read the post, grab screenshots, and produce a vertical Short with animations, sound effects, background music, and my voice.

Instead of paying for HeyGen's built-in voice tier, I hooked in my own [Fish Audio voice-cloning skill](/fish-audio-clone-voice/) so the agent generated the narration in my cloned voice for free.

The first-iteration result surprised me:

- It analyzed the article, pulled screenshots, structured the pacing, and styled the animations in my brand colors.
- It layered background music, UI click effects, and voiceover onto the timeline automatically.
- On disk, that finished Short project totaled **726 files and 41 MB**. That is big enough to notice if you create dozens of videos, though still easy to manage locally.

It was not flawless on try one. The caption spacing tightened up slightly whenever the spoken cadence bumped two words close together, which is a quick fix in a follow-up prompt or the captions panel. Even with that quirk, getting a watchable Short with synced SFX and brand styling from one prompt beat hacking on my [Python video intro scripts](/python-video-intro-editor/) from scratch.

<Notice type="info" title="Why the 726-file project size matters">
Because HyperFrames builds compositions out of HTML, scripts, fonts, audio transcripts, and storyboard frames, each project folder holds hundreds of small files. Keep an eye on disk space if you generate daily Shorts, and clean up old project folders inside `~/.hyperframes-studio` once you export the final MP4.
</Notice>

## Inside the HyperFrames Studio UI

Opening a project drops you into a three-column layout: agent chat on the left, live video preview in the center, and asset/layer panels on the right, with a collapsible timeline tucked underneath.

<Picture src={studioWorkspace} alt="HyperFrames Studio three-column editor showing agent chat, preview player, and right-hand media panel" formats={["webp"]} fallbackFormat="webp" />

### Storyboard before full render

When **Start with a storyboard** is enabled, the agent does not jump straight into rendering everything blindly. It shows every shot as a still card with timing first, so you can catch pacing mistakes or weak visuals before waiting on the full build.

<Picture src={studioStoryboard} alt="HyperFrames Studio Storyboard tab showing numbered shot cards with timing before video generation" formats={["webp"]} fallbackFormat="webp" />

### Timeline, layers, captions, and inspirations

Below the preview, clicking **Show timeline** reveals the audio and visual tracks. You can see every voice line, sound effect, and music bed the agent placed, trim or split clips, adjust speed and volume, or close gaps directly without writing a prompt.

On the right sidebar, four tabs keep everything organized:

- **All files (Media):** Every image, font, brand asset, voiceover, and SFX clip in the project.
- **Captions:** Adjust subtitle styling and timing when spacing or line breaks need cleanup.
- **Inspirations:** Ready-made templates and motion examples to remix into your cut (some free, the full 918+ library unlocked on Pro).
- **Layers:** Inspect and resize or reposition individual visual elements on the canvas directly.

<Picture src={studioLayersMedia} alt="HyperFrames Studio right sidebar showing All files, Captions, Inspirations, and Layers tabs" formats={["webp"]} fallbackFormat="webp" />

### Draw and comment directly on the frame

Typing "make the box on the left slightly smaller" into a chat box gets vague fast. Under the preview canvas, HyperFrames Studio puts three visual tools: **Select**, **Draw**, and **Comment**.

<Picture src={studioDrawEdit} alt="HyperFrames Studio Draw tool circling an object on the video frame with Select, Draw, and Comment buttons below" formats={["webp"]} fallbackFormat="webp" />

You can circle an element with **Draw** or pin a note at a specific timestamp with **Comment**, type what needs to change, and stage multiple visual notes under **Pending video edits**. Sending them together lets the agent fix several shots in one pass. You can also roll back any agent run with its built-in **Undo** button.

## Brand kits keep every video consistent

One reason the HolyArrs Short looked cohesive right away is **Brand kits** in the left sidebar.

<Picture src={studioBrandKits} alt="HyperFrames Studio Brand kits panel in the left sidebar" formats={["webp"]} fallbackFormat="webp" />

You can point the brand kit builder at your website URL (which is what I did for my channel) or upload your files manually. It extracts and stores:

- Brand colors and typography rules
- Logos and end-card assets
- Format rules and layout guidelines the agent reads before building shots

Once selected on a project, the agent stops guessing random palettes and builds titles, callouts, and backgrounds using your actual brand tokens.

## Bring your own coding agent (and free models)

You do not have to pay HeyGen for AI tokens to build videos in HyperFrames Studio. From the chat header, you can switch between agents and thinking levels using the subscriptions or API keys you already own.

<Picture src={studioAgentPicker} alt="HyperFrames Studio agent picker dropdown in the chat header showing agent and model selection" formats={["webp"]} fallbackFormat="webp" />

Supported agents include:

- **Google Antigravity** (used in my test with Gemini 4 Hydrogen)
- **Claude Code**
- **OpenAI Codex**
- **Grok**
- **GitHub Copilot**
- **OpenCode** (great if you want free daily models like DeepSeek, GLM, MiniMax, or LongCat without another paid plan)

You can also wire external skills into your agent, such as a [Fish Audio TTS skill](/fish-audio-review/) for voiceovers or a custom image-generation skill powered by your Google or OpenAI plan (or an API aggregator like [Kie.ai](/kie-ai-video-generation/)). That keeps you from getting locked into HyperFrames' paid media credits.

## Importing real footage and talking-head clips

HyperFrames Studio is not limited to pure motion graphics. You can drop existing MP4 files into a project using the **Import** / `+` button and let the agent dress up raw footage.

If you film yourself talking to a phone camera, you can ask the agent to pull screenshots, animate callout cards over your speech, add click sound effects, and sync captions to the transcript. I have not stress-tested a full talking-head vlog edit in it yet, so keep expectations realistic until you try a short test clip, but the timeline and Script editor (where cutting text cuts the video) are clearly built with that workflow in mind.

<Notice type="info" title="Screen recording vs. agent composition">
If your goal is quick macOS screen recordings with automatic mouse zooms, [Screen.Studio](/screen-studio-review/) is still faster out of the box. HyperFrames Studio wins when you want an agent to assemble scripted Shorts, animated explainers, data callouts, or multi-scene edits across Mac, Windows, and Linux.
</Notice>

## Exporting locally vs. cloud rendering

When your edit looks right, click **Export** in the top-right corner. You can choose **1080p**, **Project size**, or **4K**, export as **MP4**, **WebM**, or **MOV**, and pick your frame rate (24, 25, 30, 50, 60 fps, or custom).

<Picture src={studioExport} alt="HyperFrames Studio Export panel showing 1080p and 4K quality, MP4/WebM/MOV format, and frame rate options" formats={["webp"]} fallbackFormat="webp" />

Rendering on your own machine is **free and unlimited**. Cloud rendering keeps your computer free while it encodes, with **5 cloud exports/month on Free** and **unlimited cloud exports on Pro** (with a 200 MB project upload cap). Finished MP4s save straight to your Downloads folder.

## HyperFrames Studio pricing: Free vs. Pro ($25/month)

| Feature | Free ($0) | Pro ($25/month) |
|---|---|---|
| Desktop app (Mac, Windows, Linux) | Included | Included |
| Bring your own coding agent (Antigravity, Claude Code, Codex, OpenCode) | Included | Included |
| Built-in HyperFrames Agent | Limited starter credits (5,000) | 25,000 credits/month |
| Local MP4 / 4K rendering | Unlimited | Unlimited |
| Cloud exports | 5 / month | Unlimited |
| AI video clips (HeyGen Video 1, Seedance, MiniMax) | 3 / month | Credit-based |
| Built-in AI voiceovers, image gen, music & SFX | Limited / Pro gated | Included (with credits) |
| Background removal | Not included | Unlimited |
| Inspiration library | 15 templates | Full 918+ library |
| Reference any video & Reverse any video | Not included | Included |

**Do you need the $25/month Pro plan?** If you already have a coding plan (Antigravity, Claude Code, Codex) or run [OpenCode](/opencode-setup-guide/) with free models, and you bring your own voice/image skills like [Fish Audio](/fish-audio-clone-voice/), the **Free** tier covers almost everything. Pro only makes sense if you produce high-volume client videos and want HeyGen's built-in voice, image, background removal, and "Reference any video" cloning in one subscription.

## What works well and where it still has rough edges

<ListCheck>
<ul>
<li><strong>Zero-cost entry:</strong> Free desktop app on Mac, Windows, and Linux with unlimited local exports.</li>
<li><strong>Works with your existing agents:</strong> Plug in Antigravity, Claude Code, Codex, Grok, Copilot, or OpenCode.</li>
<li><strong>Draw-to-edit feedback loop:</strong> Circling an element on the video beats writing paragraphs describing coordinates.</li>
<li><strong>Brand kits + skills:</strong> Consistent channel styling plus custom skills (like Fish Audio voice cloning) remove the need for Pro credits.</li>
<li><strong>Editable timeline & layers:</strong> Quick trims, volume tweaks, and layer resizing do not require waiting on an agent turn.</li>
</ul>
</ListCheck>

On the downside:

- **First-pass caption spacing can drift:** Fast narration occasionally crowds word spacing until you adjust the caption style.
- **Large project folders:** 700+ files per Short means you will want to prune old projects periodically.
- **Pro gates built-in media tools:** Built-in voiceovers, image generation, background removal, and the full inspiration catalog require the $25/month plan unless you supply your own skills.

## FAQ

<Accordion label="Is HyperFrames Studio really free?" group="faq" expanded="true">
Yes. Downloading the app for macOS, Windows, or Linux, connecting your own coding agent (including OpenCode's free models), and rendering videos locally on your computer are all free. You only hit paywalls if you use HeyGen's hosted Pro features like unlimited cloud exports, built-in voice/image generation, background removal, or the 918+ inspiration library.
</Accordion>

<Accordion label="Which AI coding agents work inside HyperFrames Studio?" group="faq">
HyperFrames Studio supports Claude Code, OpenAI Codex, Google Antigravity, Grok, GitHub Copilot, and OpenCode. You can switch agents and thinking effort directly from the chat header.
</Accordion>

<Accordion label="Can I use my own cloned voice without paying for Pro?" group="faq">
Yes. If you install or create an agent skill for a service like Fish Audio, you can instruct the agent to generate voiceover audio using your cloned voice and place it on the timeline, bypassing HyperFrames' Pro voice tier.
</Accordion>

<Accordion label="Where does HyperFrames Studio save projects and exports?" group="faq">
Projects are stored locally in the hidden `.hyperframes-studio` folder inside your home directory (or wherever you import an existing HyperFrames project from). Exported MP4 files land in your Downloads folder.
</Accordion>

HyperFrames Studio puts a visual timeline and canvas on top of agent-driven video scripts. Start on the free tier, connect a brand kit and your preferred coding agent, and add a [Fish Audio voice-cloning skill](/fish-audio-clone-voice/) before deciding if you ever need the $25/month Pro upgrade.
